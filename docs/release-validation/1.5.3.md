# 1.5.3 출시 검증 기록

준비일: 2026-10-25. 사용자 요청에 따라 정식 TERM을 공유 dev 이력에서 공개한다. main 병합·이력 재작성·Preview 게시를 수행하지 않는다.

## 비교 범위와 버전

GitHub 공개 상태에서 직전 정식 `1.5.2+main.1000102.00c592c96aba`와 소스 `00c592c96aba32bb863bb205c54fdc49e22bd200`을 확인했다. 이후 공유 dev의 배포 캐시·채널 스케줄 개선 `7259497`, 세션 복구 진단 `8158e97`, AVF 진단 텍스트 표시·이벤트 확장 `37f1615`를 포함한다. 기존 진단의 사용성·원인 수집 개선이며 새 실행환경·지원 계약·필수 이전이 없으므로 PATCH `1.5.2 → 1.5.3`을 적용한다.

origin/dev를 fetch하고 로컬 dev가 기존 원격 이력을 보존한 채 세 커밋 앞선 상태임을 확인했다. 게시 준비는 dev에 커밋하고 정상 fast-forward로 공유한다. 의도하지 않은 Preview 자동 게시를 방지하도록 준비 커밋의 push CI를 생략하고 정식 채널만 명시적으로 dispatch한다. 이번 요청에는 별도 메시지 전송 지시가 없어 Discord 알림은 실행하지 않는다.

## 이미지 평가

직전 정식 소스 이후 guest·image·Rootless payload 입력 변경은 없다. 이미지 workflow 변경은 의존성·산출물 캐시와 실행 대기열 최적화이며 게스트 기능이나 제작 계약을 바꾸지 않는다. 호스트의 메타데이터·콜백·UI 변경은 wire·복구 기한·credit 계약을 유지한다. 따라서 새 이미지 제작이 필요하지 않으며 공개·검증된 Debian·Ubuntu·Arch `recovery-20261024-r4` 카탈로그를 유지한다. 공개 APK 안의 카탈로그를 승인 파일과 대조한다. 설치 환경을 자동 교체하지 않는다.

## 구현 검증과 제한

동일 구현의 표준 Gradle 빌드와 app 포맷터·protocol·runtime·image·AVF 검사는 620개 통과, 1개 skip이었다. Android MCP 기기 검사 4개는 로그 표시·설정·검색·복사·삭제 확인과 실제 소켓의 실패 진단 저장을 검증했다. 새 UI 검사의 검색 재구성 대기를 수정한 뒤 해당 검사만 재실행하여 통과했다. Replicant로 격리 앱의 정상 설정 경로에서 두 대괄호 시간 기록이 하나의 텍스트 영역에 표시되는 것과 검색을 확인했다. 테스트 앱은 제거했고 기존 Debug 앱의 임시 검색 입력도 복구했다.

연결 기기는 ReDroid15 ARM64이며 실제 특권 AVF vsock·VM·장시간 백그라운드·Doze 동작은 검증하지 않았다. 멈춤의 근본 원인 해결을 주장하지 않는다. 비공개 Activity 직접 실행과 기본 launcher 도구 실패는 정상 Setup/설정 경로로 대체했다. Jev 소스·로그 외부 전송은 앞선 자동 승인 거부에 따라 재시도하지 않았고 로컬 diff와 테스트로 검토했다. 이번 준비에서는 변경되지 않은 Android 검사를 로컬에서 반복하지 않으며 공식 서명·게시 CI 검증을 수행한다.

업데이트·채널 회귀 검사 53개와 버전·한국어 노트 일치·diff 검사가 통과했다. Debian·Ubuntu·Arch r4의 공개 manifest를 인증 없이 다시 내려받아 승인 카탈로그의 세 SHA-256과 일치함을 확인했다. 앞서 전체 공개 이미지 검증을 통과한 동일 산출물이므로 대용량 이미지를 다시 제작·다운로드하지 않는다. 공식 CI와 공개 APK 검증 후 나머지 결과를 기록한다.
