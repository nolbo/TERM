# TERM 1.7.1 출시 검증 기록

준비일: 2026-10-31. 사용자 요청에 따라 Userspace Linux 자체 엔진 개발 워크트리를 병합하지 않고 정식 TERM만 배포한다.

## 범위와 버전

직전 정식 `1.7.0+main.1000106.4b19bd5d5821` 이후 공유 dev의 AVF 세션·복구·입출력, Workspace 시작, 환경 종료와 이력 보존, 툴바 탭·이력 동작 수정을 포함한다. 기존 사용법과 데이터의 호환성을 유지하는 수정이므로 PATCH `1.7.0 → 1.7.1`을 적용한다. Jev의 버전 판단도 PATCH를 선택했다.

`.worktrees/userspace-engine`의 `work/userspace-engine` 브랜치와 미커밋 작업은 병합하거나 수정하지 않는다. 준비 시작 시 dev는 `dfe88c9b35cd80917de9c05e1e884acf6d821a74`, 별도 엔진 브랜치는 `c8f52c9ac88b2f1475dc4fbd73f4ef414edc52b5`였다. dev에 이미 있는 초기 엔진 실험 소스는 Gradle 제품 모듈·빌드 경로에 연결되어 있지 않으며, 배포 APK에도 엔진이 포함되지 않는지 확인한다. 이력을 재작성하거나 별도 출시 이력을 만들지 않는다.

## 이미지와 게시 절차

기존 unshared-20261028-r1 제작 이후 `guest/droid-sessiond`와 이미지 서비스·복구 구성이 바뀌었으므로 Debian·Ubuntu·Arch `session-20261031-r1`을 새로 제작한다. 기존 kernel producer `39715151260`의 번들은 제작 입력·실제 해시를 확인해 재사용한다. Google 원본 SHA-256은 기존 검증값 `765cec51cd3e16ea1745b7ac8f9b3816d21ab3ed069bea355a59e3ade6bdfc41`로 고정한다. 새 이미지의 제작·두 번의 정상 부팅·APK·익명 전체 다운로드 검증 후 승인 카탈로그를 dev에 커밋하고 정식 서명 APK에 포함한다. 설치된 환경은 자동 교체하지 않는다.

준비·승인·검증 기록 커밋에는 `[skip ci]`를 사용해 Preview 자동 배포를 방지한다. 공유 origin/dev 이력을 확인한 뒤 정상 fast-forward push만 사용한다. 이미지와 앱 CI는 dev에서 수동 실행하며 `notify=false`로 지정한다. main 브랜치·Preview 공개 상태를 변경하지 않는다.

## 검증 계획과 한계

표준 Gradle 빌드·단위 테스트와 변경 모듈 테스트, Rust 게스트 테스트, Python 이미지·업데이트 검사, redroid Android 15 ARM64에서 관련 앱·런타임 계측 검사를 수행한다. 최종 공개 APK의 공식 서명·패키지·버전·해시·카탈로그 및 최신 링크를 확인한다. redroid는 실제 특권 AVF 대상이 아니므로 `tests/integration/acceptance.sh`와 실제 AVF 수명·Doze 검증을 통과로 주장하지 않는다.

GitHub MCP는 원격 브랜치·CI 근거, android MCP는 기기·런타임 검증, replicant는 제공 가능한 UI 상호작용 확인, Jev는 버전 판단과 최종 검증 주장 검토에 사용한다. GitHub MCP에 없는 dispatch·태그·릴리즈 다운로드는 gh로 수행한다. 외부 API 변경이 없어 context7은 사용하지 않는다. 로컬 Git 쓰기와 네트워크는 샌드박스 밖의 승인된 실행이 필요하며 기존 캐시·도구체인을 유지한다.
