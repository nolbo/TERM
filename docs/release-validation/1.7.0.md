# 1.7.0 버전 정정 및 출시 검증 기록

준비일: 2026-10-28. 사용자가 2.0.0 대신 마이너 버전만 올리도록 지시했으므로 1.6.0 → 1.7.0으로 정정한다. 일반 MAJOR 정책보다 이번 직접 지시를 우선하며 제품 코드·호환성 변경·이전 안내는 유지한다. 기존 [2.0.0 기록](2.0.0.md)은 당시 배포·검증 사실로 보존한다.

## 범위와 업데이트 경로

현재 공개 정식은 `2.0.0+main.1000105.3c1312916333`, 소스 `3c13129163339e2983e6f10ad990f3d4b99ef86d`, 공개 release ID `426155538`이다. 이번 변경은 앱 기본 버전과 현재 안내·한국어 노트·출시 기록에 한정한다. 새 정식은 같은 패키지·공식 서명과 `1000105`보다 큰 versionCode를 사용한다. 업데이트 판정은 표시 버전 대신 versionCode를 비교하므로 2.0.0 설치에서도 새 1.7.0이 업데이트 대상이다. 앱 제거·데이터 초기화·다운그레이드 옵션을 사용하지 않는다.

공유 dev 이력의 준비 커밋을 정상 푸시하고 `android.yml`을 `publish_channel=main`, `notify=false`로 실행한다. 1.7.0 공개 파일 검증 후 잘못 지정한 2.0.0은 draft로 전환한다. 기존 태그와 원본 산출물은 덮어쓰거나 삭제하지 않는다. Preview와 main 브랜치는 변경하지 않는다.

## 이미지 재사용과 검증 범위

앞선 배포 이후 게스트·이미지 제작·커널 입력과 승인 카탈로그가 바뀌지 않았다. [2.0.0 이미지 검증](2.0.0.md#이미지-공개와-승인)에서 제작·정상 부팅·APK·공개 전체 다운로드 검증이 끝난 Debian·Ubuntu·Arch `unshared-20261028-r1`을 그대로 포함한다. 이미지 재제작이나 동일 파일 전체 다운로드 반복은 하지 않으며 새 공개 APK의 내장 카탈로그 전체 바이트를 대조한다.

공식 CI의 표준 빌드·테스트·릴리즈 lint·서명 검사를 실행하고 공개 APK의 표시 버전·패키지·인증서·해시·versionCode 및 정식 최신 링크를 검증한다. 제품 동작 코드가 동일하므로 Android UI·런타임 기기 검사를 반복하지 않는다. 기존 특권 AVF 기기·장시간 Doze 검증 제한은 유지한다. GitHub MCP는 CI 상태·로그 확인에 사용하고, MCP에 없는 릴리즈 편집·dispatch는 gh로 처리한다. 버전 표기만 바뀌므로 android·replicant·context7 추가 호출은 필요하지 않다.
