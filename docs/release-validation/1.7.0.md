# 1.7.0 버전 정정 및 출시 검증 기록

준비일: 2026-10-28. 사용자가 2.0.0 대신 마이너 버전만 올리도록 지시했으므로 1.6.0 → 1.7.0으로 정정한다. 일반 MAJOR 정책보다 이번 직접 지시를 우선하며 제품 코드·호환성 변경·이전 안내는 유지한다. 기존 [2.0.0 기록](2.0.0.md)은 당시 배포·검증 사실로 보존한다.

## 범위와 업데이트 경로

현재 공개 정식은 `2.0.0+main.1000105.3c1312916333`, 소스 `3c13129163339e2983e6f10ad990f3d4b99ef86d`, 공개 release ID `426155538`이다. 이번 변경은 앱 기본 버전과 현재 안내·한국어 노트·출시 기록에 한정한다. 새 정식은 같은 패키지·공식 서명과 `1000105`보다 큰 versionCode를 사용한다. 업데이트 판정은 표시 버전 대신 versionCode를 비교하므로 2.0.0 설치에서도 새 1.7.0이 업데이트 대상이다. 앱 제거·데이터 초기화·다운그레이드 옵션을 사용하지 않는다.

공유 dev 이력의 준비 커밋을 정상 푸시하고 `android.yml`을 `publish_channel=main`, `notify=false`로 실행한다. 1.7.0 공개 파일 검증 후 잘못 지정한 2.0.0은 draft로 전환한다. 기존 태그와 원본 산출물은 덮어쓰거나 삭제하지 않는다. Preview와 main 브랜치는 변경하지 않는다.

## 이미지 재사용과 검증 범위

앞선 배포 이후 게스트·이미지 제작·커널 입력과 승인 카탈로그가 바뀌지 않았다. [2.0.0 이미지 검증](2.0.0.md#이미지-공개와-승인)에서 제작·정상 부팅·APK·공개 전체 다운로드 검증이 끝난 Debian·Ubuntu·Arch `unshared-20261028-r1`을 그대로 포함한다. 이미지 재제작이나 동일 파일 전체 다운로드 반복은 하지 않으며 새 공개 APK의 내장 카탈로그 전체 바이트를 대조한다.

공식 CI의 표준 빌드·테스트·릴리즈 lint·서명 검사를 실행하고 공개 APK의 표시 버전·패키지·인증서·해시·versionCode 및 정식 최신 링크를 검증한다. 제품 동작 코드가 동일하므로 Android UI·런타임 기기 검사를 반복하지 않는다. 기존 특권 AVF 기기·장시간 Doze 검증 제한은 유지한다. GitHub MCP는 CI 상태·로그 확인에 사용하고, MCP에 없는 릴리즈 편집·dispatch는 gh로 처리한다. 버전 표기만 바뀌므로 android·replicant·context7 추가 호출은 필요하지 않다.

## 제작 실행

준비 소스 `4b19bd5d58210b3fa84048019d2f7eb946a73f87`를 dev에 커밋하고 원격 dev와 일치를 확인했다. 불변 태그 `main-4b19bd5d58210b3fa84048019d2f7eb946a73f87`를 같은 커밋에 고정했다. 공식 정식 제작·공개 CI는 [40621672765](https://github.com/nolbo/TERM/actions/runs/40621672765)이며, `publish_channel=main`, `notify=false`로 실행했다. 준비 커밋에는 `[skip ci]`를 사용해 의도하지 않은 Preview 자동 공개를 막았다.

## 공개·검증 결과

2026-10-28 CI의 build-and-unit-test 및 정식 공개 단계가 재시도 없이 성공했다. `./gradlew :android-app:assembleDebug :android-app:testDebugUnitTest :android-runtime:testDebugUnitTest :image:test --build-cache --console=plain`, Python 이미지 129개·업데이트 53개, USB 호스트 안전성 회귀와 릴리즈 lint·서명·APK 검증이 통과했다. 알림과 별도 Rootless 프리릴리즈 작업은 의도대로 건너뛰었다.

- 공개 버전: `1.7.0+main.1000106.4b19bd5d5821`.
- [정식 릴리즈](https://github.com/nolbo/TERM/releases/tag/main-4b19bd5d58210b3fa84048019d2f7eb946a73f87) · [TERM.apk](https://github.com/nolbo/TERM/releases/download/main-4b19bd5d58210b3fa84048019d2f7eb946a73f87/TERM.apk).
- 앱 소스: `4b19bd5d58210b3fa84048019d2f7eb946a73f87`; 이 공개 기록은 후속 커밋으로 남긴다.
- versionCode: `1000106` > 2.0.0의 `1000105`; applicationId: `dev.terminal.app`, 앱 이름: `TERM`, minSdk: `31`.
- 공개 APK: `26,897,904` bytes, SHA-256 `5f12d3a3760fd5cea32b40fe2d89f76714ab990ece38095b5e3f7605d1852e3f`.
- 공식 인증서 SHA-256: `7f639e70cc1969415beab27cfb10db6d10bf553b1f956a2f9d68d55ebf3785ba`.

인증 없는 공개 URL에서 APK·update.json·한국어 노트를 내려받아 버전·소스·크기·해시·노트 일치를 확인했다. `tools/updates/verify-release-apk.py`로 공식 인증서와 승인 이미지 카탈로그 전체 바이트 일치를 검증했다. AAPT2로 APK의 실제 버전·설치 순번·앱 ID·TERM 이름·minSdk·정식 provider authority를 확인했다. `/releases/latest`와 최신 update.json은 모두 1.7.0을 가리키며 Preview의 dev-latest 정보는 이전과 동일하다. 실제 기기에서 2.0.0 → 1.7.0 설치를 수행한 것으로 주장하지 않으며, 업데이트 판정 코드와 실제 APK의 동일 서명·패키지 및 증가한 설치 순번을 검증했다.

## 2.0.0 공개 해제

1.7.0 공개 APK 검증 이후 기존 release ID `426155538`을 draft=true로 전환했다. 전후 API를 대조해 기존 태그·대상·제목·본문과 산출물 8개의 ID·이름·크기·digest가 동일함을 확인했다. Git 원격 조회에서 기존 `main-3c13129163339e2983e6f10ad990f3d4b99ef86d` 태그의 대상도 보존됐다. 익명 API의 이전 릴리즈 조회는 404이며, 공개 해제 후에도 정식 최신 릴리즈와 업데이트 정보는 1.7.0을 유지한다. 파일 삭제·교체나 Git 이력 재작성은 하지 않았다.

Jev는 최종 공개·원본 보존 주장 두 개를 verified로 분류했지만 신뢰도 0.55로 자동 수락하지 않았다. 구체적 모순은 제시하지 않았으며 실제 익명 조회 결과, 서명·카탈로그 검사 출력과 전후 API·태그 비교 결과를 직접 검토해 완료를 판단했다. GitHub MCP로 CI 상태·로그를 확인했고, MCP 미지원 공개 조작은 gh로 수행했다. 이번 정정에서 추가 기기 검증이 필요한 제품 변경은 없고 남은 공개 단계나 일반 개발 TODO도 없다.
