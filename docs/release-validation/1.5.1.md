# 1.5.1 출시 검증 기록

작성일: 2026-10-24. 사용자는 AVF 연결·수명 관리 수정 이후 정식 TERM과 TERM Preview의 공개 및 필요한 AVF 이미지 제작을 요청했다. 공유 dev 이력에서 게시하며 main 병합이나 이력 재작성은 하지 않는다. Discord 알림은 요청되지 않아 notify=false를 유지한다.

## 범위와 이미지 판단

직전 정식 `1.5.0+main.1000098.d1a3e17cde13`과 Preview `1.5.0+dev.1000097.d1a3e17cde13`의 공통 소스는 `d1a3e17cde135adea6f0d1e41bb424348bf6af9e`다. 이후 `caf4b95`와 `25af840`의 프로필 실행환경 소유권 정리, 명시적으로 시작한 환경의 백그라운드 수명 관리, AVF 요청·연결의 유한한 대기와 취소, 검증된 VM 종료 정리, 환경별 재연결과 공유 만료 안내를 포함한다. 기존 데이터와 지원 경로를 유지하는 수정이므로 PATCH 1.5.1을 두 채널에 적용한다.

이미지 제작 소스 `e730980a2ef77b50edf0101c2647932bbd2d1807` 이후 guest·image/scripts·image/src/main·image/kernel·이미지 제작 workflow에는 변경이 없다. 앱의 수정은 기존 shareBrokerVersion=2·sessionResumeVersion=1 계약을 사용하며 새로운 게스트 프로토콜이나 마운트 정책을 요구하지 않는다. Debian·Ubuntu·Arch recovery-20261024-r3 승인 이미지를 유지한다. 공개 메타데이터와 manifest 핀·provenance를 대조하고 각 서명 APK에 승인 카탈로그의 정확한 포함을 확인한다. 기존 설치 환경을 자동 교체하지 않는다.

세 배포판의 catalog·manifest·provenance·SHA256SUMS를 인증 없이 새로 내려받아 metadata-only 검증을 통과했다. 승인 핀·제작 소스·정상 부팅 복구 증거·커널 `fa4f0fc22c316d24a417e5620e915c626ab246ef5c190b557d38c136955357ee`가 일치한다. 전체 이미지 다운로드·재부팅을 반복하지 않았으며 최초 공개 시의 전체 다운로드·부팅 결과는 [기존 검증 기록](avf-recovery-20261024.md)에 보존한다.

## 사전 검증과 한계

구현 직후 정규 `:android-app:assembleDebug :android-runtime:testDebugUnitTest :image:test`에 `:protocol:test :aosp-avf-runtime:testDebugUnitTest :android-app:assembleDebugAndroidTest`를 추가한 검증이 통과했다. protocol 35개, runtime 429개 통과·1개 skip, image 68개, AVF 43개로 총 575개 통과·1개 skip이다. Android MCP의 별도 테스트 패키지에서 실제 ParcelFileDescriptor 송수신 취소와 프로필 실행환경 수명 검사가 `OK (3 tests)`로 통과했다. 테스트 패키지는 삭제했고 기존 앱은 교체하지 않았다.

빌드 호스트의 기존 AAPT2 경로 문제는 같은 버전의 기존 실행 파일을 가리키는 임시 override로 처리했으며 SDK·Gradle·저장소 호스트 설정을 변경하지 않았다. 코드 변경이 없는 릴리즈 준비에서 동일 로컬 검사를 반복하지 않고 공식 게시 CI의 정규 검증·앱 테스트·Python 이미지/업데이트·USB 안전·release lint·서명·Rootless/Native/AVF·승인 카탈로그 검사를 공개 조건으로 유지한다.

연결된 ReDroid15 ARM64는 특권 AVF 대상이 아니다. 실제 AVF 부팅·장시간 백그라운드·Doze·운영체제 소유 프로세스 종료를 검증한 것으로 주장하지 않는다. v1 공유의 VM 종료 정책은 바꾸지 않으며 기존 이미지의 지원되는 업데이트가 필요하다. Jev 소스 검토는 앞선 작업에서 자동 승인 검토가 소스 외부 전송을 거부해 로컬 diff와 실제 검사로 대체했다.
