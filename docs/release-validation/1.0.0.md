# 1.0.0 출시 검증 기록

작성일: 2026-10-19. 정식판과 프리릴리즈판의 공통 기본 버전을 `1.0.0`으로
배포하라는 사용자의 명시적 지시에 따른 내부 기록이다. 사용자용 패치 노트는
별도로 관리한다. 버전 선택은 해당 지시를 따르지만, 이 기록이
[1.0 검증 조건](../VERSIONING.md#0x와-100)의 모든 항목 통과를 뜻하지는 않는다.
미실행·부분 검증을 통과로 바꾸지 않으며 과거 검증 기록도 소급 변경하지 않는다.

## 재사용 가능한 검증

기준 소스는 공유 `dev` 이력의 `91d6757`(프로필 취소 처리·UI 회귀 수정)과
`275b725`(정식판·프리릴리즈판 독립 설치)이다. 아래는 이 변경들을 검증한 로컬
결과이며, 최종 `1.0.0` 서명 APK의 검증을 대신하지 않는다.

## 1.0 조건별 미확인 범위

1. **지원 기기와 Rootless:** 현재 확인한 실행 대상은 API 35 Redroid다.
   지원 최소 API 31과 최신 지원 API의 기기 검증은 미확인이다.
   `compileSdk=37` 빌드 성공은 해당 API 기기 실행 결과가 아니다.
   현재 연결된 대상은 이 기기 한 대뿐이며 Android MCP의 `list_avds`는
   빈 AVD 목록과 avdmanager/emulator 설정 부재를 보고했다. 추가 SDK·에뮬레이터를
   설치해 검증 환경을 바꾸지 않고 해당 API 범위는 미검증으로 유지한다.
   일반 지원 기기에서 특별 권한 없이 Rootless를 새로 설치하고 실행하며
   패키지를 설치·사용하는 전체 흐름은 미확인이다. 종합 검사에서 기본 Rootless
   환경 미준비로 `rootlessPaste`가 건너뛰어졌고, 별도 레거시 Rootless 환경의
   그래픽 왕복 통과는 새 설치·패키지 사용 검증을 대신하지 않는다.
2. **수명주기:** 생성·입출력·탭 전환·분할·화면 재생성·백그라운드 복귀에 대한
   위 회귀 결과는 재사용한다. 실제 런타임 소유 프로세스를 종료한 뒤 세션 손실을
   정직하게 표시하는 동작의 이번 출시 기기 검증은 미확인이다.
3. **서명 업데이트와 데이터 보존:** 직전 서명 배포본에서 최종 서명 APK로
   업데이트하고 설정·프로필·작업 파일의 내용 및 Rootless 환경을 전후 대조한
   검증은 아직 미확인이다. 이전 중단·실패 복구의 단위 테스트 통과를 실제
   설치·업데이트 중단 복구 통과로 간주하지 않는다.
   현재 기기의 기존 `dev.terminal.app` 설치와 데이터를 보존하기 위해 이번
   정식 APK로 자동 교체하는 업데이트 검증은 실행하지 않는다.
   과거 개발판의 `dev.terminal.app`과 새 Preview의
   `dev.terminal.app.prerelease`는 다른 패키지다. 새 Preview의 병행 설치는
   기존 데이터의 자동 이전이나 같은 패키지 업데이트 검증이 아니다.
4. **표준 검사와 차단 결함:** 발견한 프로필 취소 오류·번역/Locale 오류 및
   관련 UI 회귀 실패는 수정·재검증했다. 이 결과만으로 모든 기기의 데이터 손실,
   보안 경계와 핵심 흐름에 알려지지 않은 문제가 없다고 증명하지 않는다.
5. **안내의 일치:** 독립 패키지·고정 업데이트 채널·기존 데이터 보존 범위는
   [업데이트 문서](../APP_UPDATES.md)와 사용자 안내에 반영했다.
   최종 1.0.0 패치 노트와 게시물에도 위 미검증 범위를 유지한다.

특권 AVF의 실제 부팅·vsock·공유 파일 I/O·네트워크, 물리 USB/iPhone은 이 환경에서
검증하지 않았다. 이 항목들은 모든 선택적 기능 완성을 1.0 필수 조건으로 삼는다는
뜻이 아니라, 제공 기능의 실제 검증 범위를 한정하는 기록이다.

## 승인 이미지 재사용 판단

이미지 담당 에이전트는 각 공개 릴리스의 `manifest.properties`, `provenance.json`,
`SHA256SUMS`를 무인증으로 내려받아 승인 카탈로그 핀 및 메타데이터 해시를 대조했다.

| 배포판 | 승인 릴리스 | manifest SHA-256 |
| --- | --- | --- |
| Debian | `avf-debian-debug-20261012-r4` | `8bfcd31d121b79698d5654a90b644ebf5a172f8c6f32b66f74c54d0e8853fffe` |
| Ubuntu | `avf-ubuntu-debug-20261013-r1` | `00b4140681ea93d6d23c831ca7620a6102027dd3ea106dedbc5f7e958c980a4f` |
| Arch Linux ARM | `avf-archlinux-debug-20261012-r5` | `6b74fbe2d14b0a482b4a391d2aacaab64fcb3d3aac8ec5e840ea005111f32dc3` |

각 producer 커밋은 `275b725`의 조상이고, producer 이후 게스트·프로토콜 변경은 없다.
후속 pacman fixture 변경은 해당 Arch 이미지에, Ubuntu rootfs의 udev 설치 변경은
해당 Ubuntu 이미지에 포함되어 있다. 공통 제작 스크립트의 후속 udev 존재 검사는
게스트 기능·파일 변경이 아니며 그 밖의 변경은 검증·provenance 기록이나 호스트
희소 이미지 설치 개선이다. 이 범위에서는 새 이미지를 제작할 필요가 없다.

이는 메타데이터와 소스 차이 검증이다. 이번에는 대용량 이미지 산출물 전체를 다시
내려받거나 부팅하지 않았다. Ubuntu provenance에는 기존 두 번의 normal boot 및
session-list RPC·패키지 초기화 포트 통과 기록이 있지만 Debian·Arch에는 같은 신규
기록이 없으며, 이를 실제 특권 Android 기기·공유 I/O·인터넷 초기화 통과로
확대하지 않는다. 최종 서명 APK에 위 승인 카탈로그가 포함됐는지는 별도 대조한다.

## 최종 출시 검증

- 진행 중: `1.0.0` 공유 dev 커밋의 CI 표준 검사와 두 채널 서명 APK 생산.
- 진행 중: 정식판 `dev.terminal.app`·프리릴리즈판
  `dev.terminal.app.prerelease`의 패키지, 버전, 기존 인증서, Rootless payload,
  승인 이미지 카탈로그, 매니페스트 해시와 공개 다운로드 대조.
- 재사용: 기능 변경은 직전 작업의 API 35 기기 검증을 사용한다. 기본 버전 변경을
  이유로 같은 기능 검증을 반복하지 않으며, 기존 공통 패키지의 정식 APK 교체와
  최소·최신 지원 API 검증은 위와 같이 미실행으로 유지한다.
- 진행 중: 최종 소스 커밋, CI 실행 및 두 공개 릴리스의 링크·검증 결과 기록.

Jev 외부 검증은 소스·로그 전송에 대한 자동 승인 심사 거절로 수행하지 않았다.
로컬 소스 검토와 독립 에이전트 검토는 보조 근거이며 실제 검사 결과를 대신하지 않는다.
