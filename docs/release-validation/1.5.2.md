# 1.5.2 출시 검증 기록

작성일: 2026-10-24. 사용자는 마이너 버전을 올리지 않는 앱 공개와 정식·프리릴리즈 디스코드 알림 누락 수정을 요청했다. 정식 TERM·TERM Preview를 1.5.2로 준비하고 필요한 세 배포판의 게스트 이미지 제작·공개·승격을 함께 수행한다. dev 공통 이력을 유지하며 main 병합이나 이력 재작성은 하지 않는다.

## 범위와 공개 조건

1.5.1 소스 `8f8fb58a933f6b02107e099771c607c041f64a2f` 이후 커밋 `c57cb68`, `d8ff3ab`, `0557f9d`, `8ea5b61`, `2d52f50`의 전송 비용·입력 순서·화면 상태 대기·게스트 공유 실패 격리·진단 보완을 포함한다. 게스트 변경은 기존 승인 recovery-r3에 없으므로 r4 제작과 두 서명 APK의 카탈로그 반영을 필수 공개 조건으로 삼는다. kernel producer `39715151260`의 검증 번들을 같은 레시피·해시 확인 후 재사용하며 설치 환경을 자동 교체하지 않는다.

1.5.1 정식 `40064114551`과 Preview `40064112884`는 배포에 성공했으나 notify-release 단계가 skipped였다. 수동 공개의 notify=false 기본값과 이전 공개 기록의 명시적 비알림 선택이 원인이다. 수동 앱 게시의 기본값을 true로 고치고 이번 두 dispatch에도 notify=true를 명시한다. 이미지-only 알림은 별도 opt-in을 유지한다.

구현 단계에서 정규 debug APK·런타임·이미지 및 protocol·AVF 단위 검사가 통과했다(607개 통과, 1개 skip). Python 이미지 검사 146개가 통과했고 실제 소켓/SFTP·Native 셸 입력·화면 복원 검증 범위는 AVF_NOTES.md에 기록했다. 연결된 ReDroid15 ARM64에는 AVF feature가 없어 실제 특권 AVF 장시간 백그라운드·Doze 검증을 통과로 주장하지 않는다. 앞선 Jev 소스 외부 전송 자동 승인 거부에 따라 소스를 재전송하지 않고 로컬 diff·검사·공개 산출물 대조로 검토한다.

GitHub 제작 로그의 manifest 핀, 제작 커밋과 실제 커널 `fa4f0fc22c316d24a417e5620e915c626ab246ef5c190b557d38c136955357ee`가 일치하며 승인 카탈로그를 승격한다. 이미지 알림은 별도 요청이 없어 notify=false였다. 앱 두 채널은 notify=true로 이어서 게시한다.
