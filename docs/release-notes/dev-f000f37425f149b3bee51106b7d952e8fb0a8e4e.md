## 정식 앱과 함께 설치

- 프리릴리즈 앱의 이름을 **TERM Preview**로 구분하고 정식 앱 **TERM**과 함께 설치할 수 있도록 분리했습니다. 두 앱의 설정·프로필·실행환경·Linux 파일은 각각 따로 보관합니다.
- 각 앱은 자신의 채널에서만 업데이트합니다. 업데이트 화면은 설치된 채널을 표시하며 정식판과 프리릴리즈 사이의 채널 선택은 제공하지 않습니다.
- 이전 개발 버전은 정식판과 같은 앱 ID를 사용했습니다. 새 Preview를 설치해도 기존 앱과 데이터는 그대로 남으며, Preview는 빈 데이터로 시작합니다. 기존 앱을 자동 삭제하거나 데이터를 자동 이전하지 않습니다.
- 기존 개발 앱의 앱 내 업데이트로는 새 Preview로 전환할 수 없으므로 [GitHub 릴리즈 페이지](https://github.com/nolbo/TERM/releases)에서 TERM Preview APK를 직접 내려받아 별도로 설치하세요.
- 필요한 환경은 기존 앱에서 백업을 내보낸 뒤 Preview에서 새 실행환경으로 복원하세요. 모든 앱 설정과 실행 중인 세션이 함께 옮겨지는 것은 아니며 AVF 전체 디스크 백업은 지원하지 않습니다. 가져온 환경과 파일을 확인하기 전에는 기존 앱을 삭제하지 마세요.
- 두 앱에 같은 외부 공유 디렉토리를 연결하면 그 디렉토리의 파일은 함께 사용합니다. 앱 데이터 자체가 자동 동기화되지는 않습니다.

## 개선 및 수정

- 프로필 편집 중 화면이 재생성될 때 정상적인 작업 취소를 오류 문구로 표시하던 문제를 수정했습니다. 입력 중인 초안은 유지합니다.
- 영어 화면에서 일부 진단·설치 안내와 명령 출력 조작 문구가 한국어로 남던 문제를 수정했습니다.
- 앱 업데이트 다운로드의 진행률·용량 표시가 현재 앱 언어와 숫자 표기를 따르도록 수정했습니다.

## 업데이트 안내 및 제한

- 버전 번호는 정식판과 같은 `1.0.0`이며 배포 채널은 프리릴리즈입니다. 불안정한 변경을 포함할 수 있으므로 설치 전에 중요한 작업을 저장하고 필요한 데이터를 백업하세요.
- 이전 개발 버전의 프로필 복제 시 원본 실행환경 공유, AVF 전용 로컬 서비스 관리와 SideStore 전용 도구 제거 정책은 유지합니다. 기존 환경의 패키지나 작업 파일을 자동 삭제하지 않습니다.
- 기존 승인 Debian·Ubuntu·Arch Linux ARM 이미지 카탈로그를 그대로 사용하며 설치된 이미지·패키지·파일을 자동 교체하거나 이전하지 않습니다.
- AVF에는 지원 ARM64 기기, 호환 플랫폼 API와 실제 가상 머신 권한이 필요하며 Android 저장소 권한과 환경별 내부저장소 접근 설정도 계속 필요합니다. 일반 Android 기기에서 AVF 기능을 제공한다고 보장하지 않습니다.
- 실제 특권 AVF 기기의 부팅·공유 파일 읽기와 쓰기·네트워크 동작과 실제 USB·iPhone 기기 작업의 모든 조합은 이번 배포에서 검증하지 않았습니다. 해당 기능은 기기와 환경의 지원 조건을 확인한 뒤 사용하세요.
