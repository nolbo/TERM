# AVF Debian 이미지 avf-debian-recovery-20261024-r1

- 대상: AVF Debian ARM64

공유 채널이 일시적으로 끊겨도 SSHFS와 열린 파일 핸들을 유지하며 재연결합니다.
60초 동안 공유 소유자를 확인할 수 없으면 해당 공유의 I/O만 차단합니다. 보호된 마운트 아래
디렉토리는 공유가 사라져도 잘못된 로컬 쓰기를 허용하지 않으며 VM과 터미널은 유지됩니다.
시작 시 마운트 보호를 확인할 수 없는 오류에는 기존 VM 종료 정책을 유지합니다.

터미널 연결도 최대 60초 동안 같은 통신 스트림을 복구합니다. 입력·출력 순서를 유지하고
버퍼가 차면 흐름 제어를 적용합니다. 프로세스 자체가 종료된 경우의 화면 복원은 보장하지 않습니다.
결과가 불명확한 명령을 자동으로 다시 실행하지 않습니다.

호환 TERM APK와 새 이미지가 함께 필요합니다. 기존 환경은 중지 후 환경 설정에서 구성요소를
업데이트하세요. 커널이 다른 경우 전체 이미지 전환과 해당 보존 제한이 적용됩니다.
기존 디스크는 자동 교체하지 않습니다. Docker/LXC 및 ReDroid 커널 지원을 유지합니다.
