# TERM 1.5.1

- 릴리즈 ID: 1.5.1
- 출시일: 2026-10-24
- 대상: Android ARM64 정식 앱 TERM·프리릴리즈 앱 TERM Preview

## 변경 사항

- 주 런타임·기본 런타임·사용자 기본 선택 개념을 제거했습니다. 선택한 프로필의 실행환경을 열어 사용하며, 앱을 열기만 해도 별도의 Native 환경을 자동 시작하던 동작을 없앴습니다.
- 세션 없이 명시적으로 실행한 환경도 백그라운드의 절전 방지와 AVF 재연결 대상에 포함했습니다. AVF 환경별로 Android 기능 연결을 관리해 다른 실행환경의 상태가 연결을 막지 않도록 수정했습니다.
- AVF 요청 전송이나 응답이 멈추면 정해진 시간 안에 연결을 해제해 복구할 수 있도록 했습니다. 지연된 연결과 막힌 소켓의 정리를 개선했으며, 결과를 확인하지 못한 명령은 자동으로 다시 실행하지 않습니다.
- AVF VM이 실제로 종료된 것을 확인하면 해당 실행환경의 오래된 연결 상태를 정리해 다시 시작할 수 있도록 수정했습니다. 다른 실행환경의 세션은 유지하고, 종료 여부가 불확실하면 기존 상태를 보존합니다.
- 공유 디렉토리의 연결 복구 기한이 지나면 해당 공유의 재시도를 끝내고 경고를 표시합니다. 백그라운드에서 발생한 문제도 앱으로 돌아왔을 때 확인할 수 있습니다.

## 업데이트 방법과 호환성

- 설치된 채널에 맞춰 TERM 또는 TERM Preview를 업데이트하세요. 기존 프로필·실행환경·작업 파일은 유지되며 수동 이전은 필요하지 않습니다. 앱 업데이트는 설치된 AVF 이미지를 자동 교체하지 않습니다.
- 새 AVF 환경에는 기존 승인된 Debian·Ubuntu·Arch Linux ARM의 recovery-r3 이미지를 계속 사용합니다. 공유 디렉토리와 세션의 연결 복구에는 해당 게스트 기능이 필요합니다. 이전 EXT4 환경은 세션 종료와 VM 중지 후 구성요소 업데이트를 확인하고, 다른 커널이나 이전 이미지 형식은 지원되는 전체 이미지 업데이트 절차를 따르세요.
- 공유 복구가 만료되면 작업을 저장하고 해당 VM을 중지한 뒤 다시 시작해야 공유를 복구할 수 있습니다. VM·앱 런타임·게스트 데몬 자체가 종료된 경우 작업 복원을 보장하지 않습니다.
- 실제 특권 Android AVF 기기의 장시간 백그라운드·Doze 동작은 이번 배포에서 검증하지 않았습니다. 운영체제의 프로세스 종료나 제조사 전원 정책에 따른 중단은 남아 있습니다.
