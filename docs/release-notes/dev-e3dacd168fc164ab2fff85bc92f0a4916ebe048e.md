# TERM 0.8.0 개발 버전

- 릴리즈 ID: dev-e3dacd168fc164ab2fff85bc92f0a4916ebe048e
- 앱 버전: 0.8.0+dev.1000049.e3dacd168fc1
- 출시일: 2026-10-03
- 대상: Android 앱, 터미널 UI, Native·Rootless 및 저장소 설정

## 추가 및 변경

- 터미널 탭과 새 세션·설정 버튼을 툴바의 **세션** 도구에 모았습니다. 탭을 세로 목록으로 표시하며, 세션이 없으면 툴바를 숨기고 빈 화면에서 새 세션과 설정을 열 수 있습니다.
- 탭을 길게 누른 뒤 위아래로 드래그해 순서를 바꿀 수 있습니다. 선택한 탭의 편집 버튼으로 제목을 변경하며, 탭 목록을 직접 스크롤한 위치를 유지합니다.
- 세션 도구 설정에 **탭 삭제 시 묻지 않기**를 추가했습니다. 기본값은 꺼짐이며, 켜면 닫기 버튼이 실행 중인 작업을 확인 없이 즉시 종료합니다.
- 단축키에 단독 **SHIFT** 버튼을 추가할 수 있습니다. 다음 키 입력에 Shift를 적용한 뒤 자동 해제하며 다시 누르면 선택을 취소합니다.
- 설정에 **앱 정보**와 오프라인 **오픈소스 라이선스** 화면을 추가했습니다. 설치된 앱 버전과 함께 포함된 소프트웨어·글꼴의 라이선스를 확인할 수 있습니다.
- 기본 UI 글꼴을 Google Sans와 한국어용 Pretendard로, 기본 터미널 글꼴을 Google Sans Code로 정리했습니다. 터미널의 넓은 문자와 사용자 글꼴 스타일 표시도 개선했습니다.
- 설정의 그룹·스크롤 제목·확장 애니메이션과 프로필·저장소의 작업 버튼을 정리했습니다. Rootless 배포판은 설치 상태별로 구분하며 앱 업데이트 화면의 상태와 안내를 읽기 쉽게 표시합니다.

## 수정

- 전체 화면 터미널 프로그램의 배경과 앱 바·툴바 주변 색상이 어긋나거나 화면 크기 변경 후 터미널 영역이 맞지 않던 문제를 수정했습니다.
- 세션 탭과 툴바 항목을 드래그할 때 가장자리와 둥근 모서리가 잘리거나 핸들에 불필요한 강조·도움말이 나타나던 문제를 수정했습니다.
- Rootless 저장소의 일부 폴더에 접근할 수 없을 때 용량이 0으로 잘못 표시되던 문제를 수정했습니다. 확인 가능한 합계는 **최소 … (일부 확인)**으로, 측정 실패는 **용량 확인 불가**로 표시합니다.
- 도구 종류에 따라 기본 툴바 높이가 달라지던 문제와 프로필 생성 화면의 저장 버튼 표시를 수정했습니다.

## 업데이트 안내 및 제한

- 기존 설정·프로필·작업 파일은 유지되며 수동 이전은 필요하지 않습니다. 업데이트 중 실행 중인 작업이 중단될 수 있으니 중요한 작업은 먼저 저장하세요.
- 터미널 캔버스를 두 번 탭해 툴바를 전환하는 동작을 제거했습니다. 툴바를 펼치거나 숨길 때는 하단 핸들을 사용하세요.
- **탭 삭제 시 묻지 않기**를 켠 상태에서 탭을 닫으면 실행 중인 작업이 종료됩니다. 종료된 프로세스는 복원할 수 없습니다.
- 저장소 용량은 전체 디스크 크기나 여유 공간이 아닌 해당 환경 파일의 합계이며, 일부 폴더에 접근할 수 없으면 실제 사용량보다 작을 수 있습니다.
- 일부 화면 재진입 상황에서 이전 터미널 스크롤 위치를 복원하지 못하는 알려진 제한이 남아 있습니다. AVF는 지원 기기와 필요한 권한이 있어야 사용할 수 있습니다.
