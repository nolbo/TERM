# TERM AVF Debian ARM64 초기 이미지

- 릴리즈 ID: avf-debian-920f34393b22d3e00806b251796684b4a2ad6f2a
- 출시일: 2026-10-03
- 대상: AVF용 Debian ARM64 이미지

## 제공 기능

- 지원 제품에서 Debian 가상 머신을 처음 준비할 때 사용할 이미지를 제공합니다. 이 이미지가 등록된 TERM 앱은 첫 AVF 세션 요청 시 다운로드·검증·설치를 자동으로 처리하므로 이미지 파일을 직접 준비할 필요가 없습니다.
- 터미널 세션과 파일 작업을 위한 게스트 구성 요소를 포함하며, 재시작 후에도 홈 파일과 설치한 패키지를 유지하는 쓰기 가능 저장공간을 제공합니다.

## 설치 안내 및 제한

- 최초 설치용 이미지입니다. 이미 설치된 AVF 이미지와 작업 파일을 자동으로 교체하거나 업그레이드하지 않습니다.
- 최초 다운로드에 인터넷 연결이 필요하며, 압축을 해제한 이미지에 약 14GiB의 저장공간이 필요합니다. 안전한 설치를 위한 임시 공간과 이후 작업 파일을 저장할 여유도 확보하세요.
- AVF 지원 ARM64 기기, 호환되는 플랫폼 API 및 실제 가상 머신 권한이 필요합니다. APK 설치만으로 시스템 권한을 얻을 수 없으며 AVF 실기기 실행 검증은 아직 완료되지 않았습니다.
- 개발 채널 프리릴리즈입니다.
