# TERM 1.5.3

- 릴리즈 ID: 1.5.3
- 출시일: 2026-10-25
- 대상: Android ARM64 정식 앱 TERM

## 개선 사항

- AVF 진단 로그를 개별 항목 목록 대신 하나의 텍스트로 표시합니다. 각 줄은 날짜·시각·밀리초·시간대를 대괄호로 표시하고, 오래된 기록부터 시간순으로 이어집니다. 가로·세로 스크롤과 여러 줄 선택을 지원합니다.
- 로그 복사 형식을 화면과 일치시키고, 표시된 시간으로도 검색할 수 있도록 개선했습니다. 기존에 저장된 기록도 같은 형식으로 읽을 수 있습니다.
- 세션 요청과 응답, 연결 복구와 재시도 대기, 입력 거부, 런타임 상태와 메모리 압력, 전원 상태와 절전 방지 동작을 더 자세히 기록합니다. 실행환경·세션·요청 식별자와 처리 단계·지연 시간·버퍼 상태·오류 원인·소스 위치·확인 가능한 오류 번호를 함께 확인할 수 있습니다.
- 반복 입력 오류가 최초 연결 장애 기록을 빠르게 밀어내지 않도록 기록 빈도를 제한하고 억제 횟수를 남깁니다. 정상 키 입력과 터미널 출력은 매번 기록하지 않습니다.

## 업데이트 방법과 제한

- 정식 앱 TERM을 업데이트하세요. 기존 프로필·실행환경·작업 파일은 유지됩니다. 이번 진단 개선을 위해 추가로 게스트 이미지를 교체할 필요는 없으며, 앱 업데이트가 설치된 AVF 환경을 자동 교체하지 않습니다.
- 진단 로그는 최대 1,000개·256 KiB를 기기에 보관합니다. 터미널 입출력·명령·파일 경로·토큰·예외 메시지는 기록하지 않으며 자동 전송하지 않습니다.
- 이번 변경은 AVF 이상 동작의 원인을 추적하기 위한 진단 개선입니다. 실제 기기의 연결 단절이나 장시간 백그라운드·Doze 중 멈춤 현상이 해결됐다고 보장하지 않습니다. VM·앱 런타임·게스트 데몬 자체가 종료된 경우 작업 복원은 보장하지 않습니다.
