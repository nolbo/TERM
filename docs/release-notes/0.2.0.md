# TERM 0.2.0 — 프로필 및 터미널 사용성 개선

- 준비 버전 ID: `0.2.0`
- 준비일: 2026-09-24
- 배포 대상일: 2026-09-24 — 개발 채널 프리릴리즈, 게시 결과는 커밋별 노트에 기록
- 대상: Android ARM64 APK, Native / Rootless Linux / AVF의 공통 UI
- 비교 기준: 저장소에 배포 확인이 기록된 `0.1.0+dev.1000038.94442b56c8f2`
- 승격 이유: 기존 데이터를 유지하는 사용자 기능 추가에 따라 MINOR 승격
- 배포 채널: `dev`; 빌드 번호와 소스 SHA는 CI 산출물에서 확정

## 추가 및 변경

- 프로필별 실행 환경 아이콘·Material Symbols·사용자 이미지를 선택할 수 있습니다.
  단색 투명 이미지는 UI 색상을 따르고, 다색 이미지는 원래 색을 유지합니다.
- 두 손가락 위·아래 쓸기로 터미널 단축키를 표시하거나 숨길 수 있습니다.
- 설정 검색이 하위 설정의 이름·설명·경로를 찾고 해당 섹션을 바로 엽니다.
- 프로필 텍스트 항목을 화살표 없는 설정 행과 입력 대화상자로 편집합니다.

## 수정 및 보안 관련 표시

- 백그라운드 복귀 시 동일한 글꼴과 크기의 렌더러를 재사용하고 세션 글자 크기를
  기본값으로 잠시 바꿨다가 되돌리는 재계산을 제거했습니다.
- 두 AVF 특권 중 하나라도 없으면 가상머신 설정과 관련 검색 결과를 숨기며,
  상세 화면 직접 진입도 차단합니다.
  OS 권한 부여 방식이나 런타임의 기존 권한 검사는 변경하지 않았습니다.

## 업데이트 및 제한

- 필수 수동 데이터 이전은 없습니다. 기존 프로필의 아이콘 기본값은 실행 환경을 따릅니다.
- 앱 ID·서명·설치 순서를 결정하는 `versionCode` 정책은 유지합니다.
- APK 업데이트는 실행 중인 프로세스를 중단할 수 있으므로 작업을 먼저 저장해야 합니다.
- AVF는 지원 기기와 특권 구성이 필요합니다. 이번 버전은 AVF 사용 권한을 부여하지 않습니다.
- 사용자 기기에서의 복귀 속도 개선 폭과 특권 AVF 기기의 UI는 미측정입니다.

## 검증

- 버전 변경 후 `./gradlew :android-app:assembleDebug :android-app:testDebugUnitTest
  :android-runtime:testDebugUnitTest :image:test --console=plain` 통과.
- 생성된 디버그 APK 메타데이터에서 기본 버전 `0.2.0` 반영을 확인했습니다.
  로컬 기본 빌드는 기존 정책대로 `origin/dev` 기반 빌드 번호·SHA를 사용하므로
  이 APK를 실제 게시용 커밋 검증 또는 서명 산출물로 간주하지 않습니다.
- 이번 세션에서 변경 전 기본 버전으로 Android 15 ARM64 기기의 외형·스크롤 회귀
  테스트 5개 통과. Native 10만 줄 출력 후 홈 화면 왕복과 비특권 AVF 설정 숨김을 확인했습니다.
- 서명 릴리스 빌드, 실제 업데이트 설치, 전체 Rootless·AVF 통합, 새 기능 전체 기기
  회귀 테스트는 이번 버전 결정 작업에서 실행하지 않았습니다.

- 배포 준비 시 업데이트·게시 회귀 테스트 19개 통과: `python3 -m unittest discover -s tests/updates -p 'test_*.py'`.
