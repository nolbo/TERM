# TERM 0.17.1 개발 버전

- 릴리즈 ID: dev-01beb0c57b43d7f08386c53441143e1c4709ea6d
- 출시일: 2026-10-17
- 대상: Android ARM64 앱, Native·Userspace Linux·AVF 실행환경

## 개선 및 수정

- Android 17에서 AVF 내부저장소·공유 디렉토리를 연결할 때 `SharedPath` 생성자 호환성 오류로 실패하던 문제를 수정했습니다. 이전 Android의 공유 연결 방식도 함께 지원합니다.
- AVF 진단에서 기본 VM 실행 조건과 내부저장소·공유 디렉토리 연결 조건을 나누어 확인할 수 있도록 개선했습니다. 공유 기능을 사용할 수 없더라도 기본 VM 진단 결과와 구분해 표시합니다.
- AVF 설치 실패 원인을 더 길게 보관하고 설치 화면에서 오류 내용을 선택하거나 **오류 복사**로 복사할 수 있도록 개선했습니다.
- 확장한 세션 목록에서 탭을 끌다가 방향을 되돌리거나 탭 사이에 놓았을 때 순서가 다시 바뀌던 문제를 수정했습니다. 조작을 취소하면 변경을 적용하지 않으며 출력 갱신·화면 재생성 뒤에도 확정한 순서를 유지합니다.

## 업데이트 안내 및 제한

- 마이너 버전 `0.17`을 유지하는 개발 채널 프리릴리즈입니다. 기존 프로필·워크스페이스·실행환경·공유 폴더·작업 파일을 유지합니다. 업데이트 전에 실행 중인 중요한 작업을 저장하세요.
- AVF 공유 호환성 수정에 새 이미지 설치는 필요하지 않습니다. 업데이트 후 실행 중인 VM을 중지하고 다시 시작해야 새 연결 설정이 적용됩니다. 설치 중 패키지 목록 초기화만 실패했다면 실행환경 상세의 **패키지 목록 갱신 재시도**를 사용할 수 있으며 설치한 디스크는 보존합니다.
- 기존 승인 Debian·Ubuntu·Arch Linux ARM 이미지 카탈로그를 그대로 사용하며 설치된 이미지·패키지·파일을 자동 교체하거나 이전하지 않습니다.
- AVF에는 지원 ARM64 기기, 호환 플랫폼 API와 실제 가상 머신 권한이 필요하며 Android 저장소 권한과 환경별 내부저장소 접근 설정도 계속 필요합니다. 진단 결과만으로 실제 마운트 성공을 보장하지 않습니다.
- 실제 Android 17 AVF 기기의 저장소 연결·부팅·vsock·공유 파일 읽기와 쓰기·네트워크 동작은 이번 배포에서 검증하지 않았습니다.
