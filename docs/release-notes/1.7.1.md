# TERM 1.7.1

- 릴리즈 ID: 1.7.1
- 출시일: 2026-10-31
- 대상: Android ARM64 정식 앱 TERM, AVF Debian·Ubuntu·Arch Linux ARM

## 수정 및 개선 사항

- AVF 세션 하나의 실패나 연결 종료가 다른 세션에 영향을 주는 문제를 줄이고, 연결 복구와 종료된 세션의 정리를 개선했습니다.
- 많은 터미널 출력이나 이미지 처리가 명령 응답·화면 크기 변경을 지연시키는 경로를 개선하고, 화면을 보고 있지 않을 때에도 세션 입출력이 진행되도록 수정했습니다.
- 실행환경은 살아 있고 연결만 일시적으로 끊긴 경우 세션과 터미널 이력을 유지하도록 복구 경로를 개선했습니다.
- 로컬 실행 프로세스가 다시 시작되거나 여러 작업을 동시에 열 때 Workspace 시작이 꼬이는 문제를 수정했습니다.
- 실행환경을 중지하면 해당 세션 탭을 정리하고, 기본·확장 툴바에서 탭을 닫는 애니메이션을 개선했습니다.
- 프로그램이 터미널 화면을 제어하는 동안에도 기존 명령 이력의 복사와 출력 열기를 사용할 수 있도록 수정했습니다.
- AVF의 불필요한 처리·복사와 선행 읽기를 줄여 입출력 처리 비용을 개선했습니다.

## 업데이트 방법과 제한

- 정식 앱 TERM을 업데이트하세요. 기존 프로필·실행환경·작업 파일은 유지하며 Preview 앱은 별도입니다.
- 함께 제공하는 Debian session-20261031-r4와 Ubuntu·Arch session-20261031-r2 이미지는 게스트 세션 복구와 입출력 개선을 포함합니다. APK 업데이트만으로 설치된 환경의 디스크를 교체하지 않습니다.
- 게스트 개선을 적용하려면 작업을 저장하고 세션과 실행환경을 중지한 뒤 지원되는 이미지 업데이트를 적용하세요. unshared-r1·resources-r1·recovery-r4·recovery-r3·EXT4-r2처럼 커널과 디스크 형식이 같은 환경은 구성요소 업데이트를 사용할 수 있으며, 다른 환경은 전체 이미지 전환 절차를 따르세요.
- Userspace Linux의 기존 실행 방식은 유지합니다. 개발 중인 자체 엔진은 이번 앱에서 제공하지 않습니다.
- 실제 특권 Android AVF 기기의 장시간 백그라운드·Doze 안정성이나 운영체제의 프로세스 종료에 따른 작업 복원을 보장하지 않습니다.
