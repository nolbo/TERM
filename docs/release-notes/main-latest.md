# TERM 1.0.0 정식 버전

- 릴리즈 ID: main-latest
- 출시일: 2026-10-19
- 대상: Android ARM64 정식 앱 TERM, Native·Userspace Linux·AVF 실행환경

## 주요 기능

- Native 셸과 Userspace Linux의 Debian·Ubuntu 24.04 LTS·Arch Linux ARM 환경을 제공합니다. 프로필별 실행환경·셸·시작 명령·아이콘·팔레트를 설정하고 여러 터미널 세션을 관리할 수 있습니다.
- 워크스페이스로 세션을 묶고 시작 구성을 등록할 수 있습니다. 같은 그룹의 터미널 두 개를 상하 또는 좌우로 분할하고 비율과 입력 대상을 조절합니다. 분할 해제는 세션을 종료하지 않으며 화면을 다시 열면 살아 있는 세션의 배치와 선택 상태를 복원합니다.
- 툴바와 단축키의 순서·위치·크기, 사용자 글꼴·팔레트·햅틱을 설정할 수 있습니다. 명령 기록에서 명령과 출력을 검색하고 보관된 출력을 펼쳐 읽거나 복사합니다. Sixel·kitty 이미지 출력과 확장 키보드 입력, 선택적인 세션 작업 알림도 지원합니다.
- 여러 환경에 연결할 수 있는 공유 디렉토리와 Native·Userspace Linux 환경의 백업·복원을 제공합니다. Userspace Linux는 설치된 배포판과 패키지를 포함하는 전체 백업도 지원합니다. 백업에 암호를 설정할 수 있으며 복원은 새 실행환경을 만듭니다.
- 지원되는 AVF 기기에서는 Debian·Ubuntu·Arch Linux ARM 이미지 설치, 패키지 초기화, 공유 디렉토리·Android 내부저장소 연결, 로컬 서비스와 포트 전달을 사용할 수 있습니다.
- Android 연동과 USB 접근을 기능별로 허용하며, 설정 검색·실행환경 진단·메모리 정보·크래시 리포트·앱 업데이트 화면에서 앱 상태를 확인할 수 있습니다.

## 개선 및 수정

- 프로필 편집 중 화면 재생성으로 취소된 작업을 오류로 표시하던 문제를 수정하고 입력 초안을 유지합니다.
- 일부 영어 진단·설치 안내·명령 출력 문구의 누락을 보완하고 업데이트 다운로드의 숫자 표기가 앱 언어를 따르도록 수정했습니다.
- 세션 탭 이동·분할 화면과 터미널 글꼴·팔레트 표시를 개선하고 AVF 이미지 설치에 필요한 임시 저장공간을 줄였습니다.

## 설치와 기존 데이터

- 정식 앱 **TERM**과 프리릴리즈 앱 **TERM Preview**를 함께 설치할 수 있습니다. 각 앱의 설정·프로필·실행환경·Linux 파일은 별도로 보관하며 TERM은 정식판, Preview는 프리릴리즈만 업데이트합니다.
- 이전에 정식판과 같은 앱 ID를 사용하던 프리릴리즈는 기존 앱과 데이터를 유지합니다. 새 Preview 설치는 그 앱을 교체하거나 삭제하지 않으며 빈 데이터로 시작합니다. 자동 이전은 없으므로 필요한 환경은 기존 앱에서 백업하고 Preview에서 새 환경으로 복원하세요. 이전을 확인하기 전에는 기존 앱을 삭제하지 마세요.
- 기존 개발 앱의 앱 내 업데이트로는 새 Preview로 전환할 수 없으므로 [GitHub 릴리즈 페이지](https://github.com/nolbo/TERM/releases)에서 TERM Preview APK를 직접 내려받아 별도로 설치하세요.
- 같은 외부 공유 디렉토리를 두 앱에 연결하면 그 파일은 함께 사용합니다. 환경 백업은 모든 앱 설정·실행 중인 세션을 옮기는 기능이 아니며 AVF 전체 디스크 백업은 지원하지 않습니다.
- 프로필 복제는 기본적으로 원본 실행환경을 사용해 패키지·홈·파일을 공유합니다. 독립 환경이 필요하면 **새 실행환경 생성**을 선택하세요.
- 예전 Userspace Linux의 자동 `/workspace` 연결은 제공하지 않습니다. 기존 파일은 보존하며 필요한 데이터를 공유 디렉토리로 가져와 연결하고 관련 프로필·스크립트·링크의 경로를 수정하세요.
- Native 전역 셸 설정 대신 프로필별 셸 설정을 사용합니다. SideStore 전용 호스트 도구와 Native·Userspace Linux의 로컬 서비스 수동 등록은 제공하지 않습니다. 로컬 서비스 관리는 **AVF Linux → 실행 → 로컬 서비스**에서 제공합니다.
- 정상 업데이트는 앱 데이터와 Linux 파일을 유지하지만 실행 중인 작업은 중단될 수 있습니다. 설치 전에 작업을 저장하고 중요한 데이터를 백업하세요. 이전 APK로의 다운그레이드는 지원하지 않습니다.

## 지원 범위와 제한

- 일반 Android 기기에서는 Native·Userspace Linux를 사용할 수 있습니다. AVF에는 지원 ARM64 기기, 호환 플랫폼과 실제 가상 머신 권한이 필요하며 APK 설치만으로 해당 권한을 얻을 수 없습니다.
- 기존 승인 Debian·Ubuntu·Arch Linux ARM 이미지를 유지하며 설치된 환경의 이미지·패키지·파일을 자동 교체하거나 다른 배포판으로 변환하지 않습니다.
- 실제 특권 AVF 기기의 부팅·공유 파일 읽기와 쓰기·네트워크 동작과 실제 USB·iPhone 기기 작업의 모든 조합은 이번 배포에서 검증하지 않았습니다. 해당 기능은 기기와 환경의 지원 조건을 확인한 뒤 사용하세요.
