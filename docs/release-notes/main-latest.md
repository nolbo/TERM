# TERM 1.1.0 정식 버전

- 릴리즈 ID: main-latest
- 출시일: 2026-10-20
- 대상: Android ARM64 정식 앱 TERM, Native·Userspace Linux·AVF 실행환경

## 추가 및 개선

- AVF에서 앱 전용 공유 디렉토리를 직접 연결할 수 있습니다. 선택한 폴더만 공유하며 Android 17에서 앱 전용 경로를 연결하지 못하던 문제를 개선했습니다. Android 내부저장소 전체 연결은 별도 선택과 저장소 권한이 계속 필요합니다.
- AVF 실행환경의 배포판 이미지에서 **업데이트 확인**을 제공합니다. 앱에 포함된 승인 이미지와 비교해 적용 가능한 구성요소 업데이트 또는 전체 이미지 업데이트를 안내합니다.
- AVF 업데이트는 기존 상태의 복사본에서 작업하며, 이전 이미지와 상태를 함께 복원할 수 있습니다. Debian·Ubuntu·Arch Linux ARM용 새 지원 이미지를 포함합니다.
- 첫 실행 화면에서 Native의 즉시 사용과 Linux 환경의 나중 설치를 안내하고, 하단 시작 버튼으로 터미널에 진입하도록 정리했습니다. AVF 이미지 설치는 실행환경 설정에서 진행합니다.
- 앱 업데이트 화면의 채널 표시를 정리했습니다. TERM은 정식판, TERM Preview는 프리릴리즈에서 계속 업데이트합니다.

## 기존 환경과 업데이트

- 앱 업데이트와 새 이미지 제공만으로 기존 실행환경·패키지·작업 파일을 교체하지 않습니다. AVF 공유 기능이 필요한 기존 환경은 실행환경 설정에서 지원 이미지로 업데이트하거나 새 환경을 설치하세요.
- AVF 업데이트 적용 전에는 VM과 모든 세션을 종료하고 중요한 파일을 백업하세요. 인터넷 연결과 이미지·상태 복사본을 위한 추가 저장공간이 필요합니다. Arch 구성요소 업데이트는 배포판 패키지도 함께 갱신할 수 있습니다.
- 전체 이미지 업데이트는 추가 패키지를 다시 설치하고 홈 디렉토리 등을 옮깁니다. 설정 충돌이나 설치할 수 없는 패키지는 작업을 중단합니다. `/var/lib`의 데이터베이스와 사용자 정의 `/usr/local` 등은 자동 이전하지 않으며 이전 버전에 남습니다.
- 이전 버전 복원은 그 시점의 이미지와 쓰기 상태를 함께 되돌립니다. 업데이트 이후 파일 변경은 병합하지 않으므로 필요한 파일을 먼저 별도로 보관하세요.
- 과거 Android 공유 저장소를 사용하던 AVF 공유 폴더는 편집 화면에서 **앱 전용 저장소로 전환**을 저장해야 옮겨집니다. 전환에는 저장소 권한과 사용 중인 세션·VM의 종료가 필요하며 원래 공개 저장소의 파일은 남깁니다.
- 공유 디렉토리에서 예전 워크스페이스 가져오기·보관 데이터 선택·ZIP 내보내기 메뉴를 제거했습니다. 기존 데이터와 백업은 보존하며 자동 `/workspace` 연결은 다시 만들지 않습니다.
- TERM과 TERM Preview는 별도 앱과 데이터 영역을 유지합니다. Native·Userspace Linux의 무특권 실행 경로와 기존 프로필·설정·파일은 유지합니다.

## 지원 범위와 제한

- AVF에는 지원 ARM64 기기, 호환 플랫폼과 실제 가상 머신 권한이 필요합니다. 앱 전용 공유 폴더는 새 지원 이미지가 필요하며 공유 파일시스템에서 임의 소유권 변경·하드링크·런타임 간 파일 잠금은 지원하지 않습니다.
- 업데이트 확인은 현재 앱이 승인한 이미지만 비교합니다. 더 새로운 이미지가 게시되어도 해당 카탈로그를 포함하는 앱 업데이트가 필요할 수 있습니다.
- 실제 특권 Android AVF 기기의 공유 폴더 연결·관리 부팅·중단 복구·이전 버전 복원은 이번 배포에서 검증하지 않았습니다. Linux 이미지 부팅 검증이 Android 기기 호환성을 보장하지 않습니다.
