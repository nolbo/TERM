# TERM 1.7.0

- 릴리즈 ID: 1.7.0
- 출시일: 2026-10-28
- 대상: Android ARM64 정식 앱 TERM, AVF Debian·Ubuntu·Arch Linux ARM

## 버전 정정

- 직전 1.6.0에서 마이너 버전만 올린 1.7.0으로 정정했습니다. 먼저 공개된 2.0.0과 기능은 같으며, 기존 2.0.0 설치에서도 앱을 삭제하지 않고 업데이트할 수 있습니다.

## 호환성 변경

- AVF의 Android 공유 디렉토리 연결, `/sdcard` 공유, 공유 디렉토리 화면의 VM 파일 사본 가져오기·내보내기를 제거했습니다. AVF에서 공유 프로젝트 경로를 사용하던 작업은 더 이상 같은 경로로 호스트 파일에 접근할 수 없습니다.
- 기존 공유 폴더의 파일과 AVF 디스크·설치한 패키지는 보존합니다. Native·Userspace Linux의 공유 디렉토리와 Android 공유 메뉴를 통한 독립적인 Linux 파일 복사는 계속 사용할 수 있습니다.

## 1.6.0 이후 수정 및 개선 사항

- 기본 크기에서 세션 탭을 끝까지 스크롤한 직후 끝쪽 탭을 한 번 눌러도 전환되지 않던 문제를 수정했습니다.
- 툴바의 세션 작업 알림을 벨 또는 명시적인 주의 요청에 맞췄습니다. 일반 명령이 오래 실행됐다는 이유만으로 완료 메시지를 표시하지 않습니다.
- 백그라운드 실행 보호를 갱신하는 순간 보호가 끊길 수 있던 문제를 수정했습니다. Android가 프로세스를 종료하지 않는다고 보장하는 기능은 아닙니다.
- AVF 세션 종료 시 정리가 지연되거나 게스트 자원이 남을 수 있던 경로를 수정했습니다. 많은 출력을 처리할 때의 불필요한 복사와 그래픽 데이터 탐색을 줄이고 터미널 상태 저장을 출력 처리에서 분리했습니다.

## 업데이트 방법과 제한

- 정식 앱 TERM을 업데이트하세요. 기존 프로필·실행환경·작업 파일은 유지하며 Preview 앱은 별도입니다.
- 공유를 사용하던 AVF 환경은 업데이트 전에 작업을 저장하고 세션과 환경을 중지한 뒤 다시 시작하세요. 공유 연결 없이 기존 디스크를 사용하며, 실행 중이던 공유 VM에는 재시작 안내가 표시될 수 있습니다.
- 함께 제공하는 Debian·Ubuntu·Arch의 unshared-20261028-r1 이미지는 공유 서비스 제거와 게스트 세션·출력 처리 개선을 포함합니다. APK 업데이트만으로 설치된 환경의 디스크를 교체하지 않습니다.
- resources-r1·recovery-r4·recovery-r3·EXT4-r2처럼 커널과 디스크 형식이 같은 환경은 작업 저장·세션 종료·환경 중지 후 지원되는 구성요소 업데이트를 적용할 수 있습니다. 다른 커널이나 형식은 실행환경의 전체 이미지 전환 절차를 따르세요.
- 실제 특권 Android AVF 기기의 장시간 백그라운드·Doze 안정성이나 운영체제의 프로세스 종료에 따른 작업 복원을 보장하지 않습니다.
