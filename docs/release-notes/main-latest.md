# TERM 1.5.0

- 릴리즈 ID: 1.5.0
- 출시일: 2026-10-24
- 대상: Android ARM64 정식 앱 TERM·프리릴리즈 앱 TERM Preview

## 변경 사항

- AVF 터미널과 공유 디렉토리의 일시적인 연결 단절을 최대 60초 동안 복구합니다. 지원 이미지에서는 같은 세션과 열린 공유 파일 핸들을 유지하며, 복구되지 않은 공유의 접근을 차단해 VM과 다른 세션을 보호합니다.
- 기본 실행방식이 Android Native인 상태에서도 기존 AVF 세션에 다시 연결할 수 있도록 수정했습니다. 화면 전송이 지연되거나 앱이 백그라운드로 이동한 경우에도 화면 처리 때문에 터미널 작업이 멈추거나 종료되지 않도록 개선했습니다.
- 설정의 진단 및 리포트에 AVF 진단 로그를 추가했습니다. VM 준비·시작·종료, 연결·복구, 공유 디렉토리, 이미지 작업과 권한 검사 결과를 확인할 수 있습니다.
- 진단 로그 기록을 켜거나 끄고 이벤트·식별자로 검색할 수 있습니다. 새로고침·로그 복사·저장된 로그 삭제는 하단 플로팅 툴바에서 제공하며, 삭제 전 확인합니다.

## 업데이트 방법과 호환성

- 설치된 채널에 맞춰 TERM 또는 TERM Preview를 업데이트하세요. 기존 프로필·실행환경·작업 파일을 유지하며 앱 업데이트만으로 설치된 AVF 이미지를 교체하지 않습니다.
- 연결 복구에는 이 앱과 새 승인 이미지가 함께 필요합니다. 새 AVF 환경에는 Debian·Ubuntu·Arch Linux ARM의 recovery-r3 이미지가 적용됩니다. 기존 EXT4 환경은 세션 종료와 VM 중지 후 구성요소 업데이트를 확인하세요. 다른 커널이나 이전 이미지 형식은 지원되는 전체 이미지 업데이트 절차를 따릅니다.
- 복구는 일시적인 연결 단절에 적용됩니다. VM, 앱 런타임 또는 게스트 데몬 자체가 종료된 경우의 작업·화면 복원을 보장하지 않으며, 결과를 받지 못한 명령을 자동으로 다시 실행하지 않습니다. 공유 소유자를 잃은 환경은 VM 중지·시작이 필요할 수 있습니다.
- 진단 로그는 기본 켜짐이며 최대 1,000개·256 KiB를 기기에 보관합니다. 꺼도 기존 기록을 유지하고 꺼져 있던 동안의 이벤트는 나중에 저장하지 않습니다. 터미널 입출력·명령·파일 경로·토큰·예외 메시지는 제외하며 자동 전송하지 않습니다.
- 실제 Android 특권 AVF 기기에서의 장시간 연결 복구와 전원 정책 동작은 이번 배포에서 검증하지 않았습니다. 이미지의 자동 부팅 검사와 앱 화면 검증 범위를 구분합니다.
