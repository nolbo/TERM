# TERM AVF Debian ARM64 초기 설정 수정

- 릴리즈 ID: avf-debian-20261004
- 출시일: 2026-10-04
- 대상: AVF용 Debian ARM64 이미지

## 수정 사항

- `droid` 사용자로 실행하는 터미널에서 `sudo`가 권한 상승을 거부하던 초기 설정을 수정했습니다. 새 이미지에서는 `sudo apt update`와 `sudo apt install`로 Debian 패키지를 관리할 수 있습니다.
- VM 소유자가 게스트를 관리할 수 있도록 `droid`에 비밀번호 없는 `sudo`를 설정했습니다. 이 권한은 Debian 가상 머신 내부에만 적용되며 Android 시스템 권한을 추가하지 않습니다.
- `droid`의 홈을 `/home/droid`로 지정하고 홈과 작업 디렉터리에 쓰기 권한을 준비했습니다. 공통 로그인 비밀번호는 제공하지 않습니다.

## 설치 안내 및 제한

- 새로 설치하는 AVF 환경에 적용되는 이미지입니다. 기존 이미지·프로필·작업 파일은 자동으로 교체하거나 이전하지 않으며, 기존 이미지의 초기 설정을 수정하지 않습니다.
- 최초 다운로드에는 인터넷 연결이 필요하며, 압축을 해제한 이미지에 약 14GiB의 저장공간이 필요합니다. 설치 임시 공간과 이후 작업 파일을 저장할 여유도 확보하세요. 설치한 환경의 터미널은 인터넷 없이 사용할 수 있지만 Debian 저장소에서 패키지를 내려받으려면 네트워크가 필요합니다.
- AVF 지원 ARM64 기기, 호환되는 플랫폼 API 및 실제 가상 머신 권한이 필요합니다. APK 설치만으로 시스템 권한을 얻을 수 없으며, 새 이미지의 AVF 실기기 실행은 아직 검증하지 않았습니다.
- 여러 VM의 동시 인터넷 연결은 Android 플랫폼의 TAP 인터페이스 지원에 달려 있습니다. 이 이미지가 고정 TAP 인터페이스로 발생하는 플랫폼 오류를 해결하지는 않습니다.
- 개발 채널 프리릴리즈입니다.
