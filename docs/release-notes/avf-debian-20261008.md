# TERM AVF Debian ARM64 패키지 목록 초기화 개선

- 릴리즈 ID: avf-debian-20261008
- 출시일: 2026-10-08
- 대상: AVF용 Debian ARM64 이미지

## 수정 사항

- 오래된 패키지·소스·번역 목록과 다운로드 캐시가 초기 이미지에 남지 않도록 정리했습니다. 저장소 설정, 서명 확인 정보와 설치된 패키지는 유지합니다.
- 지원 앱으로 온라인 설치할 때 가상 머신을 한 번 실행해 설치 시점의 전체 패키지 목록을 가져옵니다. 오래된 목록에 증분 패치를 적용하다 실패하는 문제를 줄이고, 목록 갱신이 성공해야 설치 완료로 표시합니다.
- 갱신 실패·취소 시 설치된 디스크를 보존하고 패키지 목록만 다시 갱신할 수 있습니다. 설치된 패키지를 자동 업그레이드하지 않으며, 이후 일반적인 패키지 목록 갱신은 Debian의 기본 설정을 사용합니다.
- 기존 이미지의 가상 네트워크 DHCP·DNS 설정, `/home/droid`, 비밀번호 없는 게스트 `sudo`를 유지합니다.

## 설치 안내 및 제한

- 설치 시 패키지 목록 초기화에는 TERM 0.13.1 이상의 지원 앱과 인터넷 연결이 필요합니다. 이전 앱에서는 새 초기화 절차를 수행하지 않습니다.
- 새 이미지는 신규 AVF 환경에 사용합니다. 기존 설치 이미지·패키지·사용자 파일은 자동 교체하거나 이전하지 않으며, 새 이미지로 다시 설치하려면 먼저 게스트 파일을 백업하세요.
- 최초 다운로드에는 인터넷 연결과 압축 해제된 이미지에 약 14GiB의 저장공간이 필요합니다. 설치 임시 공간과 이후 작업 파일을 저장할 여유도 확보하세요.
- AVF 지원 ARM64 기기, 호환되는 플랫폼 API와 실제 가상 머신 권한이 필요합니다. Android의 AVF 네트워크 설정이 켜져 있고 플랫폼이 VM 네트워크를 제공해야 합니다.
- 실제 AVF 기기의 DHCP·DNS·인터넷 갱신과 여러 VM의 동시 연결 검증은 완료되지 않았습니다. Android 플랫폼의 고정 TAP 인터페이스 오류를 해결하는 이미지는 아닙니다.
- 개발 채널 프리릴리즈입니다.
