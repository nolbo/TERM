# TERM 1.6.0

- 릴리즈 ID: 1.6.0
- 출시일: 2026-10-25
- 대상: Android ARM64 정식 앱 TERM, AVF Debian·Ubuntu·Arch Linux ARM

## 추가 및 개선 사항

- 세션 작업 알림을 켜면 다른 세션의 10초 이상 작업 완료를 Android 알림 대신 툴바 드래그 핸들에 표시합니다. 세션 이름과 완료 상태를 약 5초간 보여주며 핸들이 부드럽게 넓어졌다가 돌아옵니다. 숨긴 툴바에서도 확인할 수 있고 앱 복귀·화면 재생성 시 미확인 메시지를 이어서 표시합니다. 벨·명시적인 주의 요청은 기존 Android 알림을 사용합니다.
- 단축키를 누른 채 손가락을 키 밖으로 움직여도 누름 상태와 반복 입력을 유지합니다. 키를 누르는 동안 도구의 가로 전환과 단축키 영역의 세로 스크롤을 막아 입력 도중 화면이 움직이는 문제를 수정했습니다.
- AVF CPU 설정을 실제 지원 방식에 맞춘 단일 CPU·호스트 전체 CPU 선택으로 정리했습니다. 새 설정의 기본값은 단일 CPU이며, 기존 2–16개 선택은 호스트 전체 CPU로 표시합니다. 메모리에 0을 입력하면 총 RAM의 약 1/3과 가용 RAM의 절반 중 작은 값을 기준으로 1–4GiB를 자동 배정하며, 기존 수동 설정은 유지합니다. 설정은 다음 환경 시작부터 적용됩니다.
- 메모리 진단에서 실행 중 AVF 게스트의 RAM·swap·사용 가능 CPU·부하·메모리 대기율을 앱 메모리와 구분해 확인할 수 있습니다. 지원하지 않는 게스트의 값을 0으로 추정하지 않고 구성요소 업데이트가 필요함을 안내합니다.
- 터미널 질의 응답이 입출력 처리를 서로 기다리게 하던 경로와 한 세션의 느린 입출력이 다른 세션의 출력을 막을 수 있던 경로를 수정했습니다. 출력 보관·공유 파일 처리의 불필요한 복사를 줄이고 유휴 상태의 로컬 서비스 탐색 간격을 조정했습니다.

## 업데이트 방법과 제한

- 정식 앱 TERM을 업데이트하세요. 기존 프로필·실행환경·작업 파일은 유지하며 Preview 앱은 별도입니다.
- AVF 게스트 자원 진단과 게스트 입출력 개선에는 함께 제공하는 Debian·Ubuntu·Arch의 resources-20261025-r1 이미지 또는 해당 구성요소 업데이트가 필요합니다. APK 설치만으로 기존 환경을 자동 교체하지 않습니다.
- recovery-r4·recovery-r3·EXT4-r2처럼 커널과 디스크 형식이 같은 환경은 작업을 저장하고 세션을 종료한 뒤 VM을 중지하여 구성요소 업데이트를 적용하세요. 다른 커널·이미지 형식은 실행환경에서 지원하는 전체 이미지 전환 절차를 따르세요.
- 자동 메모리 배정에 필요한 1GiB를 확보할 수 없으면 자동 설정으로 환경을 시작하지 않습니다. 실행 중인 환경의 CPU·메모리와 기존 수동 값은 즉시 바뀌지 않습니다. 유휴 상태의 로컬 서비스 자동 발견은 최대 10초 걸릴 수 있습니다.
- 실제 특권 Android AVF 기기의 장시간 백그라운드·Doze 안정성이나 운영체제의 프로세스 종료에 따른 작업 복원을 보장하지 않습니다.
