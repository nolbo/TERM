# AVF Arch Linux ARM session-20261031-r2

- 릴리즈 ID: avf-archlinux-session-20261031-r2
- 출시일: 2026-10-31
- 대상: TERM의 AVF Arch Linux ARM ARM64 실행환경

## 수정 및 개선 사항

- 터미널 세션의 연결 복구와 종료 처리를 개선하고 한 세션의 실패가 다른 세션에 영향을 주는 경로를 수정했습니다.
- 많은 터미널 출력이나 이미지 처리 중에도 명령 응답과 입출력이 진행되도록 개선했습니다.
- 불필요한 세션 처리·복사·주기적 확인을 줄였습니다.

## 적용 방법과 제한

- 새 설치는 이 이미지가 포함된 TERM에서 제공합니다. APK 업데이트만으로 기존 실행환경의 디스크를 교체하지 않습니다.
- 기존 환경은 작업을 저장하고 세션과 환경을 중지한 뒤 지원되는 이미지 업데이트를 적용하세요. unshared-r1·resources-r1·recovery-r4·recovery-r3·EXT4-r2와 같은 커널·EXT4 형식의 환경은 구성요소 업데이트를 사용할 수 있으며, 다른 환경은 전체 이미지 전환 절차를 따르세요.
- 기존 사용자 파일과 설치한 환경은 자동 교체하지 않습니다. AVF의 Android 공유 디렉토리 연결은 제공하지 않습니다.
- 실제 특권 Android AVF 기기의 장시간 백그라운드·Doze 안정성을 보장하지 않습니다.
