# TERM 0.18.0 개발 버전

- 릴리즈 ID: dev-2c0ee49197c0e3d8576a93a8429aaf55a2eaf93b
- 출시일: 2026-10-18
- 대상: Android ARM64 앱, Native·Userspace Linux·AVF 실행환경

## 변경 및 제거

- SideStore 전용 호스트 도구와 관련 입력·실행 지원을 제거했습니다. 이 도구에 의존하던 SideStore 전용 작업은 더 이상 앱에서 실행할 수 없습니다.
- 로컬 서비스 관리를 **AVF Linux → 실행 → 로컬 서비스**로 이동했습니다. Native·Userspace Linux의 로컬 서비스 관리와 수동 등록 지원을 종료했으며 기존 수동 등록은 목록에 불러오지 않습니다.
- 프로필을 복제하면 기본적으로 **원본 실행환경 사용**이 선택됩니다. 복제한 프로필은 원본과 같은 패키지·홈·파일을 공유합니다. 독립 환경이 필요하면 저장 전에 **새 실행환경 생성**을 선택하세요.
- 새 프로필 이름을 실행 방식·배포판·선택한 실행환경에 맞춰 제안하고, 새 실행환경의 기본 이름에는 `env-` 접두사를 붙입니다. 직접 입력한 이름과 기존 환경 이름은 유지합니다.
- Userspace Linux의 Ubuntu 기본 설치 구성에서 `ubuntu-server`를 제외하고 `ubuntu-minimal`·`ubuntu-standard`를 사용합니다. 기존 환경에 설치된 패키지를 자동 제거하지 않습니다.

## 개선 및 수정

- 세션 탭의 가장자리를 잡고 위쪽으로 끌어 놓았을 때 순서 변경이 반영되지 않던 문제를 수정했습니다.
- 앱 배포 파일의 코드·리소스를 최적화하고, 내용이 완전히 같은 라이선스 본문은 한 번만 저장해 APK 크기를 줄였습니다. 컴포넌트별 저작권·고지·원문 연결은 유지하며 라이선스 화면에서 계속 읽을 수 있습니다.
- 코드와 문서의 실행환경 표기를 **Userspace Linux**로 정리했습니다.

## 업데이트 안내 및 제한

- 기능 제거와 기본 동작 변경을 포함하는 `0.18.0` 개발 채널 프리릴리즈입니다. 업데이트 전에 위의 제거 항목과 프로필 복제 시 환경 공유 여부를 확인하고 실행 중인 중요한 작업을 저장하세요.
- 기존 프로필·워크스페이스·실행환경·공유 폴더·작업 파일은 유지하며 삭제된 관리 기능 때문에 환경의 패키지나 파일을 자동 삭제하지 않습니다.
- 기존 승인 Debian·Ubuntu·Arch Linux ARM 이미지 카탈로그를 그대로 사용하며 설치된 이미지·패키지·파일을 자동 교체하거나 이전하지 않습니다.
- AVF에는 지원 ARM64 기기, 호환 플랫폼 API와 실제 가상 머신 권한이 필요하며 Android 저장소 권한과 환경별 내부저장소 접근 설정도 계속 필요합니다. 일반 Android 기기에서 AVF 기능을 제공한다고 보장하지 않습니다.
- 실제 특권 AVF 기기의 저장소 연결·부팅·vsock·공유 파일 읽기와 쓰기·네트워크 동작은 이번 배포에서 검증하지 않았습니다.
