# TERM 0.12.0 개발 버전

- 릴리즈 ID: dev-fbae6c10c294ffff61c1e5f9e0f6b2c6cb030352
- 출시일: 2026-10-05
- 대상: Android ARM64 앱, Native·Userspace Linux·AVF 실행환경

## 추가 및 변경

- 실행환경을 프로필과 별도로 관리합니다. 여러 프로필이 같은 실행환경의 패키지·홈·작업 파일을 공유할 수 있고, 실행환경 상세에서 시작·중지·이름 변경·삭제를 관리합니다. 프로필 변경은 이미 열린 세션에 영향을 주지 않습니다.
- 실행환경별로 Userspace Linux 배포판과 AVF Debian 이미지를 설치·재시도·제거할 수 있습니다. AVF 이미지는 실행환경 상세에서 설치를 요청하며, 설치만으로 VM이나 터미널 세션을 시작하지 않습니다.
- 설치 중 **설치 취소**를 사용할 수 있습니다. 취소 후 다시 시도할 수 있으며 이미 설치된 환경과 사용자 파일은 유지합니다. 화면만 닫으면 설치는 계속됩니다.
- Userspace Linux 설정에서 Android 네트워크 DNS 또는 최대 세 개의 사용자 지정 IPv4·IPv6 DNS 주소를 선택할 수 있습니다. 새 세션과 설치·복구 작업부터 적용됩니다.
- **진단 및 보고서**에서 런타임 정보와 최근 크래시 기록을 확인할 수 있습니다. AVF 포트 전달 설정은 AVF Linux 설정에서 관리합니다.
- 세션 도구 안에서 프로필을 선택하고 새 세션을 열 수 있습니다. 프로필 목록 스크롤과 뒤로가기, 탭 표시 및 전환을 개선했습니다.
- 마우스 입력을 지원하는 터미널 프로그램에서 가로 스크롤 제스처와 마우스·트랙패드 가로 휠을 사용할 수 있습니다. 터미널 단축키의 Shift·Alt·Ctrl·Meta 선택을 휠 입력에도 반영합니다.
- Rootless Linux의 화면 표기를 **Userspace Linux**로 정리하고 설정 화면과 앱·알림 아이콘을 개선했습니다.

## 수정

- 이미지나 배포판 설치 중에도 다른 실행환경의 세션 생성과 실행환경·프로필 정보 조회가 응답하도록 개선했습니다.
- 전체 화면 TUI 배경색을 따를 때 선택·추가·삭제 강조색에 주변 화면 색이 흔들리던 문제를 수정했습니다. 기본 배경을 확인하기 어려운 화면에서는 세션 팔레트 배경을 사용합니다.

## 업데이트 안내 및 제한

- 기존 설정·프로필·작업 파일·설치 패키지·VM 디스크는 유지됩니다. 기존 저장공간은 실행환경에 자동으로 연결하며 수동 파일 이전은 필요하지 않습니다. 새 메타데이터를 사용하는 이전 APK로의 다운그레이드는 지원하지 않습니다.
- 업데이트 중 실행 중인 작업이 중단될 수 있으니 중요한 작업을 먼저 저장하세요.
- 배포판 제거와 실행환경 전체 삭제는 서로 다릅니다. Userspace Linux 배포판 제거는 기본적으로 홈·작업공간을 보존하지만, AVF Debian 제거는 게스트 디스크의 파일을 삭제하므로 먼저 백업하세요. 프로필이나 세션이 연결된 실행환경은 전체 삭제할 수 없습니다.
- Userspace Linux는 Android 위에서 동작하는 PRoot 환경으로 별도 커널이나 systemd 부팅을 제공하지 않습니다. 기존 프로세스에는 DNS 캐시가 남을 수 있습니다.
- AVF에는 호환되는 플랫폼 API와 실제 가상 머신 권한이 필요하며 APK 설치만으로 권한을 얻을 수 없습니다. AVF 실기기·vsock 및 여러 VM의 동시 인터넷 연결 검증은 완료되지 않았습니다. Native·Userspace Linux는 기존 무특권 경로를 유지합니다.
- 전체 화면을 지우지 않고 개별 셀만 칠하는 일부 TUI 테마 변경은 주변 배경색에 바로 반영되지 않을 수 있습니다.
- 개발 채널 프리릴리즈입니다.
