# TERM 0.15.1 개발 버전

- 릴리즈 ID: dev-ec0d579d47e933dc1c1d302570878cd0f78a5693
- 출시일: 2026-10-10
- 대상: Android ARM64 앱, Native·Userspace Linux·AVF 실행환경

## 수정 및 개선

- 프로필 생성·편집에서 **기존 실행환경 사용**을 선택하면 새 실행환경의 런타임·배포판 설정과 관계없이 모든 실행환경을 표시합니다. 선택한 기존 환경에 맞춰 런타임과 배포판을 자동 반영하고, 선택 항목 아래에 같은 환경의 내용이 중복 표시되던 문제를 수정했습니다.
- 프로필과 워크스페이스의 이름 입력, 프로필의 **새 실행환경 만들기 / 기존 실행환경 사용** 선택 모달에서 버튼을 **확인**으로 통일했습니다. 확인한 값은 편집 초안에 반영하며 전체 화면의 **저장**으로 최종 적용합니다.
- 접힌 세션 도구에서 워크스페이스 선택 영역 옆의 탭 경계를 자연스럽게 흐리게 표시해 스크롤되는 탭을 알아보기 쉽게 개선했습니다.
- 배포 앱의 Userspace Linux 세션에서 연결한 공유 폴더가 `/mnt/term-shares/이름`에 나타나지 않던 문제를 수정했습니다. 기존 공유 폴더를 새로 만들거나 파일을 옮길 필요 없이 새 세션에서 연결을 사용할 수 있습니다.

## 업데이트 안내 및 제한

- `0.15.0`에서 업데이트할 때 기존 설정·프로필·실행환경·공유 폴더·작업 파일을 유지하며 추가 수동 이전은 필요하지 않습니다. 업데이트 전에 실행 중인 중요한 작업을 저장하세요.
- 개발 채널 프리릴리즈입니다. 이번에는 앱만 업데이트하며 별도 Userspace Linux 런타임이나 AVF 이미지는 배포하지 않습니다. AVF의 기기·권한 조건과 기존 설치 이미지는 유지하며 실제 AVF 기기의 동작은 이번 배포에서 검증하지 않았습니다.
