# TERM AVF Debian ARM64 이미지

- 이미지 ID: `avf-debian-20261020-r1`
- 대상: 새 AVF Debian ARM64 실행환경
- 앱 릴리즈·프리릴리즈를 포함하지 않는 이미지 전용 배포입니다.

## 변경

- 앱 전용 공유 디렉토리를 vsock와 SSHFS/FUSE로 연결하는 `shareBrokerVersion=1` 게스트 기능을 추가했습니다. 지원 앱에서 모든 파일 접근 권한 없이 선택한 폴더를 `/mnt/term-shares/<이름>`으로 공유합니다.
- 공유 폴더 준비가 끝난 후 터미널 서비스를 시작하며 앱과 공유 연결이 끊어지면 해당 VM을 종료합니다.
- Python 3·SSHFS·FUSE3와 공유 서비스를 포함합니다. 선택적인 전체 `/sdcard` 공유는 기존 권한 및 실행환경 설정을 따릅니다.
- 기존 터미널·패키지 초기화·파일 복사·포트 전달·DHCP/DNS 기능과 배포판의 패키지 관리 도구를 유지합니다.

## 검증 및 호환성

- 배포 전 기준: 파일시스템·패키지 영속성의 두 차례 부팅, 실제 systemd/vsock 터미널 RPC, 공유 파일 읽기·쓰기·이름 변경·심볼릭 링크·호스트 변경 반영 및 공유 소유자 연결 종료 검증입니다.
- 새 기능을 지원하는 앱과 AVF 권한·호환 플랫폼이 필요합니다. Android 17 실기기의 AVF·다중 VM·네트워크 검증은 별도로 필요합니다.
- 기존 실행환경의 디스크·홈·패키지·사용자 파일을 자동 교체하지 않습니다. 새 이미지가 필요한 경우 새 실행환경에 설치하고 필요한 데이터를 명시적으로 옮기세요.
- 공유 폴더의 하드링크·장치 파일·실행환경 간 파일 잠금은 지원하지 않습니다. 기존 `/workspace` 가져오기 옵션을 추가하지 않습니다.
