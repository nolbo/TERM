- 대상: Android ARM64 앱, Native·Userspace Linux·AVF 실행환경

## 추가 및 변경

- 프로필 관리 화면의 **편집**에서 핸들을 드래그해 프로필 순서를 바꿀 수 있습니다. 순서는 바로 저장되고 세션 도구와 빈 화면의 **새 세션** 목록에 함께 적용됩니다. 드래그를 취소하면 이전 순서를 유지하며, 순서를 편집한 뒤 새로 만든 프로필은 목록 끝에 추가됩니다.
- Userspace Linux·AVF 프로필을 선택할 때 **설치됨**, **미설치**, **설치 중** 상태를 표시합니다. 미설치 환경은 설치 동의를 먼저 받으며, **취소**하거나 확인창을 닫으면 다운로드와 세션 생성을 시작하지 않습니다.
- 세션 도구의 프로필 선택·뒤로가기 전환과 툴바 확장의 애니메이션 및 응답성을 개선했습니다. 가로 탭 목록의 양 끝에서 다시 쓸면 인접한 도구로 전환합니다.
- 개발·안정 채널과 디버그 앱의 실행 아이콘 색상을 구분하고, 실행환경 시작 아이콘을 더 크게 표시합니다.
- 새 AVF Debian 이미지 `avf-debian-20261005`를 신규 설치에 사용합니다. 가상 네트워크 장치의 DHCP와 DNS 초기 설정을 포함하며, 기존 설치 이미지는 자동으로 교체하지 않습니다.

## 수정

- 실행환경을 삭제할 때 해당 배포판·이미지·설치 캐시와 영속 데이터를 함께 정리합니다. 배포판이나 Debian 이미지를 별도로 먼저 제거할 필요가 없습니다.
- AVF 연결을 중지하거나 읽기·통신 오류가 발생할 때 다른 Native·Userspace Linux·AVF 실행환경의 런타임과 세션까지 종료될 수 있던 문제를 수정했습니다.

## 업데이트 안내 및 제한

- 기존 설정·프로필·설치 환경·작업 파일은 유지되며 필수 수동 이전은 없습니다. 업데이트 중 실행 중인 작업이 중단될 수 있으니 중요한 작업을 먼저 저장하세요.
- 실행환경 전체 삭제는 해당 환경의 패키지·홈·작업 파일을 삭제합니다. 연결된 프로필과 활성 세션을 먼저 정리하고 필요한 파일을 백업하세요. 설치·관리 작업 중이거나 런타임 중지를 확인할 수 없으면 삭제하지 않습니다.
- 새 이미지의 네트워크 설정은 새로 설치한 AVF 환경에 적용됩니다. 기존 환경에는 앱 업데이트만으로 적용되지 않으며, **사용자 안내 → AVF에서 APT가 DNS 오류로 실패할 때**의 복구 절차를 사용할 수 있습니다. 새 이미지로 다시 설치하려면 먼저 게스트 파일을 백업하세요.
- AVF에는 호환되는 플랫폼 API와 실제 가상 머신 권한이 필요합니다. APK 설치만으로 권한을 얻을 수 없으며, 실제 DHCP·DNS·인터넷 연결 및 여러 VM의 동시 연결 검증은 완료되지 않았습니다. Native·Userspace Linux는 기존 무특권 경로를 유지합니다.
