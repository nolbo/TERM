# AVF Ubuntu 이미지 avf-ubuntu-recovery-20261024-r2

- 대상: AVF Ubuntu ARM64

공유 디렉토리의 일시적인 통신 단절 때문에 VM 전체가 종료되던 경로를 개선했습니다.
같은 소유자의 연결이 복구되면 SSHFS와 열린 파일 핸들을 유지하며 통신을 이어갑니다.
공유 권한이 60초 동안 갱신되지 않으면 해당 공유의 I/O를 차단하고 VM과 터미널은 유지합니다.
마운트 아래의 디렉토리도 보호해 공유가 사라진 위치에 파일이 잘못 저장되는 것을 방지합니다.

터미널 통신도 같은 세션을 유지한 채 최대 60초 동안 재연결하며 입력과 출력을 순서대로 전달합니다.
버퍼가 차면 작업에 흐름 제어가 적용됩니다. 앱 런타임이나 게스트 데몬 자체가 종료된 경우의
화면·출력 복원을 보장하지 않으며, 결과를 받지 못한 명령은 자동으로 다시 실행하지 않습니다.

새 기능을 지원하는 TERM APK와 이미지가 함께 필요합니다. APK만 업데이트해도 기존 Ubuntu에
적용되지는 않습니다. 기존 환경은 중지한 뒤 환경 설정의 구성요소 업데이트를 사용하세요.
커널이 달라 전체 이미지 전환이 필요한 경우 기존 전환 제한과 보존 규칙을 따릅니다.
기존 환경과 사용자 데이터는 자동으로 덮어쓰지 않습니다. Docker/LXC 및 ReDroid 커널 지원을 유지합니다.

이미지 제작의 정상 부팅 검사는 세션 중계 포트의 초기 준비를 기다린 후 수행합니다.

이 r2는 현재 승인 ext4-r2 이미지와 커널 해시가 달라 전체 이미지 전환 대상입니다. 기존 환경을 위한 기본 카탈로그에는 승격하지 않았으며, [동일 커널을 사용하는 후속 r3](https://github.com/nolbo/TERM/releases/tag/avf-ubuntu-recovery-20261024-r3)를 사용하세요.
