# TERM 0.4.0 — 프로필 팔레트와 아이콘 관리 개선

- 릴리즈 ID: `dev-4ffa7cc72920f9c766ca76f6f261d73c2a3e763f`
- 출시일: 2026-09-25
- 앱 버전: `0.4.0+dev.1000041.4ffa7cc72920` (`versionCode=1000041`)
- 대상: Android ARM64 APK, Native / Userspace Linux / AVF 공통 UI
- 비교 기준: `0.3.0+dev.1000040.75ab03c303ae`
- 버전 결정: 기존 데이터와 사용법을 유지하는 사용자 기능 추가로 MINOR 승격 (`0.3.0 → 0.4.0`)
- Direct Linux 실험 커밋 22개는 제외하며, 기존 Direct Native는 유지합니다.

## 추가 및 변경

- 프로필마다 전경·배경·커서·ANSI 16색 팔레트를 지정할 수 있습니다. 새 프로필은
  전역 팔레트를 따르며, 초기화하면 전역 설정을 다시 상속합니다. 프로필 전환 시
  터미널과 앱 바의 색상이 함께 부드럽게 전환됩니다.
- 컬러 피커를 채도(가로)·밝기(세로) 사각형과 아래 색조 막대로 교체했습니다.
  HEX 또는 RGB 값을 직접 확인하고 편집할 수 있습니다.
- 사용자가 추가한 프로필 아이콘은 미리보기 확인 후 목록에서 삭제할 수 있습니다.
  기존 프로필·복제본·실행 중인 세션의 이미지 파일은 보존합니다. 같은 이미지를
  다시 추가하면 목록에 복원됩니다. 기본 아이콘은 삭제되지 않습니다.
- 프로필 추가·설정의 아이콘 미리보기를 설정 행 오른쪽에 배치했습니다.
- Native와 Rootless 아이콘의 모서리를 다듬고 Rootless 아이콘을 펭귄 얼굴로 바꿨습니다.

## 사용성 및 수정

- 비선택 탭과 기본 검정 배경의 앱 바 아이콘을 더 차분한 색으로 표시합니다.
- 탭과 추가 버튼 사이에 그라데이션 경계를 적용하며, 맨 오른쪽까지 스크롤하면
  그라데이션을 숨겨 마지막 탭을 가리지 않습니다.
- 탭 클릭 시 모서리 곡률이 변하고 빠르게 복귀하는 애니메이션을 적용했습니다.
- 비활성 설정은 배경 대신 텍스트·아이콘 등 전경을 어둡게 표시합니다.
- 필요한 특권이 없으면 프로필의 실행 환경 선택에서 AVF Debian을 숨깁니다.
  기존 런타임 권한 검사와 저장된 프로필은 유지하고 다른 런타임으로 자동 전환하지 않습니다.
- 아이콘 목록 변경·화면 재생성에서 발견한 Compose 접근성 노드 오류를 수정했습니다.
- 새 Android 권한이나 특권 요구, 보안 경계 변경은 없습니다.

## 업데이트 및 한계

- 기존 서명 앱을 그대로 업데이트할 수 있으며 필수 수동 데이터 이전은 없습니다.
  별도로 설치되는 디버그 앱과 서명 앱의 데이터는 계속 분리됩니다.
- APK 업데이트 전에는 실행 중인 작업을 저장하세요. Android가 프로세스를 종료할 수 있습니다.
- Rootless의 PRoot·커널 제한과 AVF의 지원 기기·특권 요구는 유지됩니다.
- 물리 기기, 특권 AVF 및 실제 서명 배포 앱의 전체 데이터 보존 업그레이드 경로는 미검증입니다.

## 검증

- 동일한 UI·프로필 소스의 로컬 정규 디버그 빌드와 단위 테스트 통과:
  앱 91개, 런타임 185개 중 184개(선택 시험 1개 생략), image 4개,
  terminal-emulator 358개, terminal-view 12개. 로컬 작업 트리에는 배포에서 제외한 Direct Linux 실험이
  남아 있으므로 배포용 분리 소스의 전체 빌드·서명 검증은 CI에서 별도로 수행합니다.
- 배포용 분리 소스에서 업데이트·게시 Python 회귀 검사 19개 통과.
- Android ARM64 에뮬레이터에서 프로필 팔레트·아이콘 테스트 11개 통과.
  Replicant로 아이콘 삭제 취소·확정 및 선택 창 재진입 후 삭제 유지 확인.
- 로컬 저장 공간 부족으로 별도 체크아웃의 전체 생성 산출물을 중복 빌드하지 않았습니다.
- GitHub Actions `36129653113`: 분리한 배포 소스의 전체 빌드·단위 테스트,
  업데이트 회귀 검사, USB 호스트 안전 검사, Rootless payload 검증, 서명 및 게시 성공.
- CI 정규 명령: `./gradlew :android-app:assembleDebug :android-app:testDebugUnitTest
  :android-runtime:testDebugUnitTest :image:test --console=plain`.
