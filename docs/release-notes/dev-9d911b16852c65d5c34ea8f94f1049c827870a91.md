# TERM 0.7.0 개발 버전

- 릴리즈 ID: `dev-9d911b16852c65d5c34ea8f94f1049c827870a91`
- 앱 버전: `0.7.0+dev.1000048.9d911b16852c`
- 출시일: 2026-10-02
- 대상: Android 앱, Native·Rootless·AVF 저장공간 설정

## 추가 및 변경

- 설정에 저장공간 관리 화면을 추가했습니다. 사용 중인 저장공간과 미사용 저장공간을 구분하고 실행 환경, 대략적인 용량, 연결된 프로필 수와 실행 중인 세션 수를 표시합니다. 상세 화면에서 저장공간 이름을 바꾸고 연결된 프로필과 세션을 확인할 수 있습니다.
- 프로필 생성·복제·편집에서 새 독립 저장공간을 선택하거나 호환되는 기존 저장공간을 연결할 수 있습니다. 새 저장공간의 기본 이름은 `Storage for [프로필 이름]`이며 같은 이름이 있으면 번호를 붙입니다. Native·Rootless·AVF 사이와 서로 다른 Rootless 배포판 사이의 연결은 허용하지 않습니다.
- 기존 레거시 환경은 사용 중인 세션이 없고 실행 상태를 확인할 수 있을 때 새 저장공간 모델로 자동 전환합니다. 기존 파일 경로와 데이터, 프로필 연결과 저장공간 이름을 유지하며 파일을 이동하거나 복사하지 않습니다. 실행 중인 세션이 있으면 종료 후 전환합니다.
- 프로필이나 실행 중인 세션이 사용하지 않는 저장공간은 상세 화면에서 직접 삭제할 수 있습니다. 자동 삭제는 하지 않으며, 전환 전 레거시 저장공간은 계속 삭제를 제한합니다.
- 터미널 꾸미기 설정에 전체 화면 프로그램의 배경색에 맞춰 앱 바와 탭 등 터미널 외곽의 색상을 바꾸는 옵션을 추가했습니다.

## 수정

- 터미널 스크롤 기록의 처음이나 끝에 가까워질 때 부드러운 스크롤이 지나치게 감속하는 문제를 수정했습니다.
- 저장공간 설정에서 화면을 벗어날 때 `The coroutine scope left the composition` 오류 알림이 뜨는 문제를 수정했습니다.

## 업데이트 안내 및 제한

- 기존 환경은 별도의 수동 이전 없이 계속 사용할 수 있습니다. 앱 업데이트 중 실행 중인 작업이 중단될 수 있으니 중요한 작업은 먼저 저장하세요.
- 새 독립 저장공간은 기존 데이터를 복사하지 않는 새 환경입니다. 프로필의 저장공간 변경은 이후 생성하는 세션에만 적용되며, 실행 중인 세션과 이전 저장공간은 유지됩니다.
- 이전 버전으로 다운그레이드하면 새 저장공간 모델에 저장한 프로필 변경이 반영되지 않을 수 있습니다. 중요한 파일과 설정은 별도로 백업해 두세요.
- 용량은 파일 크기 합계를 비동기로 계산한 대략적인 값이며 기기의 실제 사용량과 다를 수 있습니다. 이전 Rootless 환경이 공유하던 작업 폴더는 전환 후에도 공유됩니다.
- AVF는 지원 기기와 필요한 권한이 있어야 사용할 수 있습니다. VM의 실행·정지 상태를 확인할 수 없는 경우 레거시 전환이나 저장공간 삭제가 제한됩니다.
- 화면 재진입 시 출력은 유지되지만 일부 상황에서 이전 스크롤 위치를 복원하지 못하는 알려진 문제가 남아 있습니다. 종료된 프로세스는 복원하지 않습니다.
