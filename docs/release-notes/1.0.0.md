# TERM · TERM Preview 1.0.0

- 릴리즈 ID: 1.0.0
- 출시일: 2026-10-19
- 대상: Android ARM64 정식 앱 TERM, 프리릴리즈 앱 TERM Preview, Native·Userspace Linux·AVF 실행환경

## 주요 기능

- 일반 Android 기기에서 Native 셸과 Userspace Linux의 Debian·Ubuntu 24.04 LTS·Arch Linux ARM 환경을 사용할 수 있습니다. 프로필마다 실행환경·셸·시작 명령·아이콘·팔레트를 지정하고 여러 세션을 관리합니다.
- 워크스페이스로 세션을 묶고 여러 시작 구성을 등록할 수 있습니다. 같은 그룹의 터미널 두 개를 상하 또는 좌우로 분할하고 비율과 입력 대상을 조절합니다. 분할을 해제해도 두 세션은 계속 실행되며 화면을 다시 열면 살아 있는 세션의 배치와 선택 상태를 복원합니다.
- 하단 툴바와 단축키의 순서·위치·크기를 편집하고 사용자 글꼴·팔레트·햅틱을 설정할 수 있습니다. 명령 기록에서 명령과 출력을 검색하고, 보관된 출력을 펼쳐 읽거나 복사할 수 있습니다.
- Sixel·kitty 이미지 출력과 확장 키보드 입력을 지원합니다. 세션별 그래픽과 전체 화면 터미널 프로그램의 표시 상태를 유지하며, 선택적으로 긴 작업 완료와 프로그램의 확인 요청을 알립니다.
- 실행환경과 별도로 공유 디렉토리를 만들고 필요한 환경에 연결할 수 있습니다. Native·Userspace Linux의 데이터 백업과 Userspace Linux의 전체 환경 백업을 제공하며, 비밀번호 암호화를 선택할 수 있습니다. 복원은 기존 환경을 덮어쓰지 않고 새 환경을 만듭니다.
- 지원되는 AVF 기기에서는 Debian·Ubuntu·Arch Linux ARM 이미지를 설치하고 패키지 초기화, 공유 디렉토리, Android 내부저장소 연결과 로컬 서비스·포트 전달을 관리할 수 있습니다.
- Android 연동과 USB 접근은 필요한 기능을 명시적으로 허용해 사용합니다. 설정 검색, 실행환경 진단, 메모리 정보, 크래시 리포트와 앱 업데이트 화면에서 상태를 확인할 수 있습니다.

## 정식판과 프리릴리즈 분리

- 정식 앱 **TERM**과 프리릴리즈 앱 **TERM Preview**를 함께 설치할 수 있습니다. 두 앱의 설정·프로필·실행환경·Linux 파일은 각각 따로 보관하며, 각 앱은 자신의 채널에서만 업데이트합니다. 앱 안에서 정식판과 프리릴리즈 사이의 채널을 바꾸는 기능은 제공하지 않습니다.
- 이전 프리릴리즈는 정식 앱과 같은 앱 ID를 사용했습니다. 새 TERM Preview를 설치해도 그 기존 앱과 데이터는 그대로 남으며, Preview는 빈 데이터로 시작합니다. 기존 앱 삭제나 데이터 자동 이전은 수행하지 않습니다.
- 기존 개발 앱의 앱 내 업데이트로는 새 Preview로 전환할 수 없으므로 [GitHub 릴리즈 페이지](https://github.com/nolbo/TERM/releases)에서 TERM Preview APK를 직접 내려받아 별도로 설치하세요.
- 환경을 옮기려면 기존 앱에서 지원되는 환경 백업을 내보낸 뒤 Preview에서 새 실행환경으로 복원하세요. 모든 앱 설정과 실행 중인 세션이 함께 옮겨지는 것은 아닙니다. 가져온 환경과 필요한 파일을 확인하기 전에는 기존 앱을 삭제하지 마세요. 두 앱에서 같은 외부 공유 디렉토리를 연결한 경우 그 파일은 함께 사용합니다.

## 개선 및 수정

- 프로필 편집 중 화면이 재생성될 때 정상적인 작업 취소가 오류 문구로 표시되던 문제를 수정했습니다. 입력 중인 초안은 유지합니다.
- 영어 화면에서 일부 진단·설치 안내와 명령 출력 조작 문구가 한국어로 남던 문제를 수정했습니다.
- 앱 업데이트 다운로드의 진행률·용량 표시가 현재 앱 언어와 숫자 표기를 따르도록 수정했습니다.
- 최근 개발 버전의 세션 탭 이동, 분할 화면, 글꼴·팔레트 표시 개선과 AVF 이미지 설치 시 필요한 임시 저장공간 절감도 포함합니다.

## 기존 사용자 안내

- 프로필 복제는 기본적으로 원본 실행환경을 사용하므로 패키지·홈·파일을 공유합니다. 독립 환경이 필요하면 저장 전에 **새 실행환경 생성**을 선택하세요. 새 실행환경에는 `env-`로 시작하는 기본 이름을 제안하며 직접 입력한 이름은 유지합니다.
- 예전 Userspace Linux의 자동 `/workspace` 연결은 제공하지 않습니다. 기존 파일은 보존하며 공유 디렉토리 설정에서 필요한 데이터를 가져와 연결할 수 있습니다. 해당 경로를 사용하던 프로필·스크립트·링크는 새 공유 경로에 맞게 수정하세요.
- Native의 기존 전역 셸 설정 대신 프로필별 셸 설정을 사용합니다. SideStore 전용 호스트 도구와 Native·Userspace Linux의 로컬 서비스 수동 등록은 제공하지 않으며, 로컬 서비스 관리는 **AVF Linux → 실행 → 로컬 서비스**에서 제공합니다. 이 변경으로 기존 환경의 패키지나 작업 파일을 자동 삭제하지 않습니다.
- 기존 정식 앱의 업데이트는 앱 데이터와 Linux 파일을 유지하지만 실행 중인 작업은 중단될 수 있습니다. 설치 전에 중요한 작업을 저장하고 필요한 데이터를 백업하세요. 이전 버전으로의 다운그레이드는 지원하지 않습니다.

## 지원 범위와 제한

- TERM Preview는 프리릴리즈이며 불안정한 변경을 포함할 수 있습니다. 정식판과 데이터가 자동 동기화되지는 않습니다.
- AVF에는 지원 ARM64 기기와 호환 플랫폼, 실제 가상 머신 권한이 필요합니다. 일반 APK 설치만으로 이 조건을 충족하지 않으며 일반 Android 기기에는 Native·Userspace Linux 경로를 제공합니다.
- 기존 승인 Debian·Ubuntu·Arch Linux ARM 이미지를 유지합니다. 설치된 이미지·패키지·파일을 자동 교체하지 않으며, AVF 전체 디스크 백업과 다른 배포판으로의 자동 변환은 지원하지 않습니다.
- 실제 특권 AVF 기기에서의 부팅·공유 파일 읽기와 쓰기·네트워크 동작, 실제 USB·iPhone 기기 작업의 모든 조합은 이번 배포에서 검증하지 않았습니다. 해당 기능은 기기와 환경의 지원 조건을 확인한 뒤 사용하세요.
