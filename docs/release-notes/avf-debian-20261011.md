# TERM AVF Debian ARM64 공유 디렉토리 및 게스트 서비스

- 릴리즈 ID: avf-debian-20261011
- 출시일: 2026-10-11
- 대상: AVF용 Debian ARM64 이미지

## 변경 및 개선

- 지원 기기의 비보호 VM에서 연결한 공유 디렉토리를 `/mnt/term-shares/폴더이름`으로 직접 연결할 수 있도록 게스트 마운트 서비스와 virtiofs 지원을 포함했습니다.
- Android 공통 내부저장소 접근 권한과 환경별 연결을 허용하면 Android 공유 저장소를 게스트의 `/sdcard`로 연결합니다. 권한이나 연결이 없는 환경에는 해당 경로를 연결하지 않습니다.
- 호스트가 선택한 VM에서 명시적인 파일 전송과 포트 보고·호스트 전달에 사용하는 게스트 서비스를 포함했습니다.
- 설치 시 전체 패키지 목록 초기화, 실패·취소 후 재시도, DHCP·DNS 설정, `/home/droid`와 비밀번호 없는 게스트 `sudo`를 유지합니다.

## 설치 안내 및 제한

- TERM 0.16.0과 함께 사용하는 개발 채널 프리릴리즈입니다. AVF 지원 ARM64 기기, 호환되는 플랫폼 API와 실제 가상 머신 권한이 필요합니다. 직접 공유는 비보호 VM에서만 지원합니다.
- 새 이미지는 신규 AVF 환경에 사용합니다. 기존 설치 이미지·패키지·사용자 파일을 자동 교체하거나 이전하지 않으며, 새 환경이 필요하면 기존 게스트 파일을 먼저 백업하세요.
- 공유 폴더 연결·이름·환경별 내부저장소 연결 변경은 다음 VM 부팅부터 적용합니다. 실행 중인 VM에 새로운 마운트를 추가하거나 사용자 세션을 임의로 다시 시작하지 않습니다.
- 최초 다운로드와 설치에는 인터넷 연결, 압축 해제된 이미지와 설치 임시 파일을 위한 충분한 저장공간이 필요합니다. 설치 시 패키지 목록 초기화는 인터넷 연결과 플랫폼의 VM 네트워크 지원이 필요합니다.
- 실제 AVF 기기의 부팅·vsock·양방향 공유 파일 I/O·DHCP·DNS·인터넷 갱신과 여러 VM의 동시 연결은 이번 배포에서 검증하지 않았습니다. Android 플랫폼의 고정 TAP 인터페이스 오류를 해결하는 이미지는 아닙니다.
