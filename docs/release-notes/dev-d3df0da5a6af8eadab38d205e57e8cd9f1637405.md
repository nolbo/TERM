# TERM Preview 1.2.0 프리릴리즈

- 릴리즈 ID: dev-d3df0da5a6af8eadab38d205e57e8cd9f1637405
- 출시일: 2026-10-21
- 대상: Android ARM64 프리릴리즈 앱 TERM Preview

## 추가 및 개선

- Native Shell에 jq, curl, OpenSSH 클라이언트와 ssh-keygen, ripgrep, Vim을 내장했습니다. 별도 설치 없이 대화형 셸과 `sh script.sh`에서 같은 명령 이름으로 사용할 수 있습니다. Git은 포함하지 않습니다.
- Native의 홈·임시 디렉토리·명령 탐색과 셸 초기화를 정리했습니다. 사용자 설정은 `~/.termrc`, Vim 설정은 `~/.vimrc`에서 관리하며 기존 설정과 파일을 보존합니다.
- Vim에 UTF-8 편집, 문법 강조와 필수 runtime을 제공합니다. curl은 내장 인증서로 HTTPS를 검증하며 SSH는 키 인증·호스트 키 검증·포트 포워딩을 지원합니다.
- Native CLI에서 `terminal-usb storage`로 승인된 저장소를 조회하고 파일을 전송할 수 있습니다. 클립보드 복사는 터미널 설정의 Android 권한에서 사용자가 허용한 뒤 전경 세션에서 사용할 수 있습니다.
- Native 진단에서 내장 도구의 실행 상태, ABI·페이지 크기·환경 변수·저장소 오류를 확인할 수 있습니다.
- Linux 설치 진행 화면과 첫 실행 안내를 정리하고 AVF 이미지 다운로드·상태 복사를 개선했습니다. AVF 복구 기능은 별도 복구 항목에서 찾을 수 있습니다.
- 햅틱을 켜면 고밀도 피드백을 사용합니다. 세션 탭 선택 시 불필요한 자동 스크롤을 제거했습니다.

## 기존 환경과 업데이트

- 기존 프로필·설정·파일과 Native·Userspace Linux·AVF 실행환경을 유지합니다. 앱 업데이트가 설치된 Linux 환경이나 이미지를 자동 교체하지 않습니다.
- 셸 관리 설정과 개인 설정을 분리합니다. `.profile`, `.droid-shrc`, `.vimrc`, 기존 명령 기록 파일을 보존하며, 개인 셸 설정에는 `~/.termrc`를 사용하세요. 앱 내부 스크립트는 `sh script.sh`로 실행하세요.
- 터미널 설정의 내부저장소 접근 항목과 공유 디렉토리의 파일 작업 메뉴를 제거했습니다. 기존 저장소·파일과 실행환경별 연결 설정은 유지합니다.
- TERM과 TERM Preview는 별도 앱과 데이터 영역을 유지합니다. 중요한 작업은 저장한 뒤 앱을 업데이트하세요.

## 지원 범위와 제한

- 내장 CLI는 Android ARM64/Bionic용입니다. Native는 Android 환경이며 일반 Linux 배포판이나 범용 패키지 관리자를 제공하지 않습니다. APK에 포함된 승인 실행 파일만 지원합니다.
- AOSP mksh는 재시작 후 셸 기록을 저장하지 않습니다. 세션 내 기록과 TERM 명령 기록을 사용하거나 영구 셸 기록이 필요하면 Userspace Linux를 사용하세요.
- Native 클립보드는 기본 꺼짐이며 허용된 전경 복사만 지원합니다. 읽기는 기존 붙여넣기 UI를 사용하세요. Vim의 도움말·번역·맞춤법 사전·내장 터미널 작업은 포함하지 않습니다.
- Android 15 ARM64·4 KiB 가상기기에서 Native 도구와 터미널 동작을 확인했습니다. 16 KiB 기기·다른 Android 버전·SELinux enforcing 기기의 실행 검증은 남아 있습니다.
- 기존 승인 AVF 이미지를 유지합니다. 실제 특권 Android AVF의 공유 폴더·업데이트·복구 검증과 물리 USB·탈착식 저장소 검증은 이번 배포에서 수행하지 않았습니다.
