# AVF Ubuntu 이미지 avf-ubuntu-maintenance-20261022-r1

- 배포일: 2026-10-22
- 대상: AVF Ubuntu ARM64

전체 이미지 업데이트에서 기존 환경의 그룹 설정과 새 이미지의 그룹 추가가 함께 있으면 `/etc/group` 충돌로 실패하던 문제를 수정했습니다. 사용자·그룹 및 멤버십 변경을 항목별로 반영하며, 계정 번호나 비밀번호 설정이 실제로 충돌하면 기존 환경을 보존하고 업데이트를 중단합니다.

Docker/LXC 및 ReDroid용 커널 지원을 유지합니다. 64비트 전용 AVF 환경에서는 ReDroid도 64비트 전용 이미지를 사용해야 합니다.

이 이미지를 포함한 최신 TERM 또는 TERM Preview로 앱을 업데이트한 뒤, 기존 AVF 환경을 중지하고 환경 설정에서 이미지 업데이트를 다시 실행하세요. 실패한 환경을 삭제하거나 `/etc/group`을 수동으로 덮어쓸 필요는 없습니다. 새 이미지는 기존 환경에 자동으로 적용되지 않습니다.

그 밖의 설정 충돌이나 패키지 저장소 오류는 업데이트를 중단할 수 있습니다. 전체 이미지 전환 시 `/var/lib`의 애플리케이션 데이터와 사용자 설치 `/usr/local` 파일은 자동 이전되지 않으며 이전 환경에 보존됩니다.
