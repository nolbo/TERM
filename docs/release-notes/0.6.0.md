# TERM 0.6.0 개발 버전

- 출시일: 2026-10-01
- 대상: Android 앱, Native 및 Rootless 터미널

## 추가 및 변경

- Codex CLI와 Neovim 같은 프로그램의 스크롤 및 전체 화면 동작을 위한 VT/xterm 호환성을 확장했습니다. 대체 화면 전환, 커서 저장과 복원, 스크롤 영역, 원점 모드와 줄바꿈 처리를 개선했습니다.
- 앱을 백그라운드로 보냈다가 다시 열거나 화면 프로세스가 다시 생성되어도 실행 중인 세션의 화면과 스크롤 위치를 복원합니다. 일반 화면과 대체 화면, 스크롤 기록, 색상과 문자 속성, 이미지 및 터미널 모드를 함께 유지합니다.
- 업데이트 안내에서 한국어 패치 노트를 Markdown 형식으로 표시합니다.

## 수정

- 전체 화면 프로그램에서 셸로 돌아올 때 이전 화면과 커서 위치가 깨지는 문제를 수정했습니다.
- 화면이 보이지 않는 동안 발생한 출력과 터미널 상태 변경을 반영하고, 화면 복원 중 터미널 질의 응답이 중복되는 문제를 수정했습니다.
- 도구 막대 단축키의 확장 높이와 항목 간격을 개선하고, 세션 알림 제목에서 중복되는 앱 이름을 제거했습니다.
- Rootless 실행의 일부 불필요한 처리 비용을 줄였습니다.

## 업데이트 안내 및 제한

- 기존 설정과 세션 데이터는 유지되며 별도의 데이터 이전은 필요하지 않습니다. 앱 업데이트 중 실행 중인 작업이 중단될 수 있으니 중요한 작업은 먼저 저장하세요.
- 화면 복원은 세션 런타임이 살아 있는 동안 지원됩니다. 앱 강제 종료, 런타임 종료 또는 기기 재부팅으로 종료된 프로세스는 복원하지 않습니다.
- Direct Linux 실험은 일반 실행 환경으로 제공하지 않습니다. Native와 Rootless 실행 환경을 계속 사용하세요.
- AVF는 지원 기기와 필요한 권한이 있는 경우에만 사용할 수 있습니다. AVF의 백그라운드 출력 개선에는 갱신된 게스트 구성 요소가 필요합니다.
