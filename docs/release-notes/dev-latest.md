# TERM 0.5.0 개발 버전

- 출시일: 2026-09-28
- 대상: Android 앱

## 추가 및 변경

- 터미널 아래에 필요한 도구를 골라 배치할 수 있는 도구 막대를 추가했습니다. 단축키,
  명령, 메모리 표시를 설정하고 순서를 바꿀 수 있습니다.
- 자주 쓰는 명령을 도구 막대에서 바로 실행하거나 편집할 수 있습니다.
- 메모리 도구에서 앱과 세션의 메모리 사용량을 확인하고 원하는 세션으로 이동할 수
  있습니다.
- 두 손가락 쓸기 동작과 클립보드 전용 도구를 제거했습니다. 단축키는 새 도구
  막대에서 사용할 수 있습니다.
- 터미널 탭과 도구 막대의 스크롤 끝 표시, 설정 화면의 간격과 애니메이션을
  다듬었습니다.

## 수정

- 앱을 다시 열 때 마지막으로 선택했던 터미널 세션이 표시되도록 고쳤습니다.
- 도구 막대를 편집하거나 스크롤할 때 항목과 페이지 표시가 더 자연스럽게
  움직이도록 고쳤습니다.

## 업데이트 안내

- 기존 설정과 세션 데이터는 유지되며, 별도로 옮겨야 할 데이터는 없습니다.
- 앱 업데이트 중 실행 중인 작업이 중단될 수 있으니 중요한 작업은 먼저 저장하세요.
