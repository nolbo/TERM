# TERM 1.3.1

- 릴리즈 ID: 1.3.1
- 출시일: 2026-10-22
- 대상: Android ARM64 정식 앱 TERM·프리릴리즈 앱 TERM Preview

## 수정 및 개선

- AVF 전체 이미지 업데이트에서 패키지 설치가 끝난 뒤 `/etc/group` 충돌로 실패하던 문제를 수정했습니다. 기존 사용자·그룹 변경과 새 이미지의 독립적인 계정 추가를 항목별로 반영합니다.
- 계정 번호 중복, 비밀번호 설정 충돌 등 안전하게 병합할 수 없는 변경은 기존 환경을 보존한 채 중단합니다. 다른 설정 파일의 충돌 검사와 이전 이미지 복구 기능도 유지합니다.
- Ubuntu·Debian·Arch Linux의 승인 이미지에 같은 수정을 적용하고 기존 Docker/LXC 및 ReDroid용 커널 지원을 유지합니다.
- 설치·다운로드 안내 창의 제목을 가운데 정렬하고 아이콘을 추가했습니다. AVF 복구와 터미널 설정 설명을 간결하게 정리했습니다.

## 업데이트 방법

- 설치된 채널에 맞춰 TERM 또는 TERM Preview를 업데이트한 뒤, AVF 환경을 중지하고 해당 환경의 이미지 업데이트를 다시 실행하세요. 실패한 환경을 삭제하거나 `/etc/group`을 수동으로 덮어쓸 필요는 없습니다.
- 앱 업데이트는 기존 Linux 환경을 자동 교체하지 않습니다. 이미지 업데이트가 성공하면 이전 이미지와 사용자 상태가 복구용으로 보관됩니다.
- 전체 이미지 전환 시 `/var/lib`의 애플리케이션 데이터, 사용자 설치 `/usr/local` 파일과 `/.droid/state/term-redroid-test`에 둔 Docker·ReDroid 시험 데이터는 자동 이전되지 않으며 이전 환경에 보존됩니다. 중요한 데이터는 실행 전에 별도로 보관하세요.
- 실제 기기에서의 전체 이미지 전환·복구 검증은 추가로 필요합니다. Debian·Arch 실제 AVF에서의 Docker/LXC·ReDroid 실행 검증 범위도 이전 배포와 같습니다.
