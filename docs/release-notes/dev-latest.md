# TERM 0.10.0 개발 버전

- 릴리즈 ID: dev-latest
- 출시일: 2026-10-03
- 대상: Android 앱, AVF 실행 환경 및 Debian 이미지 설정

## 추가 및 수정

- 공개 Debian ARM64 이미지를 디버그 앱과 배포 앱의 자동 설치 대상으로 등록했습니다. 지원 제품에서는 첫 AVF 세션을 만들면 이미지를 자동으로 내려받고 검증·설치한 뒤 세션을 시작하며, 이미지 파일을 직접 준비할 필요가 없습니다.
- 설정의 Debian 이미지 화면에서 등록된 자동 설치 이미지와 기기의 AVF 지원 상태를 확인할 수 있습니다.
- 이미 설치한 AVF 이미지와 작업 파일은 자동 설치로 교체하지 않습니다.

## 업데이트 안내 및 제한

- 기존 설정·프로필·작업 파일은 유지되며 수동 이전은 필요하지 않습니다. 업데이트 중 실행 중인 작업이 중단될 수 있으니 중요한 작업은 먼저 저장하세요.
- 최초 설치에 인터넷 연결과 이미지용 저장공간 약 14GiB가 필요합니다. 설치 임시 공간과 이후 작업 파일을 저장할 여유도 확보하세요.
- 필요한 AVF 플랫폼 기능과 권한이 없는 기기에서는 기존 Native·Rootless 환경을 계속 사용할 수 있습니다.
- AVF 실행에는 지원 기기, 호환되는 플랫폼 API 및 실제 가상 머신 권한이 필요합니다. APK 설치만으로 이 권한을 얻을 수 없으며 AVF 실기기 실행 검증은 아직 완료되지 않았습니다.
- 개발 채널 프리릴리즈입니다.
