# TERM 0.8.1 개발 버전

- 릴리즈 ID: dev-latest
- 출시일: 2026-10-03
- 대상: Android 앱, 터미널 UI 및 세션 도구

## 변경 및 수정

- 툴바의 크기를 조절할 때 터미널 내용이 위아래로 떨리던 문제를 수정했습니다. 크기 조절이 끝나면 터미널의 마지막 행을 툴바 위에 맞춥니다.
- 세션 도구는 기존 기본 높이를 유지하면서 기본 상태에서는 헤더만 표시합니다. 왼쪽에는 현재 탭의 제목을 표시하며, 사용자 지정 제목이 있으면 원래 제목도 함께 보여줍니다. 오른쪽의 새 세션·설정 버튼은 그대로 사용할 수 있습니다.
- 툴바를 확장하면 헤더 아래에 탭 목록이 나타납니다. 펼치고 접는 동안 헤더가 부드럽게 이동하고 목록이 서서히 나타나거나 사라지며, 직접 스크롤한 목록 위치를 유지합니다.
- 전환 중 일부만 보이는 탭에서 실수로 세션을 바꾸거나 종료하지 않도록 탭 조작은 완전히 확장됐을 때 활성화합니다.

## 업데이트 안내 및 제한

- 기존 설정·프로필·작업 파일은 유지되며 수동 이전은 필요하지 않습니다. 업데이트 중 실행 중인 작업이 중단될 수 있으니 중요한 작업은 먼저 저장하세요.
- 다른 탭으로 전환하거나 탭 제목을 편집·종료하려면 하단 핸들로 툴바를 확장하세요.
- 개발 채널 프리릴리즈입니다. AVF는 지원 기기와 필요한 권한이 있어야 사용할 수 있습니다.
