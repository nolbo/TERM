# TERM 0.16.0 개발 버전

- 릴리즈 ID: dev-latest
- 출시일: 2026-10-11
- 대상: Android ARM64 앱, Native·Userspace Linux·AVF 실행환경

## 변경 및 개선

- 진단 및 리포트를 런타임·시스템·리포트 범주로 정리하고, Native·Userspace Linux·AVF·메모리·크래시 기록을 각각 독립된 화면에서 확인하도록 개선했습니다.
- 메모리 진단에서 장치 전체 사용량과 앱·프로세스 사용량을 비율 막대로 표시하고, 세부 메모리 구성을 색상 구간과 범례로 확인할 수 있도록 했습니다. 측정할 수 없거나 합계와 맞지 않는 구성은 확인 불가로 표시합니다.
- 크래시 리포트 상세에서 선택한 기록을 확인 후 삭제할 수 있습니다. 취소하면 기록을 유지하며 삭제에 실패하면 오류를 표시합니다.
- 전체 화면 TUI가 화면을 다시 칠하며 테마를 바꿀 때 터미널 주변 색상을 갱신하고, 버튼·탭·모달의 동적 색상과 대비를 개선했습니다. 빈 워크스페이스에서도 세션 툴바를 사용할 수 있습니다.
- 중첩 Bash 셸에서 명령 기록이 빠지거나 이전 명령에 연결되던 문제를 수정했습니다.
- Native 실행환경을 만들 때 실제 Android 내부저장소 접근 권한을 확인하고 권한 설정을 열 수 있도록 했습니다.
- 프로젝트가 Termux를 기반으로 하며 GPLv3-only로 배포됨을 명시했습니다.
- 새 AVF Debian 이미지의 직접 공유 폴더·Android 공유 저장소 연결과 파일 전송·포트 보고용 게스트 서비스를 함께 제공합니다.

## 제거된 기능 및 호환성 변경

- 명령 세트 툴을 제거했습니다. 기존 설정에 남은 도구는 툴바에서 제외하며 다른 도구의 순서와 사용 여부는 유지합니다. 명령 세트 편집기는 제공하지 않습니다.
- 툴바의 메모리 도구를 제거했습니다. 장치·앱 메모리는 진단 및 리포트의 메모리 화면에서, 개별 세션 메모리는 세션 정보에서 확인합니다.
- 전역 Native 기본 셸 선택 설정을 제거했습니다. Native 내장 프로필은 `/system/bin/sh`를 기본 셸로 사용하며 이전 전역 셸 선택값은 더 이상 적용하지 않습니다.

## 업데이트 안내 및 제한

- 개발 채널 프리릴리즈입니다. 기존 프로필·워크스페이스·실행환경·공유 폴더·작업 파일을 유지하며 업데이트 전에 실행 중인 중요한 작업을 저장하세요.
- 새 AVF 이미지 `avf-debian-20261011`은 신규 AVF 환경에 사용합니다. 기존 설치 이미지·패키지·파일을 자동 교체하거나 이전하지 않습니다. 새 이미지의 기능이 필요하면 기존 파일을 먼저 백업하고 새 AVF 환경을 준비하세요.
- AVF 직접 공유와 Android 공유 저장소 연결에는 호환되는 비보호 AVF 플랫폼과 실제 가상 머신 권한이 필요합니다. 연결과 권한 변경은 다음 VM 부팅부터 적용하며 기존 VM을 임의로 다시 시작하지 않습니다. Android 공통 내부저장소 권한을 해제하면 해당 저장소를 공유하던 VM은 중지합니다.
- 실제 AVF 기기의 부팅·vsock·공유 파일 읽기와 쓰기·DHCP·DNS·인터넷 갱신은 이번 배포에서 검증하지 않았습니다. 일반 APK가 AVF 특권이나 플랫폼 기능을 새로 얻는 것은 아닙니다.
