# TERM 개발 채널 — 가속 이전 실패 진단

- 릴리즈 ID: `dev-latest` (개발 채널 이동 태그)
- 날짜: 2026-09-20
- 대상: TERM Android ARM64 APK, Rootless 가속 형식 이전
- 변경 범위: `dev-70c0c6a89be01fbe7053a5b0ebdc551e8c2ad9b6` 이후

## 변경 사항

- 하드링크 생성 시험 실패 시 설정의 배포판 오류 영역에 실패 단계, 예외 종류, 운영체제의 원래 이유와 하위 예외를 표시합니다. 운영체제가 제공하는 경우 `EPERM` 등 errno도 확인할 수 있습니다.
- 기기 정책이나 하드링크 미지원으로 원인을 단정하던 안내를 수정했습니다. 상세 이유가 없는 경우에도 그 사실을 표시합니다.
- 진단은 기존 오류 화면에 표시되며 별도 영구 로그나 자동 외부 전송은 없습니다. NIO 오류의 임시 시험 파일 절대 경로는 생략합니다.
- 기존 파일 가속, stdio 버퍼링, rename 최적화 및 가속 형식 이전 기능을 유지합니다.

## 업데이트 및 제한

앱 업데이트 후 모든 세션과 외부 작업 폴더 쓰기를 종료하고 가속 형식 이전을 다시 시도하세요. 실패하면 진단 정보와 앱 버전·Android 버전·기기 모델을 함께 보고할 수 있습니다. 기존 배포판과 파일은 유지되며 삭제·재설치할 필요가 없습니다.

이번 변경은 실패 원인을 확인하기 위한 진단 개선이며 하드링크 실패 자체를 해결했다고 주장하지 않습니다. 사용자 Android 17 / SM-S947N에서의 실제 원인은 아직 확인되지 않았습니다.

## 검증

- 가속·stdio 프로필로 canonical `:android-app:assembleDebug :android-runtime:testDebugUnitTest :image:test` 및 `:android-runtime:assembleDebugAndroidTest` 성공.
- runtime 단위 테스트 161개 중 160개 통과, 기존 선택적 테스트 1개 건너뜀. image 4개 통과.
- Android MCP: API 35 별도 시험 APK에서 실제 NIO 오류 이유의 메시지 보존, 기존 파일 유지, 이전 임시 상태 정리 검증 1개 통과. 사용자 앱은 교체하지 않았습니다.
- UI 레이아웃·상호작용은 변경하지 않았으며 화면 조작 재시험은 수행하지 않았습니다. 실제 Android 17 기기의 원인 재현과 공개 APK CI 결과는 이 로컬 검증에 포함하지 않습니다.
