# TERM 개발 채널 — 단축키와 프로필 편집 개선

- 릴리즈 ID: `dev-latest`
- 앱 버전: CI 실행 시 부여되는 개발 채널 버전
- 출시일: 2026-09-23
- 대상: Android ARM64 APK, Native / Rootless Linux / AVF
- 비교 기준: `0.1.0+dev.1000037.24c5c0901ea6`

## 변경 사항

- 터미널 단축키 사용 스위치를 추가했습니다. 끄고 저장하면 하단 버튼을 숨기며, 다시 켜면 기존 배치가 복원됩니다. 기존 설정은 켜짐을 유지합니다.
- 단축키 드래그의 삽입 위치를 선으로 표시하고 대상 변경 시 진동을 제공합니다. 떠오른 키의 크기·그림자·투명도와 삽입선 이동에 Material 3 Expressive 애니메이션을 적용했습니다.
- 프로필 이름·셸·인수·경로·시작 명령·환경 변수를 화면에서 직접 편집하도록 바꿨습니다. 실행 환경·배포판·저장공간은 선택 대화상자를 사용합니다.
- 프로필 복제·삭제를 명확한 버튼으로 구분하고, 미저장 변경이 있으면 저장 후 복제하도록 안내합니다.
- 터미널 팔레트 편집 화면을 추가했습니다. 색상 견본과 미리보기, 색조·채도·밝기 슬라이더 및 HEX 입력으로 색을 조절하고 저장합니다.

## 업데이트 및 제한 사항

- 별도 데이터 이전은 필요하지 않습니다. APK 업데이트 전 실행 중인 작업을 저장하세요.
- 단축키 표시 여부와 편집 내용은 설정 화면의 저장을 눌러 적용합니다.
- Android 권한과 실행 환경 보안 경계 변경은 없습니다. AVF는 지원 기기와 특권 구성이 필요합니다.

## 검증

- 로컬 표준 빌드 및 앱 단위 테스트 통과: `:android-app:assembleDebug :android-app:testDebugUnitTest :android-runtime:testDebugUnitTest :image:test`.
- Android 15 ARM64 대상에서 android·replicant MCP로 단축키 드래그 표시, 순서 변경과 취소, 사용 스위치 저장·복원 및 Native 세션의 버튼 숨김·복원을 확인했습니다.
- 같은 대상에서 프로필 직접 입력 필드와 미저장 변경 폐기 확인을 검증했습니다.
- 이번 작업에서 팔레트 편집기 전체 UI 시나리오, AVF 특권 통합 및 실제 USB 장치 검증은 실행하지 않았습니다.
- 게시 CI는 빌드·단위 테스트·USB 호스트 안전 회귀 검사, 서명 APK 및 고정 Rootless 런타임 검증을 통과한 뒤 공개합니다.
