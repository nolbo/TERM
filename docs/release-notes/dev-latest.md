# TERM 개발 채널 — 세션 알림 유지 및 프로필 설정 UI 개선

- 릴리즈 ID: `dev-latest`
- 앱 버전: CI 실행 시 부여되는 개발 채널 버전
- 출시일: 2026-09-22
- 대상: Android ARM64 APK, Native / Rootless Linux / AVF
- 비교 기준: 개발 채널 `0.1.0+dev.1000036.bf122830d9a3`

## 변경 사항

- 실행 중인 세션을 알리는 상시 알림을 삭제해도 세션이나 진행 중인 작업이 남아 있으면 다시 표시합니다. 알림을 누를 때 자동으로 지워지지 않으며 마지막 세션과 작업 종료 시 정상적으로 사라집니다.
- 프로필 관리 목록을 공통 설정 행으로 정리하고, 추가·편집 화면에 공통 섹션 카드와 입력·라디오 선택 대화상자를 적용했습니다.
- 실행 환경·배포판·저장공간 선택과 텍스트 편집은 대화상자에서 화면 초안에 반영하고, 화면 전체 저장으로 확정합니다. 취소 시 기존 값을 유지하며 화면 재생성 시 대화상자 초안도 복원합니다.

## 업데이트 및 제한 사항

- 별도 데이터 이전은 필요하지 않습니다. APK 업데이트 전 실행 중인 작업을 저장하세요.
- Android 14 이상은 OS 정책상 개별 스와이프 삭제 자체를 막을 수 없어 삭제 후 다시 표시합니다. 알림 차단이나 앱 강제 종료 시 표시를 보장하지 않습니다.
- 알림의 **모든 세션 종료**는 실행 중인 작업을 즉시 종료합니다. 단순 알림 삭제는 세션을 종료하지 않습니다.
- Android 권한·실행 환경 보안 경계 변경은 없습니다. AVF는 기존과 같이 지원 기기와 특권 구성이 필요합니다.

## 검증

- 로컬 표준 빌드(`:android-app:assembleDebug :android-runtime:testDebugUnitTest :image:test`) 및 앱 단위 테스트 통과.
- Android 15 ARM64 기기에서 세션 알림 instrumentation 2개 통과: UI 분리 후 삭제 콜백 복구, 마지막 세션 종료 후 알림 제거, 늦은 콜백의 빈 알림 재생성 방지, 전체 세션 종료.
- android·replicant MCP로 스와이프 후 알림 표시와 **모든 세션 종료** 후 알림·포그라운드 유지 해제를 확인했습니다.
- Android 15 기기에서 프로필 instrumentation 7개 통과: 편집·저장공간 선택, 삭제 확인, 초안 복원 및 세션 유지. 최초 실행은 알림 창이 열린 상태에서 도구 타임아웃으로 결과를 확보하지 못해 알림 창을 닫고 파일 로그 방식으로 재실행했습니다.
- AVF 특권 통합 및 실제 USB 장치 검증은 실행하지 않았습니다.
- 게시 CI는 빌드·단위 테스트·USB 호스트 안전 회귀 검사, 서명 APK와 고정 Rootless 런타임 검증을 통과한 뒤 배포합니다.
