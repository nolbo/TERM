# TERM 0.11.0 개발 버전

- 릴리즈 ID: dev-latest
- 출시일: 2026-10-04
- 대상: Android 앱, AVF 실행 환경 및 Debian 이미지 설정

## 추가 및 수정

- Debian 이미지의 다운로드·검증·설치 단계를 진행률과 함께 표시합니다. AVF 프로필을 열면 세션 탭을 바로 추가하고 준비하는 동안 로딩 인디케이터를 표시합니다.
- 호환되는 기기에서 AVF 프로필과 기본 프로필을 실행하지 못하던 문제를 수정하고, 시작할 때 이미지 검증을 중복 수행하지 않도록 개선했습니다.
- AVF의 호스트 이름을 `localhost`로 설정하고 기본 시작 디렉터리를 `droid`의 홈인 `/home/droid`로 변경했습니다. 사용자가 지정한 다른 시작 경로와 기존 작업 파일은 유지합니다.
- 새로 설치하는 AVF 환경에 `sudo`와 APT 초기 설정을 수정한 Debian 이미지를 제공합니다. `droid` 사용자는 비밀번호 없이 `sudo apt update`와 `sudo apt install`로 VM 내부의 패키지를 관리할 수 있습니다. 기존 이미지는 자동으로 교체하거나 수정하지 않습니다.
- 터미널 설정에서 Native·Rootless를 포함한 백그라운드 실행 정책과 Android 배터리 최적화 제외를 관리할 수 있습니다. 기본 정책은 세션이나 작업이 있는 동안 실행을 유지하도록 변경하며, 직접 선택한 기존 정책은 보존합니다.
- 여러 AVF VM을 네트워크와 함께 시작할 때 플랫폼의 고정 TAP 인터페이스 제한이 발생하면 원인을 안내합니다.

## 업데이트 안내 및 제한

- 기존 설정·프로필·작업 파일은 유지되며 수동 이전은 필요하지 않습니다. 업데이트 중 실행 중인 작업이 중단될 수 있으니 중요한 작업은 먼저 저장하세요.
- 최초 설치에 인터넷 연결과 이미지용 저장공간 약 14GiB가 필요합니다. 설치 임시 공간과 이후 작업 파일을 저장할 여유도 확보하세요.
- 필요한 AVF 플랫폼 기능과 권한이 없는 기기에서는 기존 Native·Rootless 환경을 계속 사용할 수 있습니다.
- AVF 실행에는 지원 기기, 호환되는 플랫폼 API 및 실제 가상 머신 권한이 필요합니다. APK 설치만으로 이 권한을 얻을 수 없으며 새 이미지의 AVF 실기기 실행 검증은 아직 완료되지 않았습니다. 여러 VM의 동시 인터넷 연결은 Android 플랫폼 지원에 달려 있습니다.
- 백그라운드 실행 유지와 배터리 최적화 제외는 배터리 사용량을 늘릴 수 있습니다. 강제 종료·메모리 부족·제조사 제한·통신망 변경으로 인한 중단까지 막지는 못합니다.
- 개발 채널 프리릴리즈입니다.
