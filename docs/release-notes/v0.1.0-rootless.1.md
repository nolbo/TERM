# v0.1.0-rootless.1

- 출시일: 2026-09-18
- 종류: Rootless 파일 작업 최적화 1차 프리릴리즈
- 대상: TERM Android ARM64 APK, Rootless Debian의 가속 프로필
- 소스: `nolbo/terminal`의 동일 이름 태그. APK 배포: `nolbo/TERM`.
- 범위: 직전 main 배포 `fa20f3345141` 이후의 Rootless 최적화 누적 변경.
  Native 및 AVF에 대한 새 성능 향상을 주장하지 않는다.

## 추가·변경·수정

- native hardlink와 경로/자격 정보 공유, guest glibc DSO를 통해 stat, open,
  파일 생성·삭제와 제한된 close 처리의 PRoot 왕복을 줄였다.
- 검증된 조건에서 identity, TCGETS, rename 및 권한 처리의 중복 추적을 줄였다.
- ARM64 fchmodat2 처리를 수정해 GNU tar 추출 후 디렉터리 권한 복원을 지원한다.
- 가속 Debian 설치에 공식 nscd를 포함한다. 서비스가 passwd/group 캐시 데몬을
  관리하고 세션 간 재사용한다. 데몬 실패 시 직접 조회로 돌아가며 다음 세션에서 재시작한다.
- 서명 전 후보 APK의 버전·소스 커밋·해시를 확인하는 프리릴리즈 서명 경로를 추가했다.

## 보안과 수명

공유 자격/경로 정보는 읽기 전용으로 제공하고, 원래 syscall의 seccomp 제한을
유지한다. 새 Android 권한이나 특권은 요구하지 않는다. NSS 보조 프로세스에는
소유 파이프와 PTRACE_O_EXITKILL을 적용해 소유자 종료 뒤 고아 프로세스가 남지
않도록 했다. 일반 터미널 세션에 이 강제 종료 정책을 적용하지 않는다.

## 성능

동일 조건에서 기존 엔진 대비 8개 작업의 동일 가중 기하평균 **1.86배**.
메타데이터 **5.13배**, 작은 파일 읽기 **5.28배**, tar 추출 **2.27배**.
순차 읽기·쓰기는 약 0.98배로 개선이 없다. 전체 2배 목표는 달성하지 못했다.

API 35 ARM64 redroid/ext4, 따뜻한 캐시, 작업당 3회 중앙값이다.
실제 휴대전화나 전체 앱 실행 시간의 결과가 아니다.
[전체 측정 조건·8개 결과·제한](../ROOTLESS_PHASE1_REPORT.ko.md)을 참고한다.

## 업그레이드와 호환성

- 기존 배포와 같은 앱 ID 및 서명 키를 사용한다. 이 APK는 dev 채널 식별자를 사용하지만, 가속 프로필은 별도 수동 설치 프리릴리즈로
  배포한다. 기존 자동 업데이트 포인터를 바꾸지 않는다.
- 가속 프로필은 native-hardlink rootfs 표식이 필요하다. 기존 link2symlink 방식
  rootfs는 자동 변환하지 않으며 실행을 거부한다. 작업 파일·설정·패키지 목록을
  백업하고 새 Debian 환경으로 준비한 뒤 필요한 데이터를 복원해야 한다.
  기존 데이터를 지우기 전에 백업을 확인해야 한다.
- 이미 native-hardlink 환경이지만 nscd가 없으면 직접 NSS 조회가 유지된다.
  환경 준비/복구로 공식 nscd를 설치할 수 있다.
- fork/스레드 생성 후에는 다음 exec까지 close 가속이 해제된다.
  지원하지 않는 경로와 FD는 기존 PRoot 처리로 돌아간다.
- ptrace, fake-root, mount, namespace, cgroup, systemd 제한은 그대로다.

## 검증

통과: 가속 프로필의 `:android-app:assembleDebug`,
`:android-runtime:testDebugUnitTest`, `:image:test`,
`:android-runtime:assembleDebugAndroidTest`.
가속 프로필의 `:android-app:assembleRelease`(JDK 21, 서명 전 후보),
업데이트 도구 단위 테스트 16개, 서명 스크립트 문법 및 워크플로 YAML 검사도 통과했다.
Android MCP를 통한 새 Debian 설치 시험(88.711초, 1개), 실제 PTY의 NSS 공유 캐시,
fchmodat2 및 tar 권한 복원, 가속 경로 사용 검증이 통과했다.
네이티브 소유자 종료/파이프 시험 7개, NSS 캐시 갱신·동시 조회·데몬 실패 시험,
최종 성능 작업 48개 내용 검증도 통과했다.

최종 서명 APK의 해시와 서명 검증 결과는 릴리즈 첨부 `SHA256SUMS` 및
`signing-verification.txt`에 제공한다. 서명 전 후보는 공개 배포하지 않는다.

미실행: 실제 휴대전화/F2FS·차가운 캐시·배터리·장시간 부하,
Android 서비스 강제 종료의 전체 UI 시나리오, 권한이 필요한 AVF 통합 체크리스트.
이 프리릴리즈의 수치는 해당 항목 통과를 의미하지 않는다.
