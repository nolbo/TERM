# TERM 0.8.2 개발 버전

- 릴리즈 ID: dev-71a3be77ce467cf391d2ee2070e166c91aed25e5
- 앱 버전: 0.8.2+dev.1000051.71a3be77ce46
- 출시일: 2026-10-03
- 대상: Android 앱, Native·Rootless·AVF 실행 환경, 터미널 화면 및 세션 도구

## 변경 및 수정

- ‘활성 작업 유지’ 전원 정책에서 명령 입력을 기다리는 셸의 불필요한 절전 방지를 줄였습니다. 명령 실행 상태를 확인할 수 있는 셸에서는 출력이 없는 장시간 명령도 작업이 끝날 때까지 보호합니다.
- 앱을 잠깐 전환하면 터미널 화면을 빠르게 이어서 볼 수 있으며, 백그라운드에 오래 머무르면 화면 처리에 사용하는 전력을 줄입니다. 실행 중인 세션과 출력은 유지하고 복귀 시 화면·스크롤 기록·전체 화면 프로그램·그래픽·스크롤 위치를 복원합니다.
- 연결에 실패했을 때 재시도 간격을 점차 늘려 반복 접속으로 인한 배터리 사용을 줄였습니다. 연결 성공이나 사용자 작업에는 즉시 다시 대응하며, 유지할 세션이나 작업이 없으면 재시도를 중단합니다.
- USB·호스트 도구·메모리 화면의 갱신을 화면이 보일 때만 수행하고, 변화가 없는 상태에서는 갱신 간격을 늘렸습니다. 많은 출력이 발생할 때 터미널 화면 갱신을 모으고, 보이지 않는 터미널의 그래픽 애니메이션을 멈춥니다.
- 서명 배포 앱에서 Native·Rootless 세션의 메모리 사용량이 표시되지 않던 문제를 수정했습니다.

## 업데이트 안내 및 제한

- 기존 설정·프로필·작업 파일은 유지되며 수동 이전은 필요하지 않습니다. 업데이트 중 실행 중인 작업이 중단될 수 있으니 중요한 작업은 먼저 저장하세요.
- 명령 실행 상태를 알릴 수 없는 셸은 최근 입력·출력 이후 최대 10분 동안 ‘활성 작업 유지’의 절전 방지를 적용합니다. 이런 셸에서 출력 없는 장시간 작업이나 셸이 상태를 알리지 않는 백그라운드 작업을 계속 보호하려면 ‘항상 깨어 있음’을 선택하세요.
- 개발 채널 프리릴리즈입니다. AVF는 지원 기기와 필요한 권한이 있어야 사용할 수 있습니다.
