# TERM AVF Arch Linux ARM 디버그 이미지 후보

- 릴리즈 ID: avf-archlinux-debug-20261012-r5
- 대상: 새 AVF Arch Linux ARM 환경

## 변경 및 개선

- Userspace Linux와 동일한 체크섬 고정 Arch rootfs를 기반으로 AVF 이미지를 제작했습니다. 공통 AVF 커널·초기 부팅층과 Arch의 pacman 데이터베이스를 사용합니다.
- Debian과 같은 설치·환경 관리 흐름, 게스트 터미널·파일 전송·포트 보고 서비스를 제공합니다. 기본 계정과 홈 파일을 `droid`로 정리하고 UID/GID 1000과 sudo를 검증했습니다.
- 설치 시 pacman 저장소 데이터베이스를 초기화하며 실패 후 재시도를 지원합니다. 영속 쓰기 계층, 직접 공유 디렉토리, Android 공유 저장소 연결과 DHCP·DNS 설정을 포함합니다.
- 재부팅 검사의 동일 버전 테스트 패키지가 같은 바이트로 생성되도록 수정해 pacman 캐시를 재사용하는 상황도 검사합니다.

## 검증 및 설치 안내

- 오프라인 QEMU에서 두 차례 부팅하며 영속성, 실제 pacman 패키지 설치·삭제, 초기화 실패·성공·재실행을 검사했습니다. 압축 이미지와 원본 이미지의 해시 및 제작 출처를 검증했습니다.
- 디버그 APK에는 이미지 다운로드용 카탈로그를 포함합니다. 온라인 설치에는 이 후보의 공개 이미지 게시와 인터넷 연결이 필요합니다.
- Arch 이미지는 Arch 환경에만 설치합니다. 기존 Debian 환경이나 사용자 파일을 자동 교체하거나 이전하지 않습니다. 일반 패키지 업그레이드에는 전체 `pacman -Syu`를 사용합니다.
- 실제 AVF 기기의 부팅·vsock·공유 파일 I/O·DHCP·DNS·인터넷 패키지 갱신은 확인하지 못했습니다. AVF 지원 ARM64 기기와 호환 플랫폼 API, 실제 VM 권한이 필요합니다.
