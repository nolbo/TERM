# TERM 0.15.0 개발 버전

- 릴리즈 ID: dev-ac1829d4bf6fc69e59efab9bde5573df25f7d220
- 출시일: 2026-10-10
- 대상: Android ARM64 앱, Native·Userspace Linux·AVF 실행환경

## 추가된 기능

- **설정 → 워크스페이스**에서 세션을 워크스페이스로 묶고, 이름·아이콘·순서·실행 구성을 관리할 수 있습니다. 세션 툴에서 미소속 세션 또는 원하는 워크스페이스를 선택하며, 실행 중인 탭을 다른 그룹으로 옮겨도 작업은 계속됩니다. 임시 워크스페이스도 만들고 영구 그룹으로 저장할 수 있습니다.
- 워크스페이스마다 **시작 시 실행**할 구성을 여러 개 선택할 수 있습니다. 세션이 없는 그룹을 처음 열면 선택한 구성을 순서대로 시작하고, 화면을 다시 열거나 재생성해도 중복 실행하지 않습니다. 이름을 지정한 구성은 탭의 사용자 지정 이름으로 표시하며, 이름을 비우면 프로필의 기본 제목을 사용합니다. 원본 프로필은 바꾸지 않습니다. 빈 영구 워크스페이스의 **기본 세션 실행** 버튼으로 선택한 구성을 다시 시작할 수도 있습니다.
- **설정 → 공유 디렉토리**에서 실행환경과 독립적인 공유 폴더를 만들고 여러 환경에 연결할 수 있습니다. Native에서는 표시된 호스트 경로나 `TERM_SHARED_FOLDERS`를, Userspace Linux에서는 `/mnt/term-shares/이름`을 사용합니다. 새 연결은 새 세션부터 적용되며 기존 세션의 경로는 유지합니다. 예전 작업 폴더를 원본 보존 상태로 가져오거나 ZIP으로 내보낼 수도 있습니다.
- Native·Userspace Linux 환경의 **백업 만들기**와 **설정 → 실행환경 → 백업 및 복원**을 추가했습니다. 홈·설정 파일을 보관하는 Data Backup과 설치된 Linux 배포판·패키지까지 보관하는 Full Environment Backup을 지원하며, 비밀번호 암호화와 프로필 포함 여부를 선택할 수 있습니다. 복원은 기존 환경을 덮어쓰지 않고 새 실행환경을 만듭니다.
- **설정 → 로컬 서비스**에서 Native·Userspace Linux 서비스를 등록하고 실행환경별로 확인할 수 있습니다. 접속 주소·포트를 복사하고, HTTP/HTTPS를 지정한 서비스는 브라우저로 열 수 있습니다. 호환되는 AVF 이미지에서는 리스너와 Android 전달 포트 상태를 확인하고 호스트 포트를 변경할 수 있습니다. 화면을 닫거나 등록을 삭제해도 세션을 종료하지 않습니다.
- 명령 기록 도구에서 각 명령의 출력을 펼쳐 읽고 스크롤하거나 텍스트를 선택할 수 있습니다. 명령 행의 복사 버튼으로 명령을 복사하며, 출력 선택 뒤에는 잠시 표시되는 복사 버튼을 사용할 수 있습니다. 실행 중인 명령의 출력도 갱신됩니다.

## 수정 및 개선

- 미설치 프로필의 아이콘에 다운로드 표시를 추가하고, 설치 상태와 프로필 아이콘을 함께 알아보기 쉽게 다듬었습니다.
- 워크스페이스·프로필에서 같은 기본 아이콘 목록을 제공합니다. 아이콘 선택의 **확인**과 실행 구성 편집은 초안에 반영하며, 워크스페이스의 전체 **저장**에서 함께 적용합니다. 공유 디렉토리 만들기·편집도 별도 설정 화면에서 이름과 연결 환경을 함께 저장합니다.
- 터미널의 톱니바퀴 버튼으로 설정을 바로 엽니다. 앱을 실행하면 미소속 세션을 기본으로 선택하고, 화면 재생성·서비스 재연결과 세션 알림으로 연 워크스페이스는 유지합니다. 이전의 **모든 세션** 선택 항목은 제거됩니다.
- 세션 툴을 확장하면 현재 워크스페이스 또는 미소속 세션을 **모두 닫기**로 종료할 수 있습니다. 실행 중인 작업도 종료되므로 확인 후 사용하세요. 비어 있는 임시 워크스페이스에서는 그룹 삭제 버튼을 제공합니다. 빈 그룹에서는 세션 툴을 유지하고 세션이 생기면 다른 도구로 전환할 수 있습니다.
- 프로필 아이콘 설정의 새 이미지 가져오기는 제거했습니다. 이미 가져온 아이콘과 기존 프로필·세션의 표시는 유지합니다.
- Userspace Linux와 AVF의 설치 확인·진행 화면을 통일했습니다. 현재 단계, 단계별 완료·실패 상태와 진행률을 확인하고 취소하거나 재시도할 수 있으며 화면을 닫아도 설치 작업은 계속됩니다.
- 선택한 세션의 이름 변경·워크스페이스 이동을 메뉴에서 제공하고, 이동 대상을 선택한 뒤 확인해야 적용되도록 했습니다. 워크스페이스 순서는 드래그로 바꾸며 선택 메뉴와 이동 목록에도 반영됩니다.
- 크래시 리포트와 단축키 편집 화면의 배치·하단 작업 버튼을 정리하고, 앱 언어 설정 아이콘과 설명을 개선했습니다. 단축키 편집의 기본값 초기화 버튼은 제거하며 최근 저장 상태로 돌아가기와 개별 키 편집은 유지합니다.

## 업데이트 안내 및 제한

- 기존 설정·프로필·설치 환경·작업 파일은 보존합니다. 업데이트 중 실행 중인 작업이 중단될 수 있으니 중요한 작업을 먼저 저장하세요. 새 메타데이터가 추가되므로 이전 APK로의 다운그레이드는 지원하지 않습니다.
- **기존 Userspace Linux의 자동 `/workspace` 연결은 제거됩니다.** 원본 파일은 기존 위치에 남으며 자동 이동·삭제하지 않습니다. 공유 디렉토리 설정에서 필요한 데이터를 가져와 환경에 연결하고, `/workspace`를 사용하던 프로필·스크립트·링크는 `/mnt/term-shares/이름` 등 새 경로에 맞게 수정하세요. 워크스페이스 그룹 자체는 파일 공유나 마운트를 만들지 않습니다.
- 백업 전 대상 환경의 세션과 실행환경을 중지해야 합니다. 공유 폴더와 논리적인 워크스페이스 그룹은 환경 백업에 포함되지 않으며, 예전 작업 폴더 데이터는 별도로 선택할 수 있습니다. Data로 복원한 Linux 환경은 배포판을 따로 설치해야 하고, Full 복원 뒤 새 패키지 설치 전에는 패키지 목록을 갱신하세요. AVF 디스크, 기존 환경 덮어쓰기와 자동·정기·증분 백업은 지원하지 않습니다. 암호화 비밀번호는 복구할 수 없습니다.
- AVF 파일 사본 가져오기·내보내기에는 실행 중인 VM과 새 파일 전송 서비스를 포함한 이미지가 필요합니다. 파일 하나당 64 MiB·2분 제한이며 기존 파일을 덮어쓰거나 자동 동기화하지 않습니다. 이전 AVF 이미지의 포트 에이전트는 TCP 전달을 지원하지 않을 수 있습니다. **이번 앱 업데이트는 설치된 Debian 이미지를 교체하지 않으며 새 AVF 이미지도 함께 배포하지 않습니다.**
- Native·Userspace Linux는 Android 네트워크를 공유합니다. 서비스 등록만으로 실제 리스너 실행이나 환경별 네트워크 격리를 보장하지 않습니다. AVF의 기기·권한 조건은 기존과 같으며 실제 AVF 기기의 파일 전송·네트워크와 여러 VM의 동시 연결은 검증되지 않았습니다.
- 개발 채널 프리릴리즈입니다.
