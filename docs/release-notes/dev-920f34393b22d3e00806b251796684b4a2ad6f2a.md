# TERM 0.9.0 개발 버전

- 릴리즈 ID: dev-920f34393b22d3e00806b251796684b4a2ad6f2a
- 출시일: 2026-10-03
- 대상: Android 앱, AVF 실행 환경 및 Debian 이미지 설정

## 추가 및 수정

- 지원 제품에서 첫 AVF 세션을 만들 때 Debian 이미지를 자동으로 내려받고 검증·설치한 뒤 세션을 시작하는 기능을 추가했습니다. 승인된 이미지가 등록된 제품에서는 사용자가 이미지 파일을 따로 준비할 필요가 없습니다.
- 디버그 앱과 배포 앱에 AVF 실행 드라이버를 포함했습니다. 필요한 플랫폼 기능과 권한이 없는 기기에서는 기존 Native·Rootless 환경을 계속 사용할 수 있습니다.
- 설정의 Debian 이미지 항목을 누르면 초기 설정 화면 대신 이미지 지원 상태와 설치 안내 화면을 표시하도록 수정했습니다.
- 이미 설치한 AVF 이미지와 작업 파일은 자동 설치로 교체하지 않습니다.

## 업데이트 안내 및 제한

- 기존 설정·프로필·작업 파일은 유지되며 수동 이전은 필요하지 않습니다. 업데이트 중 실행 중인 작업이 중단될 수 있으니 중요한 작업은 먼저 저장하세요.
- 이번 일반 APK에는 아직 공개 Debian 이미지가 등록되지 않았습니다. 자동 다운로드는 검증된 이미지가 게시되고 등록된 후의 앱에서 사용할 수 있으며, 현재는 이미지 미등록 상태가 표시됩니다.
- AVF 실행에는 지원 기기, 호환되는 플랫폼 API 및 실제 가상 머신 권한이 필요합니다. APK 설치만으로 이 권한을 얻을 수 없으며 AVF 실기기 실행 검증은 아직 완료되지 않았습니다.
- 개발 채널 프리릴리즈입니다.
