## 변경 및 개선

- 배포판 공통 이미지·게스트 관리 계약에 맞춰 새 이미지를 제작했습니다. 설치 시 패키지 목록 초기화, 게스트 터미널·파일 전송·포트 보고 서비스를 포함합니다.
- 공통 AVF 커널과 초기 부팅층, 읽기 전용 시스템 디스크와 영속 쓰기 계층을 사용합니다. `droid`의 UID/GID 1000, `/home/droid`, 비밀번호 없는 게스트 sudo를 검증합니다.
- 직접 공유 디렉토리, Android 공유 저장소 연결과 DHCP·DNS 설정을 유지합니다.

## 설치 및 호환성

- 온라인 설치에는 해당 배포판을 포함한 앱의 이미지 카탈로그와 인터넷 연결이 필요합니다.
- 기존 환경의 이미지·패키지·사용자 파일을 자동 교체하지 않습니다. 새 이미지의 기능은 신규 환경에 적용합니다.
- 실제 AVF 기기의 부팅·vsock·공유 파일 I/O·DHCP·DNS·인터넷 패키지 갱신은 확인하지 못했습니다. AVF 지원 ARM64 기기와 호환 플랫폼 API, 실제 VM 권한이 필요합니다.
