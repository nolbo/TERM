# TERM 1.4.0

- 릴리즈 ID: 1.4.0
- 출시일: 2026-10-22
- 대상: Android ARM64 정식 앱 TERM·프리릴리즈 앱 TERM Preview

## 변경 사항

- Debian·Ubuntu·Arch Linux ARM의 새 AVF 이미지가 EXT4 루트를 사용합니다. Docker 저장소를 기본 `/var/lib/docker`에 둘 수 있으며 Docker/LXC·ReDroid용 커널 지원을 유지합니다.
- 전체 이미지 업데이트에서 사용자 `/usr/local`, `/var/lib`의 앱 데이터와 별도 Docker·ReDroid 저장소도 이전합니다. 소유권·권한·링크·확장 속성과 희소 파일을 보존하며, 패키지 DB와 TERM 관리 파일은 새 이미지 것을 유지합니다.
- 기존 OverlayFS 환경은 계속 실행할 수 있습니다. 새 형식으로 전환할 때는 전체 이미지 업데이트를 제공하며, 이전 이미지와 사용자 상태를 함께 복구할 수 있습니다.

## 업데이트 방법과 호환성

- 설치된 채널에 맞춰 TERM 또는 TERM Preview를 업데이트하세요. 새 환경은 새 승인 이미지를 사용하며, 기존 AVF 환경은 세션 종료와 VM 중지 후 전체 이미지 업데이트를 실행하면 전환됩니다. 앱 업데이트만으로 기존 환경을 교체하지 않습니다.
- 계정·설정 충돌, 패키지 재설치나 데이터 복사 실패 시 기존 환경을 보존하고 중단합니다. 앱별 데이터베이스 형식 변환은 수행하지 않으며, 별도로 수정한 다른 루트 경로는 이전 세대에 보존됩니다.
- 새 이미지 형식은 이전 TERM 앱에서 지원하지 않습니다. 이미지 업데이트에는 후보 디스크와 복구용 원본을 보관할 추가 공간이 필요합니다. 실제 Android AVF 기기 검증은 이번 배포에서 수행하지 않았습니다.
