# TERM 1.5.2

- 릴리즈 ID: 1.5.2
- 출시일: 2026-10-24
- 대상: Android ARM64 정식 앱 TERM·프리릴리즈 앱 TERM Preview

## 수정 사항

- AVF 입출력과 공유 파일 전송에서 불필요한 복사·작은 단위의 반복 처리를 줄이고, 정상 연결에서 입력할 때 불필요한 재연결·세션 새로고침이 실행되던 동작을 없앴습니다.
- 실행환경별로 입력을 처리해 한 환경의 전송 지연이 다른 환경의 입력까지 막지 않도록 했습니다. 종료되거나 교체된 세션에 이전 입력을 전달하지 않습니다.
- 화면 크기 변경과 세션 연결 응답을 기다리는 동안 다른 세션의 출력·화면 복원이 함께 멈추지 않도록 수정했습니다. 출력과 화면 크기 변경의 순서를 유지합니다.
- AVF 공유 디렉토리의 정상 가동 이후 감시 오류를 부팅 실패로 처리하던 경로를 수정했습니다. 공유를 안전하게 차단할 수 있으면 VM과 세션을 유지하며, 차단을 확인할 수 없는 경우에는 기존 종료 정책을 유지합니다.
- AVF 공유 연결 진단에 실패 단계·응답 상태·재시도 횟수·복구 경과를 추가했습니다. 게스트에서도 앞선 일시적 오류에 가려지던 실제 종료 원인과 오류 번호를 보존합니다.
- 정식판·프리릴리즈판 수동 공개에서 디스코드 출시 알림이 기본적으로 생략되던 설정을 수정했습니다.

## 업데이트 방법과 제한

- 설치된 채널에 맞춰 TERM 또는 TERM Preview를 업데이트하세요. 프로필·실행환경·작업 파일은 유지하며 앱 업데이트가 설치된 AVF 디스크를 자동 교체하지 않습니다.
- 공유 감시 오류 수정은 Debian·Ubuntu·Arch Linux ARM의 recovery-20261024-r4 게스트 구성요소에도 포함됩니다. 적용하려는 환경에서 작업을 저장하고 세션을 종료한 뒤 VM을 중지하여 이미지 업데이트를 확인하세요. 같은 커널과 EXT4 형식의 환경은 구성요소 업데이트를 사용하고, 다른 환경은 지원되는 전체 이미지 업데이트 절차를 따르세요.
- 공유·세션 연결의 기존 복구 기한과 흐름 제어를 유지합니다. 공유 권한 확인이 60초를 넘겨 실패하면 해당 공유는 계속 차단될 수 있으며 환경을 중지한 뒤 다시 시작해야 합니다. 결과가 불명확한 입력이나 파일 작업을 자동으로 반복하지 않습니다.
- 실제 특권 Android AVF 기기의 장시간 백그라운드·Doze에서 이번 현상이 해결됐다고 보장하지 않습니다. VM·앱 런타임·게스트 데몬 자체가 종료된 경우 작업 복원은 보장하지 않습니다.
