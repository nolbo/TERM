# TERM 0.3.0 — 업데이트 안내 및 터미널 사용성 개선

- 릴리즈 ID: `dev-75ab03c303aecd2341cc9b51e6d4cbc7c75368e7`
- 출시일: 2026-09-25
- 앱 버전: `0.3.0+dev.1000040.75ab03c303ae` (`versionCode=1000040`)
- 대상: Android ARM64 APK, Native / Rootless Linux / AVF 공통 UI
- 비교 기준: `0.2.0+dev.1000039.a84df3da8d03`
- 버전 결정: 업데이트 패치 노트 표시 기능 추가로 MINOR 승격 (`0.2.0 → 0.3.0`)
- Direct Linux 실험 커밋 22개는 제외했습니다. 기존 Direct Native는 유지합니다.

## 추가 및 변경

- 업데이트가 있으면 앱 업데이트 화면에서 한국어 패치 노트를 확인할 수 있습니다.
  노트를 가져오지 못해도 정상 업데이트의 다운로드를 막지 않습니다.
- 터미널 배경에 맞춰 앱 바·탭·단축키·새 세션 메뉴의 색상을 조정하고,
  선택한 탭을 캡슐 형태로 표시합니다. 탭 높이는 40dp입니다.
- 디버그 앱은 별도 앱 ID와 이름으로 설치되어 서명 배포 앱과 함께 사용할 수 있습니다.
  디버그 앱의 앱 내 채널 업데이트는 비활성화됩니다.

## 수정 및 보안

- 앱 바 숨김과 edge-to-edge 표시에서 상태 표시줄 아래의 터미널 내용과
  스크롤백이 가려지는 문제, 앱 바 아이콘이 보이지 않는 문제를 수정했습니다.
- 빈 터미널 화면과 앱 바의 배경을 일치시켰습니다.
- 독립 Rootless 프로필을 설치하는 동안 다른 프로필의 새 세션 생성이 막히거나
  설치 진행 표시가 잘못 연결되는 문제를 수정했습니다. 저장소별 작업 잠금을
  사용하며 전체 이전 작업의 배타성은 유지합니다.
- 새 Android 특권이나 권한을 요구하지 않으며 실행 환경을 자동 전환하지 않습니다.

## 업데이트 및 한계

- 서명 배포 앱의 ID·서명 정책과 기존 데이터 형식은 유지하며 필수 수동 이전은 없습니다.
- 디버그 앱과 서명 앱의 데이터는 분리됩니다. 기존 배포 앱을 삭제할 필요는 없습니다.
- APK 업데이트 전에 실행 중인 작업을 저장하세요. Android가 프로세스를 종료할 수 있습니다.
- Rootless의 PRoot·커널 제한과 AVF의 지원 기기·특권 요구는 유지됩니다.
- 물리 기기, 특권 AVF, 실제 배포 앱의 데이터 보존 업그레이드 전체 경로는 미검증입니다.
