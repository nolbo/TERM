# TERM 0.15.2 개발 버전

- 릴리즈 ID: 0.15.2
- 출시일: 2026-10-10
- 대상: Android ARM64 앱, Native·Userspace Linux·AVF 실행환경

## 수정 및 개선

- 사용자 지정 글꼴을 앱 내부에 보관해 앱 업데이트나 원본 파일의 이동·삭제·읽기 권한 변경 후에도 선택한 글꼴을 유지합니다. 일시적인 접근 실패 후에는 다시 읽기를 시도하며, 읽을 수 없는 새 글꼴 파일은 등록하지 않습니다.
- 오래 백그라운드에 둔 뒤 돌아오거나 앱을 다시 열면 마지막으로 선택한 워크스페이스와 활성 탭을 복원합니다. 살아 있는 세션과 워크스페이스 소속을 유지하며, 저장된 빈 워크스페이스를 복원하는 것만으로 시작 구성을 다시 실행하지 않습니다.
- Userspace Linux·AVF의 실행환경 상세 **권한 → 내부저장소 접근**과 새 실행환경 만들기에서 저장소 연결 여부를 선택할 수 있습니다. 새 환경은 기본 꺼짐이며 기존 환경은 이전 동작을 유지합니다. Native의 권한 항목은 Android 공통 권한 설정으로 이동합니다.
- 지원 이미지와 호환 기기를 사용하는 비보호 AVF VM에서 연결한 공유 디렉토리를 `/mnt/term-shares/폴더이름`으로 직접 공유하고, 공통 내부저장소 권한과 환경별 연결을 허용하면 Android 공유 저장소를 `/sdcard`로 연결할 수 있도록 했습니다. Android 공통 권한을 해제하면 해당 저장소를 공유하던 AVF VM을 중지합니다.

## 업데이트 안내 및 제한

- `0.15.1`에서 업데이트할 때 기존 설정·프로필·실행환경·공유 폴더·작업 파일을 유지하며 추가 수동 이전은 필요하지 않습니다. 업데이트 전에 실행 중인 중요한 작업을 저장하세요. 기존 등록 글꼴의 원본에 이미 접근할 수 없고 보관된 사본도 없다면 원본 파일을 다시 선택하세요.
- 환경별 내부저장소 연결을 끄는 설정은 이후 새 세션·VM 부팅부터 적용합니다. 기존 연결을 즉시 끝내려면 해당 세션 또는 VM을 중지하세요. 이 선택은 Android 권한이나 앱 내부 파일 접근을 격리하는 보안 기능이 아니며, 앱 전체의 넓은 접근을 해제하려면 Android 공통 권한을 끄세요.
- 개발 채널 프리릴리즈이며 이번에는 앱만 업데이트합니다. 별도 Userspace Linux 런타임이나 AVF 이미지는 배포하지 않고 현재 승인된 이미지와 기존 설치 이미지를 자동 교체하지 않습니다. 새 AVF 직접 공유와 `/sdcard` 연결에는 해당 기능을 지원하는 별도 이미지와 호환 플랫폼이 필요하며, 현재 승인된 이미지에 앱 업데이트만으로 적용되지는 않습니다. 폴더 연결·이름·환경별 내부저장소 설정 변경은 VM을 중지한 뒤 다시 시작해야 반영됩니다. 실제 AVF 기기의 동작은 이번 배포에서 검증하지 않았습니다.
