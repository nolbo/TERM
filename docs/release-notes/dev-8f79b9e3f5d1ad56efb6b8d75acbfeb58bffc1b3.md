# TERM 0.17.0 개발 버전

- 릴리즈 ID: dev-8f79b9e3f5d1ad56efb6b8d75acbfeb58bffc1b3
- 출시일: 2026-10-17
- 대상: Android ARM64 앱, Native·Userspace Linux·AVF 실행환경

## 새로운 기능

- 같은 워크스페이스의 터미널 두 개를 상하 또는 좌우로 함께 볼 수 있습니다. Native·Userspace Linux·AVF 세션을 섞어 사용할 수 있으며 미소속 세션끼리도 분할할 수 있습니다.
- 기본 크기 세션 탭을 길게 눌러 **분할 화면으로 열기**를 선택하거나, 확장한 세션 목록에서 탭을 다른 탭 위로 끌어 잠시 머문 뒤 놓으면 두 세션을 묶습니다. 분할 묶음의 탭이나 패널을 누르면 입력 대상이 바뀝니다.
- 패널 사이 핸들로 비율을 조절하고 핸들 메뉴에서 분할 방향을 바꾸거나 해제할 수 있습니다. 핸들을 화면 끝으로 끌어 놓아도 분할을 해제할 수 있으며 두 세션은 계속 실행됩니다. 워크스페이스를 바꾸거나 화면을 다시 열면 살아 있는 세션의 배치와 입력 대상을 복원합니다.
- 다른 일반 탭을 선택하면 해당 터미널을 단독으로 표시하고 기존 분할 묶음을 유지합니다. 묶음의 탭을 다시 누르면 분할 화면으로 돌아옵니다. 각 패널의 글꼴·스크롤 위치·TUI 색상과 그래픽은 독립적으로 표시합니다.
- AVF 실행환경에서 Debian 외에 Ubuntu 24.04 LTS와 Arch Linux ARM을 선택해 설치할 수 있습니다. 배포판에 맞춰 APT 또는 pacman 저장소를 초기화하며 실패하면 다시 시도할 수 있습니다.

## 개선 및 수정

- 분할 탭의 묶음·선택 상태와 메뉴 표시를 정리하고, 가로 탭 목록의 수동 스크롤 위치를 유지하도록 개선했습니다.
- 단축키 도구의 스크롤 정렬과 키를 길게 눌렀을 때의 반복 동작을 개선했습니다.
- 전체 화면 TUI 주변과 툴바·시트의 색상을 더 자연스럽게 맞추고 모서리 배경 표시를 수정했습니다.
- 설정의 공통 입력창에 선택한 글꼴이 올바르게 적용되도록 수정했습니다.
- AVF 이미지 설치에서 빈 디스크 영역을 희소 파일로 보관하고 중복 임시 복사를 줄여 필요한 저장공간을 줄였습니다.
- AVF 환경을 만들 때 배포판을 먼저 선택하도록 정리하고 Ubuntu의 이미지 설치 후 게스트 연결 문제를 수정한 승인 이미지를 포함했습니다.

## 업데이트 안내 및 제한

- 개발 채널 프리릴리즈입니다. 기존 프로필·워크스페이스·실행환경·공유 폴더·작업 파일은 유지합니다. 업데이트 전에 실행 중인 중요한 작업을 저장하세요.
- 터미널 분할은 같은 워크스페이스의 실행 중인 세션 최대 두 개를 대상으로 합니다. 분할을 해제해도 세션은 계속 실행되지만 탭의 종료 버튼은 실제 세션을 종료합니다. 종료되거나 다른 워크스페이스로 이동한 세션 때문에 분할을 유지할 수 없으면 단일 화면으로 돌아갑니다.
- 신규 AVF 설치에는 Debian `avf-debian-debug-20261012-r4`, Ubuntu `avf-ubuntu-debug-20261013-r1`, Arch `avf-archlinux-debug-20261012-r5` 이미지를 사용합니다. 기존 이미지·패키지·파일을 자동 교체하거나 이전하지 않습니다. 새 배포판이나 수정된 Ubuntu 이미지를 사용하려면 필요한 파일을 백업하고 새 실행환경을 설치하세요.
- AVF에는 지원 ARM64 기기, 호환 플랫폼 API와 실제 가상 머신 권한이 필요합니다. 일반 APK 업데이트만으로 해당 권한을 얻지는 않습니다. 실제 Android AVF 기기의 부팅·vsock·공유 파일 읽기와 쓰기·DHCP·DNS·인터넷 패키지 갱신은 이번 배포에서 검증하지 않았습니다.
