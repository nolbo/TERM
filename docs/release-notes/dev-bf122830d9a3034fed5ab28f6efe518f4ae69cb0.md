## 변경 사항

- 기본 프로필도 목록에서 눌러 수정·복제·삭제할 수 있습니다. 삭제한 기본 프로필은 다시 나타나지 않습니다.
- 프로필 생성 시 Native / Userspace Linux / AVF를 선택합니다. Userspace Linux는 배포판을 별도로 선택합니다.
- 새 프로필과 복제한 프로필은 독립 저장공간을 기본으로 사용하며, 같은 기반의 다른 프로필과 명시적으로 공유할 수 있습니다.
- 공유 범위는 홈·작업 폴더뿐 아니라 Rootless 설치 패키지·루트 파일시스템과 AVF VM 디스크를 포함합니다. Rootless 공유 시 대상 배포판을 사용합니다.
- AVF 특권이 없는 기기에서는 기본 AVF 프로필을 숨깁니다.
- 프로필 선택 바텀시트에 왼쪽 아이콘·텍스트 목록을 복원했습니다. 한국어에서는 프로필 관련 표기를 한글로 표시하고 세션 메뉴에 `+ 프로필 추가`를 제공합니다.
- 생성 시각이 같은 세션의 목록 순서가 실행 환경에 따라 달라질 수 있는 문제를 수정했습니다.

## 업데이트 및 제한 사항

- 기존 프로필과 데이터 경로를 유지하므로 별도 데이터 이전은 필요하지 않습니다. APK 업데이트 전 실행 중인 작업은 저장하세요.
- 프로필 수정·삭제는 이미 실행 중인 세션에 영향을 주지 않습니다. 저장공간 설정을 바꿔도 기존 파일을 이동·복사·삭제하지 않으며 사용하지 않는 공간도 자동 삭제하지 않습니다.
- 새 Rootless 공간은 첫 실행 시 배포판 설치와 추가 저장공간이 필요합니다.
- Native의 Android 시스템 및 APK 내 실행 파일은 공통입니다. 저장공간 분리는 별도 Android UID 보안 격리가 아닙니다.
- AVF는 특권 제품과 독립 백엔드 제공자, 이미지 카탈로그 또는 사전 설치 검증 이미지가 필요합니다. 일반 APK가 자체적으로 특권을 획득하지 않습니다.

- 로컬 표준 빌드 및 runtime·image 테스트, 앱 단위 테스트 통과.
- ARM64 Android 기기에서 프로필 관련 instrumentation 8개 통과: Native/실제 Debian 저장공간 분리·공유, 프로필 삭제 후 세션 유지, 편집 화면 선택·저장 등.
- android·replicant MCP로 바텀시트 정렬, 세션 생성, 프로필 추가 진입 및 한국어 표기를 확인했습니다.
