# TERM AVF Debian ARM64 네트워크 초기 설정 수정

- 릴리즈 ID: avf-debian-20261005
- 출시일: 2026-10-05
- 대상: AVF용 Debian ARM64 이미지

## 수정 사항

- 가상 네트워크 장치가 DHCP로 주소·기본 경로·DNS를 받도록 초기 설정을 추가했습니다. 네트워크 장치 이름이 달라도 적용됩니다.
- 게스트의 네트워크·DNS 서비스를 활성화하고, 빌드 환경의 DNS 주소가 남을 수 있던 문제를 수정했습니다.
- 이전 이미지의 `/home/droid`, 비밀번호 없는 게스트 `sudo` 및 Debian 패키지 관리 설정을 유지합니다. 게스트 관리자 권한은 Android 시스템 권한을 추가하지 않습니다.

## 설치 안내 및 제한

- 새 이미지는 앱의 승인된 신규 설치에 사용합니다. 기존 설치 이미지·패키지·사용자 파일은 자동 교체하거나 이전하지 않습니다. 기존 환경은 사용자 안내의 DNS 복구 절차를 사용할 수 있으며, 다시 설치할 때는 게스트 파일을 먼저 백업하세요.
- 최초 다운로드에는 인터넷 연결과 압축 해제된 이미지에 약 14GiB의 저장공간이 필요합니다. 설치 임시 공간과 이후 작업 파일을 저장할 여유도 확보하세요.
- AVF 지원 ARM64 기기, 호환되는 플랫폼 API와 실제 가상 머신 권한이 필요합니다. Android의 AVF 네트워크 설정이 켜져 있고 플랫폼이 VM 네트워크를 제공해야 합니다.
- 실제 AVF 기기의 DHCP·DNS·인터넷 연결과 여러 VM의 동시 연결은 아직 검증하지 않았습니다. 이 이미지가 Android 플랫폼의 고정 TAP 인터페이스 오류를 해결하지는 않습니다.
- 개발 채널 프리릴리즈입니다.
