# TERM 0.14.0 개발 버전

- 릴리즈 ID: dev-831dc840001ca9968f20385853451ff7f6e07428
- 출시일: 2026-10-08
- 대상: Android ARM64 앱, Native·Userspace Linux·AVF 실행환경

## 추가된 기능

- 툴바 설정의 편집에서 **명령 기록** 도구를 추가할 수 있습니다. 명령 위치를 위·아래로 이동하고, 툴바를 펼쳐 최신 명령부터 실행 상태와 종료 코드를 확인할 수 있습니다. 목록의 명령을 누르면 해당 기록으로 이동합니다.
- 명령 기록 도구에서 **명령 / 출력 / 명령과 출력** 범위를 골라 터미널 화면과 보관 중인 기록을 검색할 수 있습니다. 일치하는 글자를 강조하고 결과 순번과 개수를 표시하며, 화살표와 키보드 검색 키로 결과를 순환합니다. 검색 중에도 펼친 명령 목록은 유지됩니다.
- 프로그램이 OSC 8로 지정한 링크를 지원합니다. **터미널 설정 → 셸 → 터미널 링크 열기**를 켜면 표시 문구와 주소가 다른 링크도 탭해 브라우저로 열 수 있습니다. 지정된 링크를 우선하며 링크가 없는 위치에서는 기존 웹 주소 자동 감지를 사용합니다.
- 단축키를 빈 칸으로 자유롭게 옮기고 네 모서리에서 너비와 높이를 조절할 수 있습니다. 다른 키의 중앙으로 끌면 위치를 교환하고, 가장자리로 끌면 주변 키 사이에 끼워 넣습니다. 빈 공간과 키 크기도 저장되며 변경은 편집 화면의 **저장**을 눌러 적용합니다.
- `SPACE`, `CTRL+SPACE`, `ALT+SPACE`, `SHIFT+SPACE`, `CTRL+SHIFT+SPACE` 등 공백 키와 보조 키 조합을 단축키로 사용할 수 있습니다.

## 수정 및 개선

- 앱이 활성 상태이고 해당 세션을 보고 있을 때는 명령 완료 알림을 보내지 않습니다. 다른 세션이나 백그라운드 작업의 완료 알림과 프로그램의 확인 요청 알림은 유지됩니다.
- Bash에서 긴 출력 뒤에 입력한 명령이 명령 범위 검색에서 누락될 수 있던 문제를 수정했습니다.
- 명령 기록 검색에서 다른 툴바 도구로 이동할 때 입력 포커스를 터미널로 돌려주고, 열려 있던 키보드를 유지합니다. 이미 닫은 키보드를 다시 열지는 않습니다.
- 단축키 이동·크기 조절의 미리보기와 애니메이션을 개선하고, 선택한 키 옆의 편집·삭제 버튼과 간결한 이름·조합 편집창을 제공합니다.

## 업데이트 안내 및 제한

- 기존 설정·프로필·설치 환경·작업 파일은 유지되며 필수 수동 이전은 없습니다. 업데이트 중 실행 중인 작업이 중단될 수 있으니 중요한 작업을 먼저 저장하세요.
- 명령 이동과 명령 범위 검색에는 셸 통합이 필요합니다. Native 기본 셸과 Bash 기본 통합을 지원하며, 사용자 프롬프트나 셸 설정이 통합을 덮어쓰면 경계 보고가 필요합니다. 출력·전체 범위는 셸 통합이 없는 일반 출력도 검색합니다.
- 보관 범위를 벗어나 삭제된 기록은 검색하거나 다시 이동할 수 없습니다. Neovim·less·tmux 등 프로그램이 화면을 제어하는 동안에는 명령 이동을 사용할 수 없습니다.
- 터미널 링크 열기는 기본 꺼짐이며 `http`·`https` 주소만 허용합니다. 표시 문구와 실제 목적지는 다를 수 있습니다.
- AVF의 기기·권한 조건은 기존과 같으며, 이번 앱 업데이트는 설치된 Debian 이미지를 교체하지 않습니다. 실제 AVF 기기의 네트워크와 여러 VM의 동시 연결 검증은 완료되지 않았습니다.
- 개발 채널 프리릴리즈입니다.
