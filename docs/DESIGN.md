# UI 디자인 지침

## 1. 목적과 적용 범위

이 문서는 현재 Android 앱의 화면 구성과 공통 컴포넌트를 분석한 UI 작업 지침이다. 새 화면과 설정을 추가할 때 기존 화면의 정보 계층, 배치, 조작 방식과 일관성을 유지해야 한다. 디자인 시안만 만드는 경우에도 같은 기준을 적용한다.

[DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)는 색상·글꼴·컴포넌트·모션의 상세 계약이며, 이 문서는 화면을 구성하고 설정을 확장하는 방법을 다룬다. 런타임과 UI의 책임 경계는 [ARCHITECTURE.md](ARCHITECTURE.md)의 UI contract를 따른다. UI 변경 전 두 디자인 문서의 관련 부분과 실제 구현을 확인하고 공통 컴포넌트를 우선 재사용한다. 구현과 문서의 차이를 발견하면 현재 상태와 적용할 기준을 명시하고, 요청 범위 안에서 필요한 문서를 갱신한다.

아래의 현재 구성은 소스 구현을 기준으로 한 분석이다. 기기에서의 표시·동작 검증 결과를 대신하지 않는다. 기존 화면의 예외를 발견했다고 해서 요청하지 않은 화면 개편을 함께 수행하지 않는다.

세션 툴의 **새 세션**은 현재 비모달 BottomSheet를 펼치고 같은 시트 안에서 프로필 선택 페이지로 전환한다. 상단 뒤로가기와 Android 뒤로가기는 세션 페이지로 돌아간다. 프로필 선택 중 시트를 기본 크기로 줄여도 뒤로가기 전환 애니메이션과 현재 시트 크기를 유지한다. 프로필 선택 중에는 부모 툴바의 가로 도구 전환을 잠시 막아 세로 스크롤·플링과 충돌하지 않게 하며, 일시적인 조작 비활성화는 페이지를 닫지 않는다. 기본 크기에서 진입할 때 시트는 테마의 spatial motion으로 확장한다. 세션 페이지와 프로필 선택 페이지는 진입·뒤로가기 방향에 맞춘 가로 슬라이드와 페이드로 전환하며 RTL에서는 방향을 반전한다. 프로필 선택 후 크기 복원·편집 진입에도 같은 높이 모션을 사용한다. 프로필은 기존 아이콘·이름과 연결된 실행환경 이름·런타임을 표시하는 Material `ListItem`으로 제공하며 목록은 세로로 스크롤한다. 목록 끝의 **새 프로필 만들기**는 보조 텍스트 버튼으로 기존 편집 화면을 연다. 프로필 선택은 기존 세션 생성·선택 경로로 전달한 뒤 시트를 새 세션 버튼을 누르기 전의 기본·확장 크기로 되돌리고 세션 페이지를 표시한다. 프로필 편집 진입 때는 시트를 숨긴다. 세션과 워크스페이스가 모두 없는 초기 화면에서도 하단 세션 툴바와 핸들을 유지한다. 빈 화면에는 안내만 표시하고 워크스페이스·새 세션·설정 진입은 툴바에 둔다. 초기 화면의 새 세션도 같은 툴바 내부 프로필 선택 페이지를 사용한다.

세션 툴과 빈 화면의 **새 세션** 프로필 목록은 설치 상태를 별도 텍스트 줄로 표시하지 않는다. Userspace Linux·AVF 실행환경이 **미설치**로 확인된 프로필에만 아이콘의 아래쪽 끝 모서리에 작은 다운로드 심볼을 표시하고, 심볼 외곽을 따라 얇은 여백을 두고 프로필 아이콘을 마스킹한다. **설치됨**, **미설치**, **설치 중**, 조회 중·실패 상태는 스크린리더의 상태 설명으로 제공하며 조회 실패를 미설치로 간주하지 않는다. 프로필 선택 시 상태를 다시 확인하고, 미설치이면 실행환경 이름과 배포판 또는 배포판 이미지를 명시한 설치 확인창을 연다. 설치를 승인한 경우에만 설치 후 세션을 시작한다. 취소·뒤로가기·확인창 닫기는 설치나 세션을 만들지 않으며 화면 재생성은 확인창을 복원한다. 설치된 환경은 세션을 열고 진행 중 설치는 기존 작업을 관찰한다.

**명령 기록**은 툴바 설정의 편집에서 추가하는 선택 도구다. 기본 크기는 위·아래 명령 이동 버튼, 검색 필드, 아이콘만 표시하는 검색 범위 split button으로 구성한다. 앞쪽 아이콘은 필터 심볼로 고정하며, 앞 아이콘이나 뒤 화살표를 누르면 명령·출력·명령과 출력 선택 메뉴가 열린다. 검색은 실제 터미널 화면과 보관 중인 스크롤백의 글자를 대상으로 하며, 커밋 그래프 목록을 필터링하지 않는다. 검색어를 입력하거나 범위를 바꾸면 가장 최근 일치 위치로 이동하고, 보이는 일치 영역을 강조한다. 현재 결과에는 테두리도 표시하며 결과 순번과 전체 개수를 안내한다. 검색 중 위·아래 화살표와 키보드 검색 키는 일치 항목 사이를 순환하고, 검색어를 지우면 명령 이동으로 돌아간다. 명령 범위는 셸 통합 입력 경계를 사용하며, 출력·전체 범위는 셸 통합이 없는 일반 출력도 검색한다. 첫·마지막 명령에 도달하면 해당 방향의 버튼은 기록의 맨 위·맨 아래로 이동하는 수직 chevron-line 아이콘으로 바뀐다. 확장하면 최신 명령부터 Git 커밋 그래프처럼 세로 선과 상태 도트로 연결된 목록을 표시한다. 완료·실행 중·실패는 서로 다른 Material Symbols와 접근성 상태·툴팁으로 구분하고, 명령 이름은 작은 본문 글꼴로 표시하고 알 수 있는 종료 코드는 그 아래에 함께 표시하며, 명령 행을 누르면 보관 중인 시작 위치로 이동한다. 각 행 오른쪽에는 명령 복사 아이콘 버튼과 출력 펼침·접힘 꺾쇠 버튼을 차례로 배치하며 두 버튼은 위치를 이동하지 않는다. 펼친 영역에는 길게 눌러 선택·복사할 수 있는 읽기 전용 출력 필드를 제공한다. 별도 스크롤바나 캔버스 제스처를 추가하지 않는다.

기본 크기의 가로 세션 탭은 목록 스크롤을 우선한다. 선택 탭 가시화는 포커스가 바뀔 때만 수행하며 수동 스크롤 뒤 출력·제목·레이아웃 갱신으로 되돌리지 않는다. 목록 안쪽에서 시작한 드래그와 관성 스크롤은 마지막 탭까지 목록에서 처리한다. 시작이나 끝에 도달한 제스처는 도구 전환으로 이어지지 않으며, 그 가장자리에서 같은 방향으로 새로 스와이프하면 인접한 도구로 전환한다. 탭의 선택 여부와 제목·아이콘·여백·종료 버튼 등 스와이프 시작 위치에 관계없이 같은 동작을 제공한다.

기본 크기 세션 툴의 가로 탭 영역은 워크스페이스 버튼 쪽과 새 세션 버튼 쪽에 같은 20dp 경계 그라데이션을 제공한다. 해당 방향에 가려진 탭이 있을 때만 표시하며 RTL에서는 위치와 그라데이션 방향을 함께 반전한다.

설정 홈의 그룹 순서는 **실행환경·프로필·워크스페이스 → 공유 디렉토리 → 앱 언어·터미널 설정 → Userspace Linux·AVF Linux → 진단 및 리포트·앱 업데이트·앱 정보**다. AVF Linux 카테고리는 AVF 권한이 있는 경우에만 노출한다. Native 셸의 전역 설정 카테고리와 검색 항목은 제공하지 않으며, 셸 경로는 프로필에서 지정한다. 관련 설정을 추가할 때는 먼저 기존 카테고리와 섹션에 배치한다. 독립적인 사용자 목적과 여러 하위 설정이 있어 별도 진입이 필요한 경우에만 새 상위 카테고리를 만든다.

설정 홈의 **실행환경**은 Material Symbols Rounded의 `deployed_code`, **프로필**은 `layers`, **워크스페이스**는 `team_dashboard`, **공유 디렉토리**는 `folder_data`, AVF Linux 하위의 **로컬 서비스**는 `lan` 아이콘을 사용한다. 같은 카테고리가 검색 결과에 나타날 때도 이 아이콘을 사용하며, 40dp 원형 표면 안에 24dp 비채움 아이콘을 배치한다.

설정 홈과 카테고리 검색 결과의 **앱 언어**는 Material Symbols Rounded의 `language` 아이콘을 사용한다.

터미널 설정은 현재 **USB 디바이스, 사용자 설정, 셸, 터미널 기록, 햅틱 피드백, 공유 내부저장소, 백그라운드 실행, Android 권한**으로 나뉜다. 사용자 설정에서 툴바 설정과 터미널 모양으로 이동하며, 터미널 모양은 여백·텍스트·사용자 글꼴·컬러 팔레트를 구분한다. 관련성이 높은 옵션을 같은 섹션에 두고 기존 진입 경로를 유지한다.

프로필의 실행 설정, 개별 실행환경의 데이터·설치·실행 상태, 실행 엔진의 전역 정책을 구분한다. 개별 배포판·VM의 설치·제거·시작·중지는 설정 홈의 실행환경에서 진입하는 상세에 둔다. Userspace Linux 설정은 네트워크(DNS 전역 정책)만 제공하며 PRoot·아키텍처·가속과 엔진 상세는 진단 및 리포트의 Userspace Linux Activity에 둔다. AVF Linux 설정에는 리소스와 로컬 서비스를 둔다. 공유 디렉토리는 앱 언어 바로 위의 독립 카테고리이며, 로컬 서비스는 AVF Linux의 실행 섹션에서 AVF 서비스·포트 전달 대시보드로 연결한다. 공통 진단과 크래시 리포트 목록은 설정 홈의 진단 및 리포트에서만 제공한다. 저장소 내부 식별자와 파일 구조를 새 최상위 사용자 개념으로 노출하지 않는다.

새 프로필 만들기와 프로필 편집의 **기존 실행환경 사용**은 새 실행환경의 런타임·배포판 선택과 관계없이 모든 실행환경을 이름순으로 표시하며, 편집 중인 프로필의 현재 실행환경도 포함한다. 선택한 실행환경이 런타임·배포판을 결정하며 기본 셸·인수·시작 디렉터리는 해당 런타임에 맞추고 사용자 지정값은 유지한다. 선택 상태는 목록의 라디오 버튼으로 표시하고 같은 실행환경의 상세 행을 목록 아래에 추가하지 않는다. 편집의 **현재 실행환경 유지**로 돌아오면 원래 실행환경의 런타임·배포판도 복원한다.

프로필 복제 화면은 **기존 실행환경 사용**과 원본 프로필의 실행환경을 기본 선택한다. 선택은 화면 재생성 후에도 유지하고 전체 저장 시 원본 실행환경에 연결한다. 사용자가 **새 실행환경 만들기**로 변경하면 새 독립 실행환경을 생성한다.

사용자 화면에서는 한국어·영어 모두 PRoot 기반 Linux를 **Userspace Linux**, 파일·패키지·런타임 상태를 보관하는 단위를 **실행환경(Execution Environment)**으로 표시한다.

Userspace Linux의 DNS 상세는 공통 설정 그룹 안에서 **Android 네트워크 설정 사용**을 기본으로 한 라디오 선택을 제공한다. **사용자 지정**을 선택할 때만 DNS 서버 그룹을 표시하며 **DNS 서버 추가** 행은 IPv4 또는 IPv6 주소 한 개를 받는 대화상자를 연다. 주소는 최대 3개까지 추가할 수 있고, 3개일 때는 추가 행을 공통 비활성 색상과 제한 안내로 표시한다. 각 주소 행은 기본 UI 글꼴을 사용하며 추가·삭제 시 테마의 spatial/effects spec으로 목록 높이와 투명도를 전환한다. 주소 제거에는 툴팁·접근성 설명을 가진 20dp 빼기 아이콘을 사용하고 48dp 터치 영역을 유지한다. 버튼 중심은 다른 설정 행의 오른쪽 아이콘과 같은 위치에 맞추며 삭제 후 추가 행을 다시 활성화한다. 잘못된 주소·복수 주소·중복 주소는 추가할 수 없다. 목록과 입력 중인 대화상자 초안은 화면 재생성 시 유지하고 화면의 저장에서만 전역 정책을 반영한다. 취소·뒤로가기는 저장값을 바꾸지 않는다. PRoot 내부 옵션은 자동 관리하며 토글·고급 설정과 실행환경 관리 링크를 추가하지 않는다.

터미널 캔버스의 한 손가락 드래그는 처음 감지한 우세 축을 손가락을 뗄 때까지 유지한다. 수평 드래그는 마우스 보고를 활성화한 프로그램에 수평 휠 입력을 전달하며, 일반 셸에서는 입력이나 스크롤백을 발생시키지 않는다. 세로 스크롤·텍스트 선택·길게 누르기·핀치·실제 마우스 드래그는 기존 경로를 유지한다.

Hotkeys의 Shift·Alt·Ctrl 선택 상태와 조합은 터치 및 마우스·트랙패드의 모든 방향 휠 입력에도 적용한다. 휠 입력은 선택 상태를 소비하거나 자동 해제하지 않으며, 버튼을 다시 눌러 끄면 이후 휠 입력부터 보조 키를 제외한다. 키 입력 후 해제되는 기존 동작은 유지한다.

단축키 영역의 세로 드래그·관성 스크롤이 끝나면 버튼이 경계에 잘리지 않는 가까운 위치로 부드럽게 정렬한다. 저장된 키 위치와 높이 및 실제 뷰포트를 기준으로 위·아래 경계를 함께 고려한다. 키가 뷰포트보다 크거나 엇갈린 배치로 양쪽 정렬이 불가능하면 가까운 시작 경계를 사용한다. 일반 키·보조 키·반복 입력 키의 누름이 확인된 제스처는 마지막 손가락을 떼거나 전체 터치가 취소될 때까지 가로 툴 전환을 막는다. 버튼 밖 이동으로 눌림 표시가 취소되어도 같은 제스처의 잠금은 유지하며, 비활성화·키 교체는 남은 눌림 상태와 반복 입력을 정리한다. 보조 키의 선택 상태만으로는 툴 전환을 막지 않는다.

터미널 단축키 편집은 키별 확정 위치와 가로·세로 크기를 그리드 한 칸 단위로 다룬다. 순서에 관계없이 빈 칸에 배치한다. 이동 중인 키는 그리드와 무관하게 손가락의 실제 경로를 따르고, 놓을 위치와 모서리 크기 조절은 미리보기의 점 격자에 맞춘다. 키를 선택하면 네 모서리의 크기 조절점을 표시하고, 본문은 길게 눌러 이동한다. 선택한 키 옆에 편집·삭제 아이콘 버튼을 나란히 표시한다. 편집은 이름·조합 입력 모달을 열고, 삭제는 선택을 해제하며 초안에서 키를 제거한다. 마지막 키의 삭제는 비활성화한다. 모달은 이름·조합 입력과 펼칠 수 있는 입력 도움말, 저장·취소 버튼으로 구성한다. 이동 중 다른 키의 중앙에 겹치면 두 키의 위치를 교환하고, 가장자리에서는 주변 키를 좌우 또는 위아래로 옮겨 사이에 끼워 넣을 자리를 만든다. 같은 행·열의 공간과 이동량이 적은 방향을 우선 활용하며 관계없는 키와 빈 공간은 유지한다. 크기 조절은 겹친 키를 아래쪽으로 연쇄 이동시켜 공간을 확보한다. 이동 중인 키와 그 선택 테두리·모서리 조절점은 손가락의 좌표를 즉시 따르고, 주변 키의 재배치와 크기 조절에는 위치·크기 애니메이션을 적용한다. 손을 놓으면 이동한 키도 실제 드래그 위치에서 확정된 그리드 위치로 애니메이션한다. 누르는 동안에는 미리보기만 변경하고 손을 놓을 때 전체 배치를 한 번에 확정하며, 취소하면 원래 배치로 애니메이션한다. 화면의 전체 저장 전에는 초안만 바꾸고, 이동·크기 조절의 접근성 동작도 같은 검증과 저장 규칙을 따른다.

제목 아래에는 짧은 편집 안내를 두고, 배치 미리보기 제목 아래에는 그리드를 바로 배치한다. 단축키 편집 화면은 기존 하단 취소·저장 버튼과 본문의 추가 버튼 대신 하단 중앙의 공통 `HorizontalFloatingToolbar`에 **최근 저장 상태로 돌아가기 → 단축키 추가 → 저장**을 순서대로 제공한다. 각 동작은 되돌리기·추가·저장 아이콘과 툴팁·접근성 설명을 사용한다. 복원은 화면을 닫거나 저장값을 변경하지 않고 초안 전체를 가장 최근 저장 상태로 되돌리며, 변경이 없으면 비활성화한다. 저장은 현재 초안을 반영하고 화면을 유지하며 다음 복원의 기준을 갱신한다. 추가는 기존 입력 대화상자를 열고 48개 제한을 유지한다. 스크롤 콘텐츠 아래에는 툴바 높이와 화면 경계 여백을 확보한다. 뒤로가기는 미저장 변경 폐기를 확인한다.

## 3. 공통 시각 규칙

터미널은 같은 워크스페이스의 기존 세션 두 개까지 분할하여 표시한다. 미소속끼리도 가능하며 실행환경은 달라도 된다. 다른 일반 탭을 선택하면 단일 화면으로 열고 기존 분할 묶음은 보존하며 묶음 탭 선택으로 복원한다. 분할 탭은 기본·확장 크기에서 같은 작은 간격과 안쪽 모서리로 묶고 별도 분할 아이콘을 표시하지 않는다. 기본 크기의 분할 묶음은 포커스된 세션의 아이콘·제목·부제와 기존 닫기 버튼을 표시하고, 비포커스 세션은 48dp 아이콘 탭으로 표시한다. 아이콘 탭도 세션 이름으로 읽히며 탭하면 포커스가 바뀌고 두 탭의 너비·아이콘 위치·제목·닫기 버튼·색상이 테마 모션으로 부드럽게 전환된다. 전환 중에도 묶음의 전체 너비와 스크롤 범위는 유지한다. 케밥 버튼은 두지 않는다. 확장 세션 툴에서는 탭 본문을 길게 눌러 드래그하면 이웃 행이 이동하며 순서를 미리 보여준다. 다른 탭 중앙에 약 0.3초 머물렀을 때만 분할 의도로 감지하고 두 탭이 분할 탭 모양으로 변하는 애니메이션을 표시한다. 감지 후 좌우로 움직이면 드래그한 세션을 놓을 앞·뒤 순서가 미리보기에서 바뀐다. 손을 놓을 때 그 순서로 분할하며 중앙에 잠깐 놓거나 지나가면 순서만 변경한다. 이 동작은 현재 선택 및 메뉴 활성 여부와 독립적이고 가장자리 자동 스크롤을 유지한다. 기본 크기의 길게 누르기와 확장 크기의 메뉴 버튼은 기존 작업 메뉴를 제공한다. 새 분할의 기본 방향은 세로 화면에서 상하, 가로 화면에서 좌우이며 표시 중인 탭 메뉴에서 방향을 바꾼다. 구분선을 드래그하거나 접근성 비율 조절로 크기를 변경하며 좁은 화면과 IME 표시 시 각 패널의 최소 가용 크기를 보장한다.

확장 목록의 분할 묶음에 포커스하면 한 행에 두 탭과 공통 메뉴 영역을 나란히 묶는다. 영역 사이에는 2dp 간격을 두고 서로 맞닿는 쪽 모서리는 4dp로, 행 바깥쪽은 기존 20dp로 둔다. 기본·확장 크기에서 분할 묶음 전체가 비선택이면 옅은 중립 표면을 연결하고 탭 사이의 갭에 중앙 divider 하나만 표시하며 외곽선은 그리지 않는다. 확장 크기에서는 공통 메뉴를 숨기고 두 탭이 그 공간을 나누어 사용하며 둘째 탭의 바깥 모서리는 20dp로 돌아간다. 묶음에 포커스하면 두 탭과 확장 공통 메뉴 모두 활성 배경을 사용하고 기존 갭과 작은 안쪽 모서리로 부드럽게 돌아간다. 공통 메뉴의 48dp 폭과 2dp 간격은 테마 spatial 모션으로 펼치거나 접고, 메뉴와 divider는 effects 모션으로 전환한다. 전환 도중 다시 선택하면 현재 진행값에서 반대로 이어진다. 메뉴를 숨기기 시작하면 입력·접근성 노출을 즉시 차단하고 열린 팝업도 닫는다. 실제 입력 대상은 제목·부제의 전경색과 접근성 선택 상태로 구분하며 글자·아이콘 대비와 터치 영역은 유지한다. 각 탭의 종료 버튼은 해당 PTY를 종료하고 공통 메뉴의 분할 해제는 배치만 해제한다. 두 탭을 눌러 포커스를 바꾸며 선택 탭 색상을 사용하고 별도 분할 아이콘은 표시하지 않는다. 묶음은 순서 변경 시 한 행으로 이동하고 저장 목록의 세션을 중복하거나 삭제하지 않는다.

패널에는 포커스 테두리·배경 강조·별도 아이콘을 추가하지 않는다. 기존 단일 세션 탭 목록에서 일반 탭은 포커스된 세션만 선택 배경을 사용하고, 분할 묶음은 전체가 선택 배경을 공유하되 실제 포커스된 세션만 선택 전경색과 접근성 선택 상태를 사용한다. 기본 크기의 비포커스 분할 탭은 세션 아이콘만 표시하고 확장 크기에서는 두 탭 모두 제목을 표시한다. 표시 중인 탭은 포커스를 옮기고 다른 일반 탭은 기존 분할 묶음을 보존한 채 단독 화면으로 연다. 공통 툴바 입력·명령 기록·색상은 포커스된 세션을 따른다. **분할 해제**는 포커스된 세션을 단일 화면에 남기고 세션을 종료하지 않는다. 탭의 기존 종료 버튼은 실제 세션을 종료한다. 워크스페이스별 배치·비율·포커스는 복원하며 세션 종료나 소속 변경으로 유효하지 않은 분할은 단일 화면으로 돌아간다.

분할 패널은 실제 M3 Adaptive `SupportingPaneScaffold` 안에서 모서리를 둥글게 자르지 않은 사각형과 12dp 간격을 사용하며, 간격 중앙의 M3 drag handle로 비율을 조절한다. 핸들은 드래그 중 테마 spatial 모션으로 커지고 손을 놓거나 취소하면 원래 크기로 돌아간다. 핸들을 짧게 누르면 세션 툴과 같은 **좌우 분할 / 상하 분할 / 분할 해제** 아이콘 메뉴가 핸들에 연결되어 열린다. 드래그하거나 취소한 조작에서는 메뉴를 열지 않으며 분할 해제는 세션을 종료하지 않는다. 일반 비율·최소 크기 제한을 넘어 끝으로 끌 때도 패널 경계와 핸들은 손가락을 약간 탄성 있게 따라가며, 표시만 임시 축 방향 변환하고 PTY 크기는 안전한 범위를 유지한다. 양끝 48dp 안에 들어가면 설정에 따른 확인 햅틱을 주고 사라질 패널만 effects 모션으로 최대 12dp 흐림과 50% 어두운 표면을 적용한다. 끝에서 64dp 이상 돌아온 뒤 48dp 안에 재진입해야 확인 햅틱이 다시 발생한다. 왼쪽·위쪽 끝에서 놓으면 둘째 세션을, 오른쪽·아래쪽 끝에서 놓으면 첫째 세션을 단독 표시하고 포커스하며 양쪽 세션은 실행을 유지한다. 감지 범위 밖에서 놓거나 취소하면 분할을 유지하고 경계와 미리보기 효과를 복원한다. 상하 분할에서는 핸들도 가로로 회전한다. 단일 화면은 기존 사각형 전체 영역과 바깥 여백을 유지한다. 방향·포커스를 바꿔도 기존 native 패널과 세션은 유지하며, 터치 드래그는 기존 host가 처리하고 핸들은 같은 비율의 접근성 조절을 제공한다.

**터미널 설정 → 셸 → 터미널 링크 열기**는 기존 즉시 반영 스위치 하나로 프로그램이 지정한 링크와 주소 자동 감지를 함께 제어한다(기본 꺼짐). 한 번 탭한 셀의 OSC 8 링크를 우선하고, 없을 때만 표시된 http/https 주소를 감지한다. 허용된 http/https 목적지만 브라우저로 열며 별도 링크 UI는 추가하지 않는다. 마우스 보고·텍스트 선택·더블 탭·스크롤의 입력 우선순위는 유지한다.

터미널은 스크롤바를 표시하지 않는다. 일반 기록은 기존 세로 드래그·휠·부드러운 스크롤 경로로 탐색하며, 가로 스와이프로 별도의 기록 UI를 열지 않는다. 화면 오른쪽에서도 같은 세로 스크롤 동작을 제공한다.

앱의 일반 UI는 `DroidTheme`의 Material 3 Expressive 다크 테마를 사용한다. 새로운 화면마다 색상표·글꼴·모션을 만들거나 시스템 동적 색상을 별도로 적용하지 않는다.

| 요소 | 적용 규칙 |
| --- | --- |
| 화면 배경 | `MaterialTheme.colorScheme.background`를 사용한다. 설정 그룹의 표면은 `surfaceContainerLow`다. |
| 텍스트 | 일반 UI는 Google Sans와 번들 Pretendard 대체 글꼴을 사용하며 Material type scale을 유지한다. 터미널·명령 본문·전달 포트의 주소·크래시 원문은 Google Sans Code를 사용하고 터미널의 사용자 글꼴 설정을 존중한다. 전달 포트의 제목·설명·상태·포트 번호는 일반 UI 글꼴을 사용한다. |

앱의 메뉴는 M3 Expressive `DropdownMenuPopup`과 `DropdownMenuGroup`을 사용한다. 실행 동작은 Expressive `DropdownMenuItem`, 실행환경·명령 기록 검색 범위의 단일 선택은 `SelectableDropdownMenuItem`을 사용한다. 그룹과 항목의 곡률은 `MenuDefaults`를 따르고 현재 선택은 색상과 접근성 상태로 표시한다. 검색 범위의 기존 아이콘·체크 표시와 각 메뉴의 앵커·스크롤·닫기 동작을 유지한다.

터미널 캔버스의 사용자 팔레트·ANSI 색상·커서·선택 영역은 앱 테마와 분리한다. 터미널 화면의 툴바·탭·시스템 아이콘은 활성 캔버스 배경에 맞춘 `TerminalChromeColors`의 대비 규칙을 사용한다. 툴바 BottomSheet는 TUI 배경색 따르기 설정과 관계없이 캔버스의 색감을 유지하면서 명도가 조금 다른 표면을 사용한다. 핸들·툴 페이지·탐색 표시줄 뒤 여백에는 같은 시트 색상을 적용하고 둥근 위쪽 모서리 바깥은 캔버스 배경을 드러낸다. 전체 화면 TUI 배경색 따르기를 켠 alternate screen에서는 TUI 배경에서 M3 Expressive 동적 색상표를 생성하여 툴바의 버튼·선택 상태·카드·진행 표시와 하위 Material 컴포넌트에 적용한다. 캔버스 배경은 TUI 색상을 그대로 사용하고, 옵션 해제나 alternate screen 종료 시 기존 터미널 대비 색상을 복원한다. 터미널 화면에서 여는 모달·팝업에도 같은 동적 색상표를 적용해 표면·본문·버튼·입력 필드·선택 상태가 열린 동안의 TUI 테마 변경을 함께 따른다. 옵션 해제나 alternate screen 종료 시 모달·팝업은 앱 기본 테마로 복원하며, 활성 세션이 없거나 별도 설정 화면에서는 앱 기본 테마를 사용한다. 활성 세션이 없는 화면은 일반 앱 배경을 사용한다. 전체 세션과 워크스페이스가 모두 없는 초기 화면과 빈 워크스페이스 필터에서도 툴바와 핸들을 유지한다. 현재 워크스페이스나 미소속 필터에 세션이 없으면 세션 툴로 고정하고 다른 툴로의 전환을 막는다. 세션이 생기면 저장된 툴 목록과 순서에 따라 전환을 다시 허용하며, 이 제한은 툴바 설정이나 다른 워크스페이스의 세션 수명주기를 변경하지 않는다.

## 4. 설정 화면의 공통 골격

### 앱 바와 스크롤

설정 홈과 하위 설정·관리·편집 화면은 `SettingsPageScaffold`를 사용한다. 진단과 호스트 도구 입력처럼 설정에서 이어지는 화면 및 크래시 리포트 상세에도 같은 scaffold를 사용한다. 새 설정 화면에 별도 작은 앱 바나 자체 뒤로가기 헤더를 만들지 않는다. 초기 설정 등 다른 일반 화면의 표준 앱 바는 `AppScaffold`를 따른다.

크래시 리포트의 안내와 오류 원문은 같은 세로 스크롤 영역에 배치한다. 원문은 선택 가능한 Google Sans Code의 `bodySmall`(12sp, 줄 높이 16sp)로 표시한다. 하단 중앙의 공통 `HorizontalFloatingToolbar`에 삭제·오류 복사 아이콘을 두고 툴팁·접근성 설명으로 동작 이름을 제공한다. 삭제는 error 색의 휴지통 아이콘과 복원 가능한 확인창을 사용한다. 선택한 리포트만 백그라운드에서 삭제하며 성공하면 이전 화면으로 돌아가고 목록은 복귀 시 다시 읽는다. 취소하면 기록을 유지하고 실패하면 상세에 Snackbar를 표시한다. 리포트가 없거나 삭제 중이면 삭제·복사를 비활성화하며, 복사 후에는 완료 메시지를 표시한다. 기록을 유지한 채 나가려면 공통 뒤로가기를 사용한다. 원문 끝에는 툴바 높이와 화면 경계 여백을 확보한다.

공통 scaffold는 투명 앱 바와 내부 배경, 외곽의 명시적 화면 배경, 고정 원형 뒤로가기 버튼을 제공한다. 위로 스크롤하면 큰 제목이 작은 제목으로 전환되고, 추가 스크롤 4dp를 넘으면 작은 제목이 250ms로 사라진다. 이후 콘텐츠가 상태 표시줄 뒤까지 이어지며 상단 그라데이션이 가독성을 유지한다. 콘텐츠 시작으로 돌아오면 작은 앱 바와 큰 제목이 순서대로 복원된다. 화면별로 불투명 앱 바 배경을 덧칠하거나 자체 스크롤 애니메이션을 추가하지 않는다.

scaffold가 전달한 padding과 시스템 inset을 적용한다. 상태 표시줄 여백을 중복 추가하지 않고, 하단 시스템 영역과 입력 화면의 IME를 고려한다. 하단 플로팅 툴바가 있으면 스크롤 콘텐츠에 툴바 높이와 화면 경계 여백을 확보해 마지막 항목이 가려지지 않게 한다. 긴 목록은 `LazyColumn`, 짧은 폼은 스크롤 가능한 `Column`을 사용하며 텍스트가 늘어나도 행이 잘리지 않게 한다.

| 설정 홈 카테고리 행 | 최소 높이 72dp, 40dp 원형 아이콘 표면 안에 24dp 아이콘 |
| 실행환경 상세의 진행 내용 | 그룹 행 표면 안쪽 16dp |

새 일반 설정 화면은 이 기본값을 따른다. 현재 USB 화면의 섹션 간격 24dp, 툴바 설정의 16dp 간격, 업데이트 화면의 16dp 콘텐츠 여백·20dp 카드 안쪽 여백은 각 화면의 기존 구성이다. 해당 화면에 항목을 추가할 때는 주변 구현을 따르며, 기본값을 적용하기 위해 요청 범위 밖의 화면을 일괄 수정하지 않는다.

### 섹션과 그룹

관련 행은 섹션 제목 아래 `SettingsGroup`으로 묶는다. 기존 `SettingsSection`, `ProfileSection`, `EnvironmentSection`을 해당 화면에서 재사용한다. 섹션마다 같은 모양의 카드가 반복되는 계층을 유지하고, 개별 옵션마다 독립적인 큰 카드를 만들지 않는다.

`SettingsGroup`은 바깥 클리핑과 2dp 간격을 제공한다. 행에는 `terminalListItemShapes()`와 `terminalSettingsListItemColors()`를 적용한다. 읽기 전용 행·진행 내용·사용자 글꼴 탭처럼 클릭형 `ListItem`이 아닌 내용에는 `settingsItemSurface()`를 적용해 같은 표면을 유지한다. 한 행만 있으면 그룹 클리핑으로 네 바깥 모서리가 모두 크게 보인다. 그룹 전체를 다시 색칠해 2dp 간격을 없애거나 구분선을 추가하지 않는다.

실행환경 목록처럼 행마다 지연 로딩이 필요한 경우에는 전체 그룹을 하나의 lazy item으로 만들지 않는다. `EnvironmentGroupCard`처럼 첫 행의 위쪽과 마지막 행의 아래쪽에 28dp 모서리를 적용하고, 나머지 모서리는 4dp로 유지해 같은 그룹 형태를 만든다. 툴바 순서 편집처럼 행이 그룹 밖으로 움직이는 경우에는 기존 드래그 구현의 행별 곡률과 그림자 처리를 유지한다.

단순 사용 설명과 제한 안내는 카드 밖의 배경 없는 보조 텍스트로 둔다. 특정 옵션에 필요한 짧은 설명은 그 행의 supporting content에 넣는다. 실행 가능한 설정과 상태 확인 동작은 그룹 안에 둔다. Userspace Linux의 엔진 지원 상태는 공통 읽기 전용 `ListItem`으로 표시하고, AVF 로컬 서비스 이동 행은 실행 섹션의 `SettingsGroup`에 둔다. Userspace Linux 진단은 확인된 APK 엔진 구성만 읽기 전용 행으로 표시하고 배포판 상태를 조회하지 않는다. 제약 사항은 별도 항목·제목·화면 없이 마지막 설정 그룹 아래 카드 밖의 `bodySmall` 보조 텍스트로 표시한다.

로컬 서비스는 AVF Linux 설정 안에서 공통 큰 앱 바, 새로고침 그룹, 지연 로딩 AVF 서비스 목록을 사용한다. 런타임 필터와 수동 등록·편집·삭제 동작은 제공하지 않는다. 목록 행은 공통 `ListItem`과 2dp 간격·28dp 바깥/4dp 안쪽 곡률을 사용하며 이름·실행환경·TCP 포트·확인된 앱 프로토콜·관측 및 전달 상태·Android 접속 주소를 표시한다. 선택한 상세에는 출처·논리적 연결 여부·원본 주소·매핑·오류·식별 정보를 제공한다. AVF 매핑 변경은 저장/취소 대화상자와 호스트 포트 범위 안내를 제공한다. 주소·ID는 선택 가능한 고정폭 글꼴로 표시하며 상태는 텍스트와 아이콘으로 구분한다. 새로고침·조회 실패·빈 목록·미확인·연결 끊김·종료·충돌을 구분하고 확인되지 않은 상태를 활성이나 0개로 추정하지 않는다. 목록 위치·포트 매핑 편집 초안은 재생성 시 복원한다.

세션 툴의 기본·확장 헤더와 툴바가 없는 초기 빈 터미널 우측 상단은 기존 위치·48dp 터치 영역의 공통 `TerminalSettingsButton`을 사용한다. Rounded `settings` 아이콘을 누르면 기존 설정 화면을 바로 연다. 로컬 서비스는 **AVF Linux → 실행 → 로컬 서비스**와 AVF 하위 설정 검색에서 접근하며 AVF 권한이 없는 경우 검색에서도 숨긴다. 세션 탭·새 세션·툴바 높이·제스처·도구 페이지는 변경하지 않는다.

## 5. 설정 항목 유형과 조작 규칙

설정 홈부터 모든 하위 화면·편집 대화상자까지 설명은 핵심 기능과 필요한 조건을 한두 개의 짧은 문장으로 작성한다. 제목 반복·중복 안내·불필요한 내부 구현 설명은 줄이고 한국어·영어를 함께 정리한다. 권한 범위, 적용 시점, 보안·데이터 손실 경고, 필수 제한은 길더라도 유지하며 말줄임으로 숨기지 않는다. 상세 도움말은 반복 표현과 조작 위치 설명을 줄여 필요한 사용법을 간결하게 전달한다.

설정 행의 제목·설명은 시작 방향에 정렬한다. 앞쪽 아이콘과 뒤쪽 값·아이콘·컨트롤은 설명이 여러 줄이어도 행 전체에서 수직 중앙에 둔다. 모든 상세 행에 설정 홈의 원형 아이콘 배경을 반복하지 않는다. 앞쪽 아이콘은 실행환경이나 동작을 구분하는 데 도움이 될 때만 사용한다.

| 유형 | 행의 표시 | 조작과 저장 |
| --- | --- | --- |
| 켜기·끄기 | 제목·설명과 끝쪽 `Switch` | `BooleanSetting` 패턴을 따른다. 행 전체가 한 번만 toggle되며 자식 Switch의 `onCheckedChange`는 `null`로 둔다. 스위치 역할과 상태를 접근성에 전달하고 일반 설정에서는 즉시 반영한다. |
| 단일 선택 | 제목·설명과 현재 선택값 | `SettingsChoiceRow`의 라디오 선택 대화상자를 사용한다. 전체 선택 행을 누를 수 있고 **저장**에서만 값을 반영한다. 현재 값 영역은 기존 최대 160dp 제한을 참고해 본문 공간을 확보한다. |
| 숫자 | 현재 값과 단위 | `IntegerSetting` 패턴의 입력 대화상자를 사용한다. 단위·범위를 안내하고 전체 입력이 유효할 때만 저장과 IME 완료를 허용한다. |
| 경로·짧은 텍스트 | 현재 값 또는 설명 영역의 값 | `ProfileField` 패턴으로 입력 대화상자를 연다. 값 수정 행에는 탐색 화살표를 붙이지 않는다. 긴 값은 설명 영역이나 대화상자에서 읽을 수 있게 한다. |
| 하위 화면·시스템 설정 이동 | 제목·설명과 끝쪽 `>` | `ActionSetting` 등 기존 탐색 행을 사용한다. 설정 홈의 1차 카테고리는 화살표를 생략하는 예외다. |
| 설치·재시도·제거 등 작업 | 명확한 동작 이름, 필요한 설명과 동작 아이콘 | 실행환경의 `EnvironmentActionSetting`처럼 전체 너비의 작업 행을 사용한다. 진행 중 중복 실행을 막고 삭제·제거는 영향 설명과 확인을 제공한다. |
| 읽기 전용 정보 | 제목과 상태·값 | 클릭 의미를 추가하지 않고 공통 표면을 유지한다. 앱 버전·리비전처럼 복사가 필요한 값은 선택 가능하게 하고 긴 값은 줄바꿈한다. |
| 단순 안내 | 카드 밖 보조 텍스트 | 클릭·탐색 화살표·옵션 사이 구분선을 부여하지 않는다. |
| 펼침 정보 | 제목과 아래 방향 꺾쇠 | `SettingsExpansionContent`·`SettingsExpansionIcon`을 재사용한다. 펼침·접힘 상태를 접근성으로 알린다. |

선택지가 적고 화면 전체 상태를 즉시 전환하는 경우에는 `FilterChip`이나 사용자 글꼴 스타일의 `SecondaryTabRow` 패턴을 사용할 수 있다. 일반 단일 선택 설정은 라디오 대화상자를 기본으로 한다. 칩을 쓰는 경우 Material 기본 크기를 유지하고 좁은 화면에서는 줄바꿈한다.

앱 업데이트 화면은 상태 카드로 시작하며 채널 이름과 채널 설명을 표시하지 않는다. **TERM Debug**는 같은 디버그 키의 APK로 직접 업데이트하도록 상태 카드에서 안내한다.

조건부 설정은 관련 옵션 가까이에 배치한다. 사용할 수 없는 이유를 설명에 표시하고 `enabled = false`와 공통 비활성 색상을 사용한다. 확인 중·측정 불가·지원 불가를 꺼짐이나 0으로 표시하지 않는다. 실제로 제공하지 않는 동작을 정상 버튼처럼 노출하거나 UI에서 성공 상태를 추정하지 않는다.

## 6. 상태·편집·피드백

일반 설정의 스위치는 즉시 저장하지만 숫자·경로·단일 선택은 저장값과 입력 초안을 분리한다. 대화상자를 열 때 현재 값을 초안에 복사하고, 취소·바깥 터치·뒤로가기는 기존 값을 유지한다. 입력 검증 실패는 필드와 안내에 표시하고 저장을 비활성화한다. 화면 재생성 시 초안과 대화상자 상태를 복원한다.

사용자 글꼴 추가는 파일 검증과 앱 내부 사본 저장이 성공한 뒤 즉시 반영한다. 실패하면 안내를 표시하고 기존 목록·우선순위·사본을 유지한다. 사본은 앱 업데이트와 원본 문서의 이동·삭제·읽기 권한 상실 후에도 사용하며, 기존 URI만 저장된 항목은 처음 읽을 수 있을 때 사본을 만든다. 일반·이탤릭 양쪽 목록에서 같은 원본을 모두 제거하면 해당 사본도 삭제한다.

프로필·팔레트·단축키처럼 전체 저장이 있는 편집기는 대화상자의 **저장**도 화면 초안만 변경한다. 전체 **저장** 전에는 영속화하지 않고, 변경 후 나갈 때는 폐기를 확인한다. 툴바 도구 추가·제거·순서 변경은 현재 구현처럼 즉시 저장하며 제거가 도구 내부 설정을 지우지 않게 한다. 같은 화면 안에서 새 옵션만 다른 저장 방식을 사용하지 않는다.

프로필·워크스페이스 생성 및 편집의 이름 변경 대화상자와 프로필의 실행환경 사용 방식 선택 대화상자는 **확인·취소** 버튼을 사용한다. 확인은 부모 화면의 초안만 변경하며 전체 **저장**에서 영속화한다.

프로필 편집 화면의 재생성·종료에 따른 비동기 작업 취소는 오류로 표시하지 않는다. 입력 초안은 복원하되 일시적인 조회·저장·삭제 오류는 새 화면에 복원하지 않으며, 저장·삭제를 재시도할 때 이전 오류를 지운다.

새 프로필 이름은 생성 화면에서 선택한 실행환경 이름이나 새 실행환경의 실행 방식·배포판 이름으로 미리 채운다. 기존 프로필 이름과 겹치면 `Native (2)`처럼 숫자 접미사를 붙인다. 직접 이름을 수정하기 전까지 선택 변경을 따르며, 수정한 이름과 기존 프로필·복제본 이름은 유지한다. 기본 이름과 자동 갱신 여부도 화면 재생성 시 복원하며 전체 저장 전에는 영속화하지 않는다.

새 실행환경의 기본 이름은 `env-프로필 이름`으로 표시하고 저장하며, 기존 실행환경과 겹치면 `(2)`부터 숫자 접미사를 붙인다. 직접 실행환경 이름을 수정하기 전까지 프로필 이름 변경을 따르고, 수정한 실행환경 이름은 초안과 화면 재생성 후에도 유지한다.

프로필 관리 목록의 순서 편집은 툴바 설정과 같은 편집·완료 FAB를 사용한다. 편집 중에는 프로필 편집 화면으로 이동하지 않고 드래그 핸들과 접근성 위로·아래로 동작으로 정렬한다. 드롭 시 즉시 저장하며 드래그 취소는 원래 순서를 유지한다. 다중 행 높이를 보존하고 화면 가장자리에서 자동 스크롤하며 하단 FAB를 위한 콘텐츠 여백을 확보한다. 저장한 순서는 세션 툴과 빈 화면의 새 세션 목록에도 적용된다. 순서를 편집한 뒤 새로 만든 프로필은 목록 끝에 추가하며 삭제된 프로필은 제외한다.

툴바 도구는 세션·터미널 단축키·명령 기록으로 구성한다. 장치·앱 메모리는 진단 및 리포트의 메모리 Activity로, 개별 세션 RSS는 세션 탭의 작업 메뉴에서 여는 세션 정보로 옮긴다. 이전 설정에 제거된 도구 ID가 남아 있으면 읽을 때 제외하고 나머지 도구의 순서와 추가 툴 사용 여부를 유지한다. 제거된 도구의 기존 설정 진입은 툴바 설정으로 연결하며 검색 목록에는 표시하지 않는다. 도구 내부의 이전 저장 데이터는 변경하지 않는다.

기존 프로필 편집과 실행환경 상세의 주요 동작은 하단 중앙의 `HorizontalFloatingToolbar`와 공통 `FloatingToolbarAction`을 따른다. Material 기본 표면·높이·패딩·그림자와 원형 아이콘 버튼을 유지하고, 접근성 설명과 툴팁으로 동작 이름을 제공한다. 새 프로필·복제본 생성은 마지막 설정 뒤 전체 너비의 채움 스타일 저장 버튼을 사용한다. 저장·복제·삭제에는 각각 저장·복사·휴지통 아이콘을 사용하며 삭제는 `error` 색과 확인 절차를 따른다.

실행환경 상세의 **실행환경 시작**은 시작 동작을 나타내는 Material Symbols Rounded의 비채움 `play_arrow` 벡터 아이콘을 32dp로 표시하며, 버튼의 48dp 터치 영역을 유지한다.

**실행환경 삭제**는 기존 하단 툴바에서 한 번 확인한다. Userspace Linux 확인창은 배포판 이미지·설치 캐시·패키지·홈·설정의 삭제와 기존 /workspace·공유 디렉토리의 보존을, AVF 확인창은 배포판 이미지·패키지·홈·설정·VM 영속 상태·VM 안의 사본 삭제와 호스트 공유 디렉토리 보존을 명시한다. 별도 배포판 이미지 제거를 먼저 요구하지 않으며 설치·관리 작업 중에는 삭제를 비활성화한다. AVF 파일 삭제는 플랫폼에서 해당 VM의 중지 또는 부재를 확인한 뒤 진행한다.

AVF 온라인 설치 동의에는 가상 머신의 초기 실행과 인터넷을 통한 패키지 목록 갱신을 명시한다. 이미지 설치 이후 **배포판 초기 실행 준비**, **최신 패키지 목록 가져오기**를 진행 단계로 표시한다. 설치 파일 존재와 패키지 목록 초기화 상태를 구분하며, 실패·취소 후에도 이미지가 있으면 **갱신 필요**와 **패키지 목록 갱신 재시도**를 표시한다. 성공한 초기 갱신 시각만 표시하고 현재도 최신이라는 뜻으로 사용하지 않는다. 재시도는 동일 설치 작업 소유자를 사용하며 이미지 파일을 다시 받지 않는다. 설치·다운로드 상태는 해당 실행환경의 그룹 안에서 현재 상태와 진행을 읽을 수 있게 한다. 상태·작업·진행 행은 같은 2dp 간격과 표면을 사용하며 진행 확인을 모달에만 한정하지 않는다. 측정한 전체량이 있는 현재 단계에는 determinate wavy progress, 전체량을 모르면 indeterminate 표시를 사용한다. 현재 단계 진행률을 전체 설치 완료율로 표현하거나 남은 시간을 추정하지 않는다. 완료·실패·취소 후에는 진행 애니메이션과 경과 시간 증가를 멈춘다.

Userspace Linux 배포판 설치와 AVF Linux 이미지 설치는 공통 `InstallationConfirmationDialog`, `InstallationProgressDialog`, `InstallationProgressCard`를 사용한다. 확인창의 설명·버튼 모양과 진행 창의 제목·스크롤·닫기를 맞추고, 실행환경 상세도 같은 진행 카드를 그룹 안에 표시한다. 카드에는 현재 상태·작업 내용, 현재 단계의 진행률·용량·경과 시간, 가능한 설치 동작, 단계 목록, 안내를 순서대로 배치한다. 설치 취소와 진행 창에서 직접 제공하는 배포판 재시도는 긴 단계 목록보다 먼저 표시하며 제목을 대화상자와 카드에 중복하지 않는다. 실행환경 상세의 재시도 행과 배포판·이미지별 실제 단계, 필요한 권한·여유 공간·초기화 안내는 유지한다.

AVF Linux과 Userspace Linux의 설치 진행에는 **설치 취소**를 제공한다. 실행환경 상세와 설치 창에서 같은 작업 소유자에게 취소를 전달하며, 취소 요청 후 중복 요청을 막고 실제 중단 상태를 표시한다. **닫기**와 뒤로가기는 설치를 계속 유지한다. 취소된 설치는 같은 실행환경에서 다시 요청할 수 있으며 기존 사용자 데이터는 제거하지 않는다.

AVF 세션 시작은 선택된 새 탭의 본문 중앙에 `LoadingIndicator`만 표시하는 기존 준비 화면을 따른다. 설치 진행의 상세 정보는 실행환경 상세나 기존 진행 화면에 둔다. 이미지 설치 중 터미널 화면에는 **AVF Linux 이미지 설치 진행 보기** 버튼을 표시하지 않는다. 오류는 오류 설명과 가능한 재시도·닫기 동작을 제공한다. 화면 닫기·뒤로가기·재생성은 런타임 작업이나 세션 종료가 아니다. UI는 실제 상태를 관찰하고 명시적인 사용자 동작을 전달한다.

펼침 높이와 꺾쇠 회전은 테마의 spatial spec, 투명도는 effects spec을 사용한다. 시스템 애니메이션 배율을 따르고 전환 도중 다시 누르면 현재 위치에서 이어서 전환한다. 새 화면에 임의의 장식 모션이나 독립적인 전환 규칙을 추가하지 않는다.

## 7. 새 설정을 추가하는 절차

백업 생성은 **실행환경 → 환경 상세 → 백업 만들기**, 가져오기는 **실행환경 → 백업 및 복원 → 백업 가져오기**에서 제공한다. 가져오기는 실행환경 선택 없이 독립적인 파일을 선택하며 설정 홈에 별도 카테고리를 두지 않는다. 공통 `SettingsPageScaffold`, 섹션·그룹·선택·스위치 행을 재사용하며 한글·영문 검색 항목을 함께 등록한다. 생성 화면은 Data/Full, 프로필, 워크스페이스, 기본 켜짐 암호화와 비밀번호 확인을 제공한다. 홈·설정 파일과 배포판·패키지의 포함 범위는 선택한 백업 유형 행의 설명으로 표시하며 유형 변경에 맞춰 갱신한다. 진행 중에도 유형 이름과 설명을 유지한다. 실행환경 목록의 백업 가져오기·환경 상세의 백업 만들기·생성 화면의 저장 위치 선택 행은 앞쪽 아이콘을 표시하지 않는다. 백업 시작은 생성 화면의 스크롤 콘텐츠 마지막에 프로필 생성 화면의 저장 버튼과 같은 전체 너비 버튼으로 배치한다. Legacy 공유 워크스페이스는 별도 동의가 필요하다. SAF 파일 선택 후 명시적으로 시작하며 파일 선택만으로 작업을 실행하지 않는다. 가져오기는 미검증 메타데이터 미리보기, 새 이름, 기본 꺼짐 프로필 가져오기와 출처 신뢰 확인 후 새 환경 복원을 실행한다. 단계·처리 용량·실패 이유·취소·재시도·완료 환경 열기를 같은 화면과 작업 기록에서 제공한다. 화면 닫기·재생성은 작업을 취소하지 않으며 활성화 중에는 취소를 비활성화한다. 비밀번호는 저장 상태로 보존하지 않는다.

1. **설정의 범위를 결정한다.** 앱 공통·터미널 표시/입력·프로필 실행 설정·개별 실행환경 작업·엔진 전역 정책 중 어디에 속하는지 확인한다. 사용자가 효과를 예상할 수 있는 기존 카테고리와 섹션에 배치한다.
2. **가장 가까운 기존 행을 기준으로 삼는다.** 같은 화면의 `SettingsSection`·`ProfileSection`·`EnvironmentSection`과 위 유형 표의 컴포넌트를 재사용한다. 새 옵션 하나 때문에 별도 카드 체계나 범용 설정 프레임워크를 도입하지 않는다.
3. **제목·설명·기본값·적용 시점을 정한다.** 제목은 짧은 기능명, 설명은 사용자에게 생기는 효과와 필요한 조건으로 작성한다. 변경이 새 세션에만 적용되거나 권한·설치가 필요하면 해당 행에서 안내한다. 일반 안내는 ‘~합니다 / ~하세요’ 문체를 유지한다.
4. **주변 배치와 상태를 맞춘다.** 관련 옵션을 인접하게 두고 종속 옵션은 기준 옵션 뒤에 둔다. 삭제 등 영향이 큰 작업은 일반 선택과 구분하고 확인을 제공한다. 기존 그룹의 표면·2dp 간격·모서리·수직 정렬·비활성 규칙을 유지한다.
5. **문자열과 검색을 함께 갱신한다.** 사용자 문구는 `res/values`와 `res/values-en`의 관련 문자열 리소스에 추가한다. 검색 가능한 설정은 `SettingsSearch.kt`에 제목·설명·경로·대상을 등록한다. 새 상위 카테고리라면 `SettingsOverview`의 그룹 구성과 `SettingsActivity.open`의 목적지 분기도 함께 갱신한다.
6. **탐색과 저장을 검증한다.** 검색 결과는 화면을 열기만 해야 하며 옵션 변경·설치·삭제를 실행하지 않는다. 일반 상세 검색의 `sectionIndex`는 `LazyColumn`의 설명 항목 0을 포함한 인덱스다. 섹션을 추가·이동하면 검색 인덱스와 직접 인덱스를 전달하는 화면 이동도 함께 맞춘다. 특권 없는 사용자에게 숨겨지는 AVF 항목이 검색에 다시 나타나지 않게 한다.
7. **관련 문서를 갱신한다.** 새 동작·저장 방식·공통 배치 기준이 바뀌면 이 문서와 `DESIGN_SYSTEM.md`의 해당 계약, 필요한 사용자 안내를 요청 범위 안에서 갱신한다.

예를 들어 기록 관련 켜기·끄기 옵션을 추가한다면 **터미널 설정 → 터미널 기록**의 기존 그룹에 스위치 행을 넣고, 그 섹션으로 이동하는 검색 항목을 추가한다. 새 최상위 카테고리나 독립 카드, 해당 스위치만을 위한 별도 저장 버튼을 만들지 않는다.

기본 상세 화면의 정보 순서는 다음과 같다. 실제 동작과 치수는 공통 컴포넌트에 맡긴다.

```text
공통 큰 앱 바 / 원형 뒤로가기
화면 설명

섹션 제목
╭ 관련 옵션의 그룹 ─────────────╮
│ 제목 · 설명          현재 값 │
│          2dp 간격             │
│ 제목 · 설명          스위치  │
╰──────────────────────────────╯
카드 밖의 필요한 사용 안내

다음 섹션 제목과 그룹
하단 시스템 여백 / 편집 툴바 여유 공간
```

## 8. 변경 완료 기준

UI 변경의 검증 범위와 빌드 명령은 [AGENTS.md](../AGENTS.md)를 따른다. 아래 항목 중 변경과 관련된 사항을 확인하고, 기기 검증이 불가능하면 소스 분석과 실제 실행 결과를 구분해 보고한다.

- 기존 카테고리·섹션·설정 행 패턴과 일관되고 불필요한 독립 카드나 새 탐색 계층이 없다.
- 긴 한국어·영어 문구, 큰 글꼴, 좁은 화면·가로 화면에서도 값과 컨트롤이 겹치거나 마지막 동작이 가려지지 않는다.
- 큰 제목의 접힘·복원, 상단 페이드, 시스템 여백, IME, 하단 툴바가 공통 동작을 유지한다.
- 스위치는 행이나 컨트롤을 눌러도 한 번만 바뀌며, 선택·입력의 저장·취소·유효성 검사와 재생성 복원이 의도대로 동작한다.
- 비활성 행은 표면을 유지하고 사용 불가 이유를 표시하며, 확인 중·실패·완료 상태가 실제 상태와 일치한다.
- 검색에서 올바른 화면과 섹션이 열리고 검색 자체가 설정 동작을 실행하지 않는다.
- 아이콘 버튼의 접근성 설명, 스위치·라디오의 역할과 상태, 펼침 상태, 복사가 필요한 값의 선택이 유지된다.
- 작업 중 화면 이탈이 세션·설치를 종료하지 않고, 중복 실행과 삭제 확인이 해당 화면의 기존 규칙을 따른다.

## 워크스페이스와 공유 디렉토리

확장된 세션 탭의 케밥 버튼은 버튼에 정렬된 Expressive 메뉴에서 **이름 변경**과 **워크스페이스 이동**을 제공한다. 기본 크기의 탭을 길게 눌러도 같은 메뉴를 열며 메뉴 조작은 활성 세션을 바꾸지 않는다. 이동 창은 대상 세션 이름, 현재 소속을 표시하는 라디오 선택 그룹, 별도의 임시 워크스페이스 만들기 행과 **이동 / 취소** 버튼으로 구성한다. 미소속과 등록된 워크스페이스는 같은 행·아이콘·48dp 조작 영역을 사용하며 임시 그룹에는 보조 설명을 표시한다. 선택은 초안으로 유지하고 이동에서만 적용하며 현재 소속 또는 삭제된 목적지에는 이동을 비활성화한다. 긴 목록은 스크롤하며 만들기와 확인 동작은 목록 아래에 유지한다. 취소·뒤로가기는 이동하지 않고 화면 재생성은 대상과 선택 초안을 복원한다. 임시 생성창은 이동창과 겹치지 않으며 취소하면 기존 선택으로 돌아온다.

워크스페이스 상세의 **실행 구성 → 시작 시 실행**은 선택 개수 또는 선택 없음을 표시하는 공통 설정 행이다. 체크박스 대화상자에서 여러 구성을 선택하며 48dp 조작 영역·전체 행 토글·저장/취소·재생성 복원을 제공한다. 대화상자의 저장은 워크스페이스 초안만 바꾸고 전체 저장 시 적용한다. 실행 구성이 없으면 행을 비활성화하며 기본 선택은 없다. 세션이나 준비 중 요청이 없는 워크스페이스를 직접 선택할 때 선택한 구성을 목록 순서대로 시작한다. 설치 확인은 각 구성의 기존 동의 경로를 유지하며 프로필·작업 디렉터리 편집으로 시작 선택이 사라지지 않는다. 검색은 워크스페이스 목록으로 이동한다.

설정 홈 첫 그룹의 프로필 다음에 **워크스페이스**를 두고, **공유 디렉토리**는 그 아래의 별도 그룹에 둔다. 공통 Material 3 Scaffold·섹션·그룹·행·저장/취소 대화상자와 한국어·영어 검색 인덱스를 사용한다. 설정 홈과 검색 결과의 두 항목은 다른 카테고리와 같은 짧은 관리 요약을 사용하고, 공유 방식·수명주기 설명은 해당 목록과 상세에서 표시한다. 두 목록은 만들기 행과 이름·요약·탐색 화살표를 가진 항목 행으로 구성하며, 항목을 누르면 전체 화면 상세 편집으로 이동한다. 상세는 프로필 설정과 같은 기본 설정 섹션, 필드 행에서 여는 단일 값 저장/취소 대화상자, 기존 항목의 하단 저장·삭제 툴바와 새 항목의 전체 너비 채움 스타일 저장 버튼을 사용한다. 변경된 초안으로 뒤로가면 폐기를 확인하며 목록·상세·필드 대화상자의 초안은 화면 재생성 시 유지한다. 워크스페이스는 영구 그룹의 이름·실행 구성과 임시 그룹의 영구 전환을 제공한다. 실행 구성 이름은 선택 사항이며 비우면 목록·시작 선택·새 세션 메뉴에 참조 프로필 이름을 표시한다. 이름을 지정한 구성만 사용자 지정 탭 제목을 설정한다. 실행 구성은 상세 편집 화면에서 선택적인 이름, 공통 선택 대화상자의 기존 프로필 선택, 선택적인 절대 작업 디렉터리를 제공한다. 실행 구성의 저장·삭제는 워크스페이스 초안만 바꾸며 워크스페이스 전체 저장 시 적용한다. 원본 프로필을 바꾸지 않는다고 안내하고, 저장되지 않은 구성은 실행할 수 없다. 삭제 확인은 세션을 미소속으로 옮기고 프로세스·파일을 보존한다고 설명한다.

워크스페이스 목록은 프로필 목록처럼 설명, 별도의 만들기 그룹, 아이콘·이름·실행 구성 요약을 가진 목록 그룹 순서로 배치한다. 목록(`WorkspacesActivity`), 워크스페이스 상세(`WorkspaceEditActivity`), 실행 구성 상세(`WorkspaceLaunchEditActivity`)는 각각 별도 Activity이며 표준 Activity 이동과 결과 반환을 사용한다. 새 워크스페이스의 기본 이름은 앱 언어와 관계없이 영어 **Workspace**이며 기존 이름과 겹치면 `(2)`부터 번호를 붙인다. 초안 생성 시 한 번 제안하고 화면 재생성·서비스 재연결은 수정한 이름을 덮어쓰지 않는다. 아이콘 행은 프로필 아이콘 설정과 같은 3열 후보 선택 모달을 열며 탐색 화살표를 표시하지 않는다. 프로필과 워크스페이스 아이콘 모달의 버튼은 **확인·취소**로 표시한다. 상세의 기본 설정은 이름·아이콘 행으로 구성한다. 아이콘은 프로필과 같은 기본 후보 33개에서 선택하며 기존 실행환경·앱 아이콘에 Material Symbols Rounded 14종을 추가한다. 후보와 선택된 아이콘 설정 행에는 아이콘 이름을 표시하지 않고 접근성 설명으로 제공한다. 기존 워크스페이스의 기본값은 `team_dashboard`이며 자동 후보도 이 기본 아이콘을 사용한다. 아이콘 모달의 확인과 실행 구성 편집의 저장·삭제는 부모 워크스페이스 초안만 바꾸고 전체 저장 시 함께 적용한다. 아이콘 모달의 취소·바깥 터치·뒤로가기는 기존 초안을 유지하며 모달 상태와 선택은 재생성 시 복원한다. 프로필 아이콘 설정은 새 사용자 지정 이미지 추가를 제공하지 않으며 기존에 추가한 이미지의 선택·삭제와 저장된 이미지 참조는 유지한다. 하위 화면과 중지된 부모 화면의 재생성 후에도 초안·선택·미처리 결과를 복원한다. 단일 이름·경로·프로필 값은 기존 프로필 설정과 같은 저장/취소 대화상자로 편집한다.

워크스페이스 목록의 순서 편집은 프로필과 같은 **편집·완료** FAB와 드래그 핸들을 사용한다. 편집 중에는 상세 화면으로 이동하지 않으며 드롭과 접근성 위로·아래로 이동을 즉시 저장한다. 드래그 취소는 기존 순서를 유지하고 화면 가장자리에서 자동 스크롤한다. 저장한 순서는 워크스페이스 선택 메뉴와 세션 이동 창에도 반영한다. 이름·실행 구성 수정과 임시 그룹의 영구 전환은 위치를 유지하며 새 워크스페이스는 끝에 추가한다. 화면 재생성은 편집 모드를 복원하고 저장 중·연결 끊김에는 정렬을 막는다.

세션 툴 헤더 왼쪽의 워크스페이스 선택기는 기본 크기에서 아이콘만 표시하고 워크스페이스에 세션이 없거나 확장 크기일 때는 아이콘과 이름을 툴바 배경 위에 표시한다. 미소속 필터는 세션 유무와 크기에 관계없이 아이콘만 표시한다. 워크스페이스 영역은 별도 배경 박스 없이 새 세션 버튼 앞까지 가용 폭을 사용하며 버튼 터치 영역은 48dp를 보존한다. 헤더와 탭 목록 사이에는 확장 진행률에 따라 0~8dp 여백을 둔다. 확장 헤더의 워크스페이스 선택기 오른쪽에 있는 모두 닫기는 현재 워크스페이스 또는 미소속 필터의 세션만 종료하며 기존 종료 확인 설정을 따른다. 확인 중 새로 생긴 세션과 그룹 밖으로 이동한 세션은 종료 대상에 추가하지 않는다. 세션 목록을 받은 상태에서 소속 세션과 준비 중 요청이 없는 임시 워크스페이스는 같은 자리를 휴지통 모양의 워크스페이스 삭제 버튼으로 바꾼다. 삭제는 런타임에서 전체 세션 상태·현재 임시 여부·소속·준비 중 요청을 재확인하고 기존 메타데이터 삭제 경로를 사용한다. 로딩·연결 끊김·준비 중 요청에는 삭제로 전환하지 않는다. 현재 워크스페이스와 미소속 필터에 세션이 없으면 확장 크기에서도 모두 닫기 버튼을 표시하지 않으며, 삭제 조건을 충족하는 빈 임시 워크스페이스는 삭제 버튼을 유지한다. 세션이 없는 영구 워크스페이스에는 기본·확장 크기 모두 선택기 오른쪽에 `play_arrow` 아이콘의 **기본 세션 실행** 버튼을 표시한다. 버튼은 **시작 시 실행**으로 선택한 구성을 저장 순서대로 실행하며 선택된 구성이 없거나 세션 상태를 확인하지 못하면 비활성화한다. 클릭 시 최신 소속과 준비 중 실행을 다시 확인하고 기존 실행 큐·설치 동의 경로를 재사용한다. 세션이 있지만 닫을 수 있는 세션이 없으면 모두 닫기 버튼을 비활성화한다. 선택기는 모두 닫기 버튼을 제외한 가용 폭을 사용하고 이름은 최대 두 줄로 표시한다. 선택 메뉴는 헤더의 가용 폭과 분리한 실제 선택 버튼 영역을 앵커로 삼아 버튼 바로 위에 열며, 위쪽 공간이 부족하면 Material 기본 대체 위치를 사용한다. 메뉴는 이름의 자연 폭에 맞춰 넓어지며 화면 양옆 16dp 여백 안으로 제한한다. 긴 메뉴 이름은 줄바꿈하여 전체를 표시하고 접근성 설명에는 전체 이름·현재 필터를 제공한다. 선택 메뉴에는 미소속 세션·등록된 워크스페이스·임시 워크스페이스 생성을 제공하고 모든 세션 항목은 표시하지 않으며 현재 필터를 구분하며 세션 실행 항목을 넣지 않는다. 일반 앱 실행·런처 재진입·장시간 백그라운드 복귀·화면 재생성·서비스 재연결은 런타임에 저장된 워크스페이스 필터와 해당 그룹의 마지막 활성 탭을 복원하며 그룹·세션 소속을 보존한다. 저장된 선택이 없는 첫 실행만 미소속 세션으로 시작하고, 워크스페이스 실행 구성과 세션 알림의 명시적 대상 선택은 존중한다. 저장된 빈 그룹 복원 자체는 시작 구성을 다시 실행하지 않는다. 기존에 저장된 모든 세션 선택도 미소속 세션으로 전환한다. 알림으로 다른 그룹의 세션을 열면 해당 워크스페이스 또는 미소속 필터를 선택한다. 이동 대화상자와 선택 메뉴의 그룹 행은 저장한 아이콘을 사용한다. 선택 메뉴의 미소속·등록된 워크스페이스·임시 생성 아이콘은 모두 `MenuDefaults.LeadingIconSize`(현재 20dp)를 사용한다. 미소속 세션은 선택 버튼·선택 메뉴·이동 목록에서 Material Symbols Rounded `team_dashboard` 아이콘을 사용한다. 선택 메뉴의 임시 워크스페이스 만들기 항목은 `add` 아이콘을 사용하고 선택 목록과 별도 메뉴 그룹으로 나누며 그룹 사이에는 `MenuDefaults.GroupSpacing`의 공식 기본 간격(현재 2dp)을 둔다. 만들기 행은 메뉴 하단 위치에 맞춰 `MenuDefaults.trailingItemShape`를 사용하고 위쪽 모서리는 4dp, 아래쪽 모서리는 12dp로 둔다. 세션 툴과 빈 화면의 **새 세션** 목록은 현재 워크스페이스의 실행 구성을 `워크스페이스 이름 · 실행 구성` 카테고리로 먼저 보여주고 기존 프로필 목록을 다음 카테고리로 유지한다. 미소속 필터나 실행 구성이 없는 그룹에는 추가 카테고리를 표시하지 않는다. 실행 구성 행에는 구성 이름과 원본 프로필 이름만 표시하고 기존 설치 상태 아이콘을 유지한다. 구성 이름이 없으면 프로필 이름을 제목으로 표시하며 보조 설명에 중복하지 않는다. 삭제된 프로필 참조는 안내와 함께 실행을 비활성화한다. 새 세션은 기존 `SessionLaunchSpec`·프로필 설치 동의 경로를 유지하며 현재 그룹에 추가하고 원본 프로필을 수정하지 않는다. 탭의 길게 누르기 또는 편집 동작은 이름 변경·워크스페이스 이동 메뉴를 연다. 이동 대화상자는 미소속·기존 그룹·임시 생성 선택을 제공한다. 빈 그룹에서도 다른 세션이 있으면 툴바를 표시하며 저장한 시작 구성이 있는 그룹에 진입할 때만 해당 구성을 자동 실행한다.

공유 디렉토리 목록(`SharedFoldersActivity`)의 **만들기**는 비공개 `SharedFolderCreateActivity`, 기존 항목은 비공개 `SharedFolderEditActivity`를 연다. 목록·만들기·상세는 표준 Activity 이동을 사용하고 기존 공통 편집 UI로 이름과 연결 환경을 초안으로 관리한다. 이름 대화상자는 **확인 / 취소**를 제공하며 확인은 편집 초안에만 반영한다. 전체 **저장**에서만 기존 런타임 Binder 경로로 생성·수정하고, 성공하면 화면을 닫아 목록이 서비스에 다시 연결해 결과를 표시한다. 뒤로가기는 미저장 변경 폐기를 확인하고, 화면 재생성·서비스 재연결은 초안의 UUID·이름·연결 선택과 열린 대화상자를 덮어쓰지 않는다. AVF 파일 복사 대화상자는 상세 Activity에서 열고 기존 런타임 파일 작업을 제출한 뒤 목록의 진행 상태로 돌아온다. 각 Activity는 자신의 서비스 연결만 해제하며 세션·공유 데이터·진행 중 파일 작업을 종료하지 않는다.

공유 디렉토리 상세는 이름 행과 저장된 연결의 Native 호스트 경로/Userspace Linux 경로를 연결 환경의 체크박스 목록보다 앞에 보여준다. 환경 목록이 길어도 현재 접근 경로를 바로 확인할 수 있다. 이름과 연결은 전체 저장 시 함께 적용하며 경로 안내와 AVF 복사는 저장된 설정을 기준으로 제공한다. 초안이 바뀌면 저장 전 파일 복사를 비활성화한다. Native·Userspace Linux는 새 세션부터, AVF는 다음 VM 부팅부터 적용되며 기존 세션이나 VM을 재시작하지 않는다고 안내한다. 연결 설정이 Android UID 격리가 아님을 설명한다. AVF에는 지원 이미지·호환 기기에서 직접 공유되는 경로와 다음 VM 부팅부터 적용된다는 안내를 읽기 전용으로 표시한다. 이름 변경·연결 해제 후에도 기존 마운트가 유지되므로 VM 중지/시작이 필요함을 명시하고 실제 마운트 성공을 UI가 추정하지 않는다. 별도의 파일 사본 가져오기·내보내기는 실행 중 VM·파일 전송 기능 필요, 상대 경로·복사 크기 제한·무결성 검사·덮어쓰기 금지를 동작 가까이에 표시한다. 기존 `/workspace` 데이터의 가져오기·ZIP 내보내기 옵션과 관련 안내·검색 항목은 제공하지 않는다. 파일 작업은 처리 용량·상태·오류·취소를 같은 화면에서 관찰하며 화면 이탈·재생성으로 취소하지 않는다.

Android 17에서 AVF를 선택한 공유 디렉토리는 **Android 공유 저장소** 섹션에 실제 모든 파일 접근 권한과 Android 설정 이동을 표시한다. 권한이 없으면 전환 저장을 비활성화한다. 저장 전 확인 대화상자는 TERM 폴더의 공개 저장 위치, 다른 앱·파일 관리자 노출, 모든 연결 환경이 전환된 사본을 사용한다는 점, 세션·VM·파일 작업 중지 조건과 원본 보존·일반 파일 한도(2 GiB·100,000개)를 설명한다. 취소는 초안을 유지한다. 권한 설정 복귀 시 실제 권한을 다시 읽는다. 기존 앱 전용 AVF 폴더도 상세의 저장으로 전환하며 VM 시작 오류에서 이 경로를 안내한다. 전환된 폴더는 AVF 연결을 해제해도 저장 위치를 유지하고, 권한 해제 시 해당 공유를 사용하는 VM이 중지됨을 알린다. 전체 `/sdcard` 내보내기 선택은 별도이며 폴더 연결로 자동 활성화하지 않는다.


공유 내부저장소는 기존 터미널 설정의 Android 모든 파일 접근 설정 행을 그대로 사용한다. 개별 실행환경 상세의 **권한 → 내부저장소 접근**은 Userspace Linux·AVF의 환경별 연결 선택을 즉시 저장하는 공통 스위치와 실제 Android 모든 파일 접근 설정 이동 행을 제공한다. Userspace Linux·AVF의 새 실행환경 생성에서는 같은 권한 행을 초안으로 제공하고 전체 저장에서만 새 환경·프로필과 함께 반영하며 재생성·런타임 변경·기존 환경 선택 후 복귀에도 선택을 보존한다. 기존 환경 선택은 그 환경의 설정을 수정하지 않는다. 새 환경은 기본 꺼짐, 이전 환경은 기존 동작을 유지한다. Native는 생성 화면의 기본 런타임에서도 내부저장소 접근 스위치를 표시한다. 이 스위치는 실제 공통 Android 권한 상태를 사용하고 누르면 시스템 권한 설정으로 이동하며, 돌아온 뒤 실제 권한을 다시 표시한다. Android 공통 권한 탐색 행은 별도로 유지하고 Native 환경별 접근 차단이 불가능함을 명시한다. 상태는 실제 OS 권한을 표시하고 Native·Userspace Linux와 지원 비보호 AVF 이미지에 공통으로 적용됨을 안내한다. 새 로컬 세션과 다음 AVF VM 부팅의 적용 시점을 구분하고, 권한 해제 시 내부저장소를 공유하는 VM을 중지하며 Android가 앱·다른 세션을 종료할 수 있음을 같은 설명에 표시한다. 이미지 미지원 상태에서 실제 마운트를 성공으로 표시하지 않는다.

진단 진입점은 서비스에 연결하지 않는다. Native·Userspace Linux·AVF 진단은 각 Activity가 백그라운드에서 독립적으로 검사하며 실행환경·세션 상태를 수집하지 않는다. AVF는 Android 15+, 시스템 기능, 두 실제 권한, Custom Image API, VirtualMachineManager, TERM 드라이버의 7개 조건을 충족·미충족·확인 불가로 구분한다. 선행 조건이 부족하면 시스템 API를 호출하지 않고, 권한 부족을 API 미지원으로 표현하지 않는다. ABI와 숨김 API 차단을 구분할 수 없는 오류는 가능한 원인을 함께 안내한다. VM 생성·실행이나 이미지·기존 VM 변경은 진단에 포함하지 않으며 사전 조건 충족은 부팅 성공을 뜻하지 않는다. 내부저장소·공유 디렉토리는 별도 선택 기능 섹션에서 실제 SharedPath 생성자와 addSharedPath 접근을 검사한다. 이 결과는 기본 VM 진단 결과와 분리하며 기본 조건이 부족하면 확인 불가로 남긴다. 공유 API 검사는 파일 생성·내보내기나 virtiofs 서버 실행을 하지 않는다.

메모리 진단은 장치 전체·사용·가용·비율과 앱 합계·UI·:vmhost PSS 및 기존 Android summary 7개 분류를 표시한다. 한 프로세스라도 확인할 수 없으면 합계를 표시하지 않으며 summary 구성이나 세션 RSS를 PSS 총량에 더하지 않는다. 기존 서비스에 자동 생성 없이 연결하고 RESUMED 동안 5초마다 측정하며 진입·복귀·수동 새로고침은 최신값을 읽고 비활성화하면 측정을 취소한다. 세션 정보는 선택한 세션의 RSS만 요청하며 AVF·종료·접근 제한은 확인 불가다. 화면 종료는 연결과 측정만 해제하며 런타임이나 세션을 종료하지 않는다.

AVF의 새 실행환경은 Userspace Linux와 같은 배포판 선택 행에서 Debian·Ubuntu 24.04 LTS·Arch Linux ARM을 선택한다. 전체 프로필 저장 시 배포판을 확정하며 기존 실행환경의 배포판은 변경하지 않는다. 설치 확인에는 선택한 배포판 이름을 표시하고 배포판 이미지 섹션은 해당 배포판의 승인 카탈로그 가용성을 확인한다. 설치·취소·초기 패키지 목록 갱신·재시도·제거의 화면 구성과 작업 소유자는 세 배포판에서 동일하다.
