# Compose Material 3 design system

## Environment backup and restore

**백업 및 복원**은 실행환경 목록의 섹션으로 두고 **백업 가져오기**로 가져오기 화면을 연다. 실행환경 상세의 **백업 만들기**와 가져오기 화면은 기존 앱 테마·설정 Scaffold·그룹 표면을 따른다. 백업 유형은 선택 행, 포함 대상과 암호화는 스위치 행, 비밀번호는 가려진 입력 필드로 제공한다. 홈·설정 파일과 배포판·패키지의 포함 범위는 백업 유형의 supportingContent에 표시한다. 별도의 홈 및 설정 행은 두지 않으며 진행 중에도 유형 이름과 설명을 유지한다. 공유 워크스페이스·민감정보·출처 신뢰 안내는 관련 동작 가까이에 표시한다. 백업 가져오기·백업 만들기·저장 위치 선택 행은 앞쪽 아이콘 없이 공통 설정 행으로 표시한다. 파일 위치는 SAF 시스템 선택기로 지정하고, 실제 작업은 생성 화면 스크롤 콘텐츠 하단의 전체 너비 백업 시작 버튼으로 실행한다. 최종 버튼은 공통 Button·Expressive shape를 사용하고 저장 위치·암호 확인·공유 동의 조건을 충족한 유휴 상태에서만 활성화한다. 진행은 단계 이름과 처리 용량을 표시하며 측정 가능한 단계에만 determinate wavy progress를 사용한다. 완료·실패·취소 시 애니메이션을 멈추고 결과 및 다음 동작을 표시한다. Activity는 런타임 소유 작업을 관찰하며 뒤로가기·화면 재생성은 작업을 중단하지 않는다.

## Direction

TERM의 활성 Android UI는 Jetpack Compose와 Material 3 Expressive를 기준으로 구현한다. Compose 기반선은 2026.08 BOM이며, segmented menu와 최신 Expressive 컴포넌트를 위해 Material 3 `1.5.0-alpha27`을 명시적으로 사용한다. 앱 크롬은 시스템 테마와 관계없이 차가운 회백색 primary와 중립 surface를 갖는 명시적 다크 색상표를 사용하되 터미널 화면의 크롬은 캔버스 배경에 맞춰 조정한다. 일반 앱 UI에서 파란색은 활성·사용 가능·준비·진행 상태처럼 의미가 있는 상태에만 사용하며 민트 계열 색상은 사용하지 않는다. 전체 화면 TUI 배경색 따르기를 켠 터미널 툴바는 아래의 동적 색상 역할을 사용한다.

터미널 캔버스는 예외다. `TerminalView`와 `TerminalAppearance`가 사용자 선택 팔레트, ANSI 색상, 커서, 선택 영역과 배경을 독립적으로 관리하며 Material 앱 색상표가 이를 덮어쓰지 않는다.

터미널 화면은 상단 앱 바 없이 캔버스와 하단 툴바를 사용한다. 세션 툴의 상단에 새 세션·설정 버튼을 고정한다. 기본 크기에서는 왼쪽에 가로 스크롤 세션 탭을 표시하고, 확장 크기에서는 같은 영역에 전체 세션 수와 상태별 개수를 표시하며 그 아래 탭을 세로 목록으로 표시한다. 상태 표시줄 뒤 여백은 현재 터미널 배경색을 사용하며, 터미널 팔레트 변경 후 함께 갱신한다. 툴바 시트는 TUI 배경색 따르기 설정과 관계없이 `TerminalChromeColors.sheetBackground`를 사용한다. 시트 색상은 캔버스에 대비 전경색을 6% 혼합하되 전경 대비가 4.5:1 미만이면 반대 방향으로 혼합한다. 핸들·세션 탭 행·프로필 페이지·스크롤 페이드·탐색 표시줄 뒤 여백은 같은 시트 색상을 사용하고, 둥근 위쪽 모서리는 캔버스 배경을 드러낸다. 캔버스와 시트 색상은 같은 팔레트 전환 프레임을 따르며 글자·아이콘의 대비는 양쪽 표면을 기준으로 보정한다. 일반 셸 또는 TUI 배경색 따르기를 끈 화면에서 탭·단축키·메모리 사용량 카드·세션 메모리 행·명령어셋 항목의 컨테이너는 배경색에 대비 전경색을 14% 혼합하고,
글자·아이콘은 각 배경에 대해 대비가 높은 검정 또는 흰색을 선택한다.
활성 탭과 CTRL·ALT는 대비 4.5:1 이상인 밝은/어두운 파란색을 사용하며,
충족하지 못하면 대비 전경색으로 대체한다. 비선택 탭은 투명 배경을 유지하며,
아이콘·제목·부제목은 배경에 대비 전경색을 60% 혼합한 차분한 색상을 사용한다.
사용자 지정 배경에서 대비가 부족하면 혼합 비율을 5%p씩 높여 4.5:1 이상을 유지한다.
세션 툴의 새 세션·설정 아이콘은 같은 대비 보정 방식으로 전경색을 70% 혼합하여,
기본 검정 배경에서 순백색 대신 차분한 회색을 사용한다.
상태 표시줄·탐색 표시줄 아이콘의 밝기도 터미널 배경에 맞춘다.
세션 시트 내부 프로필 선택 페이지의 배경·프로필 이름·실행환경 설명·아이콘도 같은 대비 색상을 사용한다.
별도 설정 화면은 기존 다크 테마를 유지한다. 터미널 화면의 모달·팝업은 활성 세션의 동적 색상표를 상속하며, 동적 색상이 없거나 활성 세션이 없으면 앱 기본 테마를 사용한다.
전체 화면 TUI 배경색 따르기를 켜고 alternate screen이 활성화되면 확인한 TUI 배경을 seed로 Material Color Utilities의 `SchemeExpressive`(2025 색상 명세, PHONE 플랫폼)에서 M3 동적 색상 역할을 생성한다. `background`·`surface`는 실제 TUI 배경색을 그대로 유지하며, 카드·명령어셋 항목은 `surfaceContainerLow`·`onSurface`, 사용 가능한 일반 단축키·검색 필터 버튼은 저채도 `surfaceContainerHigh`·`onSurface` 역할에서 시작하되, 실제 TUI 배경 및 툴바 시트와 버튼 표면의 대비가 각각 2:1 이상이고 버튼 글자·아이콘의 대비가 4.5:1 이상이 되도록 각각의 HCT 명도를 보정한 전용 색상 쌍, 활성 CTRL·ALT·SHIFT는 `primary`·`onPrimary`, 선택 세션 탭은 `primaryContainer`·`onPrimaryContainer`를 사용한다. 비선택 탭·보조 설명·앱 바 아이콘은 `onSurfaceVariant`, 진행 표시는 `primary`, 구분선은 `outlineVariant`를 사용한다. 터미널 화면 전체와 그 화면에서 여는 모달·팝업은 같은 `MaterialTheme.colorScheme`을 상속해 기본 Material 버튼·메뉴·대화상자·입력 필드에도 생성한 역할을 적용한다. 대화상자 표면은 `surfaceContainerHigh`, 제목·본문은 `onSurface`·`onSurfaceVariant`, 동작 버튼은 `primary`·`onPrimary`를 사용하며 TUI 테마 전환 중에도 같은 전환 프레임을 따른다. 임의의 TUI 배경과 카드 표면에서도 주요 전경 대비가 4.5:1 이상이 되도록 생성된 역할의 HCT 색조·채도를 유지하면서 명도를 보정한다. 시스템 아이콘은 Android의 밝은/어두운 아이콘 중 배경에 대비되는 쪽을 선택한다. 배경 ARGB별 최대 16개 팔레트를 캐시하여 같은 배경의 출력 프레임마다 색상을 다시 생성하지 않는다. 옵션을 끄거나 alternate screen을 종료하면 기존 터미널 대비 색상으로 복원한다.
기본 크기 세션 툴의 가로 탭 목록은 워크스페이스 버튼과 새 세션 버튼 사이의 양쪽 경계에 20dp 그라데이션을 사용한다. 각 경계는 해당 방향으로 더 스크롤할 수 있을 때만 공통 `ScrollEdgeFade`로 표시하며 툴바 배경색·투명도 전환과 RTL 방향을 따른다. 오버레이는 탭 조작과 스크롤 입력을 가로채지 않는다.
**터미널 설정 → 사용자 설정 → 전체 화면 TUI 배경색 따르기**는 기본적으로 꺼져 있다. 켜면 alternate screen에서 명시적으로 설정된 OSC 기본 배경을 최우선으로 사용하고, 화면 전체 지움 배경이나 현재 셀에서 확인한 배경을 세션 툴·탭·툴바·터미널 외곽 여백·경계 그라데이션에 적용한다. OSC 조회는 배경 선언으로 취급하지 않으며 기본 팔레트와 같은 RGB를 설정해도 명시적 선언은 유지한다. 줄·부분 영역의 지움이나 diff·선택 강조는 화면 전체 지움 스타일을 바꾸지 않는다. 명시적 OSC 배경이 없으면 화면 양 끝을 포함해 최대 32×32 셀을 분산 표본 추출한다. 이전 전체 지움 배경이 표본에 남아 있으면 그 색을 유지한다. 그 색이 더는 보이지 않으면 한 색이 표본의 80% 이상이며 최대 두 행을 제외한 모든 표본 행에 나타날 때 추정 색을 사용한다. 기본 배경으로 다시 칠한 화면도 같은 기준으로 반영하지만, 기본 배경 셀이 섞인 화면에서 다른 색을 추정하지 않는다. 분할 창 등 판단이 어려운 화면에서는 이전 전체 지움 배경을 유지하고, 지움 정보가 없으면 세션 팔레트를 사용한다. ANSI·256색·truecolor와 반전·굵게·깜박임 속성을 렌더러와 같은 방식으로 해석하며 시스템 표시줄 아이콘 대비도 갱신한다. 명시적 OSC 배경의 전역 반전도 반영한다. OSC 선언 여부와 화면별 전체 지움 스타일은 체크포인트로 보존하고, 새 alternate screen을 비우면 이전 앱의 지움 정보는 제거한다. 화면 전체를 지우지 않고 셀만 다시 칠하는 테마 변경도 위 기준을 충족하면 다음 출력 프레임에 반영한다. 화면 전체를 같은 강조색으로 덮는 경우는 셀 색상만으로 테마 변경과 구별할 수 없다. 출력·탭 전환·설정 복귀·Activity 재생성 때 활성 세션을 기준으로 갱신하고, synchronized output 중에는 완료 또는 타임아웃까지 갱신을 미룬다. 옵션을 끄거나 TUI가 alternate screen을 종료하면 현재 세션의 팔레트 배경색으로 복원한다. 터미널 렌더러의 화면 전체 채움과 View 배경에도 같은 색상을 적용해 문자 격자 밖의 위·아래·오른쪽 여백에 기존 팔레트 배경이 남지 않게 한다. 셀의 명시적 배경·기본 배경·반전·선택 색상과 터미널 앱이 보는 팔레트 및 프로토콜 상태는 변경하지 않는다. 메모리 카드와 명령어셋 항목은 같은 반응형 컨테이너·대비 전경색을 사용하며 메모리 진행 표시와 구분선도 반응형 색상으로 표시한다.
세션과 워크스페이스가 모두 없는 초기 화면에서도 하단 세션 툴바와 핸들을 유지하며 메인 안내 영역에는 Material `background` 색을 사용하고 툴바에는 이 색상을 기준으로 명도 차이를 준 공통 시트 색상을 사용한다. 빈 화면에는 안내만 표시하고 워크스페이스·새 세션·설정 버튼은 툴바에 둔다. 새 세션의 프로필 선택은 툴바 내부 페이지를 사용한다. 세션을 열면 콘텐츠는 터미널 배경색을, 툴바는 해당 배경에서 만든 시트 색상을 사용한다.

팔레트 편집은 별도 화면에서 전경·배경·커서와 ANSI 표준/밝은 색상을 견본으로 보여 준다. 색상 견본을 누르면 Material 3 바텀시트의 정사각형 색상 영역에서 채도(가로, 오른쪽으로 증가)와 밝기(세로, 위쪽으로 증가)를 조절하고, 바로 아래 색조 막대로 색조를 선택한다. 색상 견본과 HEX·RGB 입력은 서로 동기화되며 HEX는 6자리, RGB는 채널별 0–255를 허용한다. 잘못되거나 미완성인 입력은 마지막 유효 색상을 유지하고 적용을 비활성화한다. 검정·회색에서도 선택한 색조를 보존하며, 사각형은 키보드 방향키와 접근성 증감 동작으로도 조작할 수 있다. 편집 화면의 미리보기는 저장 전 초안만 표시하며 전체 저장 시 사용자 지정 팔레트로 전환한다. 저장하지 않고 나가면 변경사항 폐기를 확인한다.

## Foundations

비활성(`enabled = false`) 설정 행은 활성 상태와 같은 배경을 유지한다.
`terminalSettingsListItemColors`로 제목·설명·앞뒤 아이콘 등 전경에만
`onSurface` 38% 불투명도를 적용하며, 행 전체나 배경의 불투명도는 변경하지 않는다.

- 비동적 다크 색상표는 primary/secondary/tertiary, 모든 on/container, surface container 단계, inverse, outline, error, scrim 역할을 명시한다. 일반 동작과 강조는 `MaterialTheme.colorScheme` 역할을 사용하고, 활성·가용·준비·진행 상태는 이름이 명시된 파란색 semantic token을 사용한다.
- 앱 루트는 `MaterialExpressiveTheme`와 `MotionScheme.expressive()`를 제공한다. 별도 Expressive API가 있는 버튼과 아이콘 버튼은 상태에 따라 형태가 변하는 `shapes` 오버로드를 사용하고, 로딩은 shape-morphing `LoadingIndicator` 또는 wavy progress indicator를 사용한다. 별도 Expressive 오버로드가 없는 scaffold, dialog, text field, switch, radio button, card, tab은 같은 테마 아래 최신 Material 3 토큰과 motion scheme을 상속한다.
- 앱 메뉴는 M3 Expressive `DropdownMenuPopup`·`DropdownMenuGroup`과 `MenuDefaults.groupShape`를 사용하고 세로 스크롤을 제공한다. 실행 항목은 `shape` 오버로드의 `DropdownMenuItem`, 실행환경 및 명령 기록 검색 범위 선택은 `SelectableDropdownMenuItem`과 `MenuDefaults.itemShape`를 사용한다. 선택 항목의 모양·색상·접근성 상태는 컴포넌트 기본값을 따르며 검색 범위의 아이콘·체크 표시와 기존 앵커·닫기 동작을 유지한다. 메뉴 표면은 자신을 연 화면의 `MaterialTheme.colorScheme`을 상속하며, 동적 색상이 활성화된 터미널에서는 터미널 색상표를 사용한다. 모션은 앱의 Expressive motion scheme을 유지한다.
- 앱 기본 글꼴은 번들 Google Sans이며, 일반·강조 텍스트 모두 Material 3 type scale을 유지한다. 기본 고정폭 글꼴은 번들 Google Sans Code이며 터미널, extra key, 명령 본문, 전달 포트 및 크래시 원문에 사용한다. 일반 UI는 Google Sans가 지원하지 않는 문자를 번들 Pretendard로 먼저 대체하고, 두 글꼴 모두 지원하지 않으면 Android 시스템 글꼴을 사용한다. Pretendard가 지원하는 한글·가나에도 요청한 UI 굵기를 유지하며, Compose와 릴리스 노트의 네이티브 TextView에 같은 순서를 적용한다. Google Sans Code의 시스템 대체 글꼴은 유지한다. 터미널 사용자 글꼴의 우선순위는 유지하며, 기본 고정폭 글꼴 선택 항목과 검색 결과는 제공하지 않는다. 이전 글꼴 선택값은 무시하고 번들 Google Sans Code를 사용한다.
- 앱 내부 아이콘은 24 dp Material Symbols Rounded의 기본 비채움 스타일을 사용한다. 실행환경 상세의 시작 버튼은 같은 `play_arrow` 벡터 아이콘을 32 dp로 표시하고 48 dp 터치 영역을 유지한다. 방향성 아이콘은 RTL 레이아웃에서 자동 반전한다.
- 앱 런처 아이콘은 [사용자 제공 SVG 원본](../art/app-icon.svg)의 계단형 프롬프트와 밑줄 도형을 사용한다. 배경은 `#0B0C0E`이며 로고의 전경색은 빌드 시 선택한다. 정식 main/release는 기존 `#E3E4E8`, main/debug는 `#00FFA1`, 프리릴리즈는 `#FF8400`, dev/debug는 `#FF0062`를 사용한다. dev/release와 `appBaseVersion`에 사전 릴리즈 접미사가 있는 release 빌드를 프리릴리즈로 구분하며, debug 빌드는 채널별 색상을 우선한다. 설치 후 앱 업데이트 화면의 채널 선택은 설치된 아이콘 색상을 바꾸지 않는다. 108 dp 캔버스의 중앙 기준으로 원본 도형을 50% 크기로 배치해 지름 66 dp의 원형 안전 영역 안에 둔다. Android 13 이상에서 지원하는 테마 아이콘은 같은 전경 도형을 `monochrome` 레이어로 재사용하고 시스템 색상을 따른다.
- 세션 유지·세션 작업·AVF 이미지 설치·Android 브리지 알림의 작은 아이콘은 같은 앱 로고 도형을 [공통 알림 벡터](../android-bridge/src/main/res/drawable/ic_notification_terminal.xml)로 사용한다. 투명 배경의 24 dp 캔버스에 약 20 dp 너비로 중앙 배치하며, 불투명한 단색 도형의 표시 색상은 Android SystemUI가 지정한다.
- 간격은 4 dp 배수를 기본으로 한다. 독립된 카드와 설정 행은 평상시 `extraLarge`(28 dp) 컨테이너 shape를 사용해 높은 곡률이 화면에서 명확히 드러나게 하고, 상호작용 가능한 `ListItem`은 눌림·포커스·선택 상태에서 Material Expressive 기본 shape로 morph한다. 앱 바, 터미널 캔버스처럼 화면 경계에 붙는 기반 surface는 직사각형을 유지한다.
- 모든 일반 상호작용 대상은 최소 48 dp다. Extra key는 최소 높이 40 dp를 사용하며, 툴바 핸들 영역은 24 dp로 압축한다. 세션 탭은 세로 목록에서 최소 48 dp 높이의 터치 영역을 사용한다.
- 아이콘 버튼에는 동작을 설명하는 content description을 제공한다. 장식 아이콘에는 중복 설명을 제공하지 않는다.
- 화면 전환에 별도 View transition을 강제하지 않는다. Compose 및 플랫폼의 애니메이터 배율을 따르는 표준 컴포넌트 상태 변화만 사용한다.

구현은 `android-app/src/main/kotlin/dev/terminal/app/ui/ComposeUi.kt`의 `DroidTheme`와 공통 scaffold/화면 컴포넌트에 모인다. 사용자 문구는 `android-app/src/main/res/values/strings.xml`에 둔다.

## Components and screens

터미널 링크 열기는 터미널 설정의 셸 섹션에 있는 기존 스위치를 사용하며 기본은 꺼짐이다. 탭한 셀의 OSC 8 링크를 먼저 확인하고, 메타데이터가 없을 때만 http/https 정규식 감지를 사용한다. 표시 문구와 목적지가 달라도 같은 탭 경로를 사용하며 http/https만 브라우저로 연다. 별도 강조·팝업·편집 UI를 추가하지 않고 기존 선택·마우스 보고·제스처 동작을 유지한다.

설정 홈과 모든 하위 설정 화면은 공통 `SettingsPageScaffold`를 사용합니다. 앱바와 내부 Scaffold 배경은 스크롤 상태와 관계없이 투명하며, 화면 배경은 외곽 Box에서 직접 칠해 상위 Surface의 tonal elevation에 따라 별도 배경층이 생기지 않게 합니다. 뒤로가기 버튼은 처음부터 원형 배경을 유지합니다. 위로 스크롤하면 Material 기본 동작으로 large app bar가 small app bar로 접히고, large 제목은 이 전환의 진행도에 따라 사라지는 동시에 small 크기의 제목이 나타납니다. Small 제목은 원형 뒤로가기 버튼 옆에 표시하며 추가 스크롤 4dp 이내에서는 유지하고, 이 범위를 넘으면 250ms 페이드아웃으로 숨깁니다. 이후 콘텐츠 위쪽 여백은 상태 표시줄 여백을 포함해 실제 추가 스크롤 거리와 1:1로 줄어들며, 손가락을 멈추면 콘텐츠 위치도 그대로 유지됩니다. 계속 스크롤하면 콘텐츠가 앱바의 기존 영역과 상태 표시줄 뒤까지 이어집니다. 상단 그라데이션은 상태 표시줄을 포함한 Small 앱바 전체 높이(상태 표시줄 높이 + 64dp)에 적용합니다. 화면 배경색의 최상단 불투명도 100%에서 높이 20% 지점의 90%, 60% 지점의 38%, 끝의 완전 투명으로 이어지며 불투명한 단색 구간은 두지 않습니다. 그라데이션은 콘텐츠 위·제목 아래에 배치하며 스크롤 진행도로 강도를 희석하지 않아 콘텐츠가 이 영역에 들어오는 즉시 충분한 페이드가 보입니다. 같은 구간에서 원형 뒤로가기 버튼에 Material elevation level 2(최대 3dp)의 기본 그림자를 점진적으로 적용해 콘텐츠와의 위계를 표현하며, Small 상태 이후의 추가 스크롤이 없을 때는 그림자가 없습니다. 아래로 스크롤해 콘텐츠의 시작에 도달하면 small app bar 높이와 제목을 먼저 복원하고 이어서 large app bar를 펼치면서 large 제목으로 전환합니다. 뒤로가기 버튼은 콘텐츠 위에 겹쳐지고 해당 버튼 밖의 콘텐츠 입력을 막지 않습니다. 하단 시스템 여백·키보드 대응·플로팅 툴바는 기존 화면별 동작을 유지합니다.
USB 메뉴의 호스트 도구 입력 화면과 진단 및 리포트 화면, 크래시 리포트 상세도 같은 앱바를 사용합니다. 진단의 새로고침은 콘텐츠 상단에 공통 그룹의 전체 너비 설정 행으로 제공하고 진단 정보는 일반 UI 글꼴의 읽기 전용 설정 행으로 표시합니다.

크래시 리포트 상세는 안내와 원문을 함께 세로 스크롤하며, 원문은 선택 가능한 번들 Google Sans Code와 `bodySmall`(12sp, 줄 높이 16sp)을 사용한다. 닫기·오류 복사는 하단 중앙의 공통 `HorizontalFloatingToolbar`와 `FloatingToolbarAction`으로 제공하며 48dp 터치 영역·24dp 아이콘·툴팁·접근성 설명을 유지한다. 원문이 준비되기 전에는 복사를 비활성화하고 복사 완료는 툴바 위의 Snackbar로 알린다. 본문 아래에는 툴바 높이와 화면 경계 여백을 확보한다.

Large app bar 제목은 뒤로가기 버튼 아래에 간격을 두고 배치합니다. Small 제목은 원형 버튼의 오른쪽에 16dp 간격을 확보하며, 네이티브 앱바의 제목 전환과 탐색 슬롯을 유지합니다.

세션 탭의 제목은 12 sp로 표시한다. 사용자 지정 제목이 있으면 아래에 원래 제목을
10 sp로 표시하고, 해당 탭의 보조 전경색에 75% 불투명도를 적용해 강조를 낮춘다.

탭의 작업 메뉴는 M3 Expressive `DropdownMenuPopup`·`DropdownMenuGroup`과 아이콘이 있는 **이름 변경 / 워크스페이스 이동** 항목을 사용한다. 확장 크기는 케밥 버튼, 기본 크기의 길게 누르기는 해당 탭을 앵커로 삼으며 준비·종료 요청 중에는 열지 않는다. 메뉴 표면은 앱 테마를 따르고 항목 선택 또는 바깥 터치·뒤로가기에 닫힌다. 이동 대화상자는 공통 `SettingsGroup` 표면·2dp 간격·모서리와 라디오 역할의 전체 선택 행을 사용한다. 현재 소속은 초기 선택이며 **이동** 확인 전에는 변경하지 않는다. 임시 워크스페이스의 보조 설명, 별도의 만들기 행, Material 기본 **이동 / 취소** 버튼과 저장 가능한 초안을 제공한다.

이름을 지정한 워크스페이스 실행 구성으로 시작하는 탭은 생성 시 구성 이름을 사용자 지정 제목으로 지정한다. 수동 실행·자동 시작·AVF 준비 탭에 동일하게 적용하며 셸 제목은 기존 사용자 지정 탭처럼 아래에 표시한다. 이후 탭 이름을 직접 바꾸면 변경한 이름을 유지한다. 이름이 없는 구성은 프로필의 기본 세션 제목을 사용하며 실행 구성 목록·시작 선택·새 세션 메뉴에는 프로필 이름을 표시한다.

초기 설정은 Native, Userspace Linux, AVF Debian을 각각 카드로 설명하고 즉시 터미널 시작과 AVF 로컬 이미지 선택을 분리한다. 세로 스크롤을 사용하므로 좁은 화면, 가로 화면, 큰 글꼴에서도 작업 버튼에 접근할 수 있다.

**AVF Linux** 설정에서 리소스를 관리하고 **전달 포트**로 이동합니다. **Userspace Linux** 설정은 엔진 지원 상태와 별도 섹션 제목 없는 제한 안내를 표시합니다. 실행환경 관리는 설정 홈의 **실행환경**에서 열며 Debian 이미지 설치 여부와 진행 상황은 해당 AVF 실행환경 상세에서 확인합니다. 기존 Debian 이미지 설정 intent도 실행환경 관리로 연결하며 초기 설정 완료 여부를 변경하지 않습니다.

터미널은 `AndroidView`에 포함된 기존 `TerminalView`와 높이를 조절하는 비모달 BottomSheet 툴바를 사용한다. 툴바에는 제거할 수 없는 **세션** 툴과 선택적인 단축키·메모리·명령어셋 툴을 둔다. 세션 툴은 기본 높이 116 dp를 유지하며 핸들을 제외한 92 dp 영역에 헤더만 표시한다. 헤더 왼쪽에는 기존 앱 바와 같은 `PrimaryScrollableTabRow`로 세션 탭을 가로로 표시한다. 기본 크기의 헤더 좌우 여백은 4 dp이며 가로 탭 줄에는 별도 끝 여백을 두지 않는다. 탭 자체의 좌우 4 dp 여백과 합쳐 화면 가장자리에서 첫 탭 배경까지는 8 dp를 확보한다. 헤더 좌우 여백은 확장 진행도에 따라 4→8 dp로 이어지며, 새 세션·설정 버튼의 48 dp 터치 영역을 유지한다. 탭은 최대 220 dp 너비와 48 dp 터치 높이를 사용하며, 실행환경 아이콘·제목·사용자 지정 제목의 원래 제목을 세로 목록과 공유한다. 기본 크기에서는 편집 버튼 없이 탭 본문을 길게 눌러 작업 메뉴를 열며 비선택 탭을 길게 눌러도 활성 세션은 바뀌지 않는다. 닫기 버튼은 선택된 탭에만 표시하고, 서로 인접한 비선택 탭 사이에는 터미널 대비 구분선 색상의 1 dp × 24 dp 세로선을 표시한다. 오른쪽 새 세션·설정 버튼의 터치 영역을 유지한다. 확장 상태에서는 헤더를 48 dp 상단 행에 고정하고, 왼쪽에 전체 세션 수와 현재 존재하는 실행 중·준비 중·생성됨·종료됨·준비 실패·상태 확인 중 개수를 표시한다. 전체 개수는 `titleMedium`(16 sp, 줄 높이 24 sp), 상태별 개수와 구분점은 `bodySmall`(12 sp, 줄 높이 16 sp)를 사용한다. 알 수 없는 상태는 상태 확인 중으로 합산하며 긴 상태 요약은 가로로 스크롤한다. 나머지 영역에는 탭의 세로 스크롤 목록을 표시한다. 가로 목록은 선택된 탭이 보이도록 이동한다. 세로 목록은 탭 선택이나 도구의 조작 가능 상태 변경으로 활성 탭에 자동 스크롤하지 않는다. 사용자가 이동한 세로 목록 위치는 탭 전환 및 기본·확장 전환 뒤에도 유지한다.

권위 있는 세션 목록이 비어 있으면 터미널 View 대신 빈 상태를 표시한다. 세션이나 워크스페이스가 있으면 툴바와 핸들을 유지해 새 세션과 설정에 접근한다. 현재 필터의 세션 목록이 비어 있으면 기본·확장 크기 모두 세션 툴만 표시하고 가로 페이징을 비활성화한다. 다른 툴을 보고 있었어도 즉시 세션 툴로 전환하며 새 세션·워크스페이스 선택·설정은 계속 사용할 수 있다. 필터에 세션이 생기면 기존 툴 목록과 순서로 페이징을 다시 제공하고 저장된 툴바 설정과 시트 크기는 유지한다. 세션과 워크스페이스가 모두 없는 초기 빈 화면에서는 툴바·핸들을 숨기고 중앙 새 세션 버튼과 상태 표시줄·컷아웃 아래 우측 상단 설정 버튼을 제공한다. 설정 버튼은 기존 설정 화면을 바로 열며 로컬 서비스는 설정 홈에서 접근한다. 새 세션 동작은 기존 프로필 선택 경로를 사용한다. 빈 상태에서는 터미널 View와 IME 포커스를 유지하지 않는다.

세션 툴의 **새 세션**은 현재 시트를 확장하고 `AnimatedContent`로 세션 페이지와 프로필 선택 페이지를 전환한다. 별도 popup menu나 두 번째 시트는 만들지 않는다. 페이지 전환은 진입 시 Start 방향, 뒤로가기 시 End 방향의 가로 슬라이드에 테마의 `defaultSpatialSpec`을 적용하며 RTL에서 방향을 반전한다. 페이드는 `defaultEffectsSpec`을 사용하고 사라지는 페이지의 동작은 비활성화한다. 프로필 선택 진입·선택 후 크기 복원·편집 이동의 시트 높이는 핸들 드래그·탭과 같은 spatial motion으로 확장·복원하거나 숨긴다. 페이지의 별도 크기 애니메이션은 사용하지 않고 시트의 높이 변화를 따른다. 프로필 선택 중에는 부모 `HorizontalPager`의 사용자 가로 스크롤을 비활성화하고 내부 목록의 세로 스크롤·플링은 유지한다. 일시적인 조작 비활성화는 페이지 닫기 조건으로 사용하지 않으며 뒤로가기·프로필 선택·편집 진입·시트 숨김으로 탐색을 종료한다. 프로필 페이지는 상단의 48dp 뒤로가기·새 세션 헤더와 세로 스크롤 `LazyColumn`으로 구성한다. 기존 프로필 아이콘·이름, 연결된 실행환경 이름과 Android Native·Userspace Linux·AVF 런타임을 공통 `ListItem`에 표시하며 실행환경 이름을 확인할 수 없으면 기존 런타임·배포판 표시로 대체한다. **새 프로필 만들기**는 목록 끝의 Material `TextButton`으로 제공한다. 상단 뒤로가기와 Android 뒤로가기는 시트를 닫지 않고 세션 페이지로 돌아가며 기존 목록 스크롤 위치를 유지한다. 프로필을 선택하면 기존 생성·선택 콜백을 즉시 호출하고 세션 페이지로 돌아가며, 시트는 새 세션 버튼을 누르기 전의 기본·확장 크기로 복원한다. 프로필 편집 진입도 시트를 숨긴다. 이 탐색은 세션 전환·명시적 종료·설치·프로필 및 런타임 수명주기를 변경하지 않는다.

시트의 애니메이션 높이는 측정 단계에서 읽고, 확장 진행도는 필요한 세션 헤더에서만 읽는다. 프로필 선택 목록과 관련 없는 도구 내용을 높이 프레임마다 재구성하지 않는다. 프로필 목록은 확장 상태로 전환할 때 확장 크기로 측정하고 시트의 클리핑으로 점진적으로 드러내며, 창·IME에 따른 확장 한도 변경이 없으면 높이 프레임마다 목록을 다시 측정하지 않는다. 기본 크기에 정착하면 목록도 실제 시트의 높이에 맞춰 스크롤 영역을 유지한다.

프로필 선택 중에도 세션 페이지를 유지하며, 시트를 기본 크기로 줄이면 가로 탭 헤더를 미리 준비한다. 가려진 세션 페이지는 기본·확장 경계만 관찰해 높이 프레임마다 다시 구성하지 않는다. 세션 페이지의 위치·투명도와 프로필 페이지의 `AnimatedContent`는 하나의 전환 상태를 공유한다. 기본 크기로 줄인 뒤 상단 또는 Android 뒤로가기를 눌러도 양쪽 페이지가 함께 슬라이드·페이드하며 현재 시트 크기는 유지한다.

양쪽 새 세션 프로필 목록의 Userspace Linux·AVF 행에는 실행환경별 설치 상태를 기존 `ListItem` 보조 텍스트로 표시한다. 선택 시 미설치 배포판·이미지는 Material 확인 대화상자에서 **설치** 또는 **취소**를 받으며 확인창을 닫는 동작도 취소로 처리한다. 상태 조회·확인창 표시·복원은 설치를 시작하지 않는다.

세션 탭은 Material 3 `Tab`을 기본 크기의 가로 목록과 확장 크기의 세로 목록으로 표시하며 선택된 탭을 터미널 배경에서 파생한 컨테이너 색상과 selected semantics로 구분한다. 눌림 상태에 따라 모서리 반경을 20→8 dp로 줄이고, 손을 떼거나 제스처가 취소되면 `defaultEffectsSpec`으로 복원한다. 클릭 시 세션 전환은 즉시 처리한다. 비선택 탭은 투명 배경을 유지한다. 목록의 상·하단 스크롤 경계는 터미널 배경색 그라데이션으로 처리하며 스크롤할 수 있을 때만 표시한다. 닫기 버튼은 기본 크기의 선택된 탭과 확장 크기의 모든 탭에 표시하며 고정 `CircleShape`를 사용해 hover·포커스·누름 상태에서도 원형을 유지한다. 확장 크기의 선택된 탭에는 제목 편집 아이콘을 추가로 표시하고 기존 이름 변경 대화상자를 연다. 탭 앞에는 20dp 실행환경 아이콘(Native 로봇, Debian 나선, Ubuntu 원형, Arch 아치, AVF 칩)을 표시한다. 상태 뱃지와 ANDROID/LINUX 등의 접두사는 표시하지 않고 제목만 표시한다. 아이콘은 실행환경 이름을 접근성 설명으로 제공하며, 세션 상태는 탭의 stateDescription으로 전달한다. 이름 변경은 기본 크기에서는 탭 본문 길게 누르기와 해당 접근성 동작으로, 확장 크기에서는 선택된 탭의 편집 아이콘으로 제공하며 사용자 지정 제목이 없으면 빈 입력 필드를 표시한다. 가로 탭의 길게 누르기는 손을 뗄 때 탭 선택을 중복 실행하지 않으며 닫기 버튼의 입력과 분리한다. 세로 목록의 탭 본문을 길게 누르면 드래그를 시작하며 놓으면 순서를 저장한다. 이동 중 주변 탭은 새 위치로 애니메이션하고 목록 가장자리에서는 자동 스크롤한다. 드래그한 탭의 확대·그림자는 좌우 여백 안쪽의 실제 캡슐에 적용하고 모서리 클리핑은 탭 본체 한 곳에서 처리해 양옆이 잘리지 않게 한다. 드래그 취소·목록 밖에 놓기·세션 목록 변경은 원래 순서를 유지한다. 접근성 위로/아래로 동작도 제공한다. 저장한 ID 순서는 상태 갱신과 Activity 재생성 뒤에도 유지하며 새 세션은 끝에 추가하고 종료된 세션은 제거한다. 순서 변경은 선택된 세션과 실행 중인 작업을 바꾸지 않는다. 탭의 종료 아이콘은 기본적으로 확인 대화상자를 연 뒤 runtime의 명시적 terminate 명령을 보낸다. 툴바 설정의 세션 툴에는 기본값이 꺼짐인 **탭 삭제 시 묻지 않기** 스위치를 제공한다. 켜면 종료 아이콘을 눌렀을 때 확인 없이 같은 terminate 경로를 사용하며, 설정 설명에는 세션과 실행 중인 작업이 즉시 종료됨을 명시한다. 설정은 영속화하고 다음 탭 종료 요청부터 적용한다. 빈 상태의 주 동작은 기존 `ModalBottomSheet`를 사용한다. 세션 툴의 프로필 선택 페이지와 빈 상태 바텀시트는 기본·사용자 프로필 이름과 실행환경을 표시한다. 목록 끝의 프로필 추가 동작은 세션 툴에서 **새 프로필 만들기**, 빈 상태에서 **Add profile**로 제공한다. 사용할 수 없는 실행환경의 프로필도 표시하며 기존 설치·설정 안내로 연결합니다. 설정의 **Profiles** 목록은 카드 전체를 눌러 프로필 설정을 엽니다. 기본 프로필도 수정·삭제할 수 있습니다. 설정은 이름·실행환경, 셸·시작 설정, 환경 변수 카드로 나누며 하단에 저장·복제·삭제를 제공합니다. 삭제에는 확인을 요구하고 모든 프로필이 삭제되면 추가 안내를 표시합니다. 양쪽 추가 동작은 같은 Material 3 프로필 편집 Activity를 엽니다. 초안은 Activity 재생성 시 복원하고 저장 시 전체 설정을 검증하며, 미저장 변경 사항을 버릴 때 확인합니다. Userspace Linux 설치 진행은 대화상자, wavy 진행 표시기, 오류 텍스트, 재시도 및 닫기 동작을 사용한다.

터미널 캔버스의 두 번 탭에는 별도 동작을 제공하지 않는다. 툴바는 핸들로 높이를 조절하거나 숨기며 숨김 상태에서도 핸들은 유지한다. 터미널 View는 상태 표시줄 뒤까지 확장되며 기록의 맨 위에서는 첫 줄을 상태 표시줄·컷아웃 아래에 배치한다. 스크롤하면 이전 줄들이 이 영역을 통과해 사라진다. 상단 inset, 텍스트 선택과 터치 좌표에는 같은 원점을 적용한다. 이 UI 변경은 세션 수명주기와 소유권을 변경하지 않는다.

터미널 하단은 비모달 BottomSheet 툴바다. 드래그 핸들의 세 앵커는 확장·기본·숨김이며,
숨김에도 24 dp 핸들 영역은 남는다. 모든 툴의 기본 높이는 핸들 24 dp와 단축키 두 줄(40 dp × 2 + 간격 4 dp + 위아래 여백 8 dp)을 합친 116 dp로 통일하며, 툴을 좌우 전환해도 높이는 바뀌지 않는다. 확장은 가용
영역의 60%(최대 480 dp)로 제한하고 IME 및 탐색 표시줄 inset을 반영한다.
핸들 영역은 모든 상태에서 높이 24 dp를 사용한다. 터미널 문자 격자의 마지막 온전한 행은 View 하단에 맞추고, 정수 행 수로 나눈 나머지 픽셀은 상단 inset에 더한다. 툴바를 확장·기본·숨김으로 전환해도 마지막 행과 핸들 사이에는 사용자 지정 터미널 여백만 유지한다. 터치·마우스·링크·선택 핸들·IME 미리보기도 같은 원점을 사용하며 PTY 행 수와 안정화 후 크기 변경 정책은 유지한다.
툴바 드래그·전환 애니메이션과 IME 크기 변경 중에는 마지막으로 적용한 문자 격자의 높이로 상단 여백을 계산해 렌더링과 입력 원점을 유지한다. 크기 변경이 안정화되면 행 수와 하단 정렬을 함께 갱신하며, 행 수가 그대로인 픽셀 단위 크기 변경도 최종 정렬에 반영한다.
세션 툴은 툴바의 실제 높이에서 구한 기본·확장 진행률을 공유한다. 펼칠 때 헤더 높이는 92 dp에서 48 dp로 연속적으로 줄고 탭 목록은 아래에서 드러나며 불투명도가 증가한다. 접을 때는 반대로 이동하며, 드래그 취소·방향 전환도 현재 진행률에서 이어진다. 헤더의 가로 탭은 확장 진행률에 따라 사라지고 세션 개수·상태별 집계는 표시하지 않는다. 별도의 지연 애니메이션 없이 같은 Expressive spatial motion을 따르며, 가로 탭의 선택·이름 변경·종료는 완전히 기본 크기일 때, 세로 탭의 선택·이름 변경·종료·순서 변경은 완전히 확장됐을 때만 활성화한다. 기본 높이와 목록 스크롤 위치는 유지한다.
단축키 뷰포트는 핸들을 제외한 툴바 영역 전체를 사용한다. 기본 상태에서는 두 줄을 표시하고, 확장 상태에서는 늘어난 높이에 맞춰 더 많은 행을 표시하며 남은 행은 세로 스크롤한다. 키 높이는 40 dp로 유지한다.
핸들 드래그·탭·접근성 동작으로 상태를 바꾸며 Expressive motion spec으로 이동한다. 새 세션 바텀시트와 툴바 바텀시트의 드래그 핸들·핸들 영역은 호버 상호작용을 전달하지 않고 호버 indication이나 지연된 툴팁을 표시하지 않는다. 세션 시트는 기본 툴팁 래퍼 대신 자체 핸들을 사용한다. 누름·포커스 표시, 드래그·탭·접근성 동작은 유지하고 바텀시트 콘텐츠의 호버 효과는 유지한다.
세로 드래그는 핸들에만 적용하여 도구의 세로 스크롤과 분리한다. 기본·확장 상태에서
HorizontalPager로 도구를 좌우 전환한다. 페이지 이동 중에는 드래그 핸들이 짧아지며 배경 없는 도트가 펼쳐지고,
이동이 멈추면 도트가 모여 핸들로 복원된다. 간격과 크기는 M3 Expressive spatial spec,
투명도는 effects spec을 사용한다. 선택 도트는 페이지 진행량을 따라 다음 도트까지
늘어났다 줄어들며 RTL에서도 진행 방향을 따른다.
페이지 표시가 콘텐츠 높이를 차지하거나 콘텐츠를 덮지 않는다. 모든 도구는 별도 도구 제목을 표시하지 않는다. 세션 툴의 헤더 왼쪽에는 워크스페이스 선택기를 기본 크기에서 아이콘만 표시하되 워크스페이스에 세션이 없으면 아이콘과 이름을 가용 폭에 표시한다. 확장 크기에서도 워크스페이스는 아이콘과 이름을 표시하며, 미소속 필터는 항상 아이콘만 표시한다. 확장 헤더의 워크스페이스 영역은 새 세션 버튼 앞까지 채우는 높이 48dp 영역이며 별도 배경 박스 없이 터미널 팔레트의 appBarIcon 색상을 사용한다. 워크스페이스 선택기 오른쪽에는 48dp 조작 대상의 모두 닫기 아이콘 버튼을 두며 현재 필터에 세션이 없으면 확장 크기에서도 표시하지 않는다. 삭제 조건을 충족하는 빈 임시 워크스페이스는 같은 자리의 삭제 버튼을 유지한다. 세션이 있지만 종료 가능한 세션이 없거나 툴이 비활성일 때 모두 닫기 버튼을 비활성화한다. 기본 크기에서는 그 옆에 가로 세션 탭을 표시하며 오른쪽에는 새 세션·설정 버튼을 표시한다.
기본 크기의 가로 세션 탭은 내부 목록 스크롤을 우선하며, 시작·끝에서 같은 방향으로 다시 스와이프하면 남은 드래그를 부모 HorizontalPager로 전달한다. 부모 페이지가 이동한 경우 내부 목록이 릴리스 속도를 소비하기 전에 동일한 Pager fling behavior로 도구 전환을 마무리한다. 활성·비활성 탭의 제목·아이콘·여백·종료 버튼에서 동일하게 동작하며 RTL에서는 방향을 반전한다. 스와이프는 탭 선택·이름 변경·종료를 실행하지 않는다.
기본 높이를 콘텐츠 전체에 맞춰 늘리지 않는다. 긴 콘텐츠는 세로 스크롤한다. 단축키 영역은 상·하단 경계에 스크롤 그라데이션을 표시하지 않는다.
기본 모드의 가로 세션 탭은 버튼 영역과 맞닿는 끝의 안쪽 20 dp에 현재 툴바 시트 배경색의 그라데이션을 겹쳐 표시한다. 해당 방향으로 더 스크롤할 수 있을 때만 표시하며 끝에 도달하면 `defaultEffectsSpec`으로 사라지고 다시 스크롤할 여유가 생기면 같은 방식으로 나타난다. 탭과 함께 기본·확장 전환의 불투명도를 따르며 포인터 입력을 가로채지 않는다. RTL에서는 버튼 위치와 그라데이션 방향을 함께 반전한다.
세션 목록·메모리 사용량·명령어셋은 더 스크롤할 수 있는 상·하단에만 툴바 시트 배경색으로 페이드하여 행과 카드가 경계에서 갑자기 잘리는 인상을 줄인다. 현재 도구는 안정적인 ID로 유지하고
도구 제거 시 첫 도구로 이동한다. 기본으로 세션과 단축키가 추가되어 있으며 메모리 사용량·명령어셋·명령 기록을 편집에서 추가한다.
명령 기록 도구는 기본 높이를 유지하며 48 dp 명령 이동 버튼 두 개, 둥근 검색 필드, 아이콘 전용 Material SplitButtonLayout을 표시한다. 범위 버튼은 TonalLeadingButton과 TonalTrailingButton을 각각 48 dp로 유지하고 앞쪽 아이콘은 24 dp filter_alt로 고정한다. 양쪽 버튼에서 같은 범위 메뉴를 열며, 범위 이름은 메뉴·툴팁·접근성 설명으로 제공한다. 메뉴를 열면 뒤 화살표가 fastSpatialSpec으로 회전하며 Expressive 체크 상태 모양을 따른다. 기본 크기에서는 안내가 없을 때 화살표·검색 필드·범위 버튼을 핸들 아래 92 dp 영역의 수직 중앙에 정렬한다. 확장 진행률에 따라 컨트롤 행 높이를 60 dp까지 연속적으로 줄인다. 명령 개수는 기본·확장 상태 모두 표시하지 않고 빈 안내 줄의 공간도 남기지 않는다. 검색 결과 순번·개수와 빈 기록·검색 결과 없음·이동 불가 안내가 필요할 때만 28 dp 안내 줄을 표시한다. 안내 줄은 공유 Transition으로 높이와 헤더 위치를 fastSpatialSpec에 맞춰 펼치고 접으며, 안내 텍스트의 등장·교체·퇴장에는 fastEffectsSpec 페이드를 적용한다. 검색어를 지우면 안내 공간을 접어 기본 컨트롤의 수직 중앙 정렬을 복원하며, 연속 입력이나 전환 취소도 현재 진행도에서 이어진다. 범위 메뉴는 명령·출력·명령과 출력 세 가지다. 검색은 터미널 셀과 보관 중인 스크롤백을 대상으로 하며 그래프 항목을 숨기지 않는다. 명령 범위는 B 경계 없이 A/C 경계만 보내는 Bash에서도 프롬프트를 제외하고, 긴 출력으로 스크롤백에 밀려난 명령까지 검색한다. 검색어 입력·범위 변경 때 가장 최근 일치 글자로 이동하고, 검색 중 화살표는 이전·다음 일치 위치를 순환하며 현재 순번과 결과 수를 표시한다. 검색어가 없을 때는 기존 명령 이동을 사용한다. 터미널 팔레트 전경색의 반투명 강조와 현재 결과의 테두리를 캔버스에 겹쳐 표시하며, 문자 선택과 프로그램이 소유한 화면에는 검색 강조를 겹치지 않는다. 검색은 하드 줄바꿈을 넘지 않고 소프트 줄바꿈·다중 셀 글자를 처리한다. 출력 변경·trim·reflow·체크포인트 교체 시 셀 위치를 다시 계산하고 도구 비활성화·세션 전환 시 이전 검색 강조를 제거한다. 검색창에 포커스가 있고 키보드가 열린 상태에서 다른 도구로 이동하면 Activity의 기존 터미널 입력 요청 경로로 포커스를 넘겨 키보드를 유지한다. 사용자가 먼저 닫은 키보드는 도구 전환만으로 다시 열지 않으며, 검색어는 유지하고 검색창으로 자동 재포커스하지 않는다. 키보드 크기 변경과 런타임의 비동기 크기 응답 뒤에도 보이던 검색 결과를 유지하며, 다른 위치를 직접 탐색 중이면 검색 결과로 되돌리지 않는다. 검색어와 결과는 렌더러에만 유지하고 세션 체크포인트에 저장하지 않는다. 첫·마지막 명령에서는 수직 chevron-line 아이콘과 기록 끝 이동 동작을 사용한다. 확장 목록은 최신순 단일 Git 커밋 그래프 형태로 2 dp 연결선, 24 dp 상태 심볼, 최소 48 dp 명령 행을 사용한다. 명령 텍스트의 상하 여백은 8 dp로 유지하고, 연결선은 상태 아이콘에서 2 dp 떨어진 위치까지 이어져 목록을 촘촘하게 표시한다. 두 줄 명령은 내용 높이에 맞춰 행을 늘려 잘림 없이 표시한다. 완료는 check_circle, 실행 중은 play_arrow, 실패는 block으로 색상 없이도 구분하며 상태와 종료 코드는 접근성·툴팁으로 설명한다. 명령 이름은 bodySmall(12 sp)로 표시하고 알 수 있는 종료 코드는 그 아래에 labelSmall 텍스트로 함께 표시하며, 실행 중이거나 종료 코드를 알 수 없으면 숫자를 만들지 않는다. 명령 본문과 종료 코드는 공통 고정폭 글꼴을 사용한다. 상태 아이콘에는 별도의 배경을 두지 않는다. 선택된 현재 명령의 아이콘과 텍스트만 터미널 배경에 맞춘 공통 파란색 강조 토큰 TerminalChromeColors.checkedContainer로 표시한다. 밝은/어두운 파란색 중 배경과의 대비가 4.5:1 이상인 색을 사용하고, 둘 다 부족하면 공통 전경색으로 보정한다. 비선택 항목은 공통 대비 보정된 차분한 전경색을 사용한다. 선택 배경·테두리·크기 변화는 추가하지 않고 그래프 선과 행 높이·텍스트 위치를 유지한다. 목록은 LazyColumn으로 구성하며 색상에는 fastEffectsSpec, 항목 이동에는 defaultSpatialSpec을 적용한다. 시트의 실제 확장 진행률로 목록을 드러내고 완전히 확장한 경우에만 행을 조작한다. 대체 화면·마우스 추적·앱 커서 모드·부분 스크롤 영역에서는 이동을 비활성화한다.

명령 기록의 각 행은 독립적인 아코디언이다. 행 본문 탭은 명령 위치 이동을 유지하고, 오른쪽 48 dp 버튼의 24 dp Material Symbols Rounded 아래 꺾쇠로 출력만 펼치고 접는다. 꺾쇠 회전·높이는 공통 아코디언의 defaultSpatialSpec, 등장은 fastEffectsSpec을 사용하며 그래프 연결선은 펼친 영역을 따라 이어진다. 명령 복사는 꺾쇠 바로 왼쪽의 아이콘 버튼으로 제공하며 접힌 상태에서도 사용할 수 있다. 명령 복사 버튼은 18 dp 심볼과 48 dp 터치 영역을 사용하며 동작 이름은 툴팁·접근성 설명으로 제공한다. 펼친 영역은 공통 고정폭 bodySmall 출력 필드로 구성하며 사방 12 dp 본문 여백을 사용한다. 출력은 SelectionContainer로 길게 눌러 선택·부분 복사할 수 있고 입력 포커스나 키보드를 요청하지 않는다. 최대 200 dp 안에서 세로로 스크롤한다. 명령 복사는 목록의 줄임 미리보기 대신 전체 입력 셀을 읽는다. 출력은 셸 통합의 입력 끝·실행 끝 anchor로 프롬프트 및 다른 명령과 구분하고, 실행 중에는 보관된 출력을 갱신한다. trim·reflow·체크포인트의 기존 anchor를 따르며 별도 명령·출력 기록을 저장하지 않는다. 펼침 상태는 도구의 일시적인 UI 상태이며 제거된 명령의 상태도 제거한다. 빈 출력은 안내를 표시한다.

앱 요약과 세부 영역은 하나의 카드에 묶고, 새로고침은 목록 끝에 둔다. 앱 메모리는 Java 힙·네이티브 힙·코드 및 리소스·스택·그래픽·기타 전용·공유 및 시스템 영역을
목록과 비율 막대로 표시한다. 누락된 영역은 측정 불가로 표시하며 한 프로세스 측정이 없으면 합계를 만들지 않는다.
메모리 설정은 다른 상세 설정과 같은 primary 섹션 제목, surfaceContainerLow extraLarge 카드,
투명 ListItem과 안쪽 구분선을 사용한다. 표시 항목과 자동 갱신을 나누고 측정 설명은 작은 보조 텍스트로 둔다.
도구 설정의 기기·앱·세션 스위치는 독립적으로 저장되며 기본은 모두 켜짐이다. 모두 끄면 측정을 중단한다.
측정 방식의 긴 설명은 도구 설정에서만 표시한다. 목록은 지연 로딩하며 세로 스크롤한다. 측정 불가 값은 0으로 표시하지 않는다. 명령어셋은 이름과 여러 줄 명령을 저장하고,
툴바에는 이름과 한 줄 명령 미리보기를 가진 최소 56 dp 행으로 표시한다. 시작 여백은 20 dp, 끝 여백은 8 dp, 위아래 여백은 4 dp로 두며 텍스트와 편집 버튼 사이에 8 dp를 확보한다.
항목은 공통 extraLarge 곡률을 사용한다. 행 탭은 전송 확인, 오른쪽 편집 아이콘은 툴 위에서 바로 수정 모달을 연다. 수정 초안은 화면 재생성 시 보존하고 저장할 때만 반영하며 취소하면 원래 명령을 유지한다. 편집은 활성 세션 없이도 가능하다.
툴 하단에는 별도 편집 버튼을 두지 않으며 목록 관리는 툴바 설정에서 연다.
명령 본문은 툴바·설정 목록·편집 입력·전송 확인에서 모두 고정폭 글꼴을 사용한다.
전송 대화상자에서 대상 세션·내용을 확인한 뒤 기존 paste 경로와 Enter 입력으로 전달한다.
세션 전환·페이지 이탈·Activity 중지 시 전송 초안을 폐기한다.
툴바 상태는 핸들 조작으로만 바꾸며 터미널의 두 손가락 스와이프에는 연결하지 않는다.
상태는 Activity 재생성 시 복원되며 세션 소유권과 설정의 사용 스위치를 바꾸지 않는다.
핀치 글꼴 크기 조절은 유지하며 멀티터치와 손가락을 뗀 뒤 남은 터치는 스크롤·탭 입력을 발생시키지 않는다.

프로필 관리 목록도 같은 편집·완료 `ExtendedFloatingActionButton`으로 순서 편집을 전환한다. 편집 중에는 48dp 터치 영역의 20dp 드래그 핸들을 표시하고 프로필 편집 이동을 막는다. 실제 행 높이를 기준으로 주변 행을 spatial motion으로 이동하고 드래그 행의 확대·그림자·배경·모서리 전환은 툴바 설정과 같은 규칙을 따른다. 화면 가장자리의 자동 스크롤과 접근성 위로·아래로 이동을 제공한다. 드롭 시 즉시 저장하고 취소는 원래 순서를 복원한다. 설정과 양쪽 새 세션 목록은 같은 저장 순서를 사용하며 순서를 편집한 뒤 새로 만든 프로필은 끝에 추가한다.

워크스페이스 관리도 프로필의 같은 정렬 컴포넌트와 편집·완료 FAB를 사용한다. 일반 행의 아이콘·이름·보조 설명을 유지하면서 편집 중에는 48dp 드래그 핸들·20dp 아이콘과 접근성 위로·아래로 동작을 제공하고 상세 이동을 막는다. 측정한 행 높이·자동 스크롤·spatial/effects 모션·취소 복원과 하단 FAB 여백은 프로필 정렬과 같은 규칙을 따른다. 드롭은 런타임의 워크스페이스 순서를 바로 저장하며 선택 메뉴와 이동 목록에도 동일하게 적용한다.

**터미널 설정 → 사용자 설정 → 툴바 설정**은 전체 활성화 스위치와 도구 목록을 제공한다.
일반 상태에서는 추가된 도구만 `>`와 함께 표시하며 누르면 도구 설정으로 이동한다.
편집 FAB를 누르면 추가된 도구에 순서 핸들과 제거 버튼, 미추가 도구에 추가 버튼만
표시한다. 도구 목록은 다른 설정과 같은 extraLarge 그룹 카드, 공통 ListItem 모양·글꼴을 사용한다. 항목 사이에는 구분선 대신 2 dp 여백을 두고 내부 모서리 반경은 4 dp로 줄인다. 섹션 제목도 공통 labelLarge 스타일과 들여쓰기를 따른다. 편집 전후 행 높이는 프로필 설정의 프로필 추가 항목과 같은 56 dp로 유지하며, 48 dp 편집 컨트롤을 수직 중앙에 배치한다. 드래그 핸들 아이콘은 20 dp이며, 편집 시 추가된 도구의 시작 여백과 모든 도구의 끝 여백을 16→8 dp로 부드럽게 줄인다. 미추가 도구의 시작 여백은 16 dp로 유지해 제목을 일반 설정 행과 맞춘다. 핸들 공간은 Expressive spatial spec으로 펼치고 접으며,
추가·제거 제어와 새 항목은 effects spec으로 전환한다. 드래그한 행은 손가락에 직접 따라가고
확대·그림자·배경 변화로 들어 올린 상태를 표시한다. 툴 목록에는 바깥 클리핑 wrapper를 사용하지 않고 각 행이 배경·내용·그림자에 같은 모서리 모양을 적용한다. 드래그한 행이 추가된 툴 목록의 맨 위 또는 맨 아래에 가까워지면 해당 방향의 모서리 반경을 4→28 dp로 연속적으로 변화시킨다. 주변 행도 실제 이동 위치에 따라 목록의 바깥 모서리를 이어받으며, 드롭·취소 시 모서리는 최종 위치의 모양으로 부드럽게 돌아간다. 주변 행은 미리보기 순서에 따라 탄성 모션으로 이동한다.
드롭 시 순서를 저장하고 취소 시 원래 순서로 복원한다. 화면 가장자리에서는 자동 스크롤한다.
드래그 핸들과 접근성 위로/아래로 동작으로 순서를 변경한다.
설정 변경은 즉시 저장하며 도구 제거는 해당 도구의 설정을 삭제하지 않는다.
추가 툴 비활성화는 세션 툴과 핸들을 유지하고 선택적인 툴만 숨긴다. 세션 툴은 설정에서 순서를 바꿀 수 있지만 제거 버튼과 별도 설정 진입은 제공하지 않는다. 기존 단축키 활성화 값은 새 설정이 없을 때만 이전한다.
기존 저장 설정에 세션 툴이 없으면 앞에 추가하며 기존 도구의 순서와 추가 툴 사용 여부를 보존한다.

Extra key는 별도의 둥근 wrapper 없이 저장한 위치와 가로·세로 크기로 배치하며, 키 사이의 빈 공간을 유지한다. 기본값은 7칸, 40dp 높이, 12sp 글자다. 가로 배치 영역은 2~10칸, 글자 크기는 10~24sp이며, 각 키는 최소 1칸 너비·40dp 높이에서 모서리 드래그로 두 축을 조절한다. 저장할 위치와 너비·높이는 그리드 한 칸 단위로 조절하며, 한 행의 피치는 44dp(기본 키 높이 40dp와 간격 4dp)다. 영역은 최대 128행까지 늘어난다. 배치 영역은 놓인 키의 오른쪽 경계보다 작게 줄일 수 없다. 좁은 화면에서는 최소 48dp 키 너비와 저장 위치를 보존하고 가로로 스크롤하며, 툴바 높이를 넘는 키와 빈 공간은 세로로 스크롤한다. 기본 툴바의 표시 높이는 기존 두 줄 기준을 유지하고 확장 시 가용 높이를 사용한다. 외곽 여백과 기본 키 간격은 4dp다. 미리보기는 surfaceContainerHigh·onSurface, 실제 터미널은 캔버스에서 파생한 대비 색상을 사용한다. CTRL·ALT·SHIFT 단독 키만 toggle semantics와 선택 상태색을 사용하며 pressed/checked shape는 `CircleShape`다.

설정의 **터미널 단축키**는 실제 툴바와 같은 좌표 기반 미리보기를 제공한다. 키를 누르면 선택 테두리와 네 모서리의 조절점을 표시한다. 키를 길게 눌러 빈 공간으로 이동하거나 조절점을 바로 끌어 가로·세로 크기를 바꾼다. 위치 이동은 드래그한 키의 중심을 시작 배치의 다른 키에 대조해 중앙과 가장자리를 구분한다. 대상 키의 가로·세로 안쪽 절반에 중심이 들어오면 두 키의 위치를 교환한다. 서로 크기가 달라도 두 사각형이 영역 안에서 다른 키와 겹치지 않을 때만 교환한다. 가장자리에서는 해당 축의 앞·뒤 삽입 후보를 계산하고, 주변 키를 좌우 또는 위아래로 연쇄 이동시켜 사이에 끼워 넣는다. 같은 행·열 안에서 공간을 확보할 수 있는 후보를 우선하고 주변 키의 총 이동량이 작은 배치를 선택한다. 공간이 없으면 가까운 빈 칸이나 인접 행·열을 활용한다. 후보가 같은 그리드 칸에 머물러도 중심과 가장자리 사이로 이동하면 미리보기를 다시 계산한다. 크기 조절은 요청한 사각형을 유지하고 겹친 키를 원래의 위→아래·시작→끝 순서에 따라 아래쪽으로 연쇄 이동시킨다. 관계없는 키의 위치와 각 키의 크기는 유지한다. 경계에서는 가까운 빈 칸을 재사용하며, 공간이 부족하거나 보이는 편집 영역 밖이면 error 테두리로 표시하고 놓기를 거부한다. 누르는 동안은 시작 시점의 배치에서 계산한 미리보기만 표시하고 손을 놓을 때 전체 배치를 초안에 한 번 반영한다. 이동·크기 조절 취소나 보이는 영역 밖 놓기는 모든 키를 원래 초안으로 되돌린다. 가장자리에서는 설정 화면을 자동 스크롤하고 아래쪽 빈 공간에 키를 놓으면 영역을 늘린다. 이동 중인 키는 소수 좌표를 포함한 손가락의 실제 이동량을 즉시 따르며, 이동 경로에 격자 맞춤이나 지연 모션을 적용하지 않는다. 놓기 후보와 주변 키의 배치 및 모서리 크기 조절은 가장 가까운 그리드 칸에 맞춘다. 주변 키 재배치와 크기 조절, 손을 놓은 뒤 실제 드래그 위치에서 확정 위치로 이동하기 및 취소 복원은 테마의 fast spatial spec으로 애니메이션한다. 버튼의 실제 배치·터치 영역·선택 테두리·네 모서리 조절점은 드래그 중에도 같은 표시 좌표를 사용한다. 끌어 올리는 그림자와 선택 상태색도 테마의 spatial/effects spec을 따르고 시스템 애니메이션 배율을 존중한다. 선택한 키의 이름 옆에 공통 48dp 편집·삭제 아이콘 버튼을 나란히 표시하며 툴팁과 접근성 설명을 제공한다. 편집은 이름·단축키 조합 모달을 열고, 삭제는 선택을 해제하며 초안에서 키를 제거한다. 마지막 키의 삭제는 비활성화하고 삭제해도 다른 키의 위치를 바꾸지 않는다. 새 키는 비어 있는 곳에 배치한다. 접근성 사용자 지정 동작도 한 칸씩 네 방향 이동과 가로·세로 늘리기·줄이기를 제공한다. 버전 1 저장값은 기존 이름·조합·너비·순서·표시 여부를 유지해서 읽고, 편집 후에는 버전 2의 위치·너비·높이를 저장한다. 기존 버전 2의 소수 좌표 배치는 그대로 읽고, 이동하거나 크기를 조절한 키는 격자에 맞추고 겹치지 않는 키는 그대로 유지한다. 초안은 Activity 재생성 때 복원되고 전체 **저장**에서만 영속화한다. 저장하지 않고 나갈 때는 변경사항 폐기를 확인한다. 단독 CTRL·ALT·SHIFT는 다음 입력 후 해제되며 조합 버튼은 선택된 보조 키를 대체한다. UI는 입력 명령만 보내며 세션 소유권은 변경하지 않는다.

제목 아래에는 짧은 편집 안내를 두고, 배치 미리보기 제목 아래에는 그리드를 바로 배치한다. 단축키 편집 화면은 기존 하단 취소·저장 버튼과 본문의 추가 버튼 대신 하단 중앙의 공통 `HorizontalFloatingToolbar`에 **최근 저장 상태로 돌아가기 → 단축키 추가 → 저장**을 순서대로 제공한다. 각 동작은 되돌리기·추가·저장 아이콘과 툴팁·접근성 설명을 사용한다. 복원은 화면을 닫거나 저장값을 변경하지 않고 초안 전체를 가장 최근 저장 상태로 되돌리며, 변경이 없으면 비활성화한다. 저장은 현재 초안을 반영하고 화면을 유지하며 다음 복원의 기준을 갱신한다. 추가는 기존 입력 대화상자를 열고 48개 제한을 유지한다. 스크롤 콘텐츠 아래에는 툴바 높이와 화면 경계 여백을 확보한다. 뒤로가기는 미저장 변경 폐기를 확인한다.

단축키 추가·편집 대화상자는 이름·조합 직접 입력, 펼칠 수 있는 입력 도움말, 저장·취소 버튼으로 구성한다. 공백 키는 `SPACE`로 지정하며 CTRL·ALT·SHIFT 및 이들의 조합과 함께 사용할 수 있다. Space 조합은 키 이벤트로 전달하여 Kitty 키보드 모드에서도 보조 키와 누름·해제 정보를 유지한다.

설정 화면은 Android 17 설정 앱의 계층을 따른다. 설정 홈은 `LargeTopAppBar`, 실제 카테고리 필터로 동작하는 둥근 검색 필드, 40 dp 원형 아이콘과 supporting text를 가진 최소 72 dp 카테고리 행을 사용한다. 1차 카테고리의 탐색 화살표는 생략하며, 실행환경·프로필·워크스페이스, 공유 디렉토리·로컬 서비스, 언어·터미널 설정, 실행환경 설정을 각각 묶고 공유 디렉토리·로컬 서비스 그룹은 앱 언어 바로 위에 두며 진단 및 리포트·업데이트·앱 정보는 함께 묶는다. 그룹 사이는 16 dp로 띄우고 그룹 안은 상세 설정과 같은 2 dp 여백·4 dp 안쪽 곡률·28 dp 바깥 곡률을 사용한다. 검색 결과에서도 1차 카테고리는 화살표를 생략하고 하위 설정 결과에는 탐색 화살표를 유지한다. 상세 화면은 큰 앱 바 아래 설명을 두고, 섹션 제목별 관련 interactive/non-interactive Expressive `ListItem`을 묶는다. 항목마다 `surfaceContainerLow` 배경을 사용하고 항목 사이에는 구분선 대신 2dp의 투명 여백을 둔다. 그룹 외곽은 `extraLarge`(28dp) 곡률을 유지하고, 인접 항목 사이의 안쪽 모서리는 4dp로 줄인다. 한 항목만 있는 그룹은 네 모서리에 큰 곡률을 적용한다. 설명이 여러 줄로 바뀌어도 leading icon과 trailing text·icon·control은 행 전체 높이에서 수직 중앙을 유지한다. 그 밖의 일반 화면 앱 바는 표준 Material 3 `TopAppBar`다. boolean 행 전체가 한 번만 toggle된다. 숫자·경로·단일 선택은 복원 가능한 입력 초안과 저장값을 분리하고, 대화상자의 **저장**에서 전체 값을 검증한 뒤에만 반영한다. Userspace Linux와 AVF Linux 설정은 엔진의 전역 지원·정책을 표시한다. 로컬 서비스는 공통 대시보드에서 관리하며 AVF Linux의 전달 포트도 같은 화면으로 연결한다. 공통 진단과 크래시 목록은 설정 홈의 진단 및 리포트에서 제공한다. 배포판·VM instance의 이름, 데이터, 설치·실행 상태 및 시작·중지·삭제는 실행환경 상세에서 관리한다. 저장 공간만 제거하는 일반 사용자 동작은 제공하지 않는다. 진단 정보는 일반 UI 글꼴의 제목·값 행으로 표시하고, 크래시 원문은 선택 가능한 고정폭 텍스트로 유지한다. 크래시 화면에서는 복사를 primary action으로, 닫기를 낮은 강조 action으로 제공한다.

설정의 **터미널 설정 → 셸 → 세션 작업 알림**은 기본 꺼짐인 스위치입니다.
10초 이상 명령 완료 및 프로그램의 확인 요청을 알린다는 설명과 Android 알림
설정 이동 행을 함께 제공합니다. 알림 권한 거부는 세션 실행을 막지 않으며,
작업 알림 채널은 기존 세션 유지용 상시 알림 채널과 분리합니다.
알림을 눌러 세션을 열 때는 서비스의 이전 선택 탭보다 알림 대상을 우선합니다.

Hotkeys의 단독 CTRL·ALT·SHIFT 선택 상태는 세로·수평 휠 입력에도 적용한다. 터치 swipe와 마우스·트랙패드는 같은 mouse modifier mask를 사용하며 휠 전송은 선택 상태를 소비하지 않는다. 사용자가 토글을 끄면 다음 휠 입력부터 제외하고, 일반 키 입력의 기존 자동 해제 동작은 유지한다.

## Insets and adaptive behavior

터미널 캔버스의 한 손가락 드래그는 터치 slop 이후 수평·수직 우세 축을 결정하고 해당 제스처 동안 고정한다. 수평 드래그는 마우스 보고가 활성화된 경우에만 표준 좌우 휠 입력을 전달하며, 문자 한 줄 높이의 이동 거리마다 한 step을 누적한다. 잔여 거리를 보존하고 방향 전환·제스처 종료 시 초기화하며 수평 관성 이동은 추가하지 않는다. 마우스·트랙패드의 수평 휠도 같은 애플리케이션 입력 경로를 사용한다.

**터미널 기록 → 부드러운 스크롤**은 기본 꺼짐이다. 켜면 일반 스크롤백의
드래그와 관성 이동을 픽셀 단위로 표시하고 프레임 타이밍에 맞춰 갱신한다.
관성 속도는 입력 세기를 따르며 기록의 위·아래 경계까지 남은 거리 때문에 낮아지지 않는다. 실제 경계에 도달하면 오버스크롤 없이 즉시 멈춘다.
부분 행과 하단의 추가 행을 함께 렌더링하며 링크·선택 좌표도 같은 오프셋을
사용한다. 마우스 보고·대체 화면은 기존 행 단위 입력을 유지한다.

터미널 설정의 **웹 링크 열기**는 기본 꺼짐이다. 활성화하면 기존 제스처 인식기의
확정된 단일 탭에서 출력된 HTTP(S) URL을 찾아 브라우저로 전달한다. 별도 터치
리스너를 설치하지 않으며 더블 탭·스크롤·선택 및 마우스 보고 입력을 우선한다.
줄바꿈된 주소와 터미널의 문자 셀 좌표를 고려하고, 탐색 범위를 초과하는 주소는
부분 주소로 열지 않는다.

새 세션 프로필 메뉴는 세션 탭과 동일한 런타임 아이콘을 사용합니다. 현재 워크스페이스의 등록 실행 구성은 세션 툴의 프로필 선택 페이지와 빈 화면 바텀시트의 첫 카테고리로 표시하고 기존 프로필 목록을 다음 카테고리로 유지합니다. 워크스페이스 카테고리 제목은 `이름 · 실행 구성`이며 각 화면의 기존 제목 스타일과 24dp 가로·8dp 세로 여백을 사용합니다. 실행 구성 행은 구성 이름과 원본 프로필 이름만 표시하고 실행환경·배포판·작업 디렉터리 설명은 표시하지 않습니다. 구성 이름이 없으면 프로필 이름을 제목으로 사용하며 보조 설명에 중복하지 않습니다. 같은 프로필 아이콘·설치 상태 배지·설정 행 모양·팔레트 대비를 재사용하고 참조 프로필이 없으면 안내와 함께 비활성화합니다. 미소속 필터와 실행 구성이 없는 워크스페이스는 기존 프로필 목록만 표시합니다. 선택한 구성은 기존 세션 생성·설치 동의 경로로 전달합니다.
세션 툴과 빈 화면의 새 세션 목록은 설치 상태 텍스트 줄을 생략합니다. 미설치가 확인된 프로필만 32dp 아이콘 영역의 아래쪽 끝 모서리에 16dp 배지 영역을 두고 12dp 다운로드 심볼을 표시하며, 별도 터치 영역을 만들지 않습니다. 다운로드 벡터의 실제 외곽을 2dp 여백만큼 둥글게 확장한 모양으로 프로필 아이콘을 마스킹합니다. 마스크는 기본 벡터와 사용자 이미지에 동일하게 적용하며 메뉴 배경이 투명하게 드러나도록 프로필 아이콘만 클리핑합니다. 다운로드 심볼은 프로필 아이콘과 같은 강조색을 사용하고 배경은 채우지 않습니다. RTL에서는 마스크와 심볼을 함께 아래쪽 왼쪽 모서리로 옮깁니다. 설치됨·설치 중·조회 중·조회 실패에는 마스크와 다운로드 심볼을 표시하지 않고 모든 설치 상태는 접근성 상태 설명으로 제공합니다.
프로필별 아이콘을 지정하면 탭·세션 추가 메뉴·바텀시트·프로필 목록에 공통 렌더러로
표시합니다. 탭은 20dp, 메뉴는 24dp이며 사용자 이미지는 투명 여백을 제거하고
128px 캔버스의 112px 영역에 종횡비를 유지해 맞춥니다. 기본 벡터와 투명 배경 단색
이미지는 해당 UI의 tint를 따르고, 다색·불투명 이미지는 색상 필터 없이 표시합니다.
프로필과 워크스페이스 아이콘 설정은 자동 선택·기본 제공 벡터를 같은 3열 모달로 제공합니다. **확인·취소** 버튼을 사용하며 확인은 부모 편집 초안만 변경하고 전체 저장에서 적용합니다. 취소·바깥 터치·뒤로가기는 기존 초안을 유지하며 모달 상태와 선택은 화면 재생성 시 복원합니다. 프로필은 기존에 추가한 이미지의 미리보기·선택·삭제를 유지하고 새 이미지 추가는 제공하지 않습니다. 안내는 아이콘 선택과 기존 이미지의 색상 표시 방식만 설명합니다.
프로필과 워크스페이스는 기본 후보 33개와 아이콘 전용 선택 셀을 공유합니다. 기존 실행환경·앱 아이콘에 구름·코드·로켓·과학·팔레트·도구·폴더·게임·책·발자국·지구·별·번개·전구 Material Symbols Rounded 14종을 더합니다. 자동 선택은 별도 심볼로 표시하며 프로필에서는 실행환경, 워크스페이스에서는 기본 팀 대시보드 아이콘을 사용합니다. 후보는 3열, 최소 높이 64dp, 중앙 28dp 아이콘과 medium 곡률을 사용합니다. 선택 셀은 secondaryContainer 배경과 2dp primary 테두리로 강조합니다. 후보와 선택된 아이콘 설정 행에는 아이콘 이름을 표시하지 않으며 지역화된 접근성 설명과 라디오 선택 상태를 제공합니다. 프로필과 워크스페이스 아이콘 설정 행은 탐색 화살표 없이 선택된 아이콘을 표시하고 모달을 엽니다.
프로필 선택 바텀시트는 도입 전 실행환경 선택과 같은 전체 너비 `ListItem`을
사용합니다. 왼쪽 아이콘 옆에 프로필 이름과 실행환경을 시작 정렬하고, 하단의
**프로필 추가**도 같은 행 배치를 사용합니다. 한국어 화면에서 Profile은 **프로필**로
표기하며, 세션 드롭다운의 **프로필 추가** 앞에도 `+` 아이콘을 표시합니다.
프로필 관리 목록은 섹션 카드 안의 `>` 화살표가 있는 설정 행을 사용합니다.
프로필 추가·편집은 일반 설정과 같은 섹션 제목, surfaceContainerLow 카드와
설정 행을 사용하며, 그룹 내부에는 2dp 여백과 4dp 안쪽 곡률을 적용합니다. 이름·셸·시작 설정·환경 변수는 현재 값을 표시하는 행을
눌러 입력 대화상자에서 수정하며, 텍스트 입력 행에는 탐색 화살표를 표시하지 않습니다.
프로필·워크스페이스 생성 및 편집의 이름 변경 대화상자는 **확인·취소** 버튼을 사용합니다. 확인은 부모 화면의 이름 초안만 변경하고 전체 저장에서 적용합니다.
프로필의 **실행환경** 선택은 공통 라디오 선택 대화상자를 사용합니다. 새 프로필에서는 새 실행환경 만들기·기존 실행환경 사용, 편집에서는 현재 실행환경 유지·새 실행환경 만들기·기존 실행환경 사용을 제공합니다. 새 실행환경 아래에 실행 방식·Userspace Linux 배포판과 실행환경 이름을 표시하며, 기본 이름은 프로필 이름을 따르고 중복 시 숫자 접미사를 붙입니다. 기존 실행환경 사용은 새 실행환경의 실행 방식·배포판 선택과 관계없이 모든 실행환경을 이름순 라디오 목록으로 표시하며 편집 중인 프로필의 현재 실행환경도 포함합니다. 행에는 이름과 실행 방식·배포판을 표시하며, 선택한 실행환경이 런타임·배포판 초안을 결정하고 기본 셸·인수·시작 디렉터리만 해당 런타임에 맞춥니다. 사용자 지정값은 유지하며 선택한 실행환경의 상세 행을 목록 아래에 중복 생성하지 않습니다. 현재 실행환경 유지로 돌아오면 원래 실행환경과 런타임을 복원하고 기존 상세 이동 행을 표시합니다. 실행환경 사용 방식 선택 대화상자는 **확인·취소** 버튼을 사용하며, 확인은 초안에 반영하고 전체 저장으로 실행환경과 프로필 참조를 원자적으로 영속화합니다. 초안은 화면 재생성 시 복원하고 저장하지 않고 나갈 때 확인합니다.
프로필 편집의 저장·복제·삭제는 하단 중앙의 Material 3 Expressive `HorizontalFloatingToolbar`에서 아이콘 버튼으로 제공합니다. 새 프로필·복제본 생성 화면은 플로팅 툴바 대신 마지막 설정 항목 뒤에 전체 너비의 채움 스타일 저장 버튼을 표시합니다. 툴바는 Material 기본 모양·높이·색상·패딩·그림자를 사용하며, 각 아이콘 버튼은 최소 48dp 터치 영역을 확보합니다. 플로팅 툴바의 아이콘 버튼은 고정 `CircleShape`를 사용해 hover·포커스·누름 상태에서도 곡률을 바꾸지 않습니다.
버튼 이름은 아이콘의 접근성 설명과 `TooltipBox`의 `PlainTooltip`으로 제공하며, 마우스 hover 또는 길게 누르면 버튼 위에 표시합니다. 툴팁을 여는 제스처는 작업을 실행하지 않습니다.
편집 툴바의 저장은 디스크 모양의 저장 아이콘, 복제는 복사 아이콘, 삭제는 휴지통 아이콘과 error 색을 사용하며 탐색 화살표를 사용하지 않습니다. 기존 프로필 편집에서는 스크롤 영역 하단에 툴바 높이와 화면 경계 여백을 확보해 마지막 설정 항목을 가리지 않습니다. 생성 화면은 저장 버튼 아래에 16dp 여백을 둡니다.
미저장 변경이 있으면 복제를 비활성화하고 저장 후 복제 안내를 표시합니다. 저장 중에는 모든 툴바 버튼을 비활성화합니다.
삭제는 기존 확인 대화상자를 거쳐야 합니다.
실행환경 설정도 같은 섹션 제목과 `surfaceContainerLow` 둥근 카드, 설정 행을 사용합니다. 사용 중·연결된 프로필이 없는 실행환경을 lazy 목록으로 표시하며 2dp 간격과 기존 그룹 모서리를 유지합니다. 목록 행은 이름을 제목, 런타임을 보조 줄, 용량을 오른쪽 값으로 표시하고 `EnvironmentDetailActivity`로 이동합니다. 뒤로 가면 목록 스크롤을 유지합니다. 용량 단위는 기존 Android formatter와 대문자 라틴 단위를 사용합니다.
실행환경 상세에는 이름·실행 방식/배포판·Execution Environment ID·저장 공간·참조 수·런타임 상태를 표시합니다. AVF는 VM ID·영속 디스크와 이미지 설치 상태/진행을 표시합니다. 하단 Material 3 Expressive 툴바에서 현재 지원하는 시작·세션 없는 런타임 중지·이름 변경·삭제를 요청합니다. 삭제 조건은 삭제 버튼의 활성화 상태에 반영하며 프로필/세션 참조, unknown/unreachable 상태 또는 legacy adoption 대기 시 비활성화합니다. 삭제 요청은 확인을 거칩니다. UI detach/recreation은 관찰만 해제하고 실행환경을 종료하지 않습니다.
Userspace Linux 실행환경 상세의 **배포판 관리**는 설치 상태·준비 단계·진행과 전체 너비의 설치/재시도/실행환경 보완 및 제거 설정 행을 제공합니다. AVF의 **Debian 이미지**도 같은 설정 행으로 설치·제거를 제공합니다. 모든 실행환경 상세 카테고리는 상단 20dp, 제목 아래 8dp의 간격을 사용합니다. 상태·동작·진행 안내는 공통 그룹의 2dp 간격·4dp 안쪽 곡률·28dp 바깥 곡률과 같은 표면색을 사용하며, 진행 내용은 16dp 안쪽 여백을 둡니다. 동작의 부가 안내는 해당 행 안에 표시합니다. 배포판 제거 확인에서는 홈 보존을 기본으로 하고 홈 삭제를 별도 체크박스로 선택합니다. AVF의 제거 확인은 VM 내부 홈·패키지·설정 삭제를 설명합니다. 배포판/Debian 제거는 실행환경 삭제와 별개의 실행환경 도메인 동작으로, 실행환경과 연결된 프로필을 유지합니다. 활성 세션·진행 중 작업·상태 확인 실패 시 해당 동작을 비활성화하고 서비스에서 다시 검사합니다.
Userspace Linux 설정은 **네트워크 → DNS**, **런타임 → PRoot·아키텍처·가속**, **정보 및 진단 → 런타임 정보**만 제공합니다. DNS와 진단 상세는 탐색 행으로 열고, 엔진 상태와 런타임 정보는 클릭 의미 없는 공통 읽기 전용 `ListItem`의 끝쪽 값으로 표시합니다. DNS 상세의 라디오 선택과 사용자 지정 서버 목록은 공통 `SettingsGroup`·`ListItem`을 사용하고 저장에서만 적용하며 목록·추가 대화상자 초안을 복원합니다. 사용자 지정 이외에는 서버 그룹을 숨깁니다. 추가 행은 한 주소 입력 대화상자를 열고 3개 제한에 도달하면 같은 표면과 공통 비활성 전경색을 유지합니다. 주소는 기본 UI 글꼴로 줄바꿈하며 추가·삭제 시 목록 높이는 테마의 defaultSpatialSpec, 투명도는 fastEffectsSpec으로 전환합니다. 주소 제거는 툴팁·접근성 설명을 가진 20dp 빼기 아이콘과 48dp 원형 터치 영역으로 제공하고, 버튼 중심을 다른 설정 행의 오른쪽 아이콘과 같은 위치에 맞춥니다. 한국어에서도 이름은 Userspace Linux를 유지합니다. 제약 사항은 탐색 항목이나 별도 화면 없이 마지막 설정 그룹 아래에 `bodySmall`·`onSurfaceVariant`의 배경 없는 보조 텍스트로 표시합니다. AVF Linux 설정은 전역 정책과 실행환경 관리 링크를 제공하며, 개별 배포판/VM 제거·초기화는 실행환경 상세의 도메인 동작으로 처리합니다. AVF suspend/resume은 현재 실제 플랫폼 operation이 아니므로 UI action으로 노출하지 않습니다.
프로필 이름과 실행환경의 실행 방식·배포판을 함께 표시하고 특권 없는 AVF 기본 프로필은 숨깁니다. 프로필 복제는 새 실행환경을 기본으로 하며 기존 실행환경을 명시적으로 선택하면 패키지·rootfs·VM 디스크까지 공유함을 안내합니다.
Userspace Linux 그룹과 설정 항목에는 WSL 아이콘처럼 얼굴을 중심으로 한 펭귄 형태의 자체 제작
`ic_runtime_rootless_group` 단색 벡터를 공통으로 사용한다. 24 dp 뷰포트에
둥근 머리·두 눈·부리와 U자형 얼굴을 표현하며 주변 UI의 아이콘 tint를 따른다.
프로필 아이콘 선택기의 Userspace Linux 아이콘도 같은 벡터를 사용한다. 사용자가 가져온
아이콘에만 휴지통 버튼과 미리보기를 포함한 삭제 확인을 제공한다. 삭제는 목록에 즉시
반영하고, 저장된 프로필·세션의 이미지 참조와 이미지 파일은 유지한다.
프로필 추가·설정 화면의 프로필 아이콘 항목은 이름과 설명을 왼쪽에,
선택된 아이콘 미리보기를 오른쪽 끝에 수직 중앙 정렬로 표시한다.
Native 로봇은 안테나 끝·머리 하단 모서리·하단 막대를 둥글게 처리한다.
Userspace Linux 펭귄 얼굴은 하단 모서리와 눈 사이 연결부를 완만하게 처리하여
주변 Material 아이콘의 둥근 형태와 조화를 이룬다.

**터미널 단축키**와 **터미널 모양**은 설정 홈에 중복 표시하지 않고,
**터미널 모양**은 **터미널 설정 → 사용자 설정**에서 편집 화면으로 이동한다.
**터미널 단축키**는 **툴바 설정**의 도구 항목을 통해서만 편집 화면을 연다.
단축키 관련 검색 결과도 편집 화면 대신 툴바 설정으로 연결한다.

설정 홈은 공통 **터미널 설정**과 **Native 셸**을 분리한다. TERM·스크롤백·
로그인 셸·공유 내부저장소·앱 권한은 공통 화면에, Native 기본 셸만 Native 화면에
둔다. 로그인 셸은 Native/Userspace Linux에만 적용됨을 명시한다. 공유 내부저장소 설정은
공통 OS 권한 설정을 공통 화면에 제공한다. 개별 실행환경 상세와 새 환경 생성의 권한 섹션에는 환경별 내부저장소 연결 선택을 제공하며 Userspace Linux 엔진 전역 설정에는 중복하지 않는다. 기존 저장 키를
유지하므로 메뉴 이동 전 설정값을 그대로 사용한다.

설정 홈의 메뉴 이름과 해당 상세 화면의 제목은 같은 문자열 리소스를 사용한다.
설정 홈의 설명은 주요 기능만 짧게 나열한다. 실행환경·프로필의 상세 안내와 홈 설명은 별도 문자열을 사용하며, 실행환경·프로필·언어·터미널에는 각각 레이어·계정 원형·`language`·터미널 아이콘을 사용한다.

설정 홈과 하위 설정 화면의 공통 큰 앱 바는 펼쳐진 상태와 스크롤로 접힌 상태 모두
투명 컨테이너를 사용한다. 스크롤 시 별도의 배경색을 덧씌우지 않으며 기존 접힘 동작을 유지한다.

터미널 모양의 텍스트 설정에는 글꼴 크기만 표시한다. 한글/CJK 등 2셀 글자는 항상 자연스러운 비율로 셀 중앙에 배치하고, 단일 셀 글자는 셀 폭 정렬을 유지한다. 별도의 자연스러운 넓은 글자·고정 문자 폭 설정이나 검색 항목은 제공하지 않으며, 이전 저장값은 렌더링 동작에 반영하지 않는다.

사용자 글꼴의 일반·이탤릭 선택은 같은 설정 그룹의 상단 `SecondaryTabRow`로 표시한다. 탭과 글꼴 추가·목록·빈 상태는 같은 `surfaceContainerLow` 배경과 그룹 외곽 곡률을 사용하고, 항목 사이에는 공통 2dp 여백을 유지한다. 선택 표시선은 탭 바로 아래의 글꼴 목록과 연결되며, 탭을 바꾸면 추가 동작과 우선순위 목록도 해당 스타일로 바뀐다.

팔레트 편집의 터미널 미리보기에서 명령 예시는 일반 사용자 글꼴 중 예시 전체를 표시할 수 있는 첫 글꼴을 사용한다. 터미널과 같은 글꼴 로더와 우선순위를 적용하고, 사용할 수 있는 사용자 글꼴이 없으면 번들 Google Sans Code로 표시한다. 미리보기 제목은 일반 UI 글꼴을 유지한다. 색상을 변경하는 동안 글꼴은 다시 로드하지 않는다.

사용자 글꼴은 검증한 앱 내부 사본으로 터미널과 팔레트 미리보기에 적용한다. 추가 실패는 공통 Toast 안내로 표시하고 기존 등록 상태를 유지한다. 일시적인 읽기 실패로 기본 글꼴을 사용한 결과는 완료된 글꼴 캐시로 저장하지 않으며, 다음 터미널 모양 적용에서 다시 읽는다.

설정의 단순 안내(공유 저장소 사용 설명, Userspace Linux 실행환경 제한)는
옵션 카드 밖에 배경 없는 텍스트로 표시한다. 옵션 사이의 구분선을 안내 문구에는
사용하지 않는다. 실행 가능한 설정과 상태 확인 동작은 카드에 유지한다.

USB 디바이스 설정도 큰 앱 바와 섹션별 둥근 옵션 카드를 사용한다. 연결된 기기,
접근 요청, 허용된 접근, 이동식 저장장치, 호스트 도구, 도움말 및 진단을 구분하며
대기 요청이 있으면 가장 먼저 표시한다. 기기는 유형과 VID/PID, 연결 사용 상태를
요약하고 연결 ID·구성·인터페이스는 펼쳐서 확인한다. 요청에는 런타임·세션·연결 ID·
접근 범위를 표시하며 Android 권한 대기 중에는 중복 승인을 비활성화한다.
승인·세션 전체 접근 해제·폴더 제거는 별도 확인을 거친다. 진단은 원본 JSON 대신
허용된 연결 수만 표시하며, 계정 입력은 기존 호스트 도구 입력 화면으로 이동한다.

설정의 아코디언(USB 기기 상세·사용 안내·진단, 단축키 편집 도움말)은 헤더에 고정된 세로 펼침·접힘과 페이드를 함께 사용한다. 높이와 펼침 꺾쇠의 0→180도 회전은 테마의 `defaultSpatialSpec`, 투명도는 `fastEffectsSpec`을 따르며, 연속 탭하면 진행 중인 위치에서 새 상태로 전환한다. 표시 심볼은 24dp Material Symbols Rounded의 아래 방향 꺾쇠이며 펼치면 위를 향한다. 접힌 내용은 전환 완료 후 제거하고, 헤더 사이의 기존 간격과 펼침·접힘 접근성 상태 설명을 유지한다. 시스템 애니메이션 배율을 따르며 애니메이션이 꺼져 있으면 즉시 전환한다.

모든 화면은 edge-to-edge다. 공통 앱 바와 표시 중인 터미널 chrome은 status bar inset을 적용하고, 터미널 앱 바를 숨기면 렌더러의 스크롤 가능한 상단 여백으로 전환한다. 하단 extra key는 navigation bar inset을 적용한다. 터미널 화면은 IME inset을 반영해 키보드가 terminal/extra key를 가리지 않게 한다. 목록 기반 화면은 고정 텍스트 높이를 사용하지 않고 스크롤한다.

상태 표시줄과 탐색 표시줄은 투명 배경을 사용하며, 일반 화면은 밝은 아이콘, 터미널 화면은 캔버스 배경에 대비되는 아이콘을 사용한다. RTL에서는 start/end 기반 배치를 사용하되, 문자 셀 정확성이 필요한 터미널 렌더러 자체는 기존 방향 규칙을 유지한다.

## Lifecycle boundary

터미널 화면이 활성 상태이며 창 포커스가 있을 때 현재 선택한 세션의 작업 완료 알림은 표시하지 않는다. 다른 세션과 앱을 벗어난 동안의 완료 알림은 유지하며 프로그램의 명시적 벨·확인 요청은 별도로 알린다. 탭 전환·화면 재생성·서비스 재연결 때 포커스를 갱신하고, 화면 일시중지·창 포커스 상실·UI 연결 해제 때 억제를 해제한다. 화면 미러의 유지 유예는 알림 억제에 영향을 주지 않는다.

실행환경 상세의 삭제는 기존 플로팅 툴바와 `AlertDialog`를 사용하며 실행환경 이름과 런타임별 삭제 범위를 표시한다. Userspace Linux는 배포판·설치 캐시와 모든 환경 데이터를, AVF는 Debian 이미지·VM 영속 상태와 공유 디렉토리까지 함께 삭제함을 안내한다. 확인 동작은 `error` 색을 유지하며 설치·관리 중에는 비활성화한다. 배포판·이미지 제거는 서비스의 전체 삭제 절차에 포함되고 화면이 따로 소유하지 않는다.

설정 홈의 **앱 업데이트**는 같은 큰 앱 바와 중립 둥근 상태 카드를 사용한다. 채널 선택을 콘텐츠 최상단에 두고, 상태 카드와 릴리즈노트를 이어서 표시한다. 상태 카드의 제목·설명·버전·진행률은 시작 방향에 정렬하며 큰 장식 아이콘은 사용하지 않는다. 확인 전에는 새 버전 확인을 안내하고, 실제 확인 결과가 최신일 때만 최신 상태를 표시한다. 버전은 굵기나 크기를 키우지 않은 `bodyMedium`으로 표시하며, 업데이트 가능·다운로드·설치 준비 상태에서는 기존 버전과 화살표 없이 새 버전만 표시한다. 주요 동작은 카드 너비에 맞춘 버튼으로 제공하고 다운로드 시 같은 영역에 진행률·용량·wavy 진행 표시를 배치한다. 다운로드 유지 안내와 작업 저장 안내는 해당 단계에서만 표시하며 안내 문체는 기존 앱의 ‘~합니다 / ~하세요’를 유지한다.
정식·개발 채널은 기본 시각 크기와 터치 영역의 단일 선택 FilterChip으로 제공하고 선택을 저장한다. 칩의 높이·여백·텍스트를 추가로 키우지 않으며 좁은 화면과 큰 글꼴에서는 줄바꿈한다. 개발
채널의 불안정 경고는 카드 밖 안내 텍스트로 표시한다. 진행 중 채널 변경은
비활성화하고 채널 변경 시 이전 설치 확인 상태를 폐기한다.
새 버전이 있으면 해당 채널·커밋의 한국어 릴리즈노트를 별도 카드에 마크다운으로 렌더링하고 다운로드·설치 준비 상태에서도 유지한다. 제목·목록·강조·인용·코드는 네이티브 TextView의 Markwon core span으로 표시하며, 본문·제목 크기와 색상은 Material 3 토큰을 따른다. 문장 중간의 일반 줄바꿈은 공백으로 이어지고 마크다운의 명시적 줄바꿈은 유지한다. 링크는 사용자가 누른 http/https 주소만 브라우저로 열며 HTML 및 원격 이미지는 로드하지 않는다. 긴 내용은 화면 스크롤로 읽으며, 노트 조회 실패 안내는 APK 다운로드를 차단하지 않는다.
확인 중·다운로드 중에는 wavy 진행 표시와 중복 동작 차단을 적용하고,
배포 없음·최신·다운로드 가능·검증 완료·오류를 구분한다. 다운로드 상태는
Application 소유 controller에서 관찰하므로 화면 재생성·닫기로 취소되지 않는다.
설치는 별도 확인을 거쳐 시스템 설치 화면에 넘기며, APK 교체로 실행 중인
터미널 세션이 끊길 수 있음을 안내한다. UI는 세션 종료나 자동 앱 삭제를 하지 않는다.

Compose 상태는 서비스 상태의 투영일 뿐 권위 있는 세션 저장소가 아니다. Activity가 시작되거나 서비스에 재연결되면 세션 목록과 runtime 상태를 다시 읽는다. `AndroidView` 재구성은 `TerminalView`를 불필요하게 만들거나 세션을 종료하지 않으며, Activity가 보이지 않으면 renderer callback을 detach하며, 로컬 emulator projection과 출력 구독은 5초 유예 후 폐기한다. 유예 시간 안에 복귀하면 미러를 재사용하고, 이후에는 authoritative runtime checkpoint로 복원한다. UI의 메모리·USB·host-tool polling은 화면이 보일 때만 실행하며 idle 상태에서는 간격을 늘린다.

PTY, 프로세스, Userspace Linux 설치와 VM은 계속 `:vmhost` runtime 서비스가 소유한다. 대화상자 닫기, 세션 전환, Activity 재생성 또는 UI task 제거는 terminate 명령이 아니다. 실제 종료는 사용자가 명시적으로 요청한 세션 종료 동작을 runtime이 처리할 때만 일어난다. 기본적으로 종료 확인 대화상자를 거치며, 사용자가 **탭 삭제 시 묻지 않기**를 켠 경우에는 종료 아이콘 클릭이 명시적 종료 요청이다.

종료 요청 중인 탭은 중복 종료를 막고, 서비스가 revision이 증가한 목록으로
제거를 확인한 뒤에만 해당 로컬 렌더러 상태를 폐기한다. 실패하면 탭과 형제
렌더러를 유지하고 해당 탭의 대기 상태만 해제한다.

### Linux 설치 공통 UI

Userspace Linux와 AVF Debian의 설치 확인창은 `InstallationConfirmationDialog`, 진행 창은 `InstallationProgressDialog`, 실행환경 상세와 진행 창의 본문은 `InstallationProgressCard`를 재사용한다. 확인 설명은 같은 본문 글꼴과 세로 스크롤을 사용하며 기존 동의 문구와 동작 이름을 유지한다. 진행 카드에는 현재 상태·작업 내용, 측정된 현재 단계 진행률·용량·경과 시간, 가능한 설치 동작, 단계 목록, 안내를 같은 순서로 배치한다. 16dp 카드 안쪽 여백·12dp 콘텐츠 간격·24dp 단계 표시를 사용하고 그룹 내부는 공통 4dp 모서리와 surfaceContainerLow를 따른다. 대화상자에서는 카드 제목을 생략하고 공통 닫기 버튼을 유지하며 본문을 세로 스크롤한다. 설치 취소는 단계 목록 위의 전체 너비 OutlinedButton으로 제공하며 요청 중 비활성화한다. 배포판 진행 창의 재시도는 같은 위치의 Button으로 제공하고 실행환경 상세의 기존 재시도 행을 유지한다. 단계의 완료·진행 중·대기·중단을 텍스트로 구분하고 진행 중은 공통 파란색, 실패는 error 색으로 표시한다. UI는 작업을 소유하지 않으며 닫기·화면 재생성은 설치를 취소하지 않는다.

### Userspace Linux 설치 진행

배포판 단계 목록은 설치 준비, 이미지 다운로드, 이미지 무결성 검증, 이미지 압축 해제 및 설치, 기본 패키지 설치, 배포판 초기 설정, 기본 환경 동작 검증, 완료로 묶는다. 패키지 다운로드·복구·설치·업그레이드는 같은 기본 패키지 단계에 머물며 현재의 세부 작업은 본문에 유지한다. 알 수 없는 단계나 중단 단계 정보가 없는 취소 결과에서는 완료 단계를 추정해 표시하지 않는다.

설정의 배포판 상태 행과 설치 대화상자는 런타임이 보관하는 같은 진행 상태를
표시한다. 현재 단계와 작업 내용, 전체 경과 시간을 보여주며 화면 재진입 시
상세 단계가 “확인 중”으로 바뀌지 않는다. 이미지 다운로드·무결성 검증 및 apt가
보고하는 진행률에는 determinate `LinearWavyProgressIndicator`를 사용하고,
전체량을 모르는 압축 해제·pacman 작업·설정 등에는 indeterminate 표시를 사용한다.
숫자는 “현재 단계” 진행률이며 전체 설치 완료율로 표시하지 않는다. 다운로드는
MiB 수치를 병기하고, 진행 보고가 20초 이상 없으면 마지막 보고 이후 시간을
표시한다. 실행 중인 배포판을 새 세션 메뉴에서 선택하면 진행 화면을 다시 연다.
오류나 완료 뒤에는 애니메이션과 경과 시간 증가를 멈춘다.

설치 중 실행환경 상세의 진행 카드와 설치 창에 **설치 취소**를 제공한다. 취소 요청을 처리하는 동안 동작을 비활성화하고 **설치 취소 중…**을 표시한다. 실제 작업 정리가 끝나면 **설치 취소됨**과 재시도를 제공하며 닫기·뒤로가기는 설치를 유지한다.

### AVF 세션 시작

AVF 프로필 선택 즉시 새 탭을 선택하고 터미널 본문 중앙에 Material 3 `LoadingIndicator`만 표시합니다. 준비 화면에는 배경 카드나 프로필 이름·안내 텍스트를 표시하지 않으며 스크린 리더에는 준비 중이라는 설명을 제공합니다. 시작 요청에는 별도 UUID를 사용하며 실제 PTY가 준비되기 전에는 터미널 렌더러를 만들거나 입력을 전달하지 않습니다. 탭 선택과 다른 실행환경의 세션 사용은 계속 가능하지만 준비 중인 탭의 이름 변경·종료·단축키 입력은 비활성화합니다. 완료된 세션은 요청 UUID로 해당 탭의 위치와 선택을 이어받으며 다른 탭의 선택을 바꾸지 않습니다.

실패한 요청은 indicator를 제거하고 해당 탭에 오류와 닫기 버튼을 표시합니다. 이 닫기는 실패 표시만 제거하며 실제 세션 종료 확인과 구분합니다. 시작 작업과 승인된 요청 상태는 런타임 서비스가 소유하고 화면 재생성·복귀 시 다시 게시합니다. 서비스 연결 전의 요청만 UI가 임시 보관하며 연결 후 한 번 전송합니다. 이미지 다운로드·설치의 상세 단계는 기존 설치 진행 화면에서 확인합니다.

### AVF 이미지 설치 진행

활성 설치 카드에는 **설치 취소** 버튼을 제공하며 관찰 중인 WorkManager 작업 ID에만 취소를 전달한다. 대기·재시도 중인 작업도 취소할 수 있다. 취소 요청 중 버튼을 비활성화하며 WorkManager의 취소 상태를 관찰해 표시한다. 창을 닫거나 재생성하는 동작은 설치를 취소하지 않는다.

새 실행환경을 사용하는 AVF 프로필을 저장한 뒤 해당 실행환경 상세에서 이미지 설치 여부를 묻는다. **나중에 설치**를 선택해도 프로필은 저장되며 다운로드를 시작하지 않는다. AVF 실행환경 설정의 **Debian 이미지**에는 실제 파일을 기준으로 **설치됨 / 미설치**를 표시하고 미설치 상태에서 설치를 요청할 수 있다. 동일 실행환경의 모든 프로필에서 공유하는 설치 진행 상태를 실행환경 상세에 표시한다. 터미널의 진행 대화상자를 닫은 뒤에는 실행환경 상세에서 진행을 확인하며, 터미널에 별도의 **AVF Debian 이미지 설치 진행 보기** 버튼을 표시하지 않는다. 준비·설치 정보 확인·다운로드 및 압축 해제·무결성 검증·설치 및 최종 검증·Debian 초기 실행 준비·최신 패키지 목록 가져오기·완료를 단계 목록으로 구분하고 완료·진행 중·대기·중단을 텍스트와 상태색으로 함께 표시한다. 현재 이미지의 이름과 순서, 다운로드한 압축 용량, 현재 단계의 측정된 진행률 및 경과 시간을 보여준다. 전체 설치 완료율이나 예상 남은 시간을 추정하지 않으며 전체량을 모르는 다운로드·검증·설치에는 indeterminate wavy 표시를 사용한다. 완료·실패·취소 후에는 애니메이션과 경과 시간 증가를 멈춘다. 설치가 끝난 프로필은 완료된 설정 과정이나 작업 이력 대신 현재 설치 여부를 표시한다. 이미지 설치 여부와 패키지 목록 초기화 상태·성공 시각을 별도 읽기 전용 행으로 표시하며, 초기화 실패·취소 시 설치 이미지를 보존하고 갱신 재시도 작업 행을 제공한다. 초기 VM 실행을 터미널 세션 생성 성공으로 표시하지 않으며 화면 닫기는 작업 취소가 아니다.

설정의 **앱 정보**는 APK의 앱 버전, 패키지명, 빌드 타입, 빌드 번호(versionCode), 업데이트 채널과 빌드 리비전을 기존 설정 그룹의 읽기 전용 행으로 제공한다. 값은 선택·복사할 수 있고, 긴 버전과 리비전은 줄바꿈한다. **오픈소스 라이선스**는 APK에 포함된 licenses assets를 디렉터리별 설정 목록으로 탐색하고 라이선스 원문과 고지문을 선택 가능한 텍스트로 보여준다. 네트워크 연결 없이 읽을 수 있으며 동일한 설정 앱 바·surfaceContainerLow·2 dp 간격·모서리 규칙을 사용한다.

### 로컬 서비스 / 전달 포트

로컬 서비스는 `SettingsPageScaffold`, 기본 크기 `FilterChip`, `SettingsGroup`, 지연 로딩 `ListItem`과 공통 Material 3 Expressive 모션·색상·typography를 재사용한다. 설정 홈의 앱 언어 바로 위에서 공유 디렉토리와 같은 그룹에 카테고리를 두고 AVF Linux의 전달 포트는 같은 화면을 AVF 필터로 연다. 서비스 목록은 2dp 간격·28dp 바깥/4dp 안쪽 곡률·`surfaceContainerLow`를 유지한다. 이름·실행환경·TCP/앱 프로토콜·관측 및 전달 상태는 일반 UI 글꼴, 주소·ID는 고정폭 글꼴로 표시한다. 상태는 텍스트와 아이콘으로 구분하며 전달 활성에도 응답 미확인을 명시한다. 상세는 접속 주소/포트 복사·명시적인 HTTP/HTTPS 브라우저 열기·수동 등록 편집/삭제·AVF 호스트 포트 변경을 제공한다. 삭제는 등록만 제거하며 서비스 종료 동작은 없다. 연결 중은 wavy progress, 빈 목록·조회 실패·충돌·연결 끊김은 각 안내를 제공한다. 화면이 보일 때만 Binder 무효화 알림을 구독하고 새로고침은 상태 조회만 한다.

세션 툴의 기본·확장 헤더와 툴바가 없는 초기 빈 화면의 우측 상단 설정 버튼은 같은 `TerminalSettingsButton`을 사용한다. 툴바가 제공되는 빈 화면에서는 중앙 새 세션 버튼과 우측 상단 설정 버튼을 표시하지 않는다. Material Symbols Rounded `settings` 아이콘과 기존 48dp 터치 영역·위치를 유지하며 클릭하면 기존 설정 화면을 바로 연다. 터미널 팔레트는 설정 버튼의 아이콘 대비에만 적용한다. 로컬 서비스는 설정 홈의 앱 언어 바로 위에서 공유 디렉토리와 같은 그룹의 카테고리로 제공한다. 서비스 등록의 실행환경 메뉴는 `SelectableDropdownMenuItem`과 `MenuDefaults.itemShape`로 선택 상태와 항목 곡률을 표현하며 메뉴 그룹은 세로 스크롤을 지원한다.

### 진단 및 리포트

설정 홈의 **진단 및 리포트**는 공통 설정 scaffold와 20dp 섹션 간격을 사용하며 진단 정보와 크래시 목록을 각각 공통 그룹에 표시한다. 진단은 런타임 상태·상세 메시지·이미지·절전 정책·세션 수를 제목과 값의 읽기 전용 `ListItem`으로 나누며 일반 UI 글꼴과 그룹의 2dp 간격·곡률·표면색을 사용한다. 값은 선택해 복사할 수 있고 런타임 상태·절전 정책은 현지화된 문구로 표시한다. 리포트 목록은 오류 요약·현지화된 날짜와 탐색 화살표를 가진 설정 행을 사용한다. 새로고침은 화면 설명 아래에 공통 그룹·설정 행·20dp 간격으로 배치하고 새로고침 아이콘·이름·갱신 대상 설명을 제공한다. 갱신 중에는 같은 크기의 LoadingIndicator와 새로고침 중 문구를 표시하며 행을 비활성화하고 중복 요청을 차단한다. 진단과 목록을 함께 갱신하며, 목록은 최신순으로 최대 20개를 표시한다. 로딩·빈 목록·읽기 실패를 명시하고 리포트 상세의 복사는 내용이 준비된 뒤 활성화한다. 상세 닫기·뒤로가기는 기록을 삭제하지 않는다. 전달 포트의 설정 진입과 검색 목적지는 AVF Linux에만 두며 Userspace Linux·이미지 설정·진단 화면에 중복하지 않는다.

## 워크스페이스 / 공유 디렉토리

일반 앱 실행·런처 재진입·장시간 백그라운드 복귀는 런타임에 저장된 워크스페이스 필터와 해당 그룹의 마지막 활성 탭을 복원한다. UI 미러의 해제나 화면 재생성은 필터·세션 소속을 초기화하지 않는다. 명시적인 워크스페이스 전환·실행 구성·세션 알림 요청이 있을 때만 그 대상을 선택하며, 저장된 선택이 없는 첫 실행은 미소속 세션으로 시작한다. 저장된 빈 워크스페이스 복원 자체는 기본 세션 실행을 다시 예약하지 않는다.

워크스페이스 실행 구성 그룹의 **시작 시 실행** 행은 공통 설정 ListItem·현재 선택 개수·설명을 사용한다. 다중 선택 대화상자는 전체 행에 체크박스 역할과 선택 상태를 제공하고 자식 체크박스는 자체 클릭을 갖지 않는다. 저장/취소는 부모 초안 규칙을 따르고 구성별 선택·대화상자는 재생성 시 복원한다. 참조 프로필이 없으면 안내하며 새 선택을 막되 기존 선택 해제는 허용한다. 자동 실행은 비어 있는 워크스페이스 진입에서만 요청하고 기존 설치 확인·준비 화면을 그대로 사용한다.

워크스페이스 카테고리의 아이콘은 Material Symbols Rounded `team_dashboard`, 공유 디렉토리는 `folder_data`를 사용하며 설정 홈과 관련 검색 결과에 동일하게 적용한다. 워크스페이스별 기본 아이콘은 `team_dashboard`이며 프로필과 같은 3열 모달에서 기본 후보 33개 중 하나를 지정한다. 후보와 설정 행은 이름 없이 아이콘만 표시하며 기본 후보와 셀은 프로필과 공통으로 관리한다. 후보는 라디오 선택 역할·상태, 48dp 이상 조작 대상과 선택 강조를 제공하며 **확인**은 부모 초안에만 반영한다. 모달의 취소·바깥 터치·뒤로가기는 기존 초안을 유지하고 모달 상태와 선택은 재생성 시 복원한다. 워크스페이스 목록·선택기·이동 행은 저장한 아이콘을 표시하고 미소속 세션의 선택 버튼·메뉴·이동 행은 `team_dashboard`을 사용한다. 선택 메뉴의 미소속·등록된 워크스페이스·임시 생성 아이콘은 모두 `MenuDefaults.LeadingIconSize`(현재 20dp)를 사용한다. 선택 메뉴의 임시 워크스페이스 만들기는 `add` 아이콘을 표시하고 선택 목록과 별도 Expressive 메뉴 그룹으로 나누며, 그룹 사이에는 `MenuDefaults.GroupSpacing`의 공식 기본 간격(현재 2dp)을 둔다. 만들기 행은 메뉴 하단 위치에 맞춰 `MenuDefaults.trailingItemShape`를 사용하고 위쪽 모서리는 4dp, 아래쪽 모서리는 12dp로 둔다. 두 그룹은 같은 가로 폭을 사용하고 함께 스크롤한다. 선택 메뉴는 헤더의 가용 폭을 유지하는 바깥 영역과 별도로 실제 버튼을 감싼 Box에 연결한다. `MenuAnchorPosition.Custom`으로 시작 방향을 버튼에 맞추고 화면 좌우 16dp 여백 안에 제한하며, 세로 위치와 공간 부족 시 대체 위치는 `MenuAnchorPosition.Above`의 기본 계산을 재사용한다. 가장자리의 작은 버튼이 Material 기본 여백 검사에서 제외되어 메뉴가 화면 중앙으로 이동하지 않게 한다. 워크스페이스는 설정 홈의 환경·프로필 그룹에 두고 공유 디렉토리는 로컬 서비스와 같은 그룹에 둔다. 두 카테고리는 공통 설정 표면·72dp 홈 항목·48dp 조작 대상·저장/취소 초안 규칙을 따른다. 워크스페이스 목록은 프로필과 같은 별도의 만들기 그룹과 목록 그룹을 사용하고, 목록·상세·실행 구성은 각각 별도 Activity로 이동하며 아이콘 선택은 상세 위의 모달로 연다. 목록과 상세 모두 16dp 가로·8dp 상단 여백과 20dp 섹션 간격을 사용한다. 설명은 bodyLarge·onSurfaceVariant와 추가 4dp 가로 여백을, 섹션 제목은 primary·labelLarge와 시작 16dp/하단 8dp 여백을 사용한다. 만들기·항목·실행 구성 탐색 행은 공통 그룹의 2dp 간격·28dp 외곽/4dp 안쪽 곡률·surfaceContainerLow 표면과 중앙 정렬을 따르며 탐색 화살표로 상세 진입을 표시한다. 필드는 프로필과 공유하는 설정 행 및 단일 값 대화상자, 프로필 참조는 공통 선택 행을 사용한다. 기존 항목의 저장·삭제는 하단 중앙 floating toolbar, 새 항목의 저장은 전체 너비의 채움 스타일 Material `Button`으로 제공한다. 연결 체크박스는 행 오른쪽에 두고 실제 적용은 전체 저장까지 미룬다. 미지원 안내는 그룹 밖 bodySmall·onSurfaceVariant로, 작업 오류는 공통 errorContainer 카드로 표시한다. 세션 툴 헤더 왼쪽에는 기본 크기에서 워크스페이스 선택 아이콘만 표시하고 워크스페이스에 세션이 없거나 확장 완료 시 아이콘 옆에 이름을 함께 표시한다. 미소속 필터는 세션 유무와 크기에 관계없이 아이콘만 표시한다. 이름 버튼은 모두 닫기 버튼을 제외한 가용 폭·최소 높이 48dp를 사용하며 최대 두 줄로 표시한다. 확장 헤더의 워크스페이스 선택기 오른쪽에 있는 모두 닫기는 세션 목록을 받은 비어 있는 임시 워크스페이스에서만 휴지통 아이콘과 워크스페이스 이름을 포함한 삭제 접근성 설명으로 전환한다. 준비 중인 소속과 연결 끊김은 삭제 전환을 막는다. 빈 영구 워크스페이스에는 기본·확장 크기 모두 선택기 오른쪽에 `play_arrow` 아이콘과 **기본 세션 실행** 접근성 설명을 가진 48dp 버튼을 표시한다. 지정한 시작 구성이 없거나 세션 상태를 확인하지 못하면 비활성화하며, 기존 시작 실행 큐로 저장 순서대로 실행한다. 미소속 필터에는 시작 실행 버튼을 표시하지 않는다. 버튼 위치와 48dp 터치 영역은 동일하게 유지한다. 워크스페이스 영역은 별도 배경 박스 없이 툴바 표면을 사용한다. 헤더와 확장 탭 목록 사이의 추가 여백은 확장 진행률에 따라 0~8dp로 변하고 기존 목록의 4dp 상단 여백을 유지한다. 선택 메뉴는 내용의 자연 폭과 최소 240dp를 기준으로 하되 창의 양옆 16dp 여백 안에 맞추고, 더 긴 이름은 말줄임 없이 줄바꿈한다. 전체 이름·현재 필터는 접근성 설명과 선택 메뉴에서도 제공한다. 선택 메뉴는 미소속 세션·등록된 워크스페이스로의 전환과 임시 생성만 제공하며 모든 세션 항목은 표시하지 않고 실행 구성은 새 세션 목록의 워크스페이스 카테고리로 표시한다. 선택기는 기존 Expressive 팝업과 그룹 컴포넌트를 사용한다. 워크스페이스 필터는 렌더러·세션 소유권을 갖지 않는다. 공유 디렉토리 목록·만들기·기존 항목 상세는 각각 비공개 Activity로 이동한다. 만들기는 기존 공통 편집 화면과 전체 너비 저장 버튼, 상세는 같은 편집 화면과 하단 저장·삭제 툴바를 사용한다. 이름 대화상자의 확인 버튼은 초안에만 반영하며 전체 저장에서 기존 Binder 경로로 적용한다. 이름·연결 환경과 필드·AVF 복사 대화상자의 초안은 화면 재생성 시 복원하고, 저장이나 파일 작업 제출이 성공하면 목록으로 돌아온다. 서비스 재연결은 편집 초안을 덮어쓰지 않으며 연결을 잃어도 파일 복사 대화상자를 취소할 수 있다. 공유 디렉토리의 호스트·게스트 경로는 선택 가능한 텍스트이며 AVF 사본과 직접 공유를 명확하게 구분한다. AVF 경로는 지원 이미지·호환 기기에서 다음 VM 부팅에 적용되는 경로로 안내하며 이름 변경·연결 해제의 VM 중지/시작 조건을 같은 읽기 전용 표면 안에 표시한다. 실제 마운트 여부를 확인하지 않은 상태에서 성공 또는 활성 상태를 표시하지 않는다. 파일 작업의 무기한 진행 표시는 실행 중에만 보이며 완료·실패·취소·중단 후 멈춘다.

공유 내부저장소의 공통 ActionSetting과 그룹 밖 InfoSetting 설명은 OS 권한 상태·지원 런타임·적용 시점·권한 해제의 VM 중지 조건을 제공한다. 모든 런타임의 환경 상세·생성 화면 권한 섹션에는 공통 ListItem·Switch 행과 Android 공통 권한 탐색 행을 묶는다. Userspace Linux·AVF에서는 행의 클릭이 한 번만 선택을 변경하고 자식 Switch는 독립 클릭 없이 상태·역할을 제공한다. 기존 환경에서는 서비스 저장 성공 후 상태를 표시하고 작업 중 중복 변경을 막는다. Userspace Linux·AVF 생성 화면은 동일 행을 저장 가능한 초안으로 사용하고 전체 저장 전에는 환경 권한을 바꾸지 않는다. Native의 스위치는 실제 OS 권한 상태를 표시하고 누르면 Android 설정으로 이동한다. Native 권한은 생성 초안이 아니라 앱 공통 OS 권한이며 시스템 설정에서 변경한 뒤 복귀하면 실제 상태를 갱신한다. 새 세션/다음 VM 부팅의 적용 시점과 Native·PRoot 접근 격리의 한계를 행 설명에 표시한다.
