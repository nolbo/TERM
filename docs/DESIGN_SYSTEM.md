# Compose Material 3 design system

## Direction

TERM의 활성 Android UI는 Jetpack Compose와 Material 3 Expressive를 기준으로 구현한다. Compose 기반선은 2026.08 BOM이며, segmented menu와 최신 Expressive 컴포넌트를 위해 Material 3 `1.5.0-alpha27`을 명시적으로 사용한다. 앱 크롬은 시스템 테마와 관계없이 차가운 회백색 primary와 중립 surface를 갖는 명시적 다크 색상표를 사용하되 터미널 화면의 크롬은 캔버스 배경에 맞춰 조정한다. 파란색은 활성·사용 가능·준비·진행 상태처럼 의미가 있는 상태에만 사용하며 민트 계열 색상은 앱 UI에 사용하지 않는다.

터미널 캔버스는 예외다. `TerminalView`와 `TerminalAppearance`가 사용자 선택 팔레트, ANSI 색상, 커서, 선택 영역과 배경을 독립적으로 관리하며 Material 앱 색상표가 이를 덮어쓰지 않는다.

터미널 화면의 상단 앱 바는 상태 표시줄 뒤 여백과 세션 탭을 포함해 현재 터미널
배경색을 사용한다. 터미널 팔레트 변경 후 화면에 돌아오면 앱 바 배경도 함께
갱신한다. 탭·단축키·메모리 사용량 카드·세션 메모리 행·명령어셋 항목의 컨테이너는 배경색에 대비 전경색을 14% 혼합하고,
글자·아이콘은 각 배경에 대해 대비가 높은 검정 또는 흰색을 선택한다.
활성 탭과 CTRL·ALT는 대비 4.5:1 이상인 밝은/어두운 파란색을 사용하며,
충족하지 못하면 대비 전경색으로 대체한다. 비선택 탭은 투명 배경을 유지하며,
아이콘·제목·부제목은 배경에 대비 전경색을 60% 혼합한 차분한 색상을 사용한다.
사용자 지정 배경에서 대비가 부족하면 혼합 비율을 5%p씩 높여 4.5:1 이상을 유지한다.
앱 바의 새 세션·설정 아이콘은 같은 대비 보정 방식으로 전경색을 70% 혼합하여,
기본 검정 배경에서 순백색 대신 차분한 회색을 사용한다.
상태 표시줄·탐색 표시줄 아이콘의 밝기도 터미널 배경에 맞춘다.
새 탭 메뉴의 컨테이너·프로필 이름·환경 설명·아이콘도 같은 대비 색상을 사용한다.
설정 화면과 그 밖의 팝업은 기존 다크 테마를 유지한다.
**터미널 설정 → 사용자 설정 → 전체 화면 TUI 배경색 따르기**는 기본적으로 꺼져 있다. 켜면 alternate screen을 사용하는 전체 화면 TUI의 셀 배경을 최대 32×32로 분산 표본 추출해 가장 넓게 쓰이는 색상을 앱 바·탭·툴바·터미널 외곽 여백·경계 그라데이션에 적용한다. ANSI·256색·truecolor와 반전 속성을 렌더러와 같은 방식으로 해석하며 시스템 표시줄 아이콘 대비도 갱신한다. 출력·탭 전환·설정 복귀·Activity 재생성 때 활성 세션을 기준으로 갱신하고, synchronized output 중에는 완료 또는 타임아웃까지 갱신을 미룬다. 옵션을 끄거나 TUI가 alternate screen을 종료하면 현재 세션의 팔레트 배경색으로 복원한다. 셀 색상이 여러 개인 화면은 최다 표본 색을 사용하므로 분할 창에서는 가장 넓은 영역의 색을 따른다. 터미널 렌더러의 화면 전체 채움과 View 배경에도 같은 색상을 적용해 문자 격자 밖의 위·아래·오른쪽 여백에 기존 팔레트 배경이 남지 않게 한다. 셀의 명시적 배경·기본 배경·반전·선택 색상과 터미널 앱이 보는 팔레트 및 프로토콜 상태는 변경하지 않는다. 메모리 카드와 명령어셋 항목은 같은 반응형 컨테이너·대비 전경색을 사용하며 메모리 진행 표시와 구분선도 반응형 색상으로 표시한다.
세션이 없는 빈 화면에서는 메인 콘텐츠와 앱 바가 같은 Material `background`
색을 사용한다. 세션을 열면 앱 바와 콘텐츠가 터미널 배경색을 사용한다.

팔레트 편집은 별도 화면에서 전경·배경·커서와 ANSI 표준/밝은 색상을 견본으로 보여 준다. 색상 견본을 누르면 Material 3 바텀시트의 정사각형 색상 영역에서 채도(가로, 오른쪽으로 증가)와 밝기(세로, 위쪽으로 증가)를 조절하고, 바로 아래 색조 막대로 색조를 선택한다. 색상 견본과 HEX·RGB 입력은 서로 동기화되며 HEX는 6자리, RGB는 채널별 0–255를 허용한다. 잘못되거나 미완성인 입력은 마지막 유효 색상을 유지하고 적용을 비활성화한다. 검정·회색에서도 선택한 색조를 보존하며, 사각형은 키보드 방향키와 접근성 증감 동작으로도 조작할 수 있다. 편집 화면의 미리보기는 저장 전 초안만 표시하며 전체 저장 시 사용자 지정 팔레트로 전환한다. 저장하지 않고 나가면 변경사항 폐기를 확인한다.

## Foundations

비활성(`enabled = false`) 설정 행은 활성 상태와 같은 배경을 유지한다.
`terminalSettingsListItemColors`로 제목·설명·앞뒤 아이콘 등 전경에만
`onSurface` 38% 불투명도를 적용하며, 행 전체나 배경의 불투명도는 변경하지 않는다.

- 비동적 다크 색상표는 primary/secondary/tertiary, 모든 on/container, surface container 단계, inverse, outline, error, scrim 역할을 명시한다. 일반 동작과 강조는 `MaterialTheme.colorScheme` 역할을 사용하고, 활성·가용·준비·진행 상태는 이름이 명시된 파란색 semantic token을 사용한다.
- 앱 루트는 `MaterialExpressiveTheme`와 `MotionScheme.expressive()`를 제공한다. 별도 Expressive API가 있는 버튼과 아이콘 버튼은 상태에 따라 형태가 변하는 `shapes` 오버로드를 사용하고, 로딩은 shape-morphing `LoadingIndicator` 또는 wavy progress indicator를 사용한다. 별도 Expressive 오버로드가 없는 scaffold, dialog, text field, switch, radio button, card, tab은 같은 테마 아래 최신 Material 3 토큰과 motion scheme을 상속한다.
- 앱 텍스트는 Material 3 type scale을 사용한다. 고정폭 글꼴은 터미널, extra key, 진단 및 크래시 payload에만 사용한다.
- 앱 내부 아이콘은 24 dp Material Symbols Rounded의 기본 비채움 스타일을 사용한다. 방향성 아이콘은 RTL 레이아웃에서 자동 반전한다.
- 간격은 4 dp 배수를 기본으로 한다. 독립된 카드와 설정 행은 평상시 `extraLarge`(28 dp) 컨테이너 shape를 사용해 높은 곡률이 화면에서 명확히 드러나게 하고, 상호작용 가능한 `ListItem`은 눌림·포커스·선택 상태에서 Material Expressive 기본 shape로 morph한다. 앱 바, 터미널 캔버스처럼 화면 경계에 붙는 기반 surface는 직사각형을 유지한다.
- 모든 일반 상호작용 대상은 최소 48 dp다. Extra key는 고정 높이 40 dp를 사용하며, 툴바 핸들 영역은 24 dp로 압축한다. 세션 탭은 밀도를 위해 시각적 높이 40 dp를 사용하며 앱 바의 위아래 여백 안으로 확장되는 터치 영역을 사용한다.
- 아이콘 버튼에는 동작을 설명하는 content description을 제공한다. 장식 아이콘에는 중복 설명을 제공하지 않는다.
- 화면 전환에 별도 View transition을 강제하지 않는다. Compose 및 플랫폼의 애니메이터 배율을 따르는 표준 컴포넌트 상태 변화만 사용한다.

구현은 `android-app/src/main/kotlin/dev/terminal/app/ui/ComposeUi.kt`의 `DroidTheme`와 공통 scaffold/화면 컴포넌트에 모인다. 사용자 문구는 `android-app/src/main/res/values/strings.xml`에 둔다.

## Components and screens

설정 홈과 모든 하위 설정 화면은 공통 `SettingsPageScaffold`를 사용합니다. 앱바는 화면 배경과 같은 색을 사용하고 뒤로가기 버튼은 처음부터 원형 배경을 유지합니다. 위로 스크롤하면 먼저 Material 기본 동작으로 large app bar가 제목과 배경을 유지하는 small app bar로 접힙니다. Small app bar 상태에서 추가로 위쪽 스크롤이 시작되면 즉시 150ms 페이드아웃을 실행해 제목과 앱바 배경을 숨기고, 뒤로가기 버튼만 고정된 위치에 남깁니다. 페이드 진행은 스크롤 거리가 아닌 시간에 따르며, 손가락을 멈춰도 끝까지 실행됩니다. 페이드 애니메이션은 제목과 앱바 배경의 불투명도에만 적용합니다. 상태 표시줄 여백을 포함한 콘텐츠 위쪽 여백은 실제 추가 스크롤 거리와 1:1로 줄어들며, 손가락을 멈추면 콘텐츠 위치도 그대로 유지됩니다. 계속 스크롤하면 콘텐츠가 앱바의 기존 영역과 상태 표시줄 뒤까지 이어지며, 상태 표시줄 아이콘 영역에만 최대 불투명도 45%의 얇은 그라데이션을 적용합니다. 아래로 스크롤해 콘텐츠의 시작에 도달하면 small app bar를 먼저 복원하고 이어서 large app bar로 펼칩니다. 뒤로가기 버튼은 콘텐츠 위에 겹쳐지고 해당 버튼 밖의 콘텐츠 입력을 막지 않습니다. 하단 시스템 여백·키보드 대응·플로팅 툴바는 기존 화면별 동작을 유지합니다.
USB 메뉴의 호스트 도구 입력 화면과 AVF 진단 화면도 같은 앱바를 사용합니다. 진단의 새로고침은 콘텐츠 상단 버튼으로 제공하고 진단 본문은 선택 가능한 고정폭 텍스트를 유지합니다.
Small app bar 제목은 고정된 뒤로가기 버튼의 원형 배경에서 16dp 떨어져 배치하며, 페이드 중에도 이 간격을 유지합니다. Large app bar 제목은 버튼 아래에 간격을 두고 배치합니다.

세션 탭의 제목은 12 sp로 표시한다. 사용자 지정 제목이 있으면 아래에 원래 제목을
10 sp로 표시하고, 해당 탭의 보조 전경색에 75% 불투명도를 적용해 강조를 낮춘다.

초기 설정은 Native, Rootless Linux, AVF Debian을 각각 카드로 설명하고 즉시 터미널 시작과 AVF 로컬 이미지 선택을 분리한다. 세로 스크롤을 사용하므로 좁은 화면, 가로 화면, 큰 글꼴에서도 작업 버튼에 접근할 수 있다.

터미널은 다음 세 영역을 유지한다.

1. Material 3 `PrimaryScrollableTabRow` 세션 탭과 고정된 새 세션/설정 아이콘 버튼
2. `AndroidView`에 포함된 기존 `TerminalView`
3. 터미널 배경 위에서 높이를 조절하고 단축키·메모리·명령어셋을 전환하는 BottomSheet 툴바

권위 있는 세션 목록이 비어 있으면 두 번째와 세 번째 영역 대신 빈 상태를
표시한다. 빈 상태는 장식 아이콘 없이 런타임이 대기 중임을 설명하고 **새 세션**
동작을 제공하며, 이 동작은 화면 하단의 Material 3 `ModalBottomSheet`에서 실행
환경을 선택하게 한다. 상단의 새 세션 메뉴와 설정 동작도 그대로 유지한다. 이때
터미널 View와 extra key를 구성하거나 IME 포커스를 유지하지 않는다.

세션 탭은 Material 3 `PrimaryScrollableTabRow`와 `Tab`을 유지하며, 선택된 탭만 터미널 배경에서 파생한 컨테이너 색상의 캡슐 모양과 selected semantics로 구분한다. 탭은 빈 화면의 새 세션 버튼과 같이 눌림 상태에 따라 모서리 반경을 20→8 dp로 줄이고, 손을 떼거나 제스처가 취소되면 축소 완료를 기다리지 않고 즉시 20 dp 복원을 시작한다. 애니메이션은 Material 3 버튼과 같은 `defaultEffectsSpec`을 사용하며 클릭 시 세션 전환은 즉시 처리한다. 기본 밑줄 indicator는 사용하지 않는다. 비선택 탭은 투명 배경을 사용하며, 서로 인접한 비선택 탭 사이에만 18 dp 세로 구분선을 표시한다. 48 dp 앱 바 안에 높이 40 dp 탭을 두고 위아래 4 dp 여백을 유지한다. 탭 목록의 새 세션 버튼 쪽 끝에는 폭 24 dp의 투명→현재 터미널 배경색 그라데이션을 겹쳐 스크롤 경계를 부드럽게 연결한다. 그라데이션은 새 세션 버튼 방향으로 더 스크롤할 수 있을 때만 표시하고, 끝에 도달하거나 모든 탭이 영역 안에 들어오면 숨긴다. 탭과 툴바 스크롤 경계 그라데이션은 공통 `defaultEffectsSpec`으로 투명도를 전환해 부드럽게 나타나고 사라진다. RTL에서는 방향을 반전하며 탭 스크롤·터치 영역은 유지한다. 닫기 버튼은 선택된 탭에만 표시하며 고정 `CircleShape`를 사용해 hover·포커스·누름 상태에서도 원형을 유지한다. 탭 앞에는 20dp 실행 환경 아이콘(Native 로봇, Debian 나선, Ubuntu 원형, Arch 아치, AVF 칩)을 표시한다. 상태 뱃지와 ANDROID/LINUX 등의 접두사는 표시하지 않고 제목만 표시한다. 아이콘은 실행 환경 이름을 접근성 설명으로 제공하며, 세션 상태는 탭의 stateDescription으로 전달한다. 탭 본문을 길게 누르면 사용자 지정 제목이 있을 때만 기존 제목을 미리 채우고, 없으면 빈 입력 필드를 표시하는 이름 변경 대화상자가 열리고, 탭의 종료 아이콘은 확인 대화상자를 연 뒤에만 runtime의 명시적 terminate 명령을 보낸다. 새 세션 버튼의 `DropdownMenuPopup` 안에는 Expressive `DropdownMenuGroup`과 위치별 segmented item shape를 둔다. 빈 상태의 주 동작은 별도 `ModalBottomSheet`를 사용한다. 상단 새 세션 메뉴와 빈 상태 바텀시트는 기본·사용자 프로필 이름과 실행 환경을 표시하고, 마지막에 **Add profile**을 제공합니다. 사용할 수 없는 실행 환경의 프로필도 표시하며 기존 설치·설정 안내로 연결합니다. 설정의 **Profiles** 목록은 카드 전체를 눌러 프로필 설정을 엽니다. 기본 프로필도 수정·삭제할 수 있습니다. 설정은 이름·실행 환경, 셸·시작 설정, 환경 변수 카드로 나누며 하단에 저장·복제·삭제를 제공합니다. 삭제에는 확인을 요구하고 모든 프로필이 삭제되면 추가 안내를 표시합니다. 양쪽 추가 동작은 같은 Material 3 프로필 편집 Activity를 엽니다. 초안은 Activity 재생성 시 복원하고 저장 시 전체 설정을 검증하며, 미저장 변경 사항을 버릴 때 확인합니다. Rootless 설치 진행은 대화상자, wavy 진행 표시기, 오류 텍스트, 재시도 및 닫기 동작을 사용한다.

같은 원점을 적용한다. 스크롤 자체는 PTY 행 수를 변경하지 않는다.
상단에는 현재 터미널 배경색에서 투명해지는 세로 그라데이션을 겹친다.

핸들 영역은 모든 상태에서 높이 24 dp를 사용한다. 터미널 문자 격자의 마지막 온전한 행은 View 하단에 맞추고, 정수 행 수로 나눈 나머지 픽셀은 상단 inset에 더한다. 툴바를 확장·기본·숨김으로 전환해도 마지막 행과 핸들 사이에는 사용자 지정 터미널 여백만 유지한다. 터치·마우스·링크·선택 핸들·IME 미리보기도 같은 원점을 사용하며 PTY 행 수와 안정화 후 크기 변경 정책은 유지한다.

전체 비활성화는 핸들도 숨긴다. 기존 단축키 활성화 값은 새 설정이 없을 때만 이전한다.
도구가 없으면 기본·확장 상태에 추가 안내를 표시한다.

Extra key는 별도의 둥근 wrapper나 그림자 없이 터미널 배경 위에서 순서대로 그리드를 채운다. 설정 미리보기도 별도 wrapper 없이 같은 키 형태를 사용한다. 기본값은 7열, 고정 40 dp 높이, 12 sp 글자이며 설정에서 최대 열 수(2–10), 글자 크기(10–24 sp), 개별 키 너비(1–4칸)를 조절한다. 가용 폭에 따라 실제 열 수와 span을 줄여 최소 48 dp 터치 폭을 유지하고, 실제 툴바는 최대 두 줄을 표시하며 세 번째 줄부터 세로 스크롤한다. 더 좁은 BottomSheet에서는 가용 높이에 맞춰 스크롤한다. 툴바 외곽 여백과 키 간격은 4 dp다. 설정 미리보기와 드래그 중인 키는 surfaceContainerHigh(#22272D) 배경과 onSurface(#E3E2E6) 글자를 사용한다. 실제 터미널의 키는 캔버스 배경에서 파생한 컨테이너와 대비 전경색을 사용한다. CTRL·ALT 단독 키만 toggle semantics와 선택 상태색을 사용하며 pressed/checked shape는 `CircleShape`다.

설정의 **터미널 단축키**는 실제 툴바와 같은 그리드 미리보기를 제공한다. 활성화·도구 추가와 제거는 **툴바 설정**에서 관리하고 배치 편집은 기존 화면에서 유지한다. 키를 눌러 이름·단축키·너비를 편집하거나 순서를 변경하고 삭제할 수 있다. 미리보기에서 키를 길게 누르면 햅틱과 함께 키가 떠오른다. 떠오른 키의 크기·그림자·투명도와 삽입선의 위치에는 Expressive motion scheme의 spatial/effects spec을 적용한다. 손가락을 따라가는 위치는 지연 없이 갱신한다. 드래그 대상이 바뀌면 햅틱이 울리고, 삽입 위치가 대상 키의 앞쪽이나 뒤쪽에 선으로 표시된다. 여러 칸을 차지하는 키도 실제 경계를 기준으로 판정하며 빈 칸은 가장 가까운 키 위치를 사용한다. 가장자리에 머무르면 설정 목록이 자동 스크롤된다. 드래그 취소나 미리보기 밖에 놓기는 순서를 바꾸지 않는다. 일반 탭 편집과 대화상자의 앞으로/뒤로 동작도 유지한다. 편집 화면의 초안은 Activity 재생성 때 보존되며 전체 **저장**에서 하나의 버전 지정 설정으로 반영한다. 저장하지 않고 나갈 때와 기본 배치를 복원할 때 확인한다. 단축키 조합은 선택되어 있던 CTRL·ALT를 대체하고 기존 terminal input 경로로 전달된다. UI는 입력 명령만 보내며 세션 소유권은 변경하지 않는다.

설정 화면은 Android 17 설정 앱의 계층을 따른다. 설정 홈은 `LargeTopAppBar`, 실제 카테고리 필터로 동작하는 둥근 검색 필드, 40 dp 원형 아이콘과 supporting text를 가진 최소 72 dp 카테고리 행을 사용한다. 1차 카테고리의 탐색 화살표는 생략하며, 저장소·프로필, 언어·터미널 설정, 실행 환경 설정을 각각 묶고 업데이트는 단독 그룹으로 둔다. 그룹 사이는 16 dp로 띄우고 그룹 안은 상세 설정과 같은 2 dp 여백·4 dp 안쪽 곡률·28 dp 바깥 곡률을 사용한다. 검색 결과에서도 1차 카테고리는 화살표를 생략하고 하위 설정 결과에는 탐색 화살표를 유지한다. 상세 화면은 큰 앱 바 아래 설명을 두고, 섹션 제목별 관련 interactive/non-interactive Expressive `ListItem`을 묶는다. 항목마다 `surfaceContainerLow` 배경을 사용하고 항목 사이에는 구분선 대신 2dp의 투명 여백을 둔다. 그룹 외곽은 `extraLarge`(28dp) 곡률을 유지하고, 인접 항목 사이의 안쪽 모서리는 4dp로 줄인다. 한 항목만 있는 그룹은 네 모서리에 큰 곡률을 적용한다. 설명이 여러 줄로 바뀌어도 leading icon과 trailing text·icon·control은 행 전체 높이에서 수직 중앙을 유지한다. 그 밖의 일반 화면 앱 바는 표준 Material 3 `TopAppBar`다. boolean 행 전체가 한 번만 toggle된다. 숫자·경로·단일 선택은 복원 가능한 입력 초안과 저장값을 분리하고, 대화상자의 **저장**에서 전체 값을 검증한 뒤에만 반영한다. Rootless 설정은 화면 상단에 Debian, Ubuntu, Arch Linux ARM의 상태와 개별 동작을 모두 표시하고, 공유 저장소 설정을 그 아래에 배치한다. Rootless 상태 행은 확인 중·설치 필요·환경 보완 필요·준비됨·오류를 구분하고 shape-morphing 로딩 표시, 설치, 환경 보완, 제거, 재시도 동작을 제공한다. 이미지가 있으면 보완 실패 상태에서도 제거할 수 있다. 패키지·설정·검증을 마치기 전에는 준비됨으로 표시하지 않는다. 진단과 크래시 payload는 선택 가능한 고정폭 텍스트로 유지한다. 크래시 화면에서는 복사를 primary action으로, 닫기를 낮은 강조 action으로 제공한다.

설정의 **터미널 설정 → 셸 → 세션 작업 알림**은 기본 꺼짐인 스위치입니다.
10초 이상 명령 완료 및 프로그램의 확인 요청을 알린다는 설명과 Android 알림
설정 이동 행을 함께 제공합니다. 알림 권한 거부는 세션 실행을 막지 않으며,
작업 알림 채널은 기존 세션 유지용 상시 알림 채널과 분리합니다.
알림을 눌러 세션을 열 때는 서비스의 이전 선택 탭보다 알림 대상을 우선합니다.

## Insets and adaptive behavior

**터미널 기록 → 부드러운 스크롤**은 기본 꺼짐이다. 켜면 일반 스크롤백의
드래그와 관성 이동을 픽셀 단위로 표시하고 프레임 타이밍에 맞춰 갱신한다.
관성 속도는 입력 세기를 따르며 기록의 위·아래 경계까지 남은 거리 때문에 낮아지지 않는다. 실제 경계에 도달하면 오버스크롤 없이 즉시 멈춘다.
부분 행과 하단의 추가 행을 함께 렌더링하며 링크·선택 좌표도 같은 오프셋을
사용한다. 마우스 보고·대체 화면은 기존 행 단위 입력을 유지한다.

터미널 설정의 **웹 링크 열기**는 기본 꺼짐이다. 활성화하면 기존 제스처 인식기의
확정된 단일 탭에서 출력된 HTTP(S) URL을 찾아 브라우저로 전달한다. 별도 터치
리스너를 설치하지 않으며 더블 탭·스크롤·선택 및 마우스 보고 입력을 우선한다.
줄바꿈된 주소와 터미널의 문자 셀 좌표를 고려하고, 탐색 범위를 초과하는 주소는
부분 주소로 열지 않는다.

새 세션 프로필 메뉴는 세션 탭과 동일한 런타임 아이콘을 사용합니다.
프로필별 아이콘을 지정하면 탭·세션 추가 메뉴·바텀시트·프로필 목록에 공통 렌더러로
표시합니다. 탭은 20dp, 메뉴는 24dp이며 사용자 이미지는 투명 여백을 제거하고
128px 캔버스의 112px 영역에 종횡비를 유지해 맞춥니다. 기본 벡터와 투명 배경 단색
이미지는 해당 UI의 tint를 따르고, 다색·불투명 이미지는 색상 필터 없이 표시합니다.
아이콘 설정 대화상자는 자동 선택, 기본 제공 벡터, 가져온 이미지 미리보기를 제공하며
선택 표시와 저장·취소, 이미지 추가를 지원합니다. 색상 변경 조건과 파일 제한을
대화상자에 안내합니다. 가져오기는 UI 스레드 밖에서 수행합니다.
프로필 선택 바텀시트는 도입 전 실행 환경 선택과 같은 전체 너비 `ListItem`을
사용합니다. 왼쪽 아이콘 옆에 프로필 이름과 실행 환경을 시작 정렬하고, 하단의
**프로필 추가**도 같은 행 배치를 사용합니다. 한국어 화면에서 Profile은 **프로필**로
표기하며, 세션 드롭다운의 **프로필 추가** 앞에도 `+` 아이콘을 표시합니다.
프로필 관리 목록은 섹션 카드 안의 `>` 화살표가 있는 설정 행을 사용합니다.
프로필 추가·편집은 일반 설정과 같은 섹션 제목, surfaceContainerLow 카드와
설정 행을 사용하며, 그룹 내부에는 2dp 여백과 4dp 안쪽 곡률을 적용합니다. 이름·셸·시작 설정·환경 변수는 현재 값을 표시하는 행을
눌러 입력 대화상자에서 수정하며, 텍스트 입력 행에는 탐색 화살표를 표시하지 않습니다.
실행 환경·배포판은 앱 언어·터미널 유형과 공통인 라디오 선택 대화상자로 편집합니다.
프로필 생성의 저장공간 행은 새 독립 저장공간·기존 저장공간을 선택하며, 새 공간이면 아래에
이름 입력 행을, 기존 공간이면 호환되는 저장공간의 설정 행 목록을 표시합니다. 새 공간의
기본 이름은 프로필 이름을 따라 `Storage for …`로 표시하고 중복 시 숫자 접미사를 붙입니다. 편집에서는
현재 공간을 먼저 표시하고 호환되는 공간과 새 독립 공간을 같은 카드의 라디오 행으로
선택합니다. 저장공간 행에는 아이콘을 표시하지 않으며 이름과 ID를 표시합니다. 대화상자의 저장은 화면 초안에 반영하고, 화면 전체 저장으로 프로필을
영속화합니다. 저장하지 않고 나갈 때 확인하며 초안은 화면 재생성 시 복원합니다.
프로필 편집의 저장·복제·삭제는 하단 중앙의 Material 3 Expressive `HorizontalFloatingToolbar`에서 아이콘 버튼으로 제공합니다. 새 프로필·복제본 생성 화면은 플로팅 툴바 대신 마지막 설정 항목 뒤에 전체 너비의 저장 아이콘·텍스트 버튼을 표시합니다. 툴바는 Material 기본 모양·높이·색상·패딩·그림자를 사용하며, 각 아이콘 버튼은 최소 48dp 터치 영역을 확보합니다. 플로팅 툴바의 아이콘 버튼은 고정 `CircleShape`를 사용해 hover·포커스·누름 상태에서도 곡률을 바꾸지 않습니다.
버튼 이름은 아이콘의 접근성 설명과 `TooltipBox`의 `PlainTooltip`으로 제공하며, 마우스 hover 또는 길게 누르면 버튼 위에 표시합니다. 툴팁을 여는 제스처는 작업을 실행하지 않습니다.
저장은 디스크 모양의 저장 아이콘, 복제는 복사 아이콘, 삭제는 휴지통 아이콘과 error 색을 사용하며 탐색 화살표를 사용하지 않습니다. 기존 프로필 편집에서는 스크롤 영역 하단에 툴바 높이와 화면 경계 여백을 확보해 마지막 설정 항목을 가리지 않습니다. 생성 화면은 저장 버튼 아래에 16dp 여백을 둡니다.
미저장 변경이 있으면 복제를 비활성화하고 저장 후 복제 안내를 표시합니다. 저장 중에는 모든 툴바 버튼을 비활성화합니다.
삭제는 기존 확인 대화상자를 거쳐야 합니다.
저장소 설정도 같은 섹션 제목과 `surfaceContainerLow` 둥근 카드, 설정 행을 사용합니다.
사용 중·미사용 목록은 행별 lazy composition을 유지하면서 2dp 여백으로 구분합니다. 그룹의 첫 행 위쪽과 마지막 행 아래쪽은 큰 곡률을, 인접 행 사이의 모서리는 4dp 곡률을 적용합니다.
미사용 저장소와 상세의 실행 중 세션이 없으면 해당 섹션 제목과 빈 상태를 숨깁니다.
저장소 목록 행에는 아이콘 없이 실행 환경 이름과 용량만 표시합니다. 저장소 이름·ID·프로필 수·활성 세션 수는 목록에서 숨기고 해당 저장소의 상세 설정에서 표시합니다.
저장소 항목은 별도의 `StorageDetailActivity`로 이동하며, 뒤로 가면 목록의 스크롤 위치를 유지합니다.
상세의 **저장소 정보** 카드에는 이름·실행 환경·ID·용량·연결된 프로필 수·활성 세션 수를 각각 읽기 전용 설정 행으로 표시합니다. 저장소 상세와 프로필 설정으로 이동하는 행에만 `>` 화살표를 둡니다.
이름 변경과 삭제는 하단 중앙의 Material 3 Expressive `HorizontalFloatingToolbar` 안의 아이콘 버튼으로 제공합니다. 이름 변경은 기존 입력 대화상자를 열고, 삭제는 error 색 버튼과 확인 대화상자를 사용합니다. 연결된 프로필·활성 세션이 있거나 보호된 legacy 저장소이면 삭제 버튼을 비활성화하며, 작업 중에는 두 버튼을 모두 비활성화합니다.
상세의 연결된 프로필·실행 중 세션·빈 상태도 같은 카드에 표시합니다. 목록 하단에는 floating toolbar 높이와 화면 경계 여백을 확보해 마지막 정보를 가리지 않습니다.
프로필 이름과 실행 환경을 함께 표시합니다. 특권이 없는 AVF 기본 프로필은 숨깁니다.
프로필 편집은 Native / Rootless Linux / AVF 기반 선택과 별도의 Rootless 배포판 선택을
제공합니다. 저장공간 카드에서 기본값인 새 독립 공간 또는 같은 기반 프로필과의 공유를
선택하며, 공유에는 패키지·루트 파일시스템·VM 디스크까지 포함됨을 안내합니다.
그 밖의 불가 환경도 선택 후 설치·설정 안내로
연결합니다. Rootless 설정 상태 행의 환경 보완 필요 상태는 배포판 아이콘 우측
하단에 고대비 원형 느낌표 배지를 표시합니다. 접근성 설명은 “기본 환경 보완 필요”를
전달하고 준비 완료 후 배지가 사라집니다.
Rootless Linux 그룹과 설정 항목에는 WSL 아이콘처럼 얼굴을 중심으로 한 펭귄 형태의 자체 제작
`ic_runtime_rootless_group` 단색 벡터를 공통으로 사용한다. 24 dp 뷰포트에
둥근 머리·두 눈·부리와 U자형 얼굴을 표현하며 주변 UI의 아이콘 tint를 따른다.
프로필 아이콘 선택기의 Rootless 아이콘도 같은 벡터를 사용한다. 사용자가 가져온
아이콘에만 휴지통 버튼과 미리보기를 포함한 삭제 확인을 제공한다. 삭제는 목록에 즉시
반영하고, 저장된 프로필·세션의 이미지 참조는 유지하며 재가져오기로 목록을 복원할 수 있다.
프로필 추가·설정 화면의 프로필 아이콘 항목은 이름과 설명을 왼쪽에,
선택된 아이콘 미리보기를 오른쪽 끝에 수직 중앙 정렬로 표시한다.
Native 로봇은 안테나 끝·머리 하단 모서리·하단 막대를 둥글게 처리한다.
Rootless 펭귄 얼굴은 하단 모서리와 눈 사이 연결부를 완만하게 처리하여
주변 Material 아이콘의 둥근 형태와 조화를 이룬다.

**터미널 단축키**와 **터미널 모양**은 설정 홈에 중복 표시하지 않고,
**터미널 모양**은 **터미널 설정 → 사용자 설정**에서 편집 화면으로 이동한다.
**터미널 단축키**는 **툴바 설정**의 도구 항목을 통해서만 편집 화면을 연다.
단축키 관련 검색 결과도 편집 화면 대신 툴바 설정으로 연결한다.

설정 홈은 공통 **터미널 설정**과 **Native 셸 설정**을 분리한다. TERM·스크롤백·
로그인 셸·공유 내부저장소·앱 권한은 공통 화면에, Native 기본 셸만 Native 화면에
둔다. 로그인 셸은 Native/Rootless에만 적용됨을 명시한다. 공유 내부저장소 설정은
공통 화면에 한 번만 제공하며 Rootless 화면에 중복하지 않는다. 기존 저장 키를
유지하므로 메뉴 이동 전 설정값을 그대로 사용한다.

설정 홈의 메뉴 이름과 해당 상세 화면의 제목은 같은 문자열 리소스를 사용한다.

설정 홈과 하위 설정 화면의 공통 큰 앱 바는 펼쳐진 상태와 스크롤로 접힌 상태 모두
투명 컨테이너를 사용한다. 스크롤 시 별도의 배경색을 덧씌우지 않으며 기존 접힘 동작을 유지한다.

설정의 단순 안내(공유 저장소 사용 설명, Rootless 환경 제한, 사용자 글꼴 빈 목록)는
옵션 카드 밖에 배경 없는 텍스트로 표시한다. 옵션 사이의 구분선을 안내 문구에는
사용하지 않는다. 실행 가능한 설정과 상태 확인 동작은 카드에 유지한다.

USB 디바이스 설정도 큰 앱 바와 섹션별 둥근 옵션 카드를 사용한다. 연결된 기기,
접근 요청, 허용된 접근, 이동식 저장장치, 호스트 도구, 도움말 및 진단을 구분하며
대기 요청이 있으면 가장 먼저 표시한다. 기기는 유형과 VID/PID, 연결 사용 상태를
요약하고 연결 ID·구성·인터페이스는 펼쳐서 확인한다. 요청에는 런타임·세션·연결 ID·
접근 범위를 표시하며 Android 권한 대기 중에는 중복 승인을 비활성화한다.
승인·세션 전체 접근 해제·폴더 제거는 별도 확인을 거친다. 진단은 원본 JSON 대신
허용된 연결 수만 표시하며, 계정 입력은 기존 호스트 도구 입력 화면으로 이동한다.

모든 화면은 edge-to-edge다. 공통 앱 바와 표시 중인 터미널 chrome은 status bar inset을 적용하고, 터미널 앱 바를 숨기면 렌더러의 스크롤 가능한 상단 여백으로 전환한다. 하단 extra key는 navigation bar inset을 적용한다. 터미널 화면은 IME inset을 반영해 키보드가 terminal/extra key를 가리지 않게 한다. 목록 기반 화면은 고정 텍스트 높이를 사용하지 않고 스크롤한다.

상태 표시줄과 탐색 표시줄은 투명 배경을 사용하며, 일반 화면은 밝은 아이콘, 터미널 화면은 캔버스 배경에 대비되는 아이콘을 사용한다. RTL에서는 start/end 기반 배치를 사용하되, 문자 셀 정확성이 필요한 터미널 렌더러 자체는 기존 방향 규칙을 유지한다.

## Profile palettes

프로필의 컬러 팔레트 카드는 색상 편집, 전역 팔레트 복제, 다른 프로필에서 가져오기,
팔레트 초기화를 제공한다. 초기값·초기화는 전역 상속이며 독립 복사와 구분해서 안내한다.
프로필 복제는 상속 여부와 색상값을 함께 복제한다. 편집기는 전역 색상 편집기를
재사용하되 결과만 프로필 초안에 반환하고 전체 저장 전에는 영속화하지 않는다.

탭 전환 및 설정 복귀 시 전경·배경·커서·ANSI 색상과 반응형 chrome 색상을 한
240ms 전환으로 보간한다. 중간에 다른 탭을 선택하면 현재 표시 프레임에서 이어간다.
시스템 애니메이션 배율을 따르며 애니메이션이 꺼져 있으면 즉시 적용한다.
상태 표시줄 아이콘의 명암은 전환 중인 배경에서 결정한다. 전환 프레임은 렌더러에만
전달하며 OSC 색상 조회·초기화와 세션 소유권은 바꾸지 않는다. 전환 완료 후에도
각 세션의 OSC 색상 변경을 보존하고 초기화는 해당 세션의 기본 팔레트로 수행한다.

## Lifecycle boundary

설정 홈의 **앱 업데이트**는 같은 큰 앱 바와 중립 둥근 상태 카드를 사용한다.
정식·개발 채널은 단일 선택 FilterChip으로 제공하고 선택을 저장한다. 개발
채널의 불안정 경고는 카드 밖 안내 텍스트로 표시한다. 진행 중 채널 변경은
비활성화하고 채널 변경 시 이전 설치 확인 상태를 폐기한다.
새 버전이 있으면 해당 채널·커밋의 한국어 릴리즈노트를 별도 카드에 마크다운으로 렌더링하고 다운로드·설치 준비 상태에서도 유지한다. 제목·목록·강조·인용·코드는 네이티브 TextView의 Markwon core span으로 표시하며, 본문·제목 크기와 색상은 Material 3 토큰을 따른다. 문장 중간의 일반 줄바꿈은 공백으로 이어지고 마크다운의 명시적 줄바꿈은 유지한다. 링크는 사용자가 누른 http/https 주소만 브라우저로 열며 HTML 및 원격 이미지는 로드하지 않는다. 긴 내용은 화면 스크롤로 읽으며, 노트 조회 실패 안내는 APK 다운로드를 차단하지 않는다.
확인 중·다운로드 중에는 wavy 진행 표시와 중복 동작 차단을 적용하고,
배포 없음·최신·다운로드 가능·검증 완료·오류를 구분한다. 다운로드 상태는
Application 소유 controller에서 관찰하므로 화면 재생성·닫기로 취소되지 않는다.
설치는 별도 확인을 거쳐 시스템 설치 화면에 넘기며, APK 교체로 실행 중인
터미널 세션이 끊길 수 있음을 안내한다. UI는 세션 종료나 자동 앱 삭제를 하지 않는다.

Compose 상태는 서비스 상태의 투영일 뿐 권위 있는 세션 저장소가 아니다. Activity가 시작되거나 서비스에 재연결되면 세션 목록과 runtime 상태를 다시 읽는다. `AndroidView` 재구성은 `TerminalView`를 불필요하게 만들거나 세션을 종료하지 않으며, Activity 정지는 renderer callback을 detach하고 로컬 emulator projection만 폐기한다.

PTY, 프로세스, Rootless 설치와 VM은 계속 `:vmhost` runtime 서비스가 소유한다. 대화상자 닫기, 세션 전환, Activity 재생성 또는 UI task 제거는 terminate 명령이 아니다. 실제 종료는 사용자가 확인한 세션 종료 동작을 runtime이 처리할 때만 일어난다.

종료 요청 중인 탭은 중복 종료를 막고, 서비스가 revision이 증가한 목록으로
제거를 확인한 뒤에만 해당 로컬 렌더러 상태를 폐기한다. 실패하면 탭과 형제
렌더러를 유지하고 해당 탭의 대기 상태만 해제한다.

### Rootless 설치 진행

설정의 배포판 상태 행과 설치 대화상자는 런타임이 보관하는 같은 진행 상태를
표시한다. 현재 단계와 작업 내용, 전체 경과 시간을 보여주며 화면 재진입 시
상세 단계가 “확인 중”으로 바뀌지 않는다. 이미지 다운로드·무결성 검증 및 apt가
보고하는 진행률에는 determinate `LinearWavyProgressIndicator`를 사용하고,
전체량을 모르는 압축 해제·pacman 작업·설정 등에는 indeterminate 표시를 사용한다.
숫자는 “현재 단계” 진행률이며 전체 설치 완료율로 표시하지 않는다. 다운로드는
MiB 수치를 병기하고, 진행 보고가 20초 이상 없으면 마지막 보고 이후 시간을
표시한다. 실행 중인 배포판을 새 세션 메뉴에서 선택하면 진행 화면을 다시 연다.
오류나 완료 뒤에는 애니메이션과 경과 시간 증가를 멈춘다.
